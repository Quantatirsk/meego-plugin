# Button 点位

Button 将插件操作放入工作项、节点、新建菜单、视图批量操作或 WBS 计划表的入口。点击后的行为可以是插件弹窗或脚本执行；运行时上下文由 [`button.getContext()`](../jssdk/button-get-context.md) 提供。

## 平台事实

| 入口 | 网页端 | 移动端 | 已知范围 |
| --- | --- | --- | --- |
| 工作项“更多”、节点“更多”、节点流转 | 支持 | 支持 | 可读取工作项或节点上下文 |
| 新建工作项 | 支持 | 未列为支持位置 | 可读取新建场景上下文 |
| 视图批量操作 | 支持 | 未列为支持位置 | 仅表格和看板视图；不支持跨工作项视图与子任务视图 |
| WBS 计划表“更多” | 有入口和上下文示例 | `source_silent` | 后台位置配置与移动端支持未在来源中定义 |

一个插件可以配置多个按钮。每个按钮独立选择适用工作项类型、端侧 `resourceId`、入口和点击效果。网页端与移动端资源分别维护。

弹窗模式加载插件 UI；脚本模式在后台执行插件脚本，不展示弹窗。`button.getContext()` 的文档针对按钮弹窗，不能据此推断脚本模式可使用全部 UI API。

网页端详情页按钮可监听表单值变化。该监听仅适用于工作项“更多”、节点“更多”和节点流转按钮，每次最多监听 10 个 key；移动端、新建、WBS 和批量场景不支持此监听。

## 实施建议

- 使用 `button.getContext()` 的实际返回字段确定操作范围，先识别入口场景再读取可选字段。
- 监听表单值后，在弹窗或组件卸载时调用返回的取消函数。
- 为批量场景逐组处理 `selectedWorkItems`，不要假定它是单一工作项列表。
- 将脚本模式和弹窗模式分别实现、测试，不把 UI 生命周期假设带入脚本逻辑。

本页中的运行场景用于说明平台行为，不是开发者后台配置 JSON 的 position enum。
