# 客户端容器的自适应机制

<!-- capability-metadata:start -->
## 平台能力标记

> 调用频次：无直接调用频次。本页用于平台说明、格式、目录或支持信息。

<!-- capability-metadata:end -->

平台的客户端尺寸自适应以插件容器内 `body` 元素的实际宽高为依据。是否根据该尺寸调整容器，取决于当前构成、调用方式或组件弹出层，宽度和高度需要分别判断。

本页中的“不自适应”指容器不按 `body` 的对应尺寸自动调整，不代表插件内部不能进行响应式布局。原文没有按网页端、移动端分别列出机制；跨端行为应继续核对对应点位文档，不能假设两端容器完全一致。

**阅读导航**：[构成容器](#395c21ce) · [自定义弹窗](#748b537a) · [组件弹出层](#7befeb5b)

## 构成容器

“按配置”表示是否自适应取决于是否显式指定该维度，具体规则见表后说明。

| 构成 | 场景 | 宽度自适应 | 高度自适应 |
| --- | --- | --- | --- |
| `Page` | 导航功能页 | 否 | 是 |
| `Tab` | 详情标签页 | 否 | 是 |
| `Control` | 表格列弹窗 / Popover | 按配置 | 按配置 |
| `Control` | 表格列 | 否 | 否 |
| `Control` | 非表格列场景 | 否 | 是 |
| `Button` | 按钮容器 | 是 | 是 |
| `View` | 视图模式 | 否 | 是 |
| `Configuration` | 插件配置 | 否 | 是 |
| `Intercept` | 拦截事件容器 | 是 | 是 |
| `Schedule` | 排期扩展 | 否 | 否 |
| `CustomField` | 字段类型扩展 | 是 | 是 |
| `LiteAppComponent` | 轻应用组件 | 否 | 否 |

### Control 表格列弹窗

宽、高各自独立处理：

| 配置 | 该方向的行为 |
| --- | --- |
| 未指定宽度 | 宽度自适应 |
| 指定宽度 | 宽度不自适应 |
| 未指定高度 | 高度自适应 |
| 指定高度 | 高度不自适应 |

这里指表格列中的弹窗，不能套用到表格单元格本身。表格列、详情页表单控件和节点表单控件的运行机制也不同，见[控件 Control](<../points/控件 Control.md>)。

支持自适应仍需要结合构成自身的尺寸配置使用；本表不额外定义统一的尺寸上下限、测量周期或溢出处理规则。

## modal.open 自定义弹窗

| 维度 | 未显式配置 | 显式配置 |
| --- | --- | --- |
| 宽度 | 不自适应，使用默认配置 | 不自适应，使用指定宽度 |
| 高度 | 自适应 | 不自适应，使用指定高度 |

专门的 [modal.open 参数定义](<../jssdk/modal.md#def9b6b7>) 将 `width` 默认值定义为 **448**，本套资料采用的官方 SDK `2.1.8` 类型注释也一致。这里的数值是 API 配置参数，不能直接当作包含边距、标题等部分的外部容器实际宽度。

源页对容器默认像素值的描述与该参数定义不一致，且未解释尺寸测量边界；**默认外框尺寸与配置宽度的换算关系待核实**。本页保留确定的自适应规则，不提供有冲突的外框像素值。需要指定尺寸时按 `modal.open` 的参数契约配置。

弹窗中的上下文传递见 [Context.getCustomContext](<../jssdk/Context.md#ddab42c2>)，容器内部的提交、关闭等能力见 [containerModal](<../jssdk/containerModal.md>)。

## 客户端组件的弹出层

| 组件弹出层 | 宽度自适应 | 高度自适应 |
| --- | --- | --- |
| `Popover` | 是 | 是 |
| `Select` | 否 | 是 |

本表描述组件的弹出层，不是整个插件页面的容器。组件库的接入与加载要求见[客户端组件库接入](<../components/客户端组件库接入.md>)；组件自身的属性与端支持见官方 [Popover](<../components/气泡卡片 Popover.md>)、[Select](<../components/选择器 Select.md>)。
