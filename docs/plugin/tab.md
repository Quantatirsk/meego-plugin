# Tab 点位

Tab 在工作项详情页的标签区域加载插件页面。插件负责页面内容和业务数据，平台负责把与构成绑定的资源加载到匹配工作项类型的详情页。

## 平台事实

Tab 支持网页端和移动端。`window.JSSDK.tab.getContext()` 在移动端要求 V7.35.0+；表单值变化监听只支持网页端。

构成需要指定适用的工作项类型和各端资源入口。运行时页面应通过 [`tab.getContext()`](../jssdk/tab-get-context.md) 获取当前空间、工作项类型和工作项实例上下文。`workItemId` 只在实例场景有值；平台没有统一规定它在其他场景的具体空值形式。

网页端详情页可使用 Tab 的表单值监听 API。该 API 返回取消函数，页面卸载后不应继续保留订阅。移动端不能依赖此监听能力。

## 实施建议

- 读取实例数据前先检查 `workItemId` 是否为有效数字。
- 以点位上下文选择数据作用域，避免将 Tab 的页面状态当成授权依据。
- 跨用户或跨设备的数据规则由插件自己的服务端或受控数据层保存并校验；本地缓存适合短期的用户私有状态。
- 双端交付时分别验证资源入口和实际调用的 JSSDK 支持范围。

这些建议不定义平台的页面挂载协议或持久化协议。
