# 按钮 / Button

按钮点位将插件操作嵌入工作项、节点、新建菜单、视图批量操作或 WBS 计划表。开发者可配置按钮名称、可见范围及点击后的行为，例如发送邮件、上传至 SVN、创建文档，或通过 XMind、Jira 导入新工作项。

本文介绍入口、后台配置与运行方式。各位置的上下文字段和监听方法见 [Button JSSDK](<../jssdk/Button.md>)。

## 按钮位置与支持范围

| 位置 | 网页端 | 移动端 | 入口及用途 |
| --- | --- | --- | --- |
| 节点流转 | 支持 | 支持 | 平铺在节点表单外层的操作按钮 |
| 节点“更多” | 支持 | 支持 | 收起在节点更多菜单中 |
| 工作项详情“更多” | 支持 | 支持 | 收起在工作项详情更多菜单中 |
| 新建工作项 | 支持 | 未列为支持位置 | 新建按钮的下拉菜单，提供其他录入方式 |
| 视图批量操作 | 支持 | 未列为支持位置 | 对当前视图选中的多个实例执行操作 |
| WBS 计划表“更多” | 有入口示例和上下文契约 | 本页未说明 | 对计划表单元执行操作 |

批量操作按钮仅支持表格、看板视图模式，不支持全景视图、资源库等跨工作项视图，也不支持子任务视图。WBS 入口没有出现在原文后台位置枚举中，实际配置入口与支持端待核实；其已公开上下文见 [WBS 计划表场景](<../jssdk/Button.md#d2100bdc>)。

## 管理员安装流程

1. 在“插件管理 > 添加插件”搜索包含所需按钮的插件，或通过插件分享链接安装。
2. 安装后，符合工作项类型与位置配置的插件按钮出现在对应菜单选项末尾。

<a id="784b4900"></a>

## 开发流程

准备 Node.js 与飞书项目开发者工具，创建插件并添加按钮构成，然后初始化工程、调试、实现、发布和安装。完整步骤见 [开发并发布第一个插件](<../guides/开发并发布第一个插件.md>)。

一个插件可以提供多个按钮，每个按钮独立配置。双端开发需要分别维护网页端和移动端代码资源。

<a id="768d5925"></a>

## 开发者后台配置

在“添加插件构成”中选择“按钮”。

| 配置项 | 含义 |
| --- | --- |
| 按钮名称 | 嵌入菜单后显示的名称，例如“发送邮件” |
| 描述 | 按钮实现的功能，例如将工作项详情快照发送到指定邮箱 |
| Key | 系统生成的点位唯一标识，不可修改 |
| 工作项类型 | 全部、需求、缺陷、版本、迭代、其他工作项；控制可见范围 |
| 指定自定义工作项类型 | 输入工作项系统标识，逗号分隔，例如 `project,task` 或 `delivery` |
| 适用端 | 网页端、移动端；分别维护对应代码 |
| resourceId | 开发者定义的代码资源唯一标识，与对应端工程入口匹配 |
| 网页端按钮位置 | 工作项“更多”、节点“更多”、节点流转、新建工作项实例、视图批量按钮 |
| 移动端按钮位置 | 工作项“更多”、节点“更多”、节点流转 |
| 点击后效果 | 弹窗或执行脚本 |
| 弹窗最小尺寸 | 弹窗模式下配置内容区的最小宽高 |

指定自定义工作项类型后，空间安装插件时，只有相应类型的实例显示该按钮；这项限制同时作用于网页端与移动端。`resourceId` 的示例值为 `button_resource_web`、`button_resource_mobile`。

### 弹窗模式

点击按钮后打开弹窗，加载并展示插件的自定义 UI。弹窗内可读取 [button.getContext()](<../jssdk/Button.md#78d2b05c>)，决定针对哪个实例、节点或选中列表执行操作。

后台配置的是弹窗内容区最小尺寸，首次配置默认宽度 448 px、高度 400 px。标题与边距另占空间；即使将配置宽高都设为 0，弹窗仍有 138 px × 80 px 的最小尺寸。

![按钮弹窗内容区尺寸配置](<../assets/8c4051b4a7eb814d5d5bf03e.png>)

### 执行脚本模式

点击按钮后在后台执行插件脚本，不展示弹窗 UI。该模式有独立的运行限制，见 [脚本模式](<../client/脚本模式.md>)。Button API 对 `getContext()` 的说明针对按钮弹窗，不应据此推导脚本模式可以使用全部 UI API。

## 上下文与表单联动

在弹窗中通过统一入口读取上下文：

```typescript
const context = await window.JSSDK.button.getContext();
console.log(context);
```

使用字段前先确定按钮所在场景，完整字段表见 [Button JSSDK](<../jssdk/Button.md#6ec5ef32>)。

| 按钮场景 | 可用上下文与边界 |
| --- | --- |
| 所有已定义场景 | `spaceId` 表示当前空间 |
| 工作项详情“更多” | `workObjectId`、number 类型的 `workItemId` |
| 节点“更多”、节点流转 | 详情上下文加 `nodeId` |
| 视图页面的新建按钮 | `workObjectId`、`viewId`；其他页面的新建按钮这两项为空 |
| 视图批量操作 | `viewId` 及 `selectedWorkItems`，内部实例列表字段为 `selectedWorkItemIds` |
| WBS 计划表“更多” | 工作项上下文与 `scheduleUnitCtx`，包含草稿、单元及单元值 |

批量操作按空间和工作项类型组织选中项。以下为演示结构，不代表可在不支持的跨工作项视图使用该按钮：

```json
{
  "selectedWorkItems": [
    {
      "spaceId": "68382b399de4b0ec6c5a0001",
      "workObjectId": "story",
      "selectedWorkItemIds": [6125420001, 6125420002]
    }
  ]
}
```

需要随表单值变化更新弹窗时，使用 [onWorkItemFormValueChanged()](<../jssdk/Button.md#20682361>)。它仅支持网页端详情页的实例“更多”、节点“更多”和节点流转按钮，每次最多监听 10 个 key；不支持移动端，也不支持新建、WBS、批量等非详情页场景。弹窗组件卸载时调用订阅返回的取消函数，完整示例见 API 文档。
