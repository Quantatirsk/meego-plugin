# 使用场景

飞书项目插件可连接外部工具、扩展业务界面或同步项目数据。本页按行业需求和官方案例整理选择入口；能力与开发边界见[什么是插件](<什么是插件.md>)，实际接口与安装要求继续查阅对应案例。

<a id="edf90d46"></a>

## 行业需求

| 行业 | 常见集成对象 | 插件承担的工作 |
| --- | --- | --- |
| 软件开发 | DevOps、测试管理、产品与研发工具 | 将开发过程的数据和进度记录或同步到飞书项目 |
| 市场营销 | 策划、推广、销售系统及客户反馈渠道 | 连接各环节的数据与人员，同步市场动态和反馈 |
| 制造业 | 生产、采购、质量检验相关系统 | 在项目管理流程中集成相关功能，支持跨部门协作 |

这些是使用方向，不表示平台已经内置所有行业系统的连接器。已有插件能否覆盖所需流程，应通过其具体功能、权限和安装条件判断。

## 官方案例

| 业务问题 | 案例 |

<a id="resource-cost"></a>

### 工时资源管理

合作伙伴开发的人力成本管理工具，关注工时和资源成本。具体说明见官方[工时资源管理](https://project.feishu.cn/b/helpcenter/1p8d7djs/bfrmeo1d)。

![工时资源管理界面](<../assets/2fd7d11771fd2ad4d2051560.png>)

<a id="okr"></a>

### OKR 集成

利用飞书项目的关联能力，将目标拆解到具体项目并持续跟进，形成目标到项目的追踪关系。见官方 [OKR 集成插件](https://project.feishu.cn/b/helpcenter/1p8d7djs/x9qc26hz)。

![OKR 与项目关联界面](<../assets/84c01315ab3a694f0c09aa2b.png>)

<a id="meetings"></a>

### 米格会议管理

合作伙伴提供的会议管理工具，用于组织会议相关信息。见官方[米格会议管理插件](https://project.feishu.cn/b/helpcenter/1p8d7djs/df8q378p)。

![米格会议管理界面](<../assets/c1cc5d7edb5bc2b4876f0c53.png>)

<a id="gitlab"></a>

### GitLab 集成

将 GitLab 的分支、提交和合并请求关联到飞书项目工作项，并通过事件实现节点或状态自动流转。见官方 [DevOps × GitLab 集成](https://project.feishu.cn/b/helpcenter/1p8d7djs/zx8t3h7s)。

![GitLab 研发活动关联](<../assets/1701f3ec4d8dcd7c850d6942.png>)

<a id="jira"></a>

### Jira Issue 同步

将第三方平台的数据资产迁移到飞书项目，原案例以 Jira Issue 为例。见官方[同步 Jira Issue 到飞书项目](https://project.feishu.cn/b/helpcenter/1p8d7djs/4sclunns)。

![Jira Issue 同步界面](<../assets/d4ee5798550b1aee7b67a998.png>)

原概览没有承诺双向同步、冲突合并或持续同步策略，实施前需继续阅读案例和对应数据接口。

### 容知日新工时管理

记录并统计工时，结合飞书项目度量能力分析项目工时分布。见官方[容知日新 × 工时管理](https://project.feishu.cn/b/helpcenter/1p8d7djs/fy96q3l0)。
