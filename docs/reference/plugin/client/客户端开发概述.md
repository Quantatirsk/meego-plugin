# 客户端开发概述

飞书项目插件客户端运行在平台提供的环境中，通过客户端 API 读取上下文和业务数据，并可使用平台注入的组件库构建界面。开发前应先确认目标点位、适用端和运行模式，再选择对应能力。

**阅读导航**：[客户端 API](#6e1e7109) · [组件库](#28fd8dbe) · [运行限制](#10d2b84b) · [开发流程](#c13c6e87)

## 客户端 API

平台通过 `window.JSSDK` 提供三类 API，完整入口见[客户端 API 简介](<../jssdk/客户端 API 概述.md>)。

| 分类 | 解决的问题 | 阅读入口 |
| --- | --- | --- |
| 上下文 | 当前登录用户、语言和主题，以及点位所在的空间、工作项等信息 | [Context](<../jssdk/Context.md>)、[Control](<../jssdk/Control.md>)、[Tab](<../jssdk/Tab.md>)、[Button](<../jssdk/Button.md>) |
| 通用能力 | 页面导航、弹窗、缓存及其他端能力 | [navigation](<../jssdk/navigation.md>)、[containerModal](<../jssdk/containerModal.md>)、[storage](<../jssdk/storage.md>) |
| 数据模型 | 查询空间基础信息、工作项类型和实例数据 | 官方 [Space](<../jssdk/Space.md>)、[WorkItem](<../jssdk/WorkItem.md>) |

可通过[客户端官方示例插件](<客户端官方示例插件.md>)体验运行效果。各方法的 Web、移动端支持和场景限制，以对应 API 文档为准；客户端 API 与[服务端 OpenAPI](<../../openapi/README.md>)是不同调用入口。

## 客户端组件库

组件库是插件运行时加载的**注入资源**，包含两类组件：

| 分类 | 用途 | 官方示例 |
| --- | --- | --- |
| 基础组件 | 通用界面元素 | [Popover](<../components/气泡卡片 Popover.md>) |
| 业务组件 | 平台特有的人员、工作项等交互能力 | [UserSelect](<../components/用户选择器 UserSelect.md>)、[WorkItemFinder](<../components/工作项筛选器 WorkItemFinder.md>) |

组件库接入需要遵循运行时注入和加载顺序，详见[客户端组件库接入](<../components/客户端组件库接入.md>)与 [shared](<../jssdk/shared.md>)。安装类型包不等同于组件运行资源已加载。

## 运行限制

客户端产物发布后在平台沙箱中运行，需要分别考虑资源额度和浏览器能力限制：

- [资源限制](<客户端开发限制.md#5cc46307>)：产物包大小、客户端 API 调用频率等限制不会随着插件使用量自动扩展。
- [沙箱限制](<客户端开发限制.md#3fe36525>)：网页端下载、导航、存储等操作受限制，自定义界面与脚本模式的能力也有区别。

运行方式见[客户端术语](<客户端术语.md>)和[脚本模式](<脚本模式.md>)；需要展示界面的点位还应核对[容器自适应机制](<客户端容器自适应机制.md>)。

## 开发流程

| 步骤 | 操作 | 官方说明 |
| --- | --- | --- |
| 1. 准备环境 | 安装 Node.js、NPM 和飞书项目开发工具 | [开发客户端环境准备](<../guides/环境准备.md#53942104>)；[Node.js 下载](https://nodejs.org/en/download) |
| 2. 初始化工程 | 在开发者平台创建插件并添加构成，再使用平台初始化命令建立客户端工程 | [初始化插件工程](<初始化插件工程.md>) |
| 3. 开发与调试 | 启动工程，在目标网页端或移动端验证对应点位 | [开发调试客户端](<开发调试客户端.md>) |
| 4. 上传产物 | 本地开发调试完成后上传客户端产物，供开放平台发布插件时使用 | [发布插件产物](<发布插件产物.md>) |
