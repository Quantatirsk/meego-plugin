# 表格列搭建工具

表格列搭建工具用于编辑控件表格页的布局配置、实时预览、调试部分事件，并通过剪贴板导入导出 JSON 模板。

它面向**网页端表格列的声明式展示布局**。根据[开发表格页控件](<../points/控件 Control.md#459e2395>)，该场景不在单元格中运行自定义客户端脚本，而由预置布局和展示态数据接口共同完成渲染。搭建工具不能替代数据接口、插件后台配置或移动端开发流程。

<a id="83a8898c"></a>

## 打开工具与选择模板

访问[表格列搭建工具](https://project.feishu.cn/openapp/plugin/dsl/builder)，从已有模板开始编辑并观察预览效果。

例如，官方控件指南使用模板资源库中的“分布条”展示关联缺陷状态：先定义布局需要的变量，再编写展示态数据接口返回这些变量对应的数据。模板位置与完整开发步骤见[实现分布条控件](<../points/控件 Control.md#3ff30d55>)。

![搭建工具界面](<../assets/06499e856e7a0daab7731c23.gif>)

布局配置包含 `definitions` 和 `template`：前者声明变量、颜色和多语言词条，后者定义布局。具体字段及表达式协议以[布局配置介绍](<../points/控件 Control.md#5b84c2ee>)为准，不应把 JSON 模板当作 React 代码或 `plugin.config.json`。

<a id="cf5c4e54"></a>

## 事件调试能力

| 事件行为 | 工具内可调试 | 控件协议中的动作标识 |
| --- | --- | --- |
| 打开网页 | 是 | `openLink` |
| 将字符串写入剪贴板 | 是 | `writeTextToClipboard` |
| 发起网络请求 | 是 | `httpRequest` |
| 打开工作项新建页 | 否 | `openWorkItemCreatePage` |
| 打开工作项详情页 | 否 | `openWorkItemDetailPage` |

最后两项仅表示**工具当前不支持调试**；正式控件协议仍有对应事件定义，需要在实际插件环境中验证。动作标识及参数见[事件处理](<../points/控件 Control.md#8681bc2e>)。

下面是原文“发起网络请求”的调试界面：

![网络请求事件调试](<../assets/1a556eb7824179640fc0b9f4.png>)

正式控件的网络动作收到响应后，会重新获取当前单元格渲染数据；请求不携带浏览器 Cookies，身份校验需结合数据接口设计。以上属于控件运行协议，工具页面的预览不替代实际身份与渲染验证。

## 导入、编辑与导出

### 导入已有布局

1. 从工具示例页面获取布局模板的 JSON 字符串，复制到剪贴板。
2. 点击“剪贴板导入”。
3. 查看预览区域：导入成功会实时更新布局；格式不正确会显示提示。

![从剪贴板导入](<../assets/30e4980657f9fb46d68fedc0.png>)

### 导出当前布局

点击“导出到剪贴板”，工具会把当前布局模板转换为 JSON 字符串并复制到剪贴板，可用于保存、分享或后续二次编辑。

![导出到剪贴板](<../assets/91e8b252c3f6c2a8abbb1a51.png>)

导出后还需把布局接入后台对应的表格列控件配置，并实现[展示态数据接口](<../points/控件 Control.md#8191feb8>)。预览中的模拟数据不能作为真实工作项数据接口使用。
