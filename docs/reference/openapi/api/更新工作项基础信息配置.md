# 更新工作项基础信息配置

修改指定工作项类型的基础配置，包括启停、导航入口、整体排期、估分与工时字段，以及排期所属角色。请求路径定位工作项类型，请求体提交需要更新的配置项。

## 使用前确认

- 调用身份需要空间管理员权限，否则返回 `10005`。
- 排期字段必须为日期区间类型，估分与实际工时字段必须为数字类型。
- `belong_role_keys` 中的角色必须已存在于流程角色配置；多个角色将平分估分。
- 关闭整体排期的状态流限制见[获取工作项基础信息配置](获取工作项基础信息配置.md)。

对应的平台功能介绍详见[基本信息页配置](https://project.feishu.cn/1ykiuvvj/2rv0xerq)和[工作项整体排期配置](https://project.feishu.cn/1ykiuvvj/3t60v7vo)。对应的权限申请在 权限管理-工作项 分类下，相关功能介绍详见 [权限管理](../guides/权限管理.md)。

<a id="请求说明"></a>

## 请求说明

- 请求方式：PUT

- 请求地址：/open_api/:project_key/work_item/type/:work_item_type_key

<a id="请求参数"></a>

## 请求参数

<a id="header"></a>

### Header

接口调用的 Header 配置详见 [Header](../guides/OpenAPI概述.md#a8e43b86)。

<a id="Path"></a>

### Path

| 参数 | 类型 | 是否必须 | 说明 |
| --- | --- | --- | --- |
| `project_key` | string | 必须 | [说明](#parameter-note-1) |
| `work_item_type_key` | string | 必须 | 工作项类型，系统自动生成，可以从[获取空间下工作项类型](获取空间下工作项类型.md)接口获取。 |

<a id="parameter-note-1"></a>

**project_key：说明**

空间 ID（project_key），或者空间域名（simple_name）。
- 空间 ID（project_key），在飞书项目空间双击空间名称获取。
- 空间域名（simple_name），`simple_name` 一般在飞书项目空间 URL 中获取。例如空间 URL 为 “https://project.feishu.cn/doc/overview”，则 `simple_name`为 “doc”。

<a id="Body"></a>

### Body

| 参数 | 类型 | 是否必须 | 说明 |
| --- | --- | --- | --- |
| `description` | string | 可选 | 工作项描述 |
| `is_disabled` | boolean | 可选 | 标识工作项是否被禁用。<br>- 当设置为 `true` 时，工作项将被禁用；<br>- 设置为 `false`时，工作项处于启用状态。 |
| `is_pinned` | boolean | 可选 | 标识工作项是否在导航栏中显示为入口。<br>- 当设置为 `true` 时，工作项将在导航栏中显示为入口；<br>- 设置为 `false`时，工作项不会在导航栏中显示为入口。 |
| `enable_schedule` | boolean | 可选 | 标识工作项是否支持整体排期。<br>- 当设置为 `true` 时，工作项将支持整体排期；<br>- 设置为 `false`时，工作项不支持整体排期。 |
| `schedule_field_key` | string | 可选 | 排期字段 key，指定一个日期区间类型字段为该工作项排期字段。 |
| `estimate_point_field_key` | string | 可选 | 估分字段 key，指定一个数字类型字段为该工作项估分字段。 |
| `actual_work_time_field_key` | string | 可选 | 实际工时字段 key，指定一个数字类型字段为该工作项实际工时字段。 |
| `belong_role_keys` | `list<string>` | 可选 | 所属角色 key，指定排期与估分所属角色，多角色间将平分估分。填写的角色，需要在流程角色配置中已经存在。 |
| `actual_work_time_switch` | boolean | 可选 | 是否打开工作项工时登记 API。 |

<a id="返回参数"></a>

## 返回参数

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `err` | object | 请求成功时返回空值，请求失败时返回实际错误信息。 |
| `err_msg` | string | 请求成功时返回空值，请求失败时返回实际错误信息。 |
| `err_code` | int32 | 请求成功时0，请求失败返回实际错误码。 |

### `err` 的字段

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `code` | int32 | 部分场景下，透出更详细错误对应的错误码。 |
| `msg` | string | 部分场景下，透出更详细的错误描述。 |
| `log_id` | string | 报错场景下的调用链标识符，用于追踪错误发生时的完整调用链路，便于日志记录和问题排查。 |
