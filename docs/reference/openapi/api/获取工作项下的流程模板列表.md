# 获取工作项下的流程模板列表

列出一个工作项类型下的流程模板，返回模板名称、启停标记、版本及多个模板标识。可先通过本接口选择模板，再按模板 ID 查询节点或状态流配置详情。

## 使用前确认

`is_disabled` 是整数枚举：`1` 禁用、`2` 启用。`template_id`、`template_key` 和 `unique_key` 是不同返回字段，后续接口需要哪一个，应按其参数定义填写。

对应的平台功能介绍详见[节点流程规则配置](https://project.feishu.cn/1ykiuvvj/3bv61iew)或[状态流程配置](https://project.feishu.cn/1ykiuvvj/2lgf2cd8)，对应的权限申请在 权限管理-流程类型 分类下，相关功能介绍详见[权限管理](../guides/权限管理.md)。

<a id="请求说明"></a>

## 请求说明

- 请求方式：GET

- 请求地址：/open_api/:project_key/template_list/:work_item_type_key

<a id="请求参数"></a>

## 请求参数

<a id="header"></a>

### Header

接口调用的 Header 配置详见 [Header](https://project.feishu.cn/b/helpcenter/developer/create-an-api-configuration#018a9fe7)。

<a id="Path"></a>

### Path

| 参数 | 类型 | 是否必须 | 说明 |
| --- | --- | --- | --- |
| `project_key` | string | 必须 | 空间 ID（project_key），在飞书项目空间双击空间名称获取。 |
| `work_item_type_key` | string | 必须 | 工作项类型，系统自动生成，可通过[获取空间下工作项类型](获取空间下工作项类型.md)接口获取。 |

<a id="返回参数"></a>

## 返回参数

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `data` | `list<object>` | 遵循[TemplateConf](../formats/数据结构汇总.md#9aa45e24)结构规范 |
| `err` | object | 请求成功时返回空值，请求失败时返回实际错误信息。 |
| `err_msg` | string | 请求成功时返回空值，请求失败时返回实际错误信息。 |
| `err_code` | int32 | 请求成功时返回0，请求失败返回实际错误码。 |

### `data` 的字段

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `template_name` | string | 流程模板名称 |
| `is_disabled` | int32 | 标识模板是否被禁用。支持的取值如下所示。<br>- `1`：禁用；<br>- `2`：启用。 |
| `version` | int64 | 模板版本 |
| `unique_key` | string | 模板标识 |
| `template_id` | string | 模板 ID |
| `template_key` | string | 模板 key |

### `err` 的字段

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `code` | int32 | 部分场景下，透出更详细错误对应的错误码。 |
| `msg` | string | 部分场景下，透出更详细的错误描述。 |
| `log_id` | string | 报错场景下的调用链标识符，用于追踪错误发生时的完整调用链路，便于日志记录和问题排查。 |
