# 获取用户详情

通过飞书项目 `user_key`、飞书开放平台 `union_id` 或绑定邮箱批量查询用户。适合已有用户标识后补齐名称、头像和状态；只有搜索关键词时，先调用[搜索租户内的用户列表](搜索租户内的用户列表.md)。接口权限位于[权限管理](../guides/权限管理.md)的“用户”分类，开发问题另见[开发调试咨询](https://project.feishu.cn/b/helpcenter/1p8d7djs/xfknq6e7)。

## 查询前确认

- `user_keys`、`out_ids`、`emails` 至少填写一项，一次最多查询 100 个用户。原文未说明同时使用多种标识时如何去重，不应据此假定可以突破 100 条上限。
- 使用邮箱查其他租户的用户时，必须传目标租户的 `tenant_key`；省略表示插件所属租户。
- 业务侧保存 `user_key`。`user_id` 已废弃且恒为 `0`，`username` 仅作为兼容字段保留。
- 使用插件凭证调用本接口时，无需 `X-User-Key`。虚拟凭证的查询范围仅包含插件协作者；查询其他用户需使用正式凭证。

## 请求说明

**请求方式**：`POST`

**请求地址**：`/open_api/user/query`

<a id="请求参数"></a>

## 请求参数

<a id="header"></a>

### 请求头

接口调用的 Header 配置详见 [Header](../guides/OpenAPI概述.md#a8e43b86)。

<a id="Body"></a>

### 请求体

| 参数         | 类型           | 是否必须 | 说明                      |
| ------------ | -------------- | -------- | ------------------------- |
| `user_keys`  | `list<string>` | 可选     | [详细说明](#field-note-1) |
| `out_ids`    | `list<string>` | 可选     | [详细说明](#field-note-2) |
| `emails`     | `list<string>` | 可选     | [详细说明](#field-note-3) |
| `tenant_key` | `string`       | 可选     | [详细说明](#field-note-4) |

<a id="field-note-1"></a>

**user_keys**

飞书项目 user_key 的数组。

- 开发者自己的 user_key，在飞书项目空间左下角双击个人头像获取。

- 租户内其他成员的 user_key，请通过[搜索租户内的用户列表](搜索租户内的用户列表.md)接口获取。

<a id="field-note-2"></a>

**out_ids**

飞书开放平台 UnionId 的数组，用于标识用户在同一应用服务商所开发的多个应用中的统一身份。获取方法见[飞书开放平台文档](https://open.larkoffice.com/document/faq/trouble-shooting/how-to-obtain-union-id)。

<a id="field-note-3"></a>

**emails**

email 的数组，使用邮箱查询需要确保飞书上已经绑定邮箱。

<a id="field-note-4"></a>

**tenant_key**

要查询的用户所在的飞书项目租户 saas_tenant_key，适用于 emails 查询场景：

- 如果需要查询非插件所属租户的用户时必填，例如租户 X 开发了插件 A，且租户 Y 安装了插件 A，想要查询租户 Y 的用户信息。获取方式详见[获取用户访问凭证 user_access_token](../guides/获取访问凭证.md#3df3fccd)。

- 如果为空，视为查询的是插件所属租户下的用户信息。

<a id="返回参数"></a>

## 返回参数

| 参数       | 类型           | 说明                                             |
| ---------- | -------------- | ------------------------------------------------ |
| `data`     | `list<object>` | 查询结果                                         |
| `err`      | `object`       | 请求成功时返回空值，请求失败时返回实际错误信息。 |
| `err_msg`  | `string`       | 请求成功时返回空值，请求失败时返回实际错误信息。 |
| `err_code` | `int32`        | 请求成功时返回0，请求失败返回实际错误码。        |

### `data`

| 参数         | 类型     | 说明                                                                                                                                                                                                        |
| ------------ | -------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `user_id`    | `int64`  | 用户 ID（已废弃），永久为 0。                                                                                                                                                                               |
| `user_key`   | `string` | 用户在飞书项目的 user_key，例如“749112601802809xxxx”。                                                                                                                                                      |
| `username`   | `string` | 用户在飞书项目的 user_key，例如“749112601802809xxxx”，建议使用 `user_key` 字段。                                                                                                                            |
| `email`      | `string` | 用户邮箱。                                                                                                                                                                                                  |
| `avatar_url` | `string` | 用户头像链接。                                                                                                                                                                                              |
| `name_cn`    | `string` | 用户中文名称。                                                                                                                                                                                              |
| `name_en`    | `string` | 用户英文名称。                                                                                                                                                                                              |
| `out_id`     | `string` | 用户在飞书开放平台的 `union_id`，用于标识用户在同一应用服务商所开发的多个应用中的统一身份。具体可参考[飞书开放平台文档](https://open.larkoffice.com/document/faq/trouble-shooting/how-to-obtain-union-id)。 |
| `status`     | `string` | [详细说明](#field-note-5)                                                                                                                                                                                   |
| `name`       | `map`    | 用户名称，包含用户中文名、英文名和默认名称。                                                                                                                                                                |

<a id="field-note-5"></a>

**status**

用户的状态，取值如下所示。

- `initialized`：初始（未登录过）；

- `resigned`：离职；

- `frozen`：冻结（被停用）；

- `activated`：使用中。

### `err`

| 参数     | 类型     | 说明                                                                                 |
| -------- | -------- | ------------------------------------------------------------------------------------ |
| `code`   | `int32`  | 部分场景下，透出更详细错误对应的错误码。                                             |
| `msg`    | `string` | 部分场景下，透出更详细的错误描述。                                                   |
| `log_id` | `string` | 报错场景下的调用链标识符，用于追踪错误发生时的完整调用链路，便于日志记录和问题排查。 |
