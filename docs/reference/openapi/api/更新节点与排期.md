# 更新节点/排期

> 接入 Open API / 工作项 / 流程与节点 / 更新节点/排期
>
> Published: 2026-08-27T10:31:05.170Z; captured: 2026-09-07T01:03:16.981Z

更新节点流工作项的一个节点，包括负责人、排期、完成表单、节点自定义字段和新增关联子项。`node_id` 可使用节点 ID 或等价的节点 `state_key`，可先通过[获取工作流详情](获取工作流详情.md)查询。权限位于**权限管理 > 工作项**，见[权限管理](../guides/权限管理.md)。

<a id="使用说明"></a>

## 使用说明

按人汇总排期与负责人需要分两次调用：先更新节点负责人，再提交 `schedules`。启用按人汇总时，节点负责人至少为两人，每项排期要包含对应的 `owners`。

`node_owners` 不传表示不更新，空数组表示删除所有负责人。角色绑定的节点通过 `role_assignee` 更新角色人员；`fields` 更新完成表单，`node_custom_fields` 更新节点自定义字段，两者不要混用。

<a id="schedule-update-modes"></a>

### 排期与估分的更新行为

动态计算使用 `node_schedule`，按人汇总使用 `schedules`。下面规则作用于提交的每个 Schedule 对象，`is_auto` 默认 `true`：

| 提交内容   | `is_auto=true`       | `is_auto=false` |
| ---------- | -------------------- | --------------- |
| 仅排期     | 根据排期差值补充估分 | 不自动补充估分  |
| 仅估分     | 清空排期             | 保留排期        |
| 排期和估分 | 按提交值保存         | 按提交值保存    |
| 两者都不填 | 估分置 `0`，排期清空 | 不修改          |

因此，“未提交整个排期字段”和“提交一个没有排期、估分的 Schedule 对象”应区分处理。原文对顶层排期参数写“无需更新则为空”，未明确 `null` 与空对象的协议差异；不要用空对象表达不更新。

`schedule_constraint_rule` 控制节点、子任务、子流程及按类型区分的 WBS 子项联动。`wbs_sub_instance_type` 为 `map<string, bool>`，键是工作项类型 key，见[ScheduleConstraintRule](../formats/数据结构汇总.md#1f822c95)。默认联动范围待核实。

### 新增节点关联子项

提交 `add_sub_workitems` 时，`relation_id` 和 `workitems` 均必填：前者是节点子项关系 UUID，后者是已有工作项实例 ID 列表，单次最多 `10` 个。空列表表示这次不新增，不清空已有关系。

<a id="请求说明"></a>

## 请求说明

**请求方式**：`PUT`

**请求地址**：`/open_api/:project_key/workflow/:work_item_type_key/:work_item_id/node/:node_id`

<a id="请求参数"></a>

## 请求参数

<a id="header"></a>

### 请求头

接口调用的 Header 配置详见 [Header](../guides/OpenAPI概述.md#a8e43b86)。

<a id="Path"></a>

### 路径参数

| 参数                 | 类型     | 是否必须 | 说明                                                                                       |
| -------------------- | -------- | -------- | ------------------------------------------------------------------------------------------ |
| `project_key`        | `string` | 必须     | 空间 ID（project_key），或者空间域名（simple_name）。 [详细说明](#field-note-1)            |
| `work_item_type_key` | `string` | 必须     | 工作项类型，可以从[获取空间下工作项类型](获取空间下工作项类型.md)接口获取。                            |

<a id="field-note-1"></a>

**project_key**

空间 ID（project_key），或者空间域名（simple_name）。

- 空间 ID（project_key），在飞书项目空间双击空间名称获取。
- 空间域名（simple_name），`simple_name` 一般在飞书项目空间 URL 中获取。例如空间 URL 为 “https://project.feishu.cn/doc/overview”，则 `simple_name`为 “doc”。

**schedules**
