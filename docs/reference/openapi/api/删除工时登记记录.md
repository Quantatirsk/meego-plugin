# 删除工时登记记录

按记录 ID 删除指定工作项下的工时登记。记录 ID 从[工时登记记录列表](获取工作项的工时登记记录列表.md)取得，接口权限位于[权限管理](../guides/权限管理.md)的“工作项实例”分类。

## 删除与重复请求

这是带 JSON 请求体的 `DELETE`：路径给出空间、工作项类型和实例，正文 `working_hour_record_ids` 给出记录 ID 列表，不是节点或子任务 ID。

原文明确：工时记录已经删除或不存在时仍返回成功。但工作项本身不存在会返回 `30005`，空间与实例不匹配会返回 `20014`。因此应区分“记录不存在”和“请求定位的工作项不正确”。

<a id="注意事项"></a>

## 注意事项

1. 调用当前接口前，请先开启工时登记 API，有以下两种方式：
   - 通过[更新工作项基础信息配置](更新工作项基础信息配置.md)将 `actual_work_time_switch` 设置为 `true`。

   - 在飞书项目空间设置中安装[工时登记](https://project.feishu.cn/1ykiuvvj/3uh9k5d9)插件。

2. 以**工时登记**的方式使用”实际工时“后，对应节点或子任务上原有的历史”实际工时“会被清空。

<a id="请求说明"></a>

## 请求说明

**请求方式**：`DELETE`

**请求地址**：`/open_api/:project_key/work_item/:work_item_type_key/:work_item_id/work_hour_record`

<a id="请求参数"></a>

## 请求参数

<a id="header"></a>

### 请求头

接口调用的 Header 配置详见 [Header](../guides/OpenAPI概述.md#a8e43b86)。

<a id="Path"></a>

### 路径参数

| 参数                 | 类型     | 是否必须 | 说明                                                                                                 |
| -------------------- | -------- | -------- | ---------------------------------------------------------------------------------------------------- |
| `project_key`        | `string` | 必须     | 空间 ID（project_key），在飞书项目空间双击空间名称获取。需要与 `work_item_id`对应实例匹配。          |
| `work_item_type_key` | `string` | 必须     | 工作项类型，可以通过[获取空间下工作项类型](获取空间下工作项类型.md)接口获取，需要与 `work_item_id`对应实例匹配。 |
| `work_item_id`       | `string` | 必须     | 工作项实例 ID，在工作项实例详情中，展开右上角 **··· \> ID** 获取。                                   |

<a id="Body"></a>

### 请求体

| 参数                      | 类型          | 是否必须 | 说明                                                                                      |
| ------------------------- | ------------- | -------- | ----------------------------------------------------------------------------------------- |
| `working_hour_record_ids` | `list<int64>` | 必须     | 需要删除的实际工时记录 ID 列表，通过[获取工作项的工时登记记录列表](获取工作项的工时登记记录列表.md)接口获取。 |

<a id="返回参数"></a>

## 返回参数

| 参数       | 类型     | 说明                                             |
| ---------- | -------- | ------------------------------------------------ |
| `err`      | `object` | 请求成功时返回空值，请求失败时返回实际错误信息。 |
| `err_msg`  | `string` | 请求成功时返回空值，请求失败时返回实际错误信息。 |
| `err_code` | `int32`  | 请求成功时0，请求失败返回实际错误码。            |

### `err`

| 参数     | 类型     | 说明                                                                                 |
| -------- | -------- | ------------------------------------------------------------------------------------ |
| `code`   | `int32`  | 部分场景下，透出更详细错误对应的错误码。                                             |
| `msg`    | `string` | 部分场景下，透出更详细的错误描述。                                                   |
| `log_id` | `string` | 报错场景下的调用链标识符，用于追踪错误发生时的完整调用链路，便于日志记录和问题排查。 |

<a id="请求示例"></a>

## 请求示例

请求路径：`DELETE /open_api/68382b399de4b0ec6c5axxxx/work_item/story/12584xxxx/work_hour_record`

```text
{
   "working_hour_record_ids":[18185****]
}
```

<a id="返回示例"></a>

## 返回示例

### 请求成功示例

```json
{
  "data": {},
  "err": {},
  "err_msg": "",
  "err_code": 0
}
```

### 错误返回示例

以下错误原因为 `work_item_id` 错误，请传入正确的工作项实例 ID。

```json
{
  "err_code": 30005,
  "err_msg": "WorkItem Not Found",
  "err": {
    "code": 30005,
    "msg": "workitem_id: 62837xxxx",
    "log_id": "20251026182941B714C61DFFEA6FE2xxxx"
  }
}
```

### 重复删除工时返回

若传入的 `working_hour_record_ids` 已被删除或不存在，不会报错，返回以下信息。

```json
{
  "data": {},
  "err": {},
  "err_msg": "",
  "err_code": 0
}
```
