# 查询全量计划表骨架

读取已经发布的实例态计划表骨架，返回行 UUID 和树形层级。无权限实例会被过滤；本接口查询实例态，不需要 `draft_id`。

## 骨架与详情的配合

递归读取 `data.wbs_structure.current_row` 与 `children`，取得目标行 UUID，再调用[查询计划表行详细信息](查询计划表行详细信息.md)补充名称、排期和负责人。草稿态使用另一组[草稿骨架](查询全量计划表草稿骨架.md)和[草稿行详情](查询计划表草稿数据行详细信息.md)接口。

`include_ui_rows` 默认 `false`，只需业务数据时可保留默认值；设为 `true` 时，按接口说明包含 `Creator`、`CardGroup`、`GridGroup` 等 UI 行。共享行类型说明同时写明 `CardGroup` 只用于视图、不用于计划表，因此不能假定它一定会出现在结果中。

`General` 是普通数据行的展示类型，不能与详情中的 `node`、`sub_instance`、`sub_task` 业务类型混为一组枚举。插件权限见[权限管理](../guides/权限管理.md)中的“工作项”。

## 请求说明

**请求方式**：`POST`
**请求地址**：`/open_api/work_item/wbs_view/structure/query`

<a id="请求参数"></a>

## 请求参数

<a id="a3c53a27"></a>

### 请求头

接口调用的 Header 配置详见[Header](../guides/OpenAPI概述.md#a8e43b86)

<a id="Body"></a>

### 请求体

| 参数 | 类型 | 是否必须 | 说明 |
| --- | --- | --- | --- |
| project_key | string | 必须 | 空间 ID（project_key）。<br>- 空间 ID（project_key），在飞书项目空间双击空间名称获取。 |

<a id="返回参数"></a>

## 返回参数

业务树结构在成功示例中位于 `data.wbs_structure`。遍历时处理可能没有 `children` 的叶子行；原示例已展示这种情况。

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `wbs_structure` | object | 计划表树结构 |
| `err` | object | 对部分错误会在这里进行更详细的错误描述，可协助日志记录和问题反馈。 |
| `err_msg` | string | 错误信息。 |
| `err_code` | int32 | 错误码。 |

### `wbs_structure`

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `children` | `list<object>` | 子行 |
| `current_row` | object | 当前行 |

### `wbs_structure.current_row`

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `type` | string | 行类型（节点、子工作项、子任务）<br>Creator,新建按钮行，含视图、计划表 的 添加按钮<br>General,普通数据行；含视图、计划表 的 节点/任务/子工作项/子流程 等<br>CardGroup,表格 card 形式分组； 视图表格使用，计划表不使用<br>GridGroup,表格 grid 形式分组； 计划表与视图表格使用 |
| `uuid` | string | 行uuid，唯一标识 |

### `err`

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `code` | int32 | 部分场景下，透出更详细错误对应的错误码。 |
| `msg` | string | 部分场景下，透出更详细的错误描述。 |
| `log_id` | string | 报错场景下的调用链标识符，用于追踪错误发生时的完整调用链路，便于日志记录和问题排查。 |
