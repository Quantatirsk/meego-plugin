# 删除评论

按空间 ID 和评论 ID 删除评论。接口使用 `POST /open_api/comment/delete`，调用身份必须与评论创建人一致。

## 使用前确认

评论 ID 可从[查询评论](查询评论.md)或创建响应获取。`10001` 表示没有操作权限，`30015` 表示目标评论不存在；HTTP 请求成功并不等于业务删除成功，应检查 `err_code`。

该接口用于删除工作项下一条指定的评论信息，对应的权限申请在**权限管理-评论**分类下，相关功能介绍详见[权限管理](../guides/权限管理.md)。

<a id="使用说明"></a>

## 使用说明

只有创建评论的人才能删除评论，且删除评论只能通过 API 操作。

<a id="请求说明"></a>

## 请求说明

- 请求方式：POST

- 请求地址：/open_api/comment/delete

<a id="请求参数"></a>

## 请求参数

<a id="header"></a>

### Header

接口调用的 Header 配置详见[Header](../guides/OpenAPI概述.md#a8e43b86)。

<a id="Body"></a>

### Body

| 参数 | 类型 | 是否必须 | 说明 |
| --- | --- | --- | --- |
| `comment_id` | string | 必须 | 评论 id ，可以通过[查询评论](查询评论.md)接口获取，也可以通过创建评论的返回值获取。 |
| `project_key` | string | 必须 | 空间 ID（project_key），在飞书项目空间双击空间名称获取。 |

| `err_code` | int32 | 错误码。 |

| 参数 | 类型 | 说明 |

| `log_id` | string | 报错场景下的调用链标识符，用于追踪错误发生时的完整调用链路，便于日志记录和问题排查。 |
