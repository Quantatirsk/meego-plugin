# 获取工作流详情

[Official source](https://project.feishu.cn/b/helpcenter/1p8d7djs/5hcmcl04) | [Local index](../INDEX.md)

> 接入 Open API / 工作项 / 流程与节点 / 获取工作流详情
>
> Published: 2026-08-31T08:35:17.269Z; captured: 2026-09-07T01:03:14.602Z

查询一个工作项实例的流程结构与当前执行信息，包括节点、连接、负责人、排期、表单和子任务。接口同时支持节点流和状态流，调用时必须与实例的实际流程类型匹配。

## 选择流程类型与读取结果

| 实例类型 | `flow_type`     | 主要返回内容                                                                       |
| -------- | --------------- | ---------------------------------------------------------------------------------- |
| 节点流   | `0`，也是默认值 | `workflow_nodes`、`connections`；按扩展参数返回人员及节点子项信息                  |
| 状态流   | 必须显式传 `1`  | `state_flow_nodes`、`connections`；连接上有 `transition_id`，不返回 `user_details` |

`fields` 仅筛选节点表单中的字段，不是整个响应的投影规则。指定字段与以 `-` 开头的排除字段不能混用，节点完成表单不返回投票类字段。

读取节点流时，应区分以下几组数据：

- `node_schedule` 是节点总排期，`schedules` 是按人员拆分的差异化排期；预计时间为毫秒时间戳，示例以开始日零点、结束日 23:59:59 表达整天排期。`actual_begin_time`、`actual_finish_time` 则是 ISO 8601 时间字符串。
- `fields` 是完成表单，`node_fields` 是节点自定义字段。多人复合节点字段按 `target_field_owner` 分别保存 `sub_field_values`。
- `finished_infos` 保存完成意见和结论；`summary_mode=calculation` 表示汇总计算，`independence` 表示独立填写。整体结果与各负责人结果分开返回，无效结果不展示。
- `sub_tasks` 是节点子任务；`node_sub_workitem_detail` 是节点关联工作项，需开启 `need_sub_workitem_detail`，其中 `workitems` 可以为空数组。

子任务的 `owner_roles` 表达角色范围或关联角色。负责人模式按已定义的 `1`（自行添加）、`2`（角色联动）解释。状态流 `role_owners.exist` 表示角色是否存在于当前实例。

平台功能见[流程图](https://project.feishu.cn/1ykiuvvj/69kaicie#%E6%B5%81%E7%A8%8B%E5%9B%BE)和[新建缺陷](https://project.feishu.cn/1ykiuvvj/5ci97x50)。接口权限位于**权限管理 > 工作项**，见[权限管理](../guides/权限管理.md)。

## 请求说明

**请求方式**：`POST`

**请求地址**：`/open_api/:project_key/work_item/:work_item_type_key/:work_item_id/workflow/query`

### 路径参数

| 参数                 | 类型     | 是否必须 | 说明                                                                                                                    |

<a id="field-note-1"></a>

**project_key**

空间 ID（project_key），或者空间域名（simple_name）。

- 空间 ID（project_key），在飞书项目空间双击空间名称获取。
- 空间域名（simple_name），`simple_name` 一般在飞书项目空间 URL 中获取。例如空间 URL 为 “https://project.feishu.cn/doc/overview”，则 `simple_name`为 “doc”。

### 请求体

| 参数        | 类型           | 是否必须 | 说明                                                                                                           |
| ----------- | -------------- | -------- | -------------------------------------------------------------------------------------------------------------- |
| `fields`    | `list<string>` | 可选     | 定义返回信息中节点表单的字段内容，默认返回全部字段。支持两种模式，两种模式不可混用。 [详细说明](#field-note-2) |

| `expand`    | `object`       | 可选     | 额外参数，该返回结构遵循结构体[ExPand](../formats/数据结构汇总.md#5e0e767b)格式与规范。                            |

<a id="field-note-2"></a>

**fields**

定义返回信息中节点表单的字段内容，默认返回全部字段。支持两种模式，两种模式不可混用。

- 指定字段模式：仅返回节点表单 `fields` 中列出的字段。如 `["name", "created_at"]`，表示只返回 `name` 和 `created_at` 字段及相关信息。
- 排除字段模式：以 `-` 开头的字段表示排除该字段。如 `["-name", "-created_at"]`，表示返回除 `name` 和 `created_at` 外的所有字段及相关信息。

<a id="field-note-3"></a>

**flow_type**

工作流类型，默认值为 `0`。支持的取值如下所示。

- `0`：节点流（如需求等）；
- `1`：状态流，状态流工作项必传（如缺陷、版本等）。

#### `expand`

| 参数                       | 类型      | 是否必须 | 说明                                                      |
| -------------------------- | --------- | -------- | --------------------------------------------------------- |
| `need_user_detail`         | `boolean` | 可选     | 扩展查询，是否需要返回用户详细信息。默认值为 `false`。    |
| `need_sub_task_parent`     | `boolean` | 可选     | 扩展查询，是否需要子任务的父级信息                        |
| `need_rich_text_mark_down` | `boolean` | 可选     | 扩展查询，是否需要返回富文本 Markdown 格式信息            |
| `need_sub_workitem_detail` | `boolean` | 可选     | 拓展查询，是否返回节点子项关联详情，未传或 false 时不返回 |

**status**

工作流节点的状态，支持的取值如下所示。

**fields**

<a id="field-note-6"></a>

**role_assignee**

角色负责人，该返回结构遵循结构体[RoleOwner](../formats/数据结构汇总.md#3209a8ce)格式与规范。

- 节点绑定的角色负责人(未绑定角色时不返回)
- 当节点负责人分配方式为与角色联动时返回

**owner_usage_mode**

- `1`：手动指定负责人；
- `2`：与角色联动。

## 请求示例

### 查询节点流

查询节点流工作项，并返回用户详情和节点子项关联详情。

**请求 Path**：`POST /open_api/676e6839bd3a3bcba14xxxx/work_item/story/126941xxx/workflow/query`

```json
{
  "flow_type": 0,
  "expand": {
    "need_user_detail": true,
    "need_sub_workitem_detail": true
  }
}
```

### 查询状态流

以下为查询状态流工作项所有信息的请求示例。

**请求 Path**：`POST /open_api/676e6839bd3a3bcba14xxxx/work_item/issue/126941xxx/workflow/query`

```json
{
  "flow_type": 1
}
```

### 定制返回字段

以下为查询节点流工作项的信息，指定表单字段 `fields` 中，仅返回 `priority` 字段。

**请求 Path**：`POST /open_api/676e6839bd3a3bcba14xxxx/work_item/story/126941xxx/workflow/query`

```json
{
  "flow_type": 0,
  "fields": ["priority"],
  "expand": {
    "need_user_detail": true
  }
}
```

### 排除返回字段

以下为查询节点流工作项的信息，指定表单字段 `fields` 中，返回除 `priority` 字段的其他字段信息。

**请求 Path**：`POST /open_api/676e6839bd3a3bcba14xxxx/work_item/story/126941xxx/workflow/query`

```json
{
  "flow_type": 0,
  "fields": ["-priority"],
  "expand": {
    "need_user_detail": true
  }
}
```
