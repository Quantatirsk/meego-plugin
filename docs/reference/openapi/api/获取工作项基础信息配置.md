# 获取工作项基础信息配置

读取指定工作项类型的名称、流程模式、整体排期、资源库和工时登记开关。此接口返回类型配置，用于判断后续业务操作应使用哪些字段及能力。

## 使用前确认

- `work_item_type_key` 从空间工作项类型列表取得。
- `enable_schedule` 控制排期字段是否生效；原文限定仅状态流工作项支持关闭整体排期的设置。
- `actual_work_time_switch` 为 `true` 时，实际工时按工时登记 OpenAPI 提交的数据计算。
- 资源库是否可用由 `enable_model_resource_lib` 表示，启用的角色和字段另见 `resource_lib_setting`。

对应的平台功能介绍详见[基本信息页配置](https://project.feishu.cn/1ykiuvvj/2rv0xerq)和[工作项整体排期配置](https://project.feishu.cn/1ykiuvvj/3t60v7vo)。对应的权限申请在**权限管理-工作项实例**分类下，相关功能介绍详见 [权限管理](../guides/权限管理.md)。

<a id="请求说明"></a>

## 请求说明

- 请求方式：GET

- 请求地址：/open_api/:project_key/work_item/type/:work_item_type_key

<a id="请求参数"></a>

## 请求参数

<a id="header"></a>

### Header

接口调用的 Header 配置详见  [Header](../guides/OpenAPI概述.md#a8e43b86)。

<a id="Path"></a>

### Path

| 参数 | 类型 | 是否必须 | 说明 |
| --- | --- | --- | --- |
| `project_key` | string | 必须 | [说明](#parameter-note-1) |
| `work_item_type_key` | string | 必须 | 工作项类型，系统自动生成，可通过[获取空间下工作项类型](获取空间下工作项类型.md)接口获取。 |

<a id="parameter-note-1"></a>

**project_key：说明**

空间 ID（project_key），或者空间域名（simple_name）。
- 空间 ID（project_key），在飞书项目空间双击空间名称获取。
- 空间域名（simple_name），`simple_name` 一般在飞书项目空间 URL 中获取。例如空间 URL 为 “https://project.feishu.cn/doc/overview”，则 `simple_name`为 “doc”。

<a id="返回参数"></a>

## 返回参数

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `data` | object | 返回工作项类型的详细信息 |
| `err` | object | 请求成功时返回空值，请求失败时返回实际错误信息。 |
| `err_msg` | string | 请求成功时返回空值，请求失败时返回实际错误信息。 |
| `err_code` | int32 | 请求成功时0，请求失败返回实际错误码。 |

### `data` 的字段

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `name` | string | 工作项的名称 |
| `api_name` | string | 工作项的系统标识 |
| `type_key` | string | 工作项类型的 key |
| `flow_mode` | string | 工作项的流程模式，用于标识工作项的状态流转方式。支持的取值如下所示。<br>- `stateflow`：状态流模式；<br>- `workflow`：工作流模式。 |
| `is_pinned` | boolean | 是否为导航栏入口 |
| `description` | string | 类型的描述 |
| `is_disabled` | boolean | 标识工作项类型是否被禁用。当为 `true` 时，表示该工作项类型已被禁用，不可用；为 `false`时，表示该工作项类型可用。 |
| `belong_roles` | `list<object>` | 所属角色 |
| `enable_schedule` | boolean | [说明](#parameter-note-2) |
| `schedule_field_key` | string | 排期字段的唯一标识符。当 `enable_schedule` 为 `true`时，该字段才生效。 |
| `schedule_field_name` | string | 排期字段的名称。当 `enable_schedule` 为 `true`时，该字段才生效。 |
| `resource_lib_setting` | object | 资源库相关配置 |
| `actual_work_time_switch` | boolean | [说明](#parameter-note-3) |
| `estimate_point_field_key` | string | 估分字段 key |
| `enable_model_resource_lib` | boolean | 资源库是否开启并可用 |
| `estimate_point_field_name` | string | 估分字段名字 |
| `actual_work_time_field_key` | string | 实际工时字段 key |
| `actual_work_time_field_name` | string | 实际工时字段名字 |

<a id="parameter-note-2"></a>

**enable_schedule：说明**

标识工作项是否支持整体排期功能。支持的取值如下所示。
- `true`：支持整体排期，此时 `schedule_field_key` 和 `schedule_field_name` 字段才生效；
- `false`：不支持整体排期，仅状态流工作项支持该设置。

<a id="parameter-note-3"></a>

**actual_work_time_switch：说明**

标识是否开启工时登记相关的 OpenAPI 接口能力。
- 当为 `true` 时，表示开启工时登记功能，实际工时的计算逻辑将通过工时登记提交的数据实现；
- 为 `false`时，表示不开启该功能。

### `data.resource_lib_setting.enable_fields` 的字段

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `field_key` | string | 字段 key |
| `field_alias` | string | 字段对接标识 |
| `field_type_key` | string | 字段类型 |
| `field_name` | string | 字段名称 |
| `is_custom_field` | boolean | 是否自定义字段，非自定义字段即为系统字段，一般OAPI不消费 |
| `options` | `list<object>` | 选项，遵循[Option](../formats/数据结构汇总.md#440d0d08)结构规范 |
| `relation_id` | string | 关联工作项的关联关系ID |
| `compound_fields` | `list<object>` | 复合字段，当字段类型是复合字段时存在。数据结构示例可参考[字段](../formats/字段与属性解析格式.md#10fb2f8d)中的复合字段。 |
| `work_item_scopes` | `list<string>` | 作用范围 |
| `value_generate_mode` | string | [说明](#parameter-note-4) |

<a id="parameter-note-4"></a>

**value_generate_mode：说明**

字段值的生成方式，支持的取值如下所示。
- `0`：人工填写；
- `1`：计算字段计算得到；
- `2`：AI 计算得到。
- `default`：系统自带
