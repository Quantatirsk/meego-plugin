# 批量更新工作项字段值

提交同一空间、同一工作项类型的批量字段更新任务，一次最多 50 个工作项，且只能修改一个字段。可编辑字段参见[创建元数据](获取创建工作项元数据.md)，接口授权位于[权限管理](../guides/权限管理.md)的“工作项实例”分类。

## 提交后查询结果

成功提交仅返回 `data.task_id`，不代表每个工作项都已更新完成。使用该 ID 调用[获取批量更新处理进度](获取批量更新处理进度.md)，检查任务状态及逐项失败信息。本接口限流为 `1 QPS`。

### 三种更新操作

| 操作      | 作用                       | `before_field_value` |
| --------- | -------------------------- | -------------------- |
| `APPEND`  | 给支持追加的多值字段增加值 | 忽略                 |
| `UPDATE`  | 将字段整体覆盖为目标值     | 忽略                 |
| `REPLACE` | 将指定旧值替换为新值       | 必填                 |

各模式支持的字段类型不同，完整列表见请求参数。这里的字符串 `update_mode` 与[单工作项更新](更新工作项.md)的数字 `0` / `1` 不是同一个枚举。富文本前后值可分别选择普通值或 Markdown 表达，不能同时提供两种表达。

<a id="注意事项"></a>

## 注意事项

目标值允许为空，原文将其解释为删除字段值。空值格式仍需遵循字段类型规范，不能将省略必填参数与明确清空混为一谈。

<a id="field-note-1"></a>

**update_mode**

本次批量操作的更新方式，支持的取值如下所示。

- `APPEND`：追加，仅支持 `多选人员`、`多选`、`多选关联工作项`（非级联）三种字段类型；
- `UPDATE`：覆盖，不支持 `计算字段`、`系统外信号`字段类型；
- `REPLACE`：替换，仅支持 `单选`、`级联单选`、`多选`、`单选按钮`、`单选人员`、`多选人员`、`单选关联工作项`、`多选关联工作项`（非级联）。

<a id="field-note-2"></a>

**after_field_value**

操作类型的目标字段值，可参考[字段与属性解析格式](../formats/字段与属性解析格式.md)。

说明：

- 允许 `field_value` 为空，等价于删除。

#### `after_field_value_markdown.mention_user_keys`

<a id="返回参数"></a>

## 返回参数

参数表中的 `task_id` 位于成功响应的 `data` 对象内，错误字段位于响应顶层。

| 参数       | 类型     | 说明                                               |
| ---------- | -------- | -------------------------------------------------- |
| `task_id`  | `string` | 任务 ID，用于[获取批量更新处理进度](获取批量更新处理进度.md)。 |
| `err`      | `object` | 请求成功时返回空值，请求失败时返回实际错误信息。   |
| `err_msg`  | `string` | 请求成功时返回空值，请求失败时返回实际错误信息。   |
| `err_code` | `int32`  | 请求成功时返回0，请求失败返回实际错误码。          |

### `err`

| 参数     | 类型     | 说明                                                                                 |
| -------- | -------- | ------------------------------------------------------------------------------------ |
| `code`   | `int32`  | 部分场景下，透出更详细错误对应的错误码。                                             |
| `msg`    | `string` | 部分场景下，透出更详细的错误描述。                                                   |
| `log_id` | `string` | 报错场景下的调用链标识符，用于追踪错误发生时的完整调用链路，便于日志记录和问题排查。 |
