# 获取视图列表及配置信息

搜索指定空间、工作项类型下的视图配置，返回视图 ID、类型、权限、协作者及可选的快捷筛选信息。可按名称模糊查找，也可直接指定视图 ID 列表。

## 使用前确认

- 不支持 `sub_task` 工作项类型。
- 单页最大及默认值均为 10，页码默认 1。
- `view_ids` 的说明明确表示传入后其他筛选失效；不要依赖它与名称、创建者、创建时间组合过滤。
- 需要快捷筛选 ID 和名称时，设置 `is_query_quick_filter=true`。
- 视图类型 `1` 为条件视图、`2` 为固定视图；`auth=1` 开放、`2` 关闭。

对应的平台功能介绍详见[视图介绍](https://project.feishu.cn/1ykiuvvj/4w2iz8d8)。

对应的权限申请在 权限管理-视图 分类下，相关功能介绍详见 [权限管理](../guides/权限管理.md)。

<a id="请求说明"></a>

## 请求说明

- 请求方式：POST

- 请求地址：/open_api/:project_key/view_conf/list

<a id="请求参数"></a>

## 请求参数

<a id="header"></a>

### Header

接口调用的 Header 配置详见 [Header](../guides/OpenAPI概述.md#a8e43b86)。

<a id="Path"></a>

### Path

| 参数 | 类型 | 是否必须 | 说明 |
| --- | --- | --- | --- |
| `project_key` | string | 必须 | [说明](#parameter-note-1) |

<a id="parameter-note-1"></a>

**project_key：说明**

空间 ID（project_key），或者空间域名（simple_name）。
- 空间 ID（project_key），在飞书项目空间双击空间名称获取。
- 空间域名（simple_name），`simple_name` 一般在飞书项目空间 URL 中获取。例如空间 URL 为 “https://project.feishu.cn/doc/overview”，则 `simple_name`为 “doc”。

<a id="Body"></a>

### Body

| 参数 | 类型 | 是否必须 | 说明 |
| --- | --- | --- | --- |
| `work_item_type_key` | string | 必须 | 工作项类型，系统自动生成，可通过[获取空间下工作项类型](获取空间下工作项类型.md)接口获取。<br>注：不支持sub_task工作项类型 |
| `view_name` | string | 可选 | 视图名称，支持模糊搜索。若同时指定了 `view_ids` 和 `view_name`，则 `view_name` 会被忽略，仅返回 `view_ids`对应的结果。 |
| `view_ids` | `list<string>` | 可选 | 视图 ID 列表，用于查询指定视图 ID 对应的视图配置信息。若指定了该参数，其他筛选条件将不会生效。 |
| `created_by` | string | 可选 | 创建者 ID，用于筛选指定用户创建的视图信息。未传 `view_ids` 时，可与 `view_name` 组合筛选；传入 `view_ids` 后其他筛选不生效。 |
| `created_at` | object | 可选 | 创建时间（支持时间区间查询，可不传截止时间，代表至今） |
| `page_size` | int64 | 可选 | 分页大小，最大页大小是10，默认为10 |
| `page_num` | int64 | 可选 | 页码，默认为1 |
| `is_query_quick_filter` | boolean | 可选 | 是否查询快捷筛选，默认为 `false`。当设置为 `true` 时，接口将返回包含快捷筛选条件的视图信息；设置为 `false`时，则不返回。 |

#### `created_at` 的字段

| 参数 | 类型 | 是否必须 | 说明 |
| --- | --- | --- | --- |
| `end` | int64 | 可选 | 结束时间，毫秒精度；不传表示至今。 |
| `start` | int64 | 可选 | 开始时间，毫秒精度。 |

<a id="返回参数"></a>

## 返回参数

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `data` | `list<object>` | 视图信息，遵循[FixView](../formats/数据结构汇总.md#65b5b377)格式规范 |
| `pagination` | object | 分页信息 |
| `err` | object | 请求成功时返回空值，请求失败时返回实际错误信息。 |
| `err_msg` | string | 请求成功时返回空值，请求失败时返回实际错误信息。 |
| `err_code` | int32 | 请求成功时返回0，请求失败返回实际错误码。 |

### `data` 的字段

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `view_id` | string | 视图 ID |
| `view_url` | string | 视图的 URL 地址，用于访问或标识该视图的具体位置 |
| `name` | string | 视图名称 |
| `view_type` | int32 | 视图的类型，支持的取值如下所示。<br>- `0`：未知类型；<br>- `1`：条件视图；<br>- `2`：固定视图。 |
| `system_view` | int32 | 标识视图是否为系统视图。支持的取值如下所示。<br>- `1`：系统视图；<br>- `2`：非系统视图。 |
| `collaborators` | `list<string>` | 协作者列表 |
| `quick_filters` | `list<object>` | 快捷筛选条件，入参 `is_query_quick_filter` 为 `true` 时返回。 |
| `auth` | int32 | 视图的权限状态，支持的取值如下所示。<br>- `1`：开放状态；<br>- `2`：关闭状态。 |
| `created_at` | int64 | 创建时间，毫秒精度。 |
| `created_by` | string | 创建人 user_key |

### `data.quick_filters` 的字段

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `quick_filter_id` | string | 快筛id |
| `quick_filter_name` | string | 快筛名称 |

### `pagination` 的字段

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `total` | int64 | 本次视图列表查询的分页总数。 |
| `page_num` | int64 | 当前页码，表示返回的数据属于分页结果的第几页。 |
| `page_size` | int64 | 每页返回的数据条目数量，表示当前分页查询中每页包含的记录数。 |

### `err` 的字段

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `code` | int32 | 部分场景下，透出更详细错误对应的错误码。 |
| `msg` | string | 部分场景下，透出更详细的错误描述。 |
| `log_id` | string | 报错场景下的调用链标识符，用于追踪错误发生时的完整调用链路，便于日志记录和问题排查。 |
