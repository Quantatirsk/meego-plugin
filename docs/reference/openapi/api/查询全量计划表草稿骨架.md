# 查询全量计划表草稿骨架

读取计划表草稿的树形骨架，取得每一行的 UUID 与父子关系。无权限的实例不会返回，因此“全量”以调用人的可见范围为限。

## 从骨架读取草稿详情

递归遍历 `data.wbs_draft_structure` 的 `current_row` 与 `children`，收集需要查询的 UUID，再调用[查询计划表草稿数据行详细信息](查询计划表草稿数据行详细信息.md)，每次最多 200 行。骨架只提供结构；名称、排期和负责人等数据需通过行详情接口读取。

`current_row.type` 是行的展示类型：`General` 为普通数据行，`Creator` 为新建按钮行，`GridGroup` 为分组行；共享定义中的 `CardGroup` 仅用于视图表格，不用于计划表。它不同于行详情中的业务类型 `node`、`sub_instance`、`sub_task`。

插件权限见[权限管理](../guides/权限管理.md)中的“工作项”。

<a id="请求说明"></a>

## 请求说明

**请求方式**：`POST`
**请求地址**：`/open_api/work_item/wbs_draft/structure/query`

<a id="请求参数"></a>

## 请求参数

<a id="a3c53a27"></a>

### 请求头

接口调用的 Header 配置详见[Header](../guides/OpenAPI概述.md#a8e43b86)

<a id="Body"></a>

### 请求体

按请求参数契约显式传入 `draft_id`，定位要读取的草稿。

| 参数 | 类型 | 是否必须 | 说明 |
| --- | --- | --- | --- |
| project_key | string | 必须 | 空间 ID（project_key）。<br>- 空间 ID（project_key），在飞书项目空间双击空间名称获取。 |
| work_item_id | int64 | 必须 | 工作项 id |
| draft_id | string | 必须 | 草稿 id |

<a id="返回参数"></a>

## 返回参数

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `wbs_draft_structure` | object | 草稿树结构 |
| `draft_id` | string | 草稿 id |
| `err` | object | 对部分错误会在这里进行更详细的错误描述，可协助日志记录和问题反馈。 |
| `err_msg` | string | 错误信息。 |
| `err_code` | int32 | 错误码。 |

### `wbs_draft_structure`

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `children` | `list<object>` | 子行 |
| `current_row` | object | 当前行 |

### `wbs_draft_structure.current_row`

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `type` | string | 行类型（节点、子工作项、子任务）<br>Creator,新建按钮行，含视图、计划表 的 添加按钮<br>General,普通数据行；含视图、计划表 的 节点/任务/子工作项/子流程 等<br>CardGroup,表格 card 形式分组； 视图表格使用，计划表不使用<br>GridGroup,表格 grid 形式分组； 计划表与视图表格使用 |
| `uuid` | string | 行uuid，唯一标识 |

### `err`

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `code` | int32 | 部分场景下，透出更详细错误对应的错误码。 |
| `msg` | string | 部分场景下，透出更详细的错误描述。 |
| `log_id` | string | 报错场景下的调用链标识符，用于追踪错误发生时的完整调用链路，便于日志记录和问题排查。 |
