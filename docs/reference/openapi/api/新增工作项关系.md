# 新增工作项关系

创建一条工作项关系配置，指定来源空间及类型，并列出允许关联的目标空间和类型。该配置既可用于同空间关系，也可用于跨空间关系；创建成功后返回 `data.relation_id`。

## 使用前确认

- 创建配置需要管理员权限；权限不足时原文示例返回 `10001`。
- 每个目标都必须填写 `project_key` 和 `work_item_type_key`，同空间关系也不能省略目标空间。
- 关系名称需要可用且不重复，否则返回 `50006`。
- 本接口请求参数没有 `relation_type`，不要将查询接口中的父子关系枚举直接当作创建参数。

对应的平台功能介绍详见[关系管理](https://project.feishu.cn/1ykiuvvj/se3xal6e)。对应的权限申请在**权限管理-工作项实例**分类下，相关功能介绍详见[权限管理](../guides/权限管理.md)。

<a id="请求说明"></a>

## 请求说明

- 请求方式：POST

- 请求地址：/open_api/work_item/relation/create

<a id="请求参数"></a>

## 请求参数

<a id="header"></a>

### Header

接口调用的 Header 配置详见 [Header](../guides/OpenAPI概述.md#a8e43b86)。

<a id="Body"></a>

### Body

| 参数 | 类型 | 是否必须 | 说明 |
| --- | --- | --- | --- |
| `project_key` | string | 必须 | [说明](#parameter-note-1) |
| `work_item_type_key` | string | 必须 | 工作项类型，可以从[获取空间下工作项类型](获取空间下工作项类型.md)接口获取。 |
| `name` | string | 必须 | 关系名称 |
| `relation_details` | `list<object>` | 必须 | 工作项关系详情列表，`project_key` 和 `work_item_type_key` 必填。 |

<a id="parameter-note-1"></a>

**project_key：说明**

空间 ID（project_key），或者空间域名（simple_name）。
- 空间 ID（project_key），在飞书项目空间双击空间名称获取。
- 空间域名（simple_name），`simple_name` 一般在飞书项目空间 URL 中获取。例如空间 URL 为 “https://project.feishu.cn/doc/overview”，则 `simple_name`为 “doc”。

#### `relation_details` 的字段

| 参数 | 类型 | 是否必须 | 说明 |
| --- | --- | --- | --- |
| `project_key` | string | 必须 | 关联空间的空间 ID。如果是同空间关联，仍需要填写该空间的 `project_key`。 |
| `project_name` | string | 可选 | 关联空间名称。 |
| `work_item_type_key` | string | 必须 | 关联工作项类型 key。 |
| `work_item_type_name` | string | 可选 | 关联工作项类型名称。 |

<a id="返回参数"></a>

## 返回参数

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `data` | object | 返回新增的工作项关系 uuid |
| `err` | object | 请求成功时返回空值，请求失败时返回实际错误信息。 |
| `err_msg` | string | 请求成功时返回空值，请求失败时返回实际错误信息。 |
| `err_code` | int32 | 请求成功时0，请求失败返回实际错误码。 |

### `data` 的字段

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `relation_id` | string | 新增的工作项关系 uuid。 |

### `err` 的字段

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `code` | int32 | 部分场景下，透出更详细错误对应的错误码。 |
| `msg` | string | 部分场景下，透出更详细的错误描述。 |
| `log_id` | string | 报错场景下的调用链标识符，用于追踪错误发生时的完整调用链路，便于日志记录和问题排查。 |

<a id="请求示例"></a>

## 请求示例

### 新增同空间工作项关系

```json
{
  "name": "\u540c\u7a7a\u95f4\u9700\u6c42-\u9700\u6c42\u5173\u8054",
  "project_key": "658b9f05809f644bxxxxx",
  "work_item_type_key": "story",
  "relation_details": [
    {
      "project_key": "658b9f05809f644bxxxxx",
      "work_item_type_key": "story"
    }
  ]
}
```

### 新增跨空间工作项关系

```json
{
  "project_key": "64f7f57d89aa3bb71bfdxxxx",
  "work_item_type_key": "story",
  "name": "\u8de8\u7a7a\u95f4\u9700\u6c42-\u7f3a\u9677\u5173\u8054",
  "relation_details": [
    {
      "project_key": "658b9f05809f644bxxxx",
      "project_name": "\u7a7a\u95f4 A",
      "work_item_type_key": "issue",
      "work_item_type_name": "\u7f3a\u9677"
    }
  ]
}
```
