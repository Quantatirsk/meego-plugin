# 删除工作项

删除指定空间、指定类型下的单个工作项实例。接口授权位于[权限管理](../guides/权限管理.md)的“工作项”分类。要保留实例并暂停推进时，应查看[终止与恢复工作项](终止与恢复工作项.md)的独立行为。

## 定位要删除的实例

空间、类型、实例 ID 均通过路径传入，本篇没有请求体参数。三个标识必须指向同一实例；空间与实例不匹配会返回 `20014`，类型错误会返回 `20003`，跨租户删除会返回 `1000051195`。

成功响应只确认删除结果，不返回被删除实例的详情。`30005` 表示实例不存在或 ID 不正确；本篇未承诺重复删除返回成功，不能依赖幂等成功响应。

<a id="请求说明"></a>

## 请求说明

**请求方式**：`DELETE`

**请求地址**：`/open_api/:project_key/work_item/:work_item_type_key/:work_item_id`

<a id="请求参数"></a>

## 请求参数

<a id="header"></a>

### 请求头

接口调用的 Header 配置详见 [Header](../guides/OpenAPI概述.md#a8e43b86)。

<a id="Path"></a>

### 路径参数

| 参数                 | 类型     | 是否必须 | 说明                                                                                |
| -------------------- | -------- | -------- | ----------------------------------------------------------------------------------- |
| `project_key`        | `string` | 必须     | 空间 ID（project_key），或者空间域名（simple_name）。 [详细说明](#field-note-1)     |
| `work_item_type_key` | `string` | 必须     | 工作项类型，创建工作项时自动生成，通过[获取空间下工作项类型](获取空间下工作项类型.md)接口获取。 |
| `work_item_id`       | `string` | 必须     | 工作项实例 ID，在工作项实例详情中，展开右上角 **··· \> ID** 获取。                  |

<a id="field-note-1"></a>

**project_key**

空间 ID（project_key），或者空间域名（simple_name）。

- 空间 ID（project_key），在飞书项目空间双击空间名称获取。
- 空间域名（simple_name），`simple_name` 一般在飞书项目空间 URL 中获取。例如空间 URL 为 “https://project.feishu.cn/doc/overview”，则 `simple_name`为 “doc”。

<a id="返回参数"></a>

## 返回参数

| 参数       | 类型     | 说明                                             |
| ---------- | -------- | ------------------------------------------------ |
| `err`      | `object` | 请求成功时返回空值，请求失败时返回实际错误信息。 |
| `err_msg`  | `string` | 请求成功时返回空值，请求失败时返回实际错误信息。 |
| `err_code` | `int32`  | 请求成功时0，请求失败返回实际错误码。            |

### `err`

| 参数     | 类型     | 说明                                                                                 |
| -------- | -------- | ------------------------------------------------------------------------------------ |
| `code`   | `int32`  | 部分场景下，透出更详细错误对应的错误码。                                             |
| `msg`    | `string` | 部分场景下，透出更详细的错误描述。                                                   |
| `log_id` | `string` | 报错场景下的调用链标识符，用于追踪错误发生时的完整调用链路，便于日志记录和问题排查。 |

## 请求示例

```http
DELETE /open_api/:project_key/work_item/:work_item_type_key/:work_item_id
```

## 返回示例

```json
{
  "data": {},

```

```json
{
  "err_code": 30005,
  "err_msg": "WorkItem Not Found",
  "err": {
    "code": 30005,
    "msg": "workitem_id: 6439876004",
    "log_id": "20251027211601C9DD92602A32863Cxxxx"
  }
}
```
