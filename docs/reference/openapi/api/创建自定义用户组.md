# 创建自定义用户组

在指定空间创建自定义用户组，同时加入首批用户成员。接口权限位于[权限管理](../guides/权限管理.md)的“用户”分类，调用必须使用用户访问凭证。

## 创建条件与后续操作

名称不能为空、不能超过 250 个字符，也不能与已有用户组或系统用户组重名。系统保留名称包含“空间管理员”“空间成员”及对应英文名称；名称中不能包含 `/` 等不支持的字符。

首批 `users` 必填且不能为空，最多 100 人，仅支持用户成员，不支持部门成员；已离职或不存在的用户不能加入。创建成功后保存 `data.id`，后续通过[更新用户组成员](更新用户组成员.md)维护成员，或通过[查询用户组成员](查询用户组成员.md)读取结果。

<a id="注意事项"></a>

凭证获取方式见[获取用户访问凭证 user_access_token](../guides/获取访问凭证.md#3df3fccd)。

<a id="请求说明"></a>

## 请求说明

**请求方式**：`POST`

**请求地址**：`/open_api/:project_key/user_group`

<a id="请求参数"></a>

## 请求参数

<a id="header"></a>

### 请求头

接口调用的 Header 配置详见 [Header](../guides/OpenAPI概述.md#a8e43b86)。

<a id="Path"></a>

### 路径参数

| 参数          | 类型     | 是否必须 | 说明                                                                            |
| ------------- | -------- | -------- | ------------------------------------------------------------------------------- |
| `project_key` | `string` | 必须     | 空间 ID（project_key），或者空间域名（simple_name）。 [详细说明](#field-note-1) |

<a id="field-note-1"></a>

**project_key**

空间 ID（project_key），或者空间域名（simple_name）。

- 空间 ID（project_key），在飞书项目空间双击空间名称获取。
- 空间域名（simple_name），`simple_name` 一般在飞书项目空间 URL 中获取。例如空间 URL 为 “https://project.feishu.cn/doc/overview”，则 `simple_name`为 “doc”。

<a id="Body"></a>

### 请求体

| 参数    | 类型           | 是否必须 | 说明                                                                                       |
| ------- | -------------- | -------- | ------------------------------------------------------------------------------------------ |
| `name`  | `string`       | 必须     | 用户组名称 [详细说明](#field-note-2)                                                       |
| `users` | `list<string>` | 必须     | 用户组员工 userKey 列表，单次添加不能超过100个员工。当前仅支持用户成员，不能添加部门成员。 |

<a id="field-note-2"></a>

**name**

用户组名称

- 不能和已存在的用户组名称以及系统用户组名称重复（空间管理员、Space administrators、空间成员、Space members 等等）。
- 不能存在特殊字符，如"/"等，长度不能超过250个字符。

<a id="返回参数"></a>

## 返回参数

成功响应通过 `data.id` 返回新用户组 ID，其余错误字段位于响应顶层。

| 参数       | 类型     | 说明                                             |
| ---------- | -------- | ------------------------------------------------ |
| `data.id`       | `string` | 新建的用户组 ID。                                |
| `err`      | `object` | 请求成功时返回空值，请求失败时返回实际错误信息。 |
| `err_msg`  | `string` | 请求成功时返回空值，请求失败时返回实际错误信息。 |
| `err_code` | `int32`  | 请求成功时0，请求失败返回实际错误码。            |

### `err`

| 参数     | 类型     | 说明                                 |
| -------- | -------- | ------------------------------------ |
| `code`   | `int32`  | 部分场景提供更具体的错误码。         |
| `msg`    | `string` | 部分场景提供更具体的错误说明。       |
| `log_id` | `string` | 调用链标识，用于日志追踪和错误排查。 |
