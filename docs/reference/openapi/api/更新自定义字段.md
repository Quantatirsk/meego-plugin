# 更新自定义字段

按 `field_key` 修改已有自定义字段的名称、选项、默认值、授权范围等配置。修改复合字段时，应先区分父字段与子字段；级联选项更新通过逐项 `action` 表达新增、修改和删除。

## 使用前确认

- 复合父字段仅允许改 `field_name`、`field_alias`、`help_description`；子字段可以正常更新属性。
- 选项 `action`：`0` 新增、`1` 修改、`2` 删除。
- `field_value` 与 `team_option` 互斥；团队范围仅适用于级联单选和级联多选。
- 字段名称及描述最多 255 字符；别名、名称需要满足不重复的要求。
- 原文将省略 `authorized_roles` 描述为默认任何人，提交前应明确期望的授权范围。

对应的平台功能介绍详见[字段配置](https://project.feishu.cn/1ykiuvvj/17mi85qv)。对应的权限申请在**权限管理-配置**分类下，相关功能介绍详见 [权限管理](../guides/权限管理.md)。

<a id="注意事项"></a>

## 注意事项

1. 工作项关系字段默认数据可见范围为固定数据范围，不支持修改条件数据范围。

2. 默认值限制见[默认值说明](#parameter-note-4)。

3. 暂不支持修改字段有效性（默认有效）。

4. 不支持更新工作项类型、创建者、提出时间、完成时间、业务线字段。

5. 不支持投票字段。

6. 修改/添加子选项时，`parent_value` 为必选。

<a id="请求说明"></a>

## 请求说明

- 请求方式：PUT

- 请求地址：/open_api/:project_key/field/:work_item_type_key

<a id="请求参数"></a>

## 请求参数

<a id="header"></a>

### Header

接口调用的 Header 配置详见 [Header](../guides/OpenAPI概述.md#a8e43b86)。

<a id="Path"></a>

### Path

| 参数 | 类型 | 是否必须 | 说明 |
| --- | --- | --- | --- |
| `project_key` | string | 必须 | [说明](#parameter-note-1) |
| `work_item_type_key` | string | 必须 | 工作项类型，系统自动生成，可以从[获取空间下工作项类型](获取空间下工作项类型.md)接口获取。 |

<a id="parameter-note-1"></a>

**project_key：说明**

空间 ID（project_key），或者空间域名（simple_name）。
- 空间 ID（project_key），在飞书项目空间双击空间名称获取。
- 空间域名（simple_name），`simple_name` 一般在飞书项目空间 URL 中获取。例如空间 URL 为 “https://project.feishu.cn/doc/overview”，则 `simple_name`为 “doc”。

<a id="Body"></a>

### Body

| 参数 | 类型 | 是否必须 | 说明 |
| --- | --- | --- | --- |
| `field_key` | string | 必须 | [说明](#parameter-note-2) |
| `field_name` | string | 可选 | 字段名称 |
| `field_value` | `list<FieldValue>` | 可选 | [说明](#parameter-note-3) |
| `free_add` | int64 | 可选 | 是否允许用户添加选项，适用于单选、多选、级联单选 和 级联多选 类型的字段，不传默认为 `2`（否）。支持的取值如下所示。<br>- `1`：是；<br>- `2`：否。 |
| `work_item_relation_uuid` | string | 可选 | 工作项关系 ID，可通过[获取字段信息](获取字段信息.md)接口获取。当字段类型为 单选关联工作项或多选工作项时必传。 |
| `default_value` | 按字段类型 | 可选 | [说明](#parameter-note-4) |
| `field_alias` | string | 可选 | 字段别名，不能够与同工作项类型其他字段重复 |
| `help_description` | string | 可选 | 帮助说明 |
| `authorized_roles` | `list<string>` | 可选 | 授权角色列表，用于指定可以访问或操作该字段的角色或系统人员。若未传入则默认为「任何人」。支持传入角色 key 或系统人员 key，例如 `_master`（管理员）、`_owner`（创建人）、`_role`（需求相关人）。 |
| `team_option` | object | 可选 | [说明](#parameter-note-5) |

<a id="parameter-note-2"></a>

**field_key：说明**

字段的唯一标识符，用于区分不同字段，可通过[获取字段信息](获取字段信息.md)接口获取。对于复合字段有以下两种情况：
- 当传入的是复合字段的父字段时，只能修改 `field_name`、`field_alias` 和 `help_description`；
- 当传入的是复合字段的子字段时，可以正常更新所有属性。

<a id="parameter-note-3"></a>

**field_value：说明**

选项值，值结构参见[FieldValue](../formats/数据结构汇总.md#530838f4)，支持单选/多选/级联单选/级联多选/单选按钮等结构。
注：该属性和 `team_option` 互斥，不能同时填，否则报错。

<a id="parameter-note-4"></a>

**default_value：说明**

字段的默认值，若传入则默认值为「展示统一默认值」。
不同字段类型的默认值结构不同，具体值结构参考[字段与属性解析格式](../formats/字段与属性解析格式.md)。附件、系统外信号、多值系统外信号类型字段暂不支持设置默认值。

<a id="parameter-note-5"></a>

**team_option：说明**

团队范围，遵循[TeamOption](../formats/数据结构汇总.md#b88f37fb)结构规范。
注意：
- 只能应用于级联单选和级联多选字段。
- 该属性和 `field_value` 互斥，不能同时填，否则报错。

#### `team_option` 的字段

| 参数 | 类型 | 是否必须 | 说明 |
| --- | --- | --- | --- |
| `team_data_scopes` | `list<object>` | 可选 | 遵循[TeamDataScope](../formats/数据结构汇总.md#6e4a484d)结构规范。当 `team_mode` = `custom`时，指定团队范围。 |
| `team_mode` | string | 可选 | [说明](#parameter-note-6) |

<a id="parameter-note-6"></a>

**team_mode：说明**

团队模式，用于指定级联单选或级联多选字段的团队范围配置。支持的取值如下所示。
- `all`：所有团队；
- `custom`：自定义团队范围（需配合 `team_data_scopes`使用）。

#### `team_option.team_data_scopes` 的字段

| 参数 | 类型 | 是否必须 | 说明 |
| --- | --- | --- | --- |
| `team_id` | string | 可选 | 团队 ID |
| `cascade` | boolean | 可选 | 是否级联。级联会联动带上下级团队。支持的取值如下所示。<br>- `true`：级联；<br>- `false`：非级联。 |

## 返回参数

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `err` | object | 请求成功时返回空值，请求失败时返回实际错误信息。 |
| `err_msg` | string | 请求成功时返回空值，请求失败时返回实际错误信息。 |
| `err_code` | int32 | 请求成功时0，请求失败返回实际错误码。 |

### `err` 的字段

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `code` | int32 | 部分场景下，透出更详细错误对应的错误码。 |
| `msg` | string | 部分场景下，透出更详细的错误描述。 |
| `log_id` | string | 报错场景下的调用链标识符，用于追踪错误发生时的完整调用链路，便于日志记录和问题排查。 |

<a id="请求示例"></a>

## 请求示例

### 更新级联选项

**请求路径**：`PUT /open_api/4789056798xxxx/field/story`

```json
{
  "field_key": "field_3bf239",
  "field_value": [
    {
      "label": "111",
      "value": "c7uqvx5j1",
      "action": 1
    },
    {
      "value": "3hj83kft4",
      "action": 2
    },
    {
      "label": "kkkk",
      "value": "kl3h3kft4",
      "action": 0
    },
    {
      "label": "option_u-0",
      "value": "b7ny0krc1",
      "action": 1,
      "parent_value": "bjgy0krc"
    },
    {
      "label": "option_u-9",
      "value": "b7ny0krc19",
      "action": 0,
      "parent_value": "b7ny0krc"
    }
  ]
}
```

### 更新团队范围

**请求路径**：`PUT /open_api/4789056798xxxx/field/story`

```json
{
  "field_key": "field_c35b69",
  "team_option": {
    "team_data_scopes": [
      {
        "team_id": "747039911773106xxxx",
        "cascade": true
      },
      {
        "team_id": "747079387064580xxxx",
        "cascade": true
      }
    ],
    "team_mode": "custom"
  }
}
```

### 更新数字字段配置

**请求路径**：`PUT /open_api/4789056798xxxx/field/story`

```json
{
  "field_key": "field_3bf239",
  "number_config": {
    "scaling_ratio": "0.01",
    "display_digits": -1,
    "symbol_setting": {
      "display": "custom",
      "value": "%",
      "layout": "right"
    }
  }
}
```
