# 删除流程角色配置

从指定工作项类型删除流程角色配置。请求使用 `POST`，在 Body 中传角色 ID 或对接标识；被流程节点引用的角色不能直接删除。

## 使用前确认

`role_id` 与 `role_alias` 至少填写一个，二者同时出现时按 ID 定位。返回 `20093` 表示角色仍在流程中使用，应根据错误信息检查引用节点；返回 `20006` 表示角色不存在或已经删除。

对应的平台功能介绍详见[常见问题：角色管理](https://project.feishu.cn/1ykiuvvj/py7go937)。对应的权限申请在 **权限管理-配置** 分类下，相关功能介绍详见[权限管理](../guides/权限管理.md)。

<a id="请求说明"></a>

## 请求说明

- 请求方式：POST

- 请求地址：/open_api/:project_key/flow_roles/:work_item_type_key/delete_role

<a id="请求参数"></a>

## 请求参数

<a id="header"></a>

### Header

接口调用的 Header 配置详见[Header](../guides/OpenAPI概述.md#a8e43b86)。

<a id="Path"></a>

### Path

| 参数 | 类型 | 是否必须 | 说明 |
| --- | --- | --- | --- |
| `project_key` | string | 必须 | [说明](#parameter-note-1) |
| `work_item_type_key` | string | 必须 | 工作项类型，系统自动生成，可以从[获取空间下工作项类型](获取空间下工作项类型.md)接口获取。 |

<a id="parameter-note-1"></a>

**project_key：说明**

空间 ID（project_key），或者空间域名（simple_name）。
- 空间 ID（project_key），在飞书项目空间双击空间名称获取。
- 空间域名（simple_name），`simple_name` 一般在飞书项目空间 URL 中获取。例如空间 URL 为 “https://project.feishu.cn/doc/overview”，则 `simple_name`为 “doc”。

<a id="Body"></a>

### Body

| 参数 | 类型 | 是否必须 | 说明 |
| --- | --- | --- | --- |
| `role_id` | string | 可选 | 流程角色 ID，可以通过[获取流程角色配置详情](获取流程角色配置详情.md)获取。<br>与 `role_alias`必填一个，两个都传入则使用角色 ID。 |
| `role_alias` | string | 可选 | 角色对接标识，可以通过[获取流程角色配置详情](获取流程角色配置详情.md)获取。<br>与 `role_id`必填一个，两个都传入则使用角色 ID。 |

<a id="返回参数"></a>

## 返回参数

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `err` | object | 请求成功时返回空值，请求失败时返回实际错误信息。 |
| `err_msg` | string | 请求成功时返回空值，请求失败时返回实际错误信息。 |
| `err_code` | int32 | 请求成功时0，请求失败返回实际错误码。 |

### `err` 的字段

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `code` | int32 | 部分场景下，透出更详细错误对应的错误码。 |
| `msg` | string | 部分场景下，透出更详细的错误描述。 |
| `log_id` | string | 报错场景下的调用链标识符，用于追踪错误发生时的完整调用链路，便于日志记录和问题排查。 |

<a id="请求示例"></a>

## 请求示例

**请求路径**：`POST /open_api/68382b399de4b0ec6c5axxxx/flow_roles/story/delete_role`

```json
{
  "role_id": "5727769"
}
```

<a id="返回示例"></a>

## 返回示例

### 请求成功示例

```json
{
  "err": {},
  "err_code": 0,
  "err_msg": "",
  "data": {}
}
```

### 错误返回示例

以下错误原因为传入的 `role_id` 对应角色不存在或者已经被删除。

```json
{
  "err_code": 20006,
  "err_msg": "Invalid Param",
  "err": {
    "code": 20006,
    "msg": "role_id `{5727769}` not exists",
    "log_id": "2025110615412103B2359971E124F8xxxx"
  }
}
```
