# 获取视图下工作项列表（非全景视图）

分页读取非全景视图中的工作项 ID 列表，并可应用已配置的快捷筛选。返回视图元信息、`work_item_id_list` 和分页总数；需要完整工作项字段时，可再调用详情接口。

## 使用前确认

单页最多 200 条，页码从 1 开始。此接口不支持全景视图，全景场景使用[获取视图下工作项列表（全景视图）](获取视图下工作项列表（全景视图）.md)。查询数量超过 20 万会失败，应增加筛选条件缩小结果范围。

对应的平台功能介绍详见[视图介绍](https://project.feishu.cn/1ykiuvvj/4w2iz8d8)。对应的权限申请在 权限管理-视图 分类下，相关功能介绍详见 [权限管理](../guides/权限管理.md)。

<a id="请求说明"></a>

## 请求说明

- 请求方式：GET

- 请求地址：/open_api/:project_key/fix_view/:view_id

<a id="请求参数"></a>

## 请求参数

<a id="header"></a>

### Header

接口调用的 Header 配置详见 [Header](../guides/OpenAPI概述.md#a8e43b86)。

<a id="Path"></a>

### Path

| 参数 | 类型 | 是否必须 | 说明 |
| --- | --- | --- | --- |
| `project_key` | string | 必须 | [说明](#parameter-note-1) |
| `view_id` | string | 必须 | 非全景视图 ID，从对应视图的浏览器 URL 末段取得。 |

<a id="parameter-note-1"></a>

**project_key：说明**

空间 ID（project_key），或者空间域名（simple_name）。
- 空间 ID（project_key），在飞书项目空间双击空间名称获取。
- 空间域名（simple_name），`simple_name` 一般在飞书项目空间 URL 中获取。例如空间 URL 为 “https://project.feishu.cn/doc/overview”，则 `simple_name`为 “doc”。

<a id="Query"></a>

### Query

| 参数 | 类型 | 是否必须 | 说明 |
| --- | --- | --- | --- |
| `page_size` | int32 | 可选 | 每页数据，最大200 |
| `page_num` | int32 | 可选 | 分页页码，从1开始，默认为1 |
| `quick_filter_id` | string | 可选 | 快捷筛选的标识 ID，用于快速筛选视图列表中的数据。可通过[获取某工作项的视图列表及配置信息](获取视图列表及配置信息.md)接口获取。 |

<a id="返回参数"></a>

## 返回参数

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `data` | object | 视图信息 |
| `pagination` | object | 分页信息 |
| `err` | object | 请求成功时返回空值，请求失败时返回实际错误信息。 |
| `err_msg` | string | 请求成功时返回空值，请求失败时返回实际错误信息。 |
| `err_code` | int32 | 请求成功时返回0，请求失败返回实际错误码。 |

### `data` 的字段

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `view_id` | string | 视图 ID。 |
| `name` | string | 视图名称。 |
| `created_by` | string | 创建人 user_key。 |
| `created_at` | int64 | 创建时间，毫秒精度。 |
| `modified_by` | string | 最后一次修改人 user_key。 |
| `work_item_id_list` | `list<int64>` | 固定视图包含的工作项 ID 列表。 |
| `editable` | boolean | 当前视图是否可编辑。 |

### `pagination` 的字段

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `total` | int64 | 视图中工作项的总数。 |
| `page_num` | int64 | 当前页码，表示返回的数据属于分页结果的第几页。 |
| `page_size` | int64 | 每页返回的数据条目数量，表示当前分页查询中每页包含的记录数。 |

### `err` 的字段

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `code` | int32 | 部分场景下，透出更详细错误对应的错误码。 |
| `msg` | string | 部分场景下，透出更详细的错误描述。 |
| `log_id` | string | 报错场景下的调用链标识符，用于追踪错误发生时的完整调用链路，便于日志记录和问题排查。 |

<a id="请求示例"></a>

## 请求示例

### 普通查询

```http
GET /open_api/6437890344xxxx/fix_view/DJ4xxxx?page_size=50&page_num=1
```

### 查询指定快筛条件的结果

```http
GET /open_api/6437890344xxxx/fix_view/DJ4xxxx?page_size=50&page_num=1&quick_filter_id=REPLACE_WITH_QUICK_FILTER_ID
```
