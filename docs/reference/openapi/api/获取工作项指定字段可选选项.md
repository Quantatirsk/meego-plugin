# 获取工作项指定字段可选选项

读取当前用户在某个工作项实例、某个字段上实际可选的选项，排除已禁用或不满足可见条件的选项。接口权限位于[权限管理](../guides/权限管理.md)的“工作项实例”分类。

## 按实例读取选项

空间、工作项类型、实例 ID 和 `field_key` 均必填，类型必须与实例匹配。此结果带用户和实例上下文，不等于[字段配置](获取字段信息.md)中的全部静态选项。

响应的 `options[].value` 是选项值，`label` 用于展示；级联字段还需读取 `children`、`level_mode` 和 `level_class`。`free_add` 表示当前字段是否允许用户自行添加选项。

分页入口是 `first_option_key`，返回通过 `has_more` 指示是否还有选项。本篇没有定义 `page_size` 或如何从末项计算下一页起点，不应擅自拼出常规页码协议。

<a id="请求说明"></a>

## 请求说明

**请求方式**：`POST`

**请求地址**：`/open_api/work_item/field/options`

<a id="请求参数"></a>

## 请求参数

<a id="header"></a>

### 请求头

接口调用的 Header 配置详见 [Header](../guides/OpenAPI概述.md#a8e43b86)。

<a id="Body"></a>

### 请求体

| 参数                 | 类型     | 是否必须 | 说明                                                                            |
| -------------------- | -------- | -------- | ------------------------------------------------------------------------------- |
| `work_item_id`       | `int64`  | 必须     | 工作项实例 ID，在工作项实例详情中，展开右上角 **··· \> ID**获取。               |
| `project_key`        | `string` | 必须     | 空间 ID（project_key），或者空间域名（simple_name）。 [详细说明](#field-note-1) |
| `work_item_type_key` | `string` | 必须     | 工作项类型key。需要与 `work_item_id`对应实例匹配。                              |
| `field_key`          | `string` | 必须     | 字段key                                                                         |
| `first_option_key`   | `string` | 可选     | 查询的第一个选项key（用于分页使用）                                             |

<a id="field-note-1"></a>

**project_key**

空间 ID（project_key），或者空间域名（simple_name）。

- 空间 ID（project_key），在飞书项目空间双击空间名称获取。
- 空间域名（simple_name），`simple_name` 一般在飞书项目空间 URL 中获取。例如空间 URL 为 “https://project.feishu.cn/doc/overview”，则 `simple_name`为 “doc”。

<a id="返回参数"></a>

## 返回参数

| 参数       | 类型     | 说明                                                               |
| ---------- | -------- | ------------------------------------------------------------------ |
| `data`     | `object` | 返回的选项                                                         |
| `err`      | `object` | 对部分错误会在这里进行更详细的错误描述，可协助日志记录和问题反馈。 |
| `err_msg`  | `string` | 错误信息。                                                         |
| `err_code` | `int32`  | 错误码。                                                           |

### `data`

| 参数          | 类型           | 说明                 |
| ------------- | -------------- | -------------------- |
| `options`     | `list<object>` | 选项                 |
| `free_add`    | `boolean`      | 是否允许用户添加选项 |
| `has_more`    | `boolean`      | 分页使用             |
| `field_key`   | `string`       | 字段key              |
| `field_name`  | `string`       | 字段名称             |
| `field_type`  | `string`       | 字段类型             |
| `level_mode`  | `string`       | 级联字段选项类型     |
| `field_alias` | `string`       | 字段别名             |
| `level_class` | `string`       | 级联字段可选层级     |

### `data.options`

| 参数                 | 类型           | 说明                                                                                                                                                  |
| -------------------- | -------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------- |
| `label`              | `string`       | 选项标签                                                                                                                                              |
| `value`              | `string`       | 选项值                                                                                                                                                |
| `children`           | `list<object>` | 子选项，当字段类型为级联单选/多选时存在，可参考[级联单选/多选字段的option数据结构](https://project.feishu.cn/b/helpcenter/1p8d7djs/k6nbktn1#bf019a32) |
| `color`              | `string`       | 选项颜色                                                                                                                                              |
| `order`              | `int64`        | 选项顺序                                                                                                                                              |
| `is_disabled`        | `int64`        | 是否禁用                                                                                                                                              |
| `is_visibility`      | `int64`        | 是否可见                                                                                                                                              |
| `work_item_type_key` | `string`       |                                                                                                                                                       |

### `err`

| 参数     | 类型     | 说明                                                                                 |
| -------- | -------- | ------------------------------------------------------------------------------------ |
| `code`   | `int32`  | 部分场景下，透出更详细错误对应的错误码。                                             |
| `msg`    | `string` | 部分场景下，透出更详细的错误描述。                                                   |
| `log_id` | `string` | 报错场景下的调用链标识符，用于追踪错误发生时的完整调用链路，便于日志记录和问题排查。 |
