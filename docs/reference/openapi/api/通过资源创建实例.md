# 通过资源创建实例

以已有资源库实例为基础创建对应工作项实例。工作项须先开启资源库，并已通过[创建资源实例](创建工作项资源库.md)等方式准备资源。接口授权位于[权限管理](../guides/权限管理.md)的“工作项”分类。

## 资源值与创建值的关系

路径中的 `work_item_id` 指向来源资源，响应的 `data.work_item_id` 则是新创建实例，二者用途不同。请求可补充名称、流程模板和字段值；模板省略时使用该类型第一个流程模板。

资源字段和资源角色可能导致本次传入的创建值被忽略。如果名称属于资源字段，传入的顶层 `name` 也会被忽略。创建成功后除保存新 ID，还应检查 `ignore_create_info.field_keys` 与 `ignore_create_info.role_ids`，确认哪些值未按请求写入。

<a id="请求说明"></a>

## 请求说明

**请求方式**：`POST`

**请求地址**：`/open_api/work_item/resource/:project_key/:work_item_id/create_instance`

<a id="请求参数"></a>

## 请求参数

<a id="header"></a>

### 请求头

接口调用的 Header 配置详见 [Header](../guides/OpenAPI概述.md#a8e43b86)。

<a id="Path"></a>

### 路径参数

| 参数           | 类型     | 是否必须 | 说明                                                                            |
| -------------- | -------- | -------- | ------------------------------------------------------------------------------- |
| `project_key`  | `string` | 必须     | 空间 ID（project_key），或者空间域名（simple_name）。 [详细说明](#field-note-1) |
| `work_item_id` | `string` | 必须     | 工作项实例 ID，在工作项实例详情中，展开右上角 **··· \> ID** 获取。              |

<a id="field-note-1"></a>

**project_key**

空间 ID（project_key），或者空间域名（simple_name）。

- 空间 ID（project_key），在飞书项目空间双击空间名称获取。
- 空间域名（simple_name），`simple_name` 一般在飞书项目空间 URL 中获取。例如空间 URL 为 “https://project.feishu.cn/doc/overview”，则 `simple_name`为 “doc”。

<a id="Body"></a>

### 请求体

| 参数                 | 类型           | 是否必须 | 说明                                                                            |
| -------------------- | -------------- | -------- | ------------------------------------------------------------------------------- |
| `work_item_type_key` | `string`       | 必须     | 工作项类型，系统自动生成，可以从[获取空间下工作项类型](获取空间下工作项类型.md)接口获取。   |
| `name`               | `string`       | 可选     | 工作项名称 ，当名称是资源字段时，会默认忽略这个值。                             |
| `template_id`        | `int64`        | 可选     | 模板 ID，未传值时，会选取该工作项类型的第一个流程模版 [详细说明](#field-note-2) |
| `field_value_pairs`  | `list<object>` | 可选     | 遵循[FieldValuePair](../formats/数据结构汇总.md#10c42182)结构规范。                 |

<a id="field-note-2"></a>

**template_id**

模板 ID，未传值时，会选取该工作项类型的第一个流程模版

可以从以下途径获取:

- [获取创建工作项元数据](获取创建工作项元数据.md)接口中的 `template` 字段的 `options` 中获取，选择对应的 `value`。
- [获取工作项下的流程模板列表](获取工作项下的流程模板列表.md)接口的 `template_id`。
- [获取字段信息](获取字段信息.md)接口中的 `template` 字段的 `options` 中获取，选择对应的 `value`。

#### `field_value_pairs`

| 参数                   | 类型     | 是否必须 | 说明                                                                                                                             |
| ---------------------- | -------- | -------- | -------------------------------------------------------------------------------------------------------------------------------- |
| `field_key`            | `string` | 必须     | 待更新的字段 ID，需与 `field_alias`二选一填写，不能同时为空。                                                                    |
| `field_alias`          | `string` | 可选     | 待更新字段的别名                                                                                                                 |
| `field_value`          | `object` | 必须     | 字段值，可参考[字段与属性解析格式](../formats/字段与属性解析格式.md)                                                                       |
| `update_mode`          | `int32`  | 可选     | 字段的更新模式，用于控制字段值的更新方式。支持的取值如下所示。 [详细说明](#field-note-3)                                         |
| `field_type_key`       | `string` | 可选     | 字段类型                                                                                                                         |
| `field_name`           | `string` | 可选     | 字段名称                                                                                                                         |
| `field_value_markdown` | `object` | 可选     | 富文本内容 Markdown 格式，遵循 [Markdown 格式说明](../formats/Markdown%20格式说明.md)结构规范，和`field_value` 二选一，仅富文本格式字段生效 |

<a id="field-note-3"></a>

**update_mode**

字段的更新模式，用于控制字段值的更新方式。支持的取值如下所示。

- `0`：替换模式，提交的字段值将完全替换原有值；
- `1`：更新模式，仅更新提交的字段值，不影响其他字段。

默认值：`0`（替换模式）

#### `field_value_pairs.field_value_markdown`

| 参数                | 类型           | 是否必须 | 说明                      |
| ------------------- | -------------- | -------- | ------------------------- |
| `markdown`          | `string`       | 可选     | 富文本内容 Markdown 格式  |
| `mention_user_keys` | `list<object>` | 可选     | 富文本中 @ 提到的人员信息 |

#### `field_value_pairs.field_value_markdown.mention_user_keys`

| 参数       | 类型     | 是否必须 | 说明                  |
| ---------- | -------- | -------- | --------------------- |
| `id`       | `string` | 可选     | 富文本中对应的人员 id |
| `user_key` | `string` | 可选     | 对应的人员的 user_key |

<a id="返回参数"></a>

## 返回参数

| 参数       | 类型     | 说明                                                                                                        |
| ---------- | -------- | ----------------------------------------------------------------------------------------------------------- |
| `data`     | `object` | 返回创建的工作项实例信息，参见[ResourceCreateInstanceResponseData](../formats/数据结构汇总.md#48dde960)结构规范 |
| `err`      | `object` | 请求成功时返回空值，请求失败时返回实际错误信息。                                                            |
| `err_msg`  | `string` | 请求成功时返回空值，请求失败时返回实际错误信息。                                                            |
| `err_code` | `int32`  | 请求成功时0，请求失败返回实际错误码。                                                                       |

### `data`

| 参数                 | 类型     | 说明                                                                                                            |
| -------------------- | -------- | --------------------------------------------------------------------------------------------------------------- |
| `work_item_id`       | `int64`  | 创建的实例 ID                                                                                                   |
| `ignore_create_info` | `object` | 忽略创建信息，参见[ResourceCreateInstanceResponseDataIgnoreCreateInfo](../formats/数据结构汇总.md#1bf7bf43)结构规范 |

### `data.ignore_create_info`

| 参数         | 类型           | 说明                                                                         |
| ------------ | -------------- | ---------------------------------------------------------------------------- |
| `role_ids`   | `list<string>` | 忽略创建的角色 ID，如果一个角色因为资源角色的原因在创建时被忽略了则会返回。  |
| `field_keys` | `list<string>` | 忽略创建的字段 key，如果一个字段因为资源字段的原因在创建时被忽略了则会返回。 |

### `err`

| 参数     | 类型     | 说明                                                                                 |
| -------- | -------- | ------------------------------------------------------------------------------------ |
| `code`   | `int32`  | 部分场景下，透出更详细错误对应的错误码。                                             |
| `msg`    | `string` | 部分场景下，透出更详细的错误描述。                                                   |
| `log_id` | `string` | 报错场景下的调用链标识符，用于追踪错误发生时的完整调用链路，便于日志记录和问题排查。 |

<a id="请求示例"></a>

## 请求示例

**请求路径**：`POST /open_api/work_item/resource/68382b399de4b0ec6c5axxxx/:work_item_id/create_instance`

```json
{
  "work_item_type_key": "story",
  "template_id": 123123,
  "name": "2333",
  "field_value_pairs": [
    {
      "field_key": "description",
      "field_value": "2333"
    },
    {
      "field_key": "priority",
      "field_value": {
        "value": "xxxxxx"
      }
    },
    {
      "field_key": "role_owners",
      "field_value": [
        {
          "role": "rd",
          "owners": ["testuser"]
        }
      ]
    }
  ]
}
```

## 返回示例

### 请求成功示例

```json
{
  "data": {
    "work_item_id": 1123,
    "ignore_create_info": {
      "field_keys": [],
      "role_ids": []

  },
  "err": {},
```

### 错误返回示例

以下错误原因为传入的字段 `priority` 是一个单选类型字段，但是传入的 `field_value_pairs` 结构不符合单选字段规范，字段规范参考[字段与属性解析格式](../formats/字段与属性解析格式.md)。

```json
{
  "err_code": 20006,
  "err_msg": "Invalid Param",
  "err": {
    "code": 20006,
    "msg": "field [priority] is illegal",
    "log_id": "202510302030302420D7314CAF22B1xxxx"
  }
}
```
