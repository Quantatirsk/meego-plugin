# 评审结论标签值查询

读取节点配置中允许选择的评审结论标签，用于填写评审结论前构建选项列表。一次请求限定同一工作项，`node_ids` 最多 10 个。

## 选择正确的标签集合

| 返回字段 | 用途 | 状态 |
| --- | --- | --- |
| `finished_owners_conclusion_option` | 负责人评审结论的可选标签 | 推荐按对应场景使用 |
| `finished_overall_conclusion_option` | 整体评审结论的可选标签 | 推荐按对应场景使用 |
| `finished_conclusion_option` | 兼容旧版统一标签集合 | 官方计划废弃 |

旧字段优先反映已开启的整体评审结论；整体未开启而负责人评审结论开启时，才与负责人标签集合一致。调用方应保留标签 `key` 原值，不根据显示名称自行生成 key：官方示例既包含普通 ID，也包含长复合 key。

已填写的结果使用[批量查询评审意见、评审结论](批量查询评审意见、评审结论.md)读取，写入使用[修改评审结论和评审意见](修改评审结论和评审意见.md)。申请权限见[权限管理](../guides/权限管理.md)中的“工作项实例”。

## 请求说明

**请求方式**：`POST`
**请求地址**：`/open_api/work_item/finished/query_conclusion_option`

## 请求参数

### 请求头

| 参数 | 类型 | 是否必须 | 说明 |

<a id="parameter-notes-1"></a>

**finished_conclusion_option 的填写说明**

配置的统一评审结论标签，计划废弃，建议使用 `finished_owners_conclusion_option` 或 `finished_overall_conclusion_option` 替代。

- 如果整体评审结论配置开启，则与 `finished_overall_conclusion_option` 一致；

- 如果整体不开启而负责人评审结论配置开启，则与 `finished_owners_conclusion_option`一致。

| 参数 | 类型 | 说明 |

| `key` | string | 标签 key。 |
| `label` | string | 标签名称。 |
| `origin_label` | string | 原始标签名称。 |

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `key` | string | 标签 key。 |
| `label` | string | 标签名称。 |
| `origin_label` | string | 原始标签名称。 |

### `data.finished_overall_conclusion_option`

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `key` | string | 标签 key。 |
| `label` | string | 标签名称。 |
| `origin_label` | string | 原始标签名称。 |

### `err`

| 参数 | 类型 | 说明 |
| --- | --- | --- |

## 请求示例

请求方法为 `POST`，路径为 `/open_api/work_item/finished/query_conclusion_option`。下方数值 ID 为演示值，调用时替换为真实工作项 ID。

```json
{
    "project_key": "681c29c58d0d3cfe1498****",
    "work_item_id": 6437110000,
    "node_ids": [
        "started_0"
    ]
}
```
