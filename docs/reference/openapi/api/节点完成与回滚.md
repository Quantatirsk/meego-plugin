# 节点完成/回滚

[Official source](https://project.feishu.cn/b/helpcenter/1p8d7djs/48ft4i1k) | [Local index](../INDEX.md)

> 接入 Open API / 工作项 / 流程与节点 / 节点完成/回滚
>
> Published: 2026-08-27T10:30:53.056Z; captured: 2026-09-07T01:03:17.851Z

完成或回滚节点流工作项的指定节点，并可在同一次请求中更新负责人、排期、完成表单和节点自定义字段。节点 ID 与节点 `state_key` 等价；仅修改节点信息而不流转时，使用[更新节点/排期](更新节点与排期.md)。

## 操作条件与附带更新

| 操作     | `action`   | 关键条件                                                           |
| -------- | ---------- | ------------------------------------------------------------------ |
| 完成节点 | `confirm`  | 节点必须已经开始且未完成；多人完成节点还会检查当前调用人的完成状态 |
| 回滚节点 | `rollback` | 必须提供 `rollback_reason`                                         |

调用时显式指定 `action`。已终止实例无法流转节点，配置的插件拦截规则也可能阻止本次操作。

负责人未提交表示不更新，`node_owners: []` 表示清空。角色绑定的节点用 `role_assignee`，完成表单用 `fields`，节点自定义字段用 `node_custom_fields`。字段 ID 与别名、普通值与富文本 Markdown 值分别按二选一规则提交；原表中的静态“必须”标记不能解释为要求两种形式同时存在。

<a id="schedule-update-modes"></a>

非差异化排期使用 `node_schedule`，差异化排期使用 `schedules`。每个 Schedule 的 `is_auto` 默认为 `true`：

| 提交排期 / 估分 | `is_auto=true`       | `is_auto=false` |
| --------------- | -------------------- | --------------- |
| 仅排期          | 自动按排期差值补估分 | 不补估分        |
| 仅估分          | 清空排期             | 保留排期        |
| 两者都有        | 按提交值保存         | 按提交值保存    |
| 两者都没有      | 估分置 `0`，清空排期 | 不修改          |

没有更新意图时应省略相应参数；提交空 Schedule 对象可能触发上表的清空行为。原文未定义本次流转与附带字段更新之间的事务或失败回滚保证，失败后可通过[获取工作流详情](获取工作流详情.md)核对实际状态。

平台操作见[流转节点](https://project.feishu.cn/1ykiuvvj/69kaicie#%E6%B5%81%E8%BD%AC%E8%8A%82%E7%82%B9)、[回滚节点](https://project.feishu.cn/1ykiuvvj/69kaicie#%E5%9B%9E%E6%BB%9A%E8%8A%82%E7%82%B9)。权限位于**权限管理 > 工作项实例**，见[权限管理](../guides/权限管理.md)。

## 请求说明

**请求方式**：`POST`

**请求地址**：`/open_api/:project_key/workflow/:work_item_type_key/:work_item_id/node/:node_id/operate`

### 路径参数

| 参数                 | 类型     | 是否必须 | 说明                                                                                       |
| -------------------- | -------- | -------- | ------------------------------------------------------------------------------------------ |
| `project_key`        | `string` | 必须     | 空间 ID（project_key），或者空间域名（simple_name）。 [详细说明](#field-note-1)            |

<a id="field-note-1"></a>

**project_key**

空间 ID（project_key），或者空间域名（simple_name）。

- 空间 ID（project_key），在飞书项目空间双击空间名称获取。
- 空间域名（simple_name），`simple_name` 一般在飞书项目空间 URL 中获取。例如空间 URL 为 “https://project.feishu.cn/doc/overview”，则 `simple_name`为 “doc”。

- `rollback`：回滚节点。

- 传入空数组表示删除所有负责人。
