# 获取指定的工作项列表（单空间）

在一个空间内，按名称、类型、人员、状态和时间等条件搜索工作项实例。接口授权位于[权限管理](../guides/权限管理.md)的“工作项”分类，常见问题参见[工作项实例 FAQ](../reference/OpenAPI调用咨询.md#3fc52507)。

## 组织查询条件

常规查询必须提供 `work_item_type_keys`，注意本接口使用类型数组；[跨空间查询](获取指定的工作项列表（跨空间）.md)使用单个 `work_item_type_key`。`user_keys` 最多 10 个，可匹配创建人、关注人或角色人员。

使用客户端搜索交互返回的 `search_id` 时，其他请求参数失效；应将其作为独立查询方式。

分页从 `1` 开始，单页最多 `200` 条，累计只能读取匹配结果中的前 20 万条。超过该范围时需要缩小筛选区间，例如按时间分段；单纯减小 `page_size` 不会突破总量上限。

### 选择返回内容

| 需要的内容      | `expand` 开关              | 返回位置                                    |
| --------------- | -------------------------- | ------------------------------------------- |
| 节点流工作流    | `need_workflow`            | `data[].workflow_infos`；状态流不支持此扩展 |
| 富文本详细内容  | `need_multi_text`          | `data[].multi_texts`                        |
| 富文本 Markdown | `need_rich_text_mark_down` | 对应字段的 Markdown 对象                    |
| 人员详情        | `need_user_detail`         | `data[].user_details`                       |
| 子任务父级      | `need_sub_task_parent`     | `data[].sub_task_parent_info`               |
| 关联字段详情    | `relation_fields_detail`   | `data[].relation_fields_detail`             |

下面按父对象拆分字段定义：标题给出完整父路径，表格仅列当前对象的直接字段；数组路径表示每个元素的结构。

<a id="注意事项"></a>

## 注意事项

- 排序是默认平台列表页排序顺序，暂不支持指定顺序

- 默认查询数据返回中不包含已终止工作项，已终止状态与其他状态互斥，查询时如出现此情况，需分开查询结果后合并处理

<a id="field-note-1"></a>

**project_key**

空间 ID（project_key），或者空间域名（simple_name）。

- 空间 ID（project_key），在飞书项目空间双击空间名称获取。
- 空间域名（simple_name），`simple_name` 一般在飞书项目空间 URL 中获取。例如空间 URL 为 “https://project.feishu.cn/doc/overview”，则 `simple_name`为 “doc”。

<a id="field-note-2"></a>

**sub_stages**

- [获取字段信息](获取字段信息.md)接口中 work_item_status 的 options 中获取，选择对应的 value
- [获取创建工作项元数据](获取创建工作项元数据.md)接口中的 work_item_status 字段的options 中获取，选择对应的 value

<a id="field-note-3"></a>

**work_item_status**

工作项状态列表，遵循[WorkItemStatus](../formats/数据结构汇总.md#9b44f95f)结构规范，用于筛选当前处于指定状态的工作项实例。可通过以下方式获取状态值：

- 调用[获取字段信息](获取字段信息.md)接口，从 `work_item_status` 字段的 `options` 中获取对应 `value`；
- 调用[获取创建工作项元数据](获取创建工作项元数据.md)接口，从 `work_item_status` 字段的 `options` 中获取对应 `value`。
