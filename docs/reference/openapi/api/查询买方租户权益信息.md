# 查询买方租户权益信息

ISV 认证租户按买方 `tenant_key` 查询插件权益，响应涵盖商品目录、买方当前方案、权益状态、有效期及升级、续费和重购能力。接口权限需在「权限管理 → 企业信息」添加并授权。

## 使用前确认

| 对象 | 读取用途 |
| --- | --- |
| `entitlement.product` | 商品详情、卖方租户及全部商品付费方案 |
| `entitlement.product.product_prices[]` | 商品可配置的方案目录 |
| `entitlement.product_price` | 当前买方实际购买的方案 |
| `entitlement.status` | `Trial` 试用、`Occupied` 使用中、`Expired` 过期、`Aborted` 终止 |
| `start_time`、`use_deadline` | 毫秒时间戳表示的权益开始与到期时间 |

`price` 为整数；币种字段 `CNY_FEN` 表示人民币分，不能把该数值直接当元。付费模式与权益状态是两组不同枚举，例如免费方案的权益也可能处于 `Occupied`。

原示例的扩展字段还包括 `order_items`、`licenses`（暂不返回数据），商品 `extra` 中包含子类型、审核状态、隐私协议、用户协议、方案顺序、插件版本、下架原因及内部套餐 ID。保留这些示例字段，但不将其未定义的结构扩大为稳定接口约束。

本接口仅在 ISV 场景使用。ISV 认证租户可以通过本接口获取买方租户的详细权益信息，包括购买产品的类型、付费版本、付费方案、具体金额等信息。接口权限在飞书项目开放平台插件详情中**权限管理 \> 企业信息**下添加并授权。

## 请求说明

- 请求方式：GET

- 请求地址：/open_api/commercial/product/tenant_entitlement

<a id="parameter-note-1"></a>

**status：说明**

买方租户权益的状态，表示当前租户权益的有效性状态。支持的取值如下所示。
- `Trial`：试用状态；
- `Occupied`：已占用状态；
- `Expired`：已过期状态；
- `Aborted`：已终止状态。
