# 下载附件

下载工作项中的一个附件或富文本文件。路径定位工作项，请求体使用 `uuid` 定位文件；成功响应直接返回二进制流，错误响应才使用 JSON 错误结构。

## 先获取文件标识

调用[获取工作项详情](获取工作项详情.md)，从富文本 `multi_texts` 或附件 `multi_file` 类型字段中取得目标文件标识。原文附件示例将来源称为 `uid`，接口请求参数始终名为 `uuid`，应按此名称提交。当前最大支持 100M。

权限位于“权限管理 → 工作项实例”，见[权限管理](../guides/权限管理.md)。

<a id="请求说明"></a>

## 请求说明

**请求方式**：`POST`
**请求地址**：`/open_api/:project_key/work_item/:work_item_type_key/:work_item_id/file/download`

<a id="请求参数"></a>

## 请求参数

<a id="header"></a>

### 请求头

接口调用的 Header 配置详见 [Header](../guides/OpenAPI概述.md#a8e43b86)。

<a id="Path"></a>

### 路径参数

| 参数 | 类型 | 是否必须 | 说明 |
| --- | --- | --- | --- |
| project_key | string | 必须 | [填写说明](#parameter-notes-1) |
| work_item_type_key | string | 必须 | 工作项类型，系统自动生成，可通过[获取空间下工作项类型](获取空间下工作项类型.md)接口获取 |
| work_item_id | string | 必须 | 工作项实例 ID，在工作项实例详情中，展开右上角 **··· \> ID**获取。 |

<a id="parameter-notes-1"></a>

**project_key 的填写说明**

空间 ID（project_key），或者空间域名（simple_name）。

- 空间 ID（project_key），在飞书项目空间双击空间名称获取。

- 空间域名（simple_name），`simple_name` 一般在飞书项目空间 URL 中获取。例如空间 URL 为 “https://project.feishu.cn/doc/overview”，则 `simple_name`为 “doc”。

<a id="Body"></a>

### 请求体

| 参数 | 类型 | 是否必须 | 说明 |
| --- | --- | --- | --- |
| uuid | string | 必须 | 附件 ID，目前最大支持100M，可从[获取工作项详情](获取工作项详情.md)接口下的富文本（multi_texts）或附件字段（multi_file 类型）中获取。 |

<a id="返回参数"></a>

## 返回参数

成功返回目标附件的二进制流，不能固定按 JSON 解码。失败时可能返回 `err_code`、`err_msg` 和 `err`；处理示例见下文。

<a id="请求示例"></a>

## 请求示例

**下载富文本**

先通过[获取工作项详情](获取工作项详情.md)接口，获取 multi_texts 文件的 uuid，然后使用以下请求示例。

```json
{
  "uuid": "a0e0104f-94bc-4999-bf07-239fd2f7xxxx"
}
```

**下载附件**

先通过[获取工作项详情](获取工作项详情.md)接口，获取 fileds 中类型为 multi_file 字段的 uid，然后使用以下请求示例。

```json
{
  "uuid": "ledZpaH2HWn_Z2fWjWuFrddKjAkE3QlQEhL9cVM6VNB-DPbJaf0tv9u9bRK0ISWBr0A0afvIGUxeIUpIXTMyHYVX8vys7zF-dXNoTvtndeTGcKTNmDmoy1CeunpqHtC6IYtzAlpzlwsGMrJETfxxxx"
}
```

<a id="返回示例"></a>

## 返回示例

**下载成功**

响应体是文件二进制流。原文仅提供这项说明，没有可展示的 JSON 成功样例。

### 错误返回示例

以下错误原因为传入的 uuid 不正确，可从[获取工作项详情](获取工作项详情.md)接口下的富文本（multi_texts）或附件字段（multi_file 类型）中获取。

```json
{
  "err_code": 30019,
  "err_msg": "file not found",
  "err": {
    "code": 30019,
    "msg": "uuid not found"
  }
}
```

<a id="错误码"></a>

## 错误码

以下列出了该接口相关的错误码信息，若需查看更多通用错误码说明，参见 [Open API 错误码](../formats/Open%20API%20错误码.md)。

| err_code | err_msg | err.code | err.msg | 说明 |
| --- | --- | --- | --- | --- |
| 1000050255 | ErrAPIProjectNotFound | 1000050255 | Project Not Found | 传入的 `project_key` 不正确 |

响应示例还列出 `30019 / file not found`，其详细错误为 `uuid not found`，应检查文件标识与工作项归属。
