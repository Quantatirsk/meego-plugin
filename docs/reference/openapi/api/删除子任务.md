# 删除子任务

删除一个工作项实例中的指定子任务。请求使用 `DELETE`，工作项和子任务均通过路径定位；本篇未定义请求体，也不需要额外传入 `node_id`。

## 定位待删除任务

先通过[获取指定的子任务列表（跨空间）](获取指定的子任务列表（跨空间）.md)或[获取子任务详情](获取子任务详情.md)核对 `task_id` 与所属工作项。删除对象是子任务；若只是撤销完成状态，应使用[子任务完成/回滚](子任务完成与回滚.md)的 `rollback` 操作。

产品行为见[任务管理](https://project.feishu.cn/1ykiuvvj/40gyakm8)，插件需申请[权限管理](../guides/权限管理.md)中的“工作项实例”权限。工作项中止、工作项不存在和插件拦截都可能导致删除失败。

<a id="请求说明"></a>

## 请求说明

**请求方式**：`DELETE`
**请求地址**：`/open_api/:project_key/work_item/:work_item_type_key/:work_item_id/task/:task_id`

<a id="请求参数"></a>

## 请求参数

<a id="header"></a>

### 请求头

接口调用的 Header 配置详见 [Header](../guides/OpenAPI概述.md#a8e43b86)。

<a id="Path"></a>

### 路径参数

| 参数 | 类型 | 是否必须 | 说明 |
| --- | --- | --- | --- |
| project_key | string | 必须 | [填写说明](#parameter-notes-1) |
| work_item_type_key | string | 必须 | 工作项类型，系统自动生成，可通过[获取空间下工作项类型](获取空间下工作项类型.md)接口获取。 |
| work_item_id | string | 必须 | 工作项实例 ID，在工作项实例详情中，展开右上角 **··· \> ID**获取。 |
| task_id | string | 必须 | 子任务的唯一标识 ID，通过[获取指定的子任务列表（跨空间）](获取指定的子任务列表（跨空间）.md)接口获取。 |

<a id="parameter-notes-1"></a>

**project_key 的填写说明**

空间 ID（project_key），或者空间域名（simple_name）。

- 空间 ID（project_key），在飞书项目空间双击空间名称获取。

- 空间域名（simple_name），`simple_name` 一般在飞书项目空间 URL 中获取。例如空间 URL 为 “https://project.feishu.cn/doc/overview”，则 `simple_name`为 “doc”。

<a id="返回参数"></a>

## 返回参数

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| err | object | 请求成功时返回空值，请求失败时返回实际错误信息。 |
| err.code | int32 | 部分场景下，透出更详细错误对应的错误码。 |
| err.msg | string | 部分场景下，透出更详细的错误描述。 |
| err.log_id | string | 报错场景下的调用链标识符，用于追踪错误发生时的完整调用链路，便于日志记录和问题排查。 |
| err_msg | string | 请求成功时返回空值，请求失败时返回实际错误信息。 |
| err_code | int32 | 请求成功时0，请求失败返回实际错误码。 |

<a id="请求示例"></a>

## 请求示例

HTTP 请求行示意，路径中的脱敏 ID 需替换为实际值：

```http
DELETE /open_api/66f11218c3b4a0b42334xxxx/work_item/story/12584xxxx/task/12345xxxx
```

<a id="返回示例"></a>

## 返回示例

### 请求成功示例

```json
{
  "err": {},
  "err_code": 0,
  "err_msg": ""
}
```

### 错误返回示例

以下错误原因为指定的 `task_id`在工作流中不存在，无法找到对应的子任务。

```json
{
  "err_code": 20046,
  "err_msg": "Task ID Not Exist In Workflow",
  "err": {
    "code": 20046,
    "msg": "Task ID Not Exist In Workflow, please refer to https://project.feishu.cn/b/helpcenter/1p8d7djs/5aueo3jr",
    "log_id": "2025102920284085818EA8B7F893C4xxxx"
  }
}
```

## 错误码

以下列出了该接口相关的错误码信息，若需查看更多通用错误码说明，参见 [Open API 错误码](../formats/Open%20API%20错误码.md)。

| err_code | err_msg | err.code | err.msg | 说明 |
| --- | --- | --- | --- | --- |
| 20007 | WorkItem Is Already Aborted | 20007 | Unable to operate on terminated work items | 表示工作项是否已被中止。 |
| 20090 | Your request has been Intercept | 20090 | Your request has been intercepted. | 通常用于标识请求被系统或安全策略拦截的具体情况。 |
| 30005 | WorkItem Not Found | 30005 | workitem_id: 6190988990 | 当工作项未找到时返回的错误码，用于标识特定的错误情况。 |

原文错误表未列出响应示例中的 `20046 / Task ID Not Exist In Workflow`。遇到该错误应检查子任务是否存在，以及是否属于路径指定的工作项。
