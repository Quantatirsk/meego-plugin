# 搜索租户内的用户列表

在指定租户内按关键词模糊搜索用户，返回匹配用户的标识、名称、邮箱及状态。接口权限位于[权限管理](../guides/权限管理.md)的“用户”分类。已经持有明确的用户标识时，可直接使用[获取用户详情](获取用户详情.md)。

## 确定搜索范围

| 场景                                 | `project_key` 要求             |
| ------------------------------------ | ------------------------------ |
| 企业插件，用户主租户与插件租户一致   | 可省略                         |
| 企业插件，用户主租户与插件租户不一致 | 必填，通过空间确定要搜索的租户 |
| 市场插件                             | 必填                           |

`query` 用于匹配名称等关键词，不是用户 ID。关键词“用户1”可能同时匹配“用户1”和“用户1.1”。接口没有在本篇定义分页参数，不要擅自添加 `page_size` 或 `page_num`。

<a id="请求说明"></a>

## 请求说明

**请求方式**：`POST`

**请求地址**：`/open_api/user/search`

<a id="请求参数"></a>

## 请求参数

<a id="b0783d71"></a>

### 请求头

接口调用的 Header 配置详见[Header](../guides/OpenAPI概述.md#a8e43b86)。

本接口的 `X-User-Key` 可选。若填写的用户标识不存在，可能返回 `30006`。

<a id="Body"></a>

### 请求体

| 参数          | 类型     | 是否必须 | 说明                                                                                          |
| ------------- | -------- | -------- | --------------------------------------------------------------------------------------------- |
| `query`       | `string` | 可选     | 搜索的关键词，例如用户名称。                                                                  |
| `project_key` | `string` | 条件必填 | 空间 ID，用于确定搜索租户；可在飞书项目中双击空间名称获取。具体必填条件见上方“确定搜索范围”。 |

<a id="返回参数"></a>

## 返回参数

| 参数       | 类型           | 说明                                             |
| ---------- | -------------- | ------------------------------------------------ |
| `data`     | `list<object>` | 查询用户信息                                     |
| `err`      | `object`       | 请求成功时返回空值，请求失败时返回实际错误信息。 |
| `err_msg`  | `string`       | 请求成功时返回空值，请求失败时返回实际错误信息。 |
| `err_code` | `int32`        | 请求成功时返回0，请求失败返回实际错误码。        |

### `data`

| 参数         | 类型     | 说明                                                                                                                                                                                                        |
| ------------ | -------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `user_id`    | `int64`  | 用户 ID（已废弃），永久为 0。                                                                                                                                                                               |
| `user_key`   | `string` | 用户在飞书项目的 user_key，例如“749112601802809xxxx”。                                                                                                                                                      |
| `username`   | `string` | 用户在飞书项目的 user_key，例如“749112601802809xxxx”，建议使用 `user_key` 字段。                                                                                                                            |
| `email`      | `string` | 用户邮箱。                                                                                                                                                                                                  |
| `avatar_url` | `string` | 用户头像链接。                                                                                                                                                                                              |
| `name_cn`    | `string` | 用户中文名称。                                                                                                                                                                                              |
| `name_en`    | `string` | 用户英文名称。                                                                                                                                                                                              |
| `out_id`     | `string` | 用户在飞书开放平台的 `union_id`，用于标识用户在同一应用服务商所开发的多个应用中的统一身份。具体可参考[飞书开放平台文档](https://open.larkoffice.com/document/faq/trouble-shooting/how-to-obtain-union-id)。 |
| `status`     | `string` | 用户的状态，取值如下所示。 [详细说明](#field-note-1)                                                                                                                                                        |
| `name`       | `map`    | 用户名称，包含用户中文名、英文名和默认名称。                                                                                                                                                                |

<a id="field-note-1"></a>

**status**

用户的状态，取值如下所示。

- `initialized`：初始（未登录过）；
- `resigned`：离职；
- `frozen`：冻结（被停用）；
- `activated`：使用中。

### `err`

| 参数     | 类型     | 说明                                                                                 |
| -------- | -------- | ------------------------------------------------------------------------------------ |
| `code`   | `int32`  | 部分场景下，透出更详细错误对应的错误码。                                             |
| `msg`    | `string` | 部分场景下，透出更详细的错误描述。                                                   |
| `log_id` | `string` | 报错场景下的调用链标识符，用于追踪错误发生时的完整调用链路，便于日志记录和问题排查。 |

### 调用成功但空返回

`err_code: 0` 且 `data: []` 表示请求成功但没有匹配用户。原文列出的原因包括 `query` 为空，或目标租户内不存在匹配用户；不能把空结果当作接口调用失败。

```json
{
  "err": {},
  "err_code": 0,
  "err_msg": "",
  "data": []
}
```

### 错误返回示例

此报错表示 `project_key` 对应的空间不存在。应改为正确的空间 ID；仅在上方允许省略的场景中，才可移除该参数。

```json
{
  "err_code": 1000052063,
  "err_msg": "Project Not Exist",
  "err": {
    "code": 1000052063,
    "msg": "project: 66f11218c3b4a0b4xxxx not found",
    "log_id": "20251017111430C903716E21A4C4E5xxxx"
  }
}
```
