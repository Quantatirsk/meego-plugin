# 更新评论

更新一条已有评论的文本内容。使用空间 ID 和评论 ID 定位目标，调用身份必须是评论创建人；附件类评论不支持更新。

## 使用前确认

`content.type=TEXT` 时提交 `text`；`RICHTEXT` 时可使用富文本结构或 Markdown，`rich_text` 与 `markdown` 二选一。评论 ID 可来自查询或创建响应，错误 `10001` 表示当前操作人不是评论创建人，`30015` 表示评论不存在。

该接口用于对指定评论更新其内容，被更新的评论会显示该评论由插件添加。对应的权限申请在**权限管理-评论**分类下，相关功能介绍详见[权限管理](../guides/权限管理.md)。

<a id="使用说明"></a>

## 使用说明

- 仅评论创建人可以更新该评论。

- 附件类评论不支持更新。

<a id="请求说明"></a>

## 请求说明

- 请求方式：POST

- 请求地址：/open_api/comment/update

<a id="请求参数"></a>

## 请求参数

<a id="header"></a>

### Header

接口调用的 Header 配置详见 [Header](../guides/OpenAPI概述.md#a8e43b86)。

<a id="Body"></a>

### Body

| 参数 | 类型 | 是否必须 | 说明 |
| --- | --- | --- | --- |
| `comment_id` | string | 必须 | 评论 ID，可以通过[查询评论](查询评论.md)接口获取，也可以通过创建评论的返回值获取。 |
| `project_key` | string | 必须 | 空间 ID（project_key），在飞书项目空间双击空间名称获取。 |
| `content` | object | 必须 | 更新内容 |

#### `content` 的字段

| 参数 | 类型 | 是否必须 | 说明 |
| --- | --- | --- | --- |
| `text` | string | 可选 | 纯文本 |
| `type` | string | 必须 | 内容类型<br>- RICHTEXT（富文本）：`rich_text` 或 `markdown` 二选一<br>- TEXT(纯文本): 需要传参 text |
| `markdown` | string | 可选 | 富文本格式，富文本内容 Markdown 格式，遵循 [ ](https://arcosite.bytedance.net/sites/1698370054562/6552139f9045fa02fe4f6435/editor/6a4c9f3c029ec1050c4d18a6?docLang=zh&bv=656ef48385acee02ee573dac)[Markdown 格式说明](../formats/Markdown%20格式说明.md)结构规范，和`rich_text` 二选一 |
| `rich_text` | `list<object>` | 可选 | 评论内容，支持富文本格式，可参考<br>[富文本格式](../formats/字段与属性解析格式.md#110a33af) |
