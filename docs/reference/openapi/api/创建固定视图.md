# 创建固定视图

在指定空间和工作项类型下创建固定视图，显式指定纳入视图的工作项 ID，最多 200 个。可同时设置协作范围，成功响应返回视图 ID、编辑权限及已包含的工作项列表。

## 使用前确认

`work_item_id_list` 与 `name` 必填，所有工作项类型必须与路径一致。协作模式 `1` 指定人员或团队（默认），`2` 全部空间管理员，`3` 全部空间成员；人员和团队列表仅在模式 `1` 下适用。

对应的平台功能介绍详见[固定视图](https://project.feishu.cn/1ykiuvvj/4w2iz8d8#%E5%9B%BA%E5%AE%9A%E8%A7%86%E5%9B%BE)。对应的权限申请在**权限管理-视图&度量**分类下，相关功能介绍详见 [权限管理](../guides/权限管理.md)。

<a id="请求说明"></a>

## 请求说明

- 请求方式：POST

- 请求地址：/open_api/:project_key/:work_item_type_key/fix_view

<a id="请求参数"></a>

## 请求参数

<a id="header"></a>

### Header

接口调用的 Header 配置详见 [Header](../guides/OpenAPI概述.md#a8e43b86)。

<a id="Path"></a>

### Path

| 参数 | 类型 | 是否必须 | 说明 |
| --- | --- | --- | --- |
| `project_key` | string | 必须 | [说明](#parameter-note-1) |
| `work_item_type_key` | string | 必须 | 工作项类型，通过[获取空间下工作项类型](获取空间下工作项类型.md)接口获取。 |

<a id="parameter-note-1"></a>

**project_key：说明**

空间 ID（project_key），或者空间域名（simple_name）。
- 空间 ID（project_key），在飞书项目空间双击空间名称获取。
- 空间域名（simple_name），`simple_name` 一般在飞书项目空间 URL 中获取。例如空间 URL 为 “https://project.feishu.cn/doc/overview”，则 `simple_name`为 “doc”。

<a id="Body"></a>

### Body

| 参数 | 类型 | 是否必须 | 说明 |
| --- | --- | --- | --- |
| `work_item_id_list` | `list<int64>` | 必须 | 工作项 ID 列表，数量上限为 200。 |
| `name` | string | 必须 | 视图名称。 |
| `cooperation_mode` | int64 | 可选 | 协作模式，用于指定视图的协作范围，默认值为 `1`。支持的取值如下所示。<br>- 1：指定人员或团队；<br>- 2：全部空间管理员；<br>- 3：全部空间成员。 |
| `cooperation_user_keys` | `list<string>` | 可选 | [说明](#parameter-note-2) |
| `cooperation_team_ids` | `list<int64>` | 可选 | 指定团队 team_id，`cooperation_mode` 为 1 时适用，团队 ID 可通过接口[获取空间下团队人员](获取空间下团队人员.md)拿到。 |

<a id="parameter-note-2"></a>

**cooperation_user_keys：说明**

指定人员 user_key，`cooperation_mode` 为 1 时适用。
- 开发者自己的 user_key，在飞书项目空间左下角双击个人头像获取。
- 租户内其他成员的 user_key，请通过[搜索租户内的用户列表](搜索租户内的用户列表.md)接口获取。

<a id="返回参数"></a>

## 返回参数

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `data` | object | 返回新创建的视图信息。该返回结构遵循结构体[FixView](../formats/数据结构汇总.md#65b5b377)格式与规范。 |
| `pagination` | object | 分页信息用于展示视图中的工作项信息。 |
| `err` | object | 请求成功时返回空值，请求失败时返回实际错误信息。 |
| `err_msg` | string | 请求成功时返回空值，请求失败时返回实际错误信息。 |
| `err_code` | int32 | 请求成功时0，请求失败返回实际错误码。 |

### `data` 的字段

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `view_id` | string | 视图 ID。 |
| `name` | string | 视图名称。 |
| `created_by` | string | 创建人 user_key。 |
| `created_at` | int64 | 创建时间，毫秒精度。 |
| `modified_by` | string | 最后一次修改人 user_key。 |
| `work_item_id_list` | `list<int64>` | 固定视图包含的工作项 ID 列表。 |
| `editable` | boolean | 当前视图是否可编辑。 |

### `pagination` 的字段

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `total` | int64 | 视图中工作项的总数。 |
| `page_num` | int64 | 当前页码，表示返回的数据属于分页结果的第几页。 |
| `page_size` | int64 | 每页返回的数据条目数量，表示当前分页查询中每页包含的记录数。 |

### `err` 的字段

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `code` | int32 | 部分场景下，透出更详细错误对应的错误码。 |
| `msg` | string | 部分场景下，透出更详细的错误描述。 |
| `log_id` | string | 报错场景下的调用链标识符，用于追踪错误发生时的完整调用链路，便于日志记录和问题排查。 |

<a id="请求示例"></a>

## 请求示例

### 创建指定协作模式视图

创建指定人员或团队的固定视图，即 `cooperation_mode` 为 1。

**Path 示例：**`POST /open_api/688b63d4610c48aef7c7/story/fix_view`

```text
{
    "work_item_id_list": [628372xxxx,621541xxxx],
    "name": "\u6d4b\u8bd5\u89c6\u56fe",
    "cooperation_mode": 1,
    "cooperation_user_keys": ["749112601802809xxxx"],
    "cooperation_team_ids": [756190043848060xxxx]
}
```

### 创建默认视图

仅传入必填参数创建视图，协作模式沿用默认值 `1`。

**Path 示例：**`POST /open_api/688b63d4610c48aef7c7/story/fix_view`

```text
{
    "work_item_id_list": [628372xxxx,621541xxxx],
    "name": "\u6d4b\u8bd5\u89c6\u56fe\u9ed8\u8ba4\u7248"
}
```
