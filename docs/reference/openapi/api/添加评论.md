# 添加评论

为工作项、字段或一级评论添加评论，支持纯文本、富文本、Markdown 和附件内容。成功后保存返回的 `data.comment_id`，后续查询回复、更新和删除均使用该标识。

## 使用前确认

- 工作项评论提供类型和实例 ID；字段评论再提供 `field_key`；子评论提供同一实例的一级 `parent_id`，不能回复二级评论形成更深层级。
- `content.type=TEXT` 使用 `text`；`RICHTEXT` 使用 `rich_text` 或 `markdown`，二者选一；`FILE` 使用上传接口取得的 `file_token`。
- 字段评论支持下文列出的文本、选择及日期类型，扩展字段和复合字段暂不支持。
- 需要工作项查看权限；超过实例评论数量上限返回 `1000053856`，原文未给出具体上限数值。

该接口用于在指定工作项下添加一条评论，添加的评论内容会出现在工作项详情页的评论或备注页签中，并会显示该评论由插件添加。对应的权限申请在**权限管理-工作项实例** 分类下，相关功能介绍详见[权限管理](../guides/权限管理.md)。

<a id="使用说明"></a>

## 使用说明

### 针对工作项评论

在飞书项目工作项实例详情页下方，或点击右上角「评论」，均可针对当前工作项进行评论。

### 针对字段评论

在工作项实例详情页，将鼠标悬停在字段，支持关联该字段作为评论话题，同时可引用该字段当前值。

点击评论中被引用字段，若字段配置在详情页中，将自动定位到所配置位置。*存在多个配置时，定位至第一个配置位置。*

> 注：当前字段类型包括：单行文本、多行文本、富文本、单选、多选、级联单选、级联多选、日期、日期区间、日期+时间，扩展字段和复合字段暂不支持。

<a id="请求说明"></a>

## 请求说明

- 请求方式：POST

- 请求地址：/open_api/comment/create

<a id="请求参数"></a>

## 请求参数

<a id="header"></a>

### Header

接口调用的 Header 配置详见[Header](../guides/OpenAPI概述.md#a8e43b86)。

<a id="Body"></a>

### Body

| 参数 | 类型 | 是否必须 | 说明 |
| --- | --- | --- | --- |
| `object` | object | 必须 | 评论对象 |
| `project_key` | string | 必须 | 空间 ID（project_key），在飞书项目空间双击空间名称获取。 |
| `content` | object | 必须 | 评论内容 |

#### `object` 的字段

| 参数 | 类型 | 是否必须 | 说明 |
| --- | --- | --- | --- |
| `type` | string | 必须 | [说明](#parameter-note-1) |
| `field_key` | string | 可选 | 字段 key，需要和工作项类型的中字段对齐 |
| `parent_id` | string | 可选 | 父评论 id ，可以通过[查询评论](查询评论.md)接口获取，也可以通过创建评论的返回值获取。<br>相同实例下的一级评论的 id。不可以使用二级评论 id |
| `work_item_id` | string | 可选 | 工作项实例 ID，在工作项实例详情中，展开右上角 **··· \> ID** 获取。 |
| `work_item_type_key` | string | 可选 | 工作项类型，从[获取空间下工作项类型](获取空间下工作项类型.md)接口获取。 |

<a id="parameter-note-1"></a>

**type：说明**

评论对象类型
- CHILDCOMMENT(子评论): 需要传参 parent_id
- WORKITEM(工作项): 需要传参 work_item_type_key+work_item_id
- WORKITEMFIELD(工作项字段): 需要传参 work_item_type_key+work_item_id+field_key

#### `content` 的字段

| 参数 | 类型 | 是否必须 | 说明 |
| --- | --- | --- | --- |
| `text` | string | 可选 | 纯文本 |
| `type` | string | 必须 | 内容类型<br>- RICHTEXT(富文本): rich_text<br>- FILE(附件): file_token<br>- TEXT(纯文本): text |
| `markdown` | string | 可选 | 富文本格式，富文本内容 Markdown 格式，遵循 [Markdown 格式说明](../formats/Markdown%20格式说明.md)结构规范，和`rich_text` 二选一 |
| `rich_text` | `list<object>` | 可选 | 评论内容，支持富文本格式，可参考<br>[富文本格式](../formats/字段与属性解析格式.md#110a33af) |
| `file_token` | string | 可选 | 附件 Token（获取参考：[上传文件](上传文件.md)、[完成分片上传](完成分片上传.md)） |
