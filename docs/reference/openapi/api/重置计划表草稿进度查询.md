# 重置计划表草稿进度查询

查询[重置计划表草稿](重置计划表草稿.md)的重置进度。

## 重置状态

| `data.draft_status` | 含义 |
| --- | --- |
| `0` | 未知状态 |
| `2` | 重置完成 |
| `3` | 重置中 |
| `4` | 部分重置中 |

以 `2` 判定重置完成；`3` 和 `4` 表示仍在处理，不能将查询成功视为重置完成。

请求需要空间、工作项与 `draft_id`。重置接口返回 `new_draft_id`，本篇未解释新旧 ID 在查询期间的适用关系；应保存重置响应并在接入联调时核实。建议的轮询间隔来自重置接口 `recommend_interval_ms`。插件权限见[权限管理](../guides/权限管理.md)中的“工作项”。

<a id="请求说明"></a>

## 请求说明

**请求方式**：`POST`
**请求地址**：`/open_api/work_item/wbs_draft_reset/progress/query`

<a id="请求参数"></a>

## 请求参数

<a id="a3c53a27"></a>

### 请求头

接口调用的 Header 配置详见[Header](../guides/OpenAPI概述.md#a8e43b86)

<a id="Body"></a>

### 请求体

| 参数 | 类型 | 是否必须 | 说明 |
| --- | --- | --- | --- |
| project_key | string | 必须 | 空间 ID（project_key）。<br>- 空间 ID（project_key），在飞书项目空间双击空间名称获取。 |

| data.draft_status | int32 | 重置进度：`0` 未知；`2` 完成；`3` 重置中；`4` 部分重置中 |
| err | object | 对部分错误会在这里进行更详细的错误描述，可协助日志记录和问题反馈。 |
| err.code | int32 | 部分场景下，透出更详细错误对应的错误码。 |
| err.msg | string | 部分场景下，透出更详细的错误描述。 |
| err.log_id | string | 报错场景下的调用链标识符，用于追踪错误发生时的完整调用链路，便于日志记录和问题排查。 |
| err_msg | string | 错误信息。 |
| err_code | int32 | 错误码。 |
