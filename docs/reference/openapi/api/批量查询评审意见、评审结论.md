# 批量查询评审意见、评审结论

一次读取同一工作项最多 10 个节点的评审意见和评审结论。结果同时包含汇总信息与各负责人的个人信息，适合展示已填写的评审结果。

需要查询可选标签时，使用[评审结论标签值查询](评审结论标签值查询.md)；需要写入或清空评审结果时，使用[修改评审结论和评审意见](修改评审结论和评审意见.md)。本接口的权限位于“权限管理 → 工作项实例”，见[权限管理](../guides/权限管理.md)。

<a id="请求说明"></a>

## 请求说明

**请求方式**：`POST`
**请求地址**：`/open_api/work_item/finished/batch_query`

<a id="请求参数"></a>

## 请求参数

<a id="header"></a>

### 请求头

接口调用的 Header 配置详见 [Header](../guides/OpenAPI概述.md#a8e43b86)。

<a id="Body"></a>

### 请求体

| 参数 | 类型 | 是否必须 | 说明 |
| --- | --- | --- | --- |
| project_key | string | 必须 | 空间 ID（project_key），在飞书项目空间双击空间名称获取。 |
| work_item_id | int64 | 必须 | 工作项实例 ID，在工作项实例详情中，展开右上角 **··· \> ID** 获取。 |
| node_ids | `list<string>` | 必须 | 目标节点的 ID 列表，可以是节点 ID 或节点 `state_key`，可通过[获取工作流详情](获取工作流详情.md)获取。数量不超过 `10`个。 |

<a id="返回参数"></a>

## 返回参数

### 阅读响应

`summary_mode` 为 `calculation` 时使用汇总计算，为 `independence` 时使用独立填写。不要将 `opinion` 下的文本意见与 `conclusion` 下的标签结论合并成同一种字段。

业务数据位于 `data` 下：`project_key`、数值型 `work_item_id` 和 `finished_infos`。人员结论列表为 `owners_finished_conclusion_result`，其中每个人的结论对象为 `finished_conclusion_result`。

### 字段定义

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `data.project_key` | string | 空间 ID |
| `data.work_item_id` | int64 | 工作项 ID |
| `data.finished_infos` | `list<object>` | 评审信息列表，遵循[FinishedInfoItem](../formats/数据结构汇总.md#b11e2393)结构规范 |
| `err` | object | 请求成功时返回空值，请求失败时返回实际错误信息。 |
| `err_msg` | string | 请求成功时返回空值，请求失败时返回实际错误信息。 |
| `err_code` | int32 | 请求成功时0，请求失败返回实际错误码。 |

#### `finished_infos`

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `node_id` | string | 目标节点 ID |
| `opinion` | object | 评审意见，遵循[FinishedOpinionInfo](../formats/数据结构汇总.md#2710fa12)结构规范 |
| `conclusion` | object | 评审结论 |
| `summary_mode` | string | 评审信息的汇总模式，用于指定评审结果的汇总方式。支持的取值如下所示。<br>- `calculation`：汇总计算；<br>- `independence`：独立填写。 |

#### `finished_infos.opinion`

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `finished_opinion_result` | string | 汇总意见 |
| `owners_finished_opinion_result` | `list<object>` | 人员意见，遵循[FinishedOwnerOpinionInfo](../formats/数据结构汇总.md#0da8073b)结构规范 |

#### `finished_infos.opinion.owners_finished_opinion_result`

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `owner` | string | 用户 user_key |
| `finished_opinion_result` | string | 评审意见 |

#### `finished_infos.conclusion`

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `finished_conclusion_result` | object | 汇总结论，遵循[FinishedConclusionInfoItem](../formats/数据结构汇总.md#71196af0)结构规范 |
| `owners_finished_conclusion_result` | `list<object>` | 人员结论，遵循[FinishedOwnerConclusionInfo](../formats/数据结构汇总.md#fccb0843) |

#### `finished_infos.conclusion.finished_conclusion_result`

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `key` | string | 标签 key。 |
| `label` | string | 标签名称。 |
| `origin_label` | string | 原始标签名称。 |

#### `finished_infos.conclusion.owners_finished_conclusion_result`

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `owner` | string | 用户user_key |
| `finished_conclusion_result` | object | 结论，遵循[FinishedConclusionInfoItem](../formats/数据结构汇总.md#71196af0) |

#### `finished_infos.conclusion.owners_finished_conclusion_result.finished_conclusion_result`

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `key` | string | 标签 key。 |
| `label` | string | 标签名称。 |
| `origin_label` | string | 原始标签名称。 |

#### `err`

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `code` | int32 | 部分场景下，透出更详细错误对应的错误码。 |
| `msg` | string | 部分场景下，透出更详细的错误描述。 |
| `log_id` | string | 报错场景下的调用链标识符，用于追踪错误发生时的完整调用链路，便于日志记录和问题排查。 |
