# 获取空间详情

批量读取空间名称、ID、域名及管理员信息，实际返回范围为请求空间与插件已安装空间的交集。接口权限位于[权限管理](../guides/权限管理.md)的“空间”分类。

## 输入与返回范围

`project_keys` 和 `simple_names` 至少填写一项，`project_keys` 最多 100 个。请求体中的 `user_key` 必填，用于判断是否可以返回管理员信息：目标用户是空间管理员时，返回全部管理员；普通成员不获得管理员列表信息，原文示例以空数组表示。

成功响应的 `data` 是以空间 ID 为键的映射，业务字段位于 `data[project_key]` 内。它不是单个空间对象，也不是数组；下方空间字段表按每个映射值的结构阅读。

<a id="请求说明"></a>

## 请求说明

**请求方式**：`POST`

**请求地址**：`/open_api/projects/detail`

<a id="请求参数"></a>

## 请求参数

<a id="header"></a>

### 请求头

接口调用的 Header 配置详见 [Header](../guides/OpenAPI概述.md#a8e43b86)。

<a id="Body"></a>

### 请求体

| 参数           | 类型           | 是否必须 | 说明                                                                                                                             |
| -------------- | -------------- | -------- | -------------------------------------------------------------------------------------------------------------------------------- |
| `project_keys` | `list<string>` | 可选     | 安装插件的飞书项目空间（project_key）列表，上限是100个。`project_key` 在飞书项目空间双击空间名称获取。 [详细说明](#field-note-1) |
| `simple_names` | `list<string>` | 可选     | [详细说明](#field-note-2)                                                                                                        |
| `user_key`     | `string`       | 必须     | 指定查询用户，当用户为空间管理员时，返回该空间的管理员信息。 [详细说明](#field-note-3)                                           |

<a id="field-note-1"></a>

**project_keys**

安装插件的飞书项目空间（project_key）列表，上限是100个。`project_key` 在飞书项目空间双击空间名称获取。

**说明：project_keys 和 simple_names 不可同时为空。**

<a id="field-note-2"></a>

**simple_names**

安装插件的飞书项目空间（simple_name）列表。`simple_name` 一般在飞书项目空间 URL 中获取。例如空间 URL 为 “https://project.feishu.cn/doc/overview”，则 `simple_name` 为 “doc”。

**说明：project_keys 和 simple_names 不可同时为空。**

<a id="field-note-3"></a>

**user_key**

指定查询用户，当用户为空间管理员时，返回该空间的管理员信息。

- 开发者自己的 user_key，在飞书项目空间左下角双击个人头像获取。
- 租户内其他成员的 user_key，请通过[搜索租户内的用户列表](搜索租户内的用户列表.md)接口获取。

<a id="返回参数"></a>

## 返回参数

| 参数       | 类型     | 说明                                             |
| ---------- | -------- | ------------------------------------------------ |
| `data`     | `map`    | 空间信息                                         |
| `err`      | `object` | 请求成功时返回空值，请求失败时返回实际错误信息。 |
| `err_msg`  | `string` | 请求成功时返回空值，请求失败时返回实际错误信息。 |
| `err_code` | `int32`  | 请求成功时返回0，请求失败返回实际错误码。        |

### `data`

| 参数             | 类型           | 说明                                 |
| ---------------- | -------------- | ------------------------------------ |
| `name`           | `string`       | 该飞书项目空间的名称。               |
| `project_key`    | `string`       | 该飞书项目空间的 `project_key`**。** |
| `simple_name`    | `string`       | 该飞书项目空间的 `simple_name`。     |
| `administrators` | `list<string>` | 空间管理员的 `user_key`。            |

### `err`

| 参数     | 类型     | 说明                                                                                                                                                                             |
| -------- | -------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `code`   | `int32`  | In some scenarios, display the error codes corresponding to more detailed errors.                                                                                                |
| `msg`    | `string` | In some scenarios, more detailed error descriptions are displayed.                                                                                                               |
| `log_id` | `string` | The call chain identifier in the error reporting scenario is used to track the complete call chain when an error occurs, facilitating log recording and problem troubleshooting. |

## 错误码

以下列出了该接口相关的错误码信息，若需查看更多通用错误码说明，参见 [Open API 错误码](../formats/Open%20API%20错误码.md)。

<a id="field-note-4"></a>

**10211**

`plugin_token` 信息不正确。

- 插件 Token 错误，无法解析出具体信息。
- 如果访问凭证用的 plugin_token，则原因为未传 `X-USER-KEY`。
