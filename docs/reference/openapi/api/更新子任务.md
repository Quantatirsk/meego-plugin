# 更新子任务

更新指定工作项节点下的一个子任务，可修改名称、负责人、排期、备注、交付物和自定义字段。路径需要同时定位工作项、节点与 `task_id`；只知道子任务名称不足以调用。

## 更新前检查

- `assignee` 用于非角色负责人，`role_assignee` 用于角色负责人，两者不能同时设置。
- 只有已配置交付物的子任务才能更新 `deliverable`。
- `update_fields` 更新指定字段；共享字段值结构的 `update_mode` 默认 `0`（替换），`1` 为更新。富文本值与 Markdown 值二选一。
- 原文明确子任务不支持 `schedule.owners` 和 `schedule.actual_work_time`，即使共享排期结构列出这些字段，也不应据此使用。

自定义字段也可通过[更新工作项](更新工作项.md)修改，使用 `work_item_type_key = sub_task`。本接口权限见[权限管理](../guides/权限管理.md)中的“工作项实例”；产品操作见[任务管理](https://project.feishu.cn/1ykiuvvj/40gyakm8)与[完成任务](https://project.feishu.cn/1ykiuvvj/3bv61iew#%E5%AE%8C%E6%88%90%E4%BB%BB%E5%8A%A1)。

### 排期更新如何处理省略值

| 提交内容 | `schedule.is_auto = true`（默认） | `schedule.is_auto = false` |
| --- | --- | --- |
| 只有排期 | 自动补估分为排期间差值 | 不自动补估分 |
| 只有估分 | 清空排期 | 不清空排期 |
| 两者都提交 | 按值写入 | 按值写入 |
| 两者都未提交 | 估分置 0、排期清空 | 不做改动 |

## 请求说明

**请求方式**：`POST`
**请求地址**：`/open_api/:project_key/work_item/:work_item_type_key/:work_item_id/workflow/:node_id/task/:task_id`

<a id="parameter-notes-2"></a>

**is_auto 的填写说明**

排期与估分更新模式，不传表示为 true

true：

- 若只填写了排期，则自动将估分补充为排期之间的差值

- 若只填写了估分，则会将排期清空

- 若排期、估分均填写，会按所填值落库

- 若排期、估分均未填写，则会将估分置为0、排期清空

false：

- 若只填写了排期，不会将估分补充为排期之间的差值

- 若只填写了估分，不会将排期清空

- 若排期、估分均填写，会按所填值落库

- 若排期、估分均未填写，则视为不做改动，而非清空

## 请求示例

负责人放在 `assignee` 或 `role_assignee`，不放入 `schedule`；排期开始与结束均为毫秒时间戳。

请求路径：`POST /open_api/64f7f57d89aa3bb71bfdxxxx/work_item/story/12584xxxx/workflow/doing/task/12345xxxx`

```json
{
  "name": "1234",
  "note": "chayihua",
  "role_assignee": [
    {
      "role": "RD",
      "owners": [
        "xxx"
      ]
    }
  ],
  "schedule": {
    "points": 3,
    "estimate_start_date": 1724169600000,
    "estimate_end_date": 1724428799999
  },
  "deliverable": [
    {
      "field_key": "field_123",
      "field_value": "test"
    }
  ],
  "update_fields": [
    {
      "field_key": "field_184c63",
      "field_value": 1646409600000
    }
  ]
}
```

### 错误返回示例

以下错误表示子任务负责人类型为角色负责人时，`role_assignee` 和 `assignee` 不能同时设置。

- 当节点负责人类型为非角色负责人时，使用 `assignee`；

- 当节点负责人类型为角色负责人时，使用 `role_assignee`。

```json
  "err_msg": "Role_Assignee and Assignee Can't Be Set Together",

  }
}
```
