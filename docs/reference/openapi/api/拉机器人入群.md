# 拉机器人入群

将 `app_ids` 中的飞书应用机器人加入指定工作项已经关联的群聊。工作项由路径定位，工作项类型放在请求体中；这里不直接接受任意 `chat_id`。

产品中的群关联方式见[绑定飞书群](https://project.feishu.cn/1ykiuvvj/55tqfakx)，插件权限见[权限管理](../guides/权限管理.md)中的“工作项实例”。

<a id="注意事项"></a>

## 注意事项

1. 群聊已经与目标工作项绑定。
2. 群内已经存在“飞书项目”机器人。
3. 待加入的应用机器人对操作人可见，且操作人拥有邀请用户或机器人入群的权限。

前两项是原文明确的使用条件，第三项对应本篇可返回的可见性和邀请权限错误。

<a id="请求说明"></a>

## 请求说明

**请求方式**：`POST`
**请求地址**：`/open_api/:project_key/work_item/:work_item_id/bot_join_chat`

<a id="请求参数"></a>

## 请求参数

<a id="header"></a>

### 请求头

接口调用的 Header 配置详见 [Header](../guides/OpenAPI概述.md#a8e43b86)。

<a id="Path"></a>

### 路径参数

| 参数 | 类型 | 是否必须 | 说明 |
| --- | --- | --- | --- |
| project_key | string | 必须 | [填写说明](#parameter-notes-1) |
| work_item_id | string | 必须 | 工作项实例 ID，在工作项实例详情中，展开右上角 **··· \> ID**获取。 |

<a id="parameter-notes-1"></a>

**project_key 的填写说明**

空间 ID（project_key），或者空间域名（simple_name）。

- 空间 ID（project_key），在飞书项目空间双击空间名称获取。

- 空间域名（simple_name），飞书项目空间 URL 中的空间标识，一般在在创建空间时自定义。例如 URL 为`https://project.feishu.cn/simple_name` ，则 simple_name 为 `simple_name`。

<a id="Body"></a>

### 请求体

| 参数 | 类型 | 是否必须 | 说明 |
| --- | --- | --- | --- |
| work_item_type_key | string | 必须 | 工作项类型，可以从[获取空间下工作项类型](获取空间下工作项类型.md)接口获取。 |
| app_ids | `list<string>` | 必须 | 飞书开放平台应用 App ID，获取方式参见[飞书文档](https://open.larkoffice.com/document/faq/trouble-shooting/how-to-obtain-app-id)。 |

<a id="返回参数"></a>

## 返回参数

`err_code = 0` 不等于所有机器人都已加入。成功样例同时包含 `failed_members` 和 `success_members`，应分别按 App ID 记录结果。`chat_id` 表示实际处理的工作项关联群。

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `data` | object | 返回数据 |
| `err` | object | 对部分错误会在这里进行更详细的错误描述，可协助日志记录和问题反馈。 |
| `err_msg` | string | 错误信息。 |
| `err_code` | int32 | 错误码。 |

### `data`

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `chat_id` | string | 群组 ID |
| `failed_members` | `list<string>` | 失败应用 |
| `success_members` | `list<string>` | 成功应用 |

### `err`

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `code` | int32 | 部分场景下，透出更详细错误对应的错误码。 |
| `msg` | string | 部分场景下，透出更详细的错误描述。 |
| `log_id` | string | 报错场景下的调用链标识符，用于追踪错误发生时的完整调用链路，便于日志记录和问题排查。 |

<a id="请求示例"></a>

## 请求示例

**请求路径**：`POST /open_api/6760240b9fbad1**/work_item/6751**/bot_join_chat`

```json
{
  "work_item_type_key": "story",
  "app_ids": [
    "cli_a56f3d7c98******"
  ]
}
```

<a id="返回示例"></a>

## 返回示例

**请求成功返回**

```json
{
  "data": {
    "chat_id": "oc_be9d34a9c08f4daxxxxxx",
    "failed_members": [
      "cli_a144xxxxx"
    ],
    "success_members": [
      "cli_a133xxxxx"
    ]
  },
  "err": {},
  "err_msg": "",
  "err_code": 0
}
```


**请求失败返回**

以下错误原因为传入的 `app_ids` 不正确，或者该飞书应用（机器人）对用户不可见。

```json
{
  "err_code": 50006,
  "err_msg": "Bot is invisible to user",
  "err": {
    "code": 50006,
    "msg": "Please contact administrators of {APP_DISPLAY_NAME} for application visibility",
    "log_id": "2025102614481240B434871E2B269Cxxxx"
  }
}
```
