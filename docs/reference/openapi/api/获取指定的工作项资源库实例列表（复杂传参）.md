# 获取指定的工作项资源库实例列表（复杂传参）

按组合条件读取资源库实例列表及选定字段。目标工作项类型必须已启用资源库，接口权限位于[权限管理](../guides/权限管理.md)的“工作项实例”分类。

## 数据源、筛选与分页

每个 `data_sources` 元素包含空间 ID 和资源工作项类型。注意 `work_item_type_keys` 虽为复数名称，类型却是逗号分隔的字符串，不是数组。

只有创建时间、创建者、所属空间、资源工作项 ID、更新人、更新时间和资源库配置字段可筛选。复合字段使用 `ANY` / `EVERY` 和 `value_search_groups` 时遵循下方限制，不能假定普通工作项的所有筛选键都可直接使用。

`pagination` 必填，单页最多 200 条，按资源工作项 ID 排序；原文明确总查询数量不设上限，通过响应的 `search_after` 续查。首次可省略游标，后续原样传回，不按示例数字自行推算。

`field_selected` 最多 20 个字段，省略时只有 ID 有实际查询值。原示例仍输出其他键的空对象、空数组或零值，因此“仅返回 ID”不等于 JSON 中绝无其他键。

## 请求说明

**请求方式**：`POST`

**请求地址**：`/open_api/work_item/resource/search/params`

| 参数             | 类型           | 是否必须 | 说明                                                                                             |

<a id="field-note-1"></a>

**search_group**

筛选条件，遵循[SearchGroup](../formats/数据结构汇总.md#a889b622)结构规范。

仅创建时间、创建者、所属空间、资源工作项 ID、更新人、更新时间和资源库配置字段可进行筛选，可参考[条件视图格式及常用示例](条件视图格式及常用示例.md)。

<a id="field-note-2"></a>

**field_selected**

**field_selected 查询参数说明**

- **字段选择机制**：支持按需查询，用户可自定义指定需返回的字段集合，该参数为非必选项。如未指定，系统默认仅返回工作项 ID。
- **字段数量限制**：当前系统设定单次查询最多可返回20个字段。
- **字段格式规范**：具体字段格式定义及属性解析规则，请参阅[字段与属性解析格式](../formats/字段与属性解析格式.md)。

#### `data_sources`

| 参数                  | 类型     | 是否必须 | 说明                                                                                |
| --------------------- | -------- | -------- | ----------------------------------------------------------------------------------- |
| `project_key`         | `string` | 必须     | 飞书项目空间的唯一标识，在飞书项目空间双击空间名称即可获取。                        |
| `work_item_type_keys` | `string` | 必须     | 资源的工作项类型，英文逗号分隔。可以从[获取空间下工作项类型](获取空间下工作项类型.md)接口获取。 |

#### `search_group`

| 参数            | 类型           | 是否必须 | 说明                                                                                 |
| --------------- | -------------- | -------- | ------------------------------------------------------------------------------------ |
| `conjunction`   | `string`       | 可选     | 用于指定搜索条件组之间的逻辑连接关系。支持的取值如下所示。 [详细说明](#field-note-3) |
| `search_groups` | `list<object>` | 可选     | 子筛选组，用于嵌套组合多个筛选条件组，支持递归嵌套。                                 |
| `search_params` | `list<object>` | 可选     | 固定参数，遵循[SearchParam](../formats/数据结构汇总.md#e2caf2db)结构规范                 |

<a id="field-note-3"></a>

**conjunction**

用于指定搜索条件组之间的逻辑连接关系。支持的取值如下所示。

- `AND`：表示所有条件必须同时满足；
- `OR`：表示任一条件满足即可。

#### `search_group.search_params`

| 参数                  | 类型     | 是否必须 | 说明                                                                                                                           |
| --------------------- | -------- | -------- | ------------------------------------------------------------------------------------------------------------------------------ |
| `value`               | `file`   | 可选     | 搜索字段值结构 [详细说明](#field-note-4)                                                                                       |
| `operator`            | `string` | 可选     | 用于指定搜索条件的操作符类型，支持的取值如下所示。 [详细说明](#field-note-5)                                                   |
| `param_key`           | `string` | 可选     | 字段 key                                                                                                                       |
| `pre_operator`        | `string` | 可选     | 前置操作符，用于指定复合字段搜索条件的逻辑关系。目前仅用于复合字段相关搜索场景。支持的取值如下所示。 [详细说明](#field-note-6) |
| `value_search_groups` | `object` | 可选     | 出现条件：param_key 为复合字段的「父字段」且 operator 为 [详细说明](#field-note-7)                                             |

<a id="field-note-4"></a>

**value**

搜索字段值结构

- 搜索可参考[搜索参数格式及常用示例](../formats/搜索参数格式及常用示例.md)
- 条件视图可参考[条件视图格式及常用示例](条件视图格式及常用示例.md)。

<a id="field-note-5"></a>

**operator**

用于指定搜索条件的操作符类型，支持的取值如下所示。

-

`Reg = "~" //匹配`

-

`NReg = "!~" //不匹配`

-

`Eq = "=" //等于`

-

`Ne = "!=" //不等于`

-

`Lt = "<" //小于`

-

`Gt = ">" //大于`

-

`Lte = "<=" //小于等于`

-

`Gte = ">=" //大于等于`

-

`HasAnyOf = "HAS ANY OF" //存在选项属于`

-

`HasNoneOf = "HAS NONE OF" //全部选项均不属于`

-

`IsNull = "IS NULL" //为空`

-

`NotNull = "IS NOT NULL" //不为空`

-

`Contains = "CONTAINS" //包含`

-

`NotContains = "NOT CONTAINS" //不包含`

-

`Meet = "MEET" //满足`

-

`NotMeet = "NOT MEET" //不满足`

<a id="field-note-6"></a>

**pre_operator**

前置操作符，用于指定复合字段搜索条件的逻辑关系。目前仅用于复合字段相关搜索场景。支持的取值如下所示。

- `ANY`：满足任意一组条件；
- `EVERY`：满足所有组条件。

<a id="field-note-7"></a>

**value_search_groups**

出现条件：param_key 为复合字段的「父字段」且 operator 为

“满足/不满足”。

内容：value_search_groups 中包含「复合字段子字段」的 param_key、value、operator；value、operator 跟随「复合字段子字段」param_key。

注意：value_search_groups 内部目前不支持 pre_operator

#### `pagination`

| -------------- | -------- | -------- | ---------------------------------------------------------------- |
| `page_size`    | `int64`  | 可选     | 每页数据，最大200；排序方式：按照资源工作项id排序                |
| `search_after` | `string` | 可选     | 代表从哪里继续往下查询， search_after 会在返回结果中返回最新数据 |
