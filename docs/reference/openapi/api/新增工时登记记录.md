# 新增工时登记记录

为指定工作项的节点或子任务登记实际工时。接口权限位于[权限管理](../guides/权限管理.md)的“工作项实例”分类；先确认工作项已启用工时登记，并通过[工作流详情](获取工作流详情.md)取得关联对象 ID。

## 日期、对象与工时上限

`work_begin_date` 和 `work_end_date` 是毫秒时间戳，可取对应日期内任意时刻，但开始值必须小于结束值。`include_holidays` 必填，用于选择是否包含节假日。

每条记录用 `resource_type` 区分 `node` 与 `sub_task`，再由 `resource_id` 指定节点或子任务。工时单位是天；同一空间内，每位用户在任意一天的累计登记不能超过 3 人天，超限返回 `1000051914`。已终止工作项不允许登记。

成功响应返回新记录 ID 及其关联对象。后续修改应使用记录 `id`，不是节点 ID。

<a id="注意事项"></a>

## 注意事项

1. 调用当前接口前，请先开启工时登记 API，有以下两种方式：
   - 通过[更新工作项基础信息配置](更新工作项基础信息配置.md)将 `actual_work_time_switch` 设置为 `true`。

   - 在飞书项目空间设置中安装[工时登记](https://project.feishu.cn/1ykiuvvj/3uh9k5d9)插件。

2. 以**工时登记**的方式使用”实际工时“后，对应节点或子任务上原有的历史”实际工时“会被清空。

<a id="请求说明"></a>

## 请求说明

**请求方式**：`POST`

**请求地址**：`/open_api/:project_key/work_item/:work_item_type_key/:work_item_id/work_hour_record`

<a id="请求参数"></a>

## 请求参数

<a id="header"></a>

### 请求头

接口调用的 Header 配置详见 [Header](../guides/OpenAPI概述.md#a8e43b86)。

<a id="Path"></a>

### 路径参数

| 参数                 | 类型     | 是否必须 | 说明                                                                                         |
| -------------------- | -------- | -------- | -------------------------------------------------------------------------------------------- |
| `project_key`        | `string` | 必须     | 空间 ID（project_key），在飞书项目空间双击空间名称获取。需要与 `work_item_id` 对应实例匹配。 |
| `work_item_type_key` | `string` | 必须     | 工作项类型，通过[获取工作项详情](获取工作项详情.md)接口获取。需要与 `work_item_id` 对应实例匹配。  |
| `work_item_id`       | `string` | 必须     | 本次新增工时登记记录的所属工作项实例 ID。                                                    |

<a id="Body"></a>

### 请求体

| 参数                   | 类型           | 是否必须 | 说明                                                                                               |
| ---------------------- | -------------- | -------- | -------------------------------------------------------------------------------------------------- |
| `work_begin_date`      | `int64`        | 必须     | 工作开始日期（毫秒级别时间戳），对应日期内任意时刻的时间戳均可；该时间戳须小于 `work_end_date`。   |
| `work_end_date`        | `int64`        | 必须     | 工作结束日期（毫秒级别时间戳），对应日期内任意时刻的时间戳均可；该时间戳须大于 `work_begin_date`。 |
| `include_holidays`     | `boolean`      | 必须     | 是否包含节假日。                                                                                   |
| `working_hour_records` | `list<object>` | 必须     | 待创建工时的记录列表，遵循[CreateWorkingHourRecord](../formats/数据结构汇总.md#ccc642ba)结构规范。     |

#### `working_hour_records`

| 参数               | 类型     | 是否必须 | 说明                                                 |
| ------------------ | -------- | -------- | ---------------------------------------------------- |
| `resource_type`    | `string` | 必须     | 关联对象类型： [详细说明](#field-note-1)             |
| `resource_id`      | `string` | 必须     | 关联对象 ID，通过[获取工作流详情](获取工作流详情.md)获取。 |
| `work_time`        | `string` | 必须     | 实际工时，单位为天。                                 |
| `work_description` | `string` | 可选     | 工作描述。                                           |

<a id="field-note-1"></a>

**resource_type**

关联对象类型：

- 节点为 `node`
- 子任务为 `sub_task`

<a id="返回参数"></a>

## 返回参数

| 参数       | 类型           | 说明                                             |
| ---------- | -------------- | ------------------------------------------------ |
| `data`     | `list<object>` | 返回工时登记记录的列表，包含每条记录的详细信息。 |
| `err`      | `object`       | 请求成功时返回空值，请求失败时返回实际错误信息。 |
| `err_msg`  | `string`       | 请求成功时返回空值，请求失败时返回实际错误信息。 |
| `err_code` | `int32`        | 请求成功时0，请求失败返回实际错误码。            |

### `data`

| 参数            | 类型     | 说明                                                                       |
| --------------- | -------- | -------------------------------------------------------------------------- |
| `id`            | `int64`  | 工时登记记录 ID。                                                          |
| `resource_id`   | `string` | 关联对象 ID，对象类型为节点时返回节点 ID，类型为子任务时返回子任务 ID。    |
| `resource_type` | `string` | 关联对象类型，对象类型为节点时返回 `node`，类型为子任务时返回 `sub_task`。 |

### `err`

| 参数     | 类型     | 说明                                                                                 |
| -------- | -------- | ------------------------------------------------------------------------------------ |
| `code`   | `int32`  | 部分场景下，透出更详细错误对应的错误码。                                             |
| `msg`    | `string` | 部分场景下，透出更详细的错误描述。                                                   |
| `log_id` | `string` | 报错场景下的调用链标识符，用于追踪错误发生时的完整调用链路，便于日志记录和问题排查。 |

<a id="请求示例"></a>

## 请求示例

**请求路径**：`POST /open_api/66f11218c3b4a0b42334xxxx/work_item/story/12584xxxx/work_hour_record`

`work_time` 按请求参数和 `CreateWorkingHourRecord` 定义传入数值字符串，单位为天。

```json
{
  "work_begin_date": 1756656000000,
  "work_end_date": 1759247999000,
  "include_holidays": false,
  "working_hour_records": [
    {
      "resource_type": "node",
      "resource_id": "doing",
      "work_time": "1",
      "work_description": "\u4f7f\u7528 API \u521b\u5efa\u5de5\u65f6"
    }
  ]
}
```
