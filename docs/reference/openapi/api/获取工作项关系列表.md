# 获取工作项关系列表

列出空间中的工作项关系配置，返回关系 ID、启停状态、本空间工作项类型，以及可关联的目标空间和工作项类型。关系 ID 可供后续更新、删除关系配置或创建关联字段使用。

## 使用前确认

`relation_type=0` 表示普通关系，`1` 表示父子关系。`relation_details` 描述关系允许指向的空间与类型，属于配置层；返回结果不包含具体工作项实例之间的关联记录。

对应的平台功能介绍详见[关系管理](https://project.feishu.cn/1ykiuvvj/se3xal6e)。对应的权限申请在**权限管理-工作项实例**分类下，相关功能介绍详见[权限管理](../guides/权限管理.md)。

<a id="请求说明"></a>

## 请求说明

- 请求方式：GET

- 请求地址：/open_api/:project_key/work_item/relation

<a id="请求参数"></a>

## 请求参数

<a id="header"></a>

### Header

接口调用的 Header 配置详见 [Header](../guides/OpenAPI概述.md#a8e43b86)。

<a id="Path"></a>

### Path

| 参数 | 类型 | 是否必须 | 说明 |
| --- | --- | --- | --- |
| `project_key` | string | 必须 | [说明](#parameter-note-1) |

<a id="parameter-note-1"></a>

**project_key：说明**

空间 ID（project_key），或者空间域名（simple_name）。
- 空间 ID（project_key），在飞书项目空间双击空间名称获取。
- 空间域名（simple_name），`simple_name` 一般在飞书项目空间 URL 中获取。例如空间 URL 为 “https://project.feishu.cn/doc/overview”，则 `simple_name`为 “doc”。

<a id="返回参数"></a>

## 返回参数

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `data` | `list<object>` | 工作项关系，遵循[WorkItemRelation](../formats/数据结构汇总.md#713bd03c)结构规范 |
| `err` | object | 请求成功时返回空值，请求失败时返回实际错误信息。 |
| `err_msg` | string | 请求成功时返回空值，请求失败时返回实际错误信息。 |
| `err_code` | int32 | 请求成功时0，请求失败返回实际错误码。 |

### `data` 的字段

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `id` | string | 工作项关系 ID |
| `name` | string | 工作项关系名称 |
| `relation_type` | int64 | 工作项关联关系的类型。支持的取值如下所示。<br>- `0`：普通关系；<br>- `1`：父子关系。 |
| `disabled` | boolean | 是否禁用 |
| `work_item_type_key` | string | 本空间工作项类型key |
| `work_item_type_name` | string | 本空间工作项名称 |
| `relation_details` | `list<object>` | 关联工作项，遵循[RelationDetail](../formats/数据结构汇总.md#82b169ec)结构规范 |

### `data.relation_details` 的字段

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `project_key` | string | 关联空间的空间 ID。如果是同空间关联，仍需要填写该空间的 `project_key`。 |
| `project_name` | string | 关联空间名称。 |
| `work_item_type_key` | string | 关联工作项类型 key。 |
| `work_item_type_name` | string | 关联工作项类型名称。 |

### `err` 的字段

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `code` | int32 | 部分场景下，透出更详细错误对应的错误码。 |
| `msg` | string | 部分场景下，透出更详细的错误描述。 |
| `log_id` | string | 报错场景下的调用链标识符，用于追踪错误发生时的完整调用链路，便于日志记录和问题排查。 |
