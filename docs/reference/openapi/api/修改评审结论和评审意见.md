# 修改评审结论和评审意见

更新某个工作项节点的评审意见和评审结论，也可清空已有评审信息。插件权限位于“权限管理 → 工作项实例”。

## 选择操作语义

| 意图 | 参数写法 | 原文规定的权限与行为 |
| --- | --- | --- |
| 保留某个字段 | 不传 `opinion` 或 `finished_conclusion_option_key` | 未传字段不做处理 |
| 删除某个字段 | 对应字段传空字符串 | 删除该项意见或结论 |
| 更新节点汇总信息 | `operation_type: "node"` | 仅节点负责人可操作 |
| 更新个人评论 | `operation_type: "owner"` | 操作个人评论 |
| 置空当前评审信息 | `reset: true` | 仅流转人可执行 |

`reset` 默认 `false`，此时 `operation_type` 必填。标签 key 可通过[批量查询评审意见、评审结论](批量查询评审意见、评审结论.md)读取已有值，也可通过[评审结论标签值查询](评审结论标签值查询.md)核对节点配置。

<a id="请求说明"></a>

## 请求说明

**请求方式**：`POST`
**请求地址**：`/open_api/work_item/finished/update`

<a id="请求参数"></a>

## 请求参数

<a id="header"></a>

### 请求头

接口调用的 Header 配置详见 [Header](../guides/OpenAPI概述.md#a8e43b86)。

<a id="Body"></a>

### 请求体

| 参数 | 类型 | 是否必须 | 说明 |
| --- | --- | --- | --- |
| project_key | string | 必须 | 空间 ID（project_key），在飞书项目空间双击空间名称获取。 |
| work_item_id | int64 | 必须 | 工作项 ID。 |
| node_id | string | 必须 | 目标节点 ID（节点 ID 或节点 state_key 等价），可通过[获取工作流详情](获取工作流详情.md)获取。 |
| opinion | string | 可选 | 评审意见，传入空字符串表示删除，不传不做处理。 |
| finished_conclusion_option_key | string | 可选 | 评审结论 label key，通过[批量查询评审意见、评审结论](批量查询评审意见、评审结论.md)查询获取，传入空字符串表示删除，不传不做处理。 |
| operation_type | string | 可选 | 操作更新类型，用于指定当前操作是针对节点评审信息还是个人评论。支持的取值如下所示。<br>- `node`：操作节点评审信息（仅节点负责人可操作）；<br>- `owner`：操作个人评论。当 `reset` 为 `false`时，该字段为必填。 |
| reset | boolean | 可选 | 是否置空当前评审信息，默认 `false`；仅流转人可执行。为 `true` 时，`opinion`、`finished_conclusion_option_key` 和 `operation_type` 可为空。 |

## 返回参数

| --- | --- | --- |
| err | object | 请求成功时返回空值，请求失败时返回实际错误信息。 |
| err.code | int32 | 部分场景下，透出更详细错误对应的错误码。 |
| err.msg | string | 部分场景下，透出更详细的错误描述。 |
| err.log_id | string | 报错场景下的调用链标识符，用于追踪错误发生时的完整调用链路，便于日志记录和问题排查。 |
| err_msg | string | 请求成功时返回空值，请求失败时返回实际错误信息。 |
| err_code | int32 | 请求成功时返回0，请求失败返回实际错误码。错误码。 |

<a id="请求示例"></a>

## 请求示例

示例中的数值型脱敏标识已用等长演示数字替代，调用时填写真实 ID；中文数据采用等义 Unicode 转义。

中文意见“实例意见”使用等义 Unicode 转义；调用时填写真实工作项 ID 和标签 key。

```json
{
  "project_key": "676e6839bd3a3bcba14b****",
  "work_item_id": 126940000,
  "node_id": "start_0",
  "opinion": "\u5b9e\u4f8b\u610f\u89c1",
  "finished_conclusion_option_key": "ukesh****",
  "operation_type": "node"
}
```
