# 上传文件或富文本图片

上传文件并取得资源路径，主要用于富文本图片。目标由空间路径确定，成功后的 `data` 是附件链接；本接口没有工作项 ID 或附件字段参数。

## 上传方式

通过 `multipart/form-data` 的 `file` 字段提交文件二进制流，单文件最大 100M。需要直接把文件加入工作项附件字段时，应使用[添加附件](添加附件.md)。插件权限见[权限管理](../guides/权限管理.md)中的“工作项实例”。

<a id="请求说明"></a>

## 请求说明

**请求方式**：`POST`
**请求地址**：`/open_api/:project_key/file/upload`

<a id="请求参数"></a>

## 请求参数

<a id="header"></a>

### 请求头

接口调用的 Header 配置详见 [Header](../guides/OpenAPI概述.md#a8e43b86)。

<a id="Path"></a>

### 路径参数

| 参数 | 类型 | 是否必须 | 说明 |
| --- | --- | --- | --- |
| project_key | string | 必须 | [填写说明](#parameter-notes-1) |

<a id="parameter-notes-1"></a>

**project_key 的填写说明**

空间 ID（project_key），或者空间域名（simple_name）。

- 空间 ID（project_key），在飞书项目空间双击空间名称获取。

- 空间域名（simple_name），`simple_name` 一般在飞书项目空间 URL 中获取。例如空间 URL 为 “https://project.feishu.cn/doc/overview”，则 `simple_name`为 “doc”。

<a id="Body"></a>

### 请求体

| 参数 | 类型 | 是否必须 | 说明 |
| --- | --- | --- | --- |
| file | file，form 表单中上传 | 必须 | 附件-目前最大支持100M |

## 返回参数

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| data | string | 附件链接 |
| err | object | 请求成功时返回空值，请求失败时返回实际错误信息。 |
| err.code | int32 | 部分场景下，透出更详细错误对应的错误码。 |

| err_msg | string | 请求成功时返回空值，请求失败时返回实际错误信息。 |
| err_code | int32 | 请求成功时0，请求失败返回实际错误码。 |

<a id="请求示例"></a>

## 请求示例

### multipart 请求

以下根据原文的表单定义整理，环境变量需替换为实际身份与空间。

```bash
curl --request POST "https://project.feishu.cn/open_api/${PROJECT_KEY}/file/upload" \
  --header "X-Plugin-Token: ${PLUGIN_ACCESS_TOKEN}" \
  --header "X-User-Key: ${USER_KEY}" \
  --form 'file=@example.jpg;type=image/jpeg'
```


<a id="返回示例"></a>

## 返回示例

成功时读取 `data` 中的资源路径。原文未在本接口中说明链接有效期，不能直接套用其他文件接口的暂存期限。

### 成功返回示例

```json
{
  "data": "https://project.feishu.cn/goapi/v1/tos/file/meego/checklist/c11210bb-adc8-4ff8-8925-eed36912f4f3.png?isSaas=1",
  "err": {},
  "err_msg": "",
  "err_code": 0
}
```

### 错误返回示例

以下错误原因为传入的 `project_key` 不正确。

```json
{
  "err_code": 30016,
  "err_msg": "Project Not Found",
  "err": {
    "code": 30016,
    "msg": "Project Not Found"
  }
}
```
