# 查询用户组成员

分页查询指定空间的管理员、空间成员或自定义用户组成员。接口授权位于[权限管理](../guides/权限管理.md)的“用户”分类。请求需要用户凭证，不能直接沿用普通插件凭证调用。

## 选择用户组并分页

| 查询目标         | `user_group_type` | `user_group_ids`                     |
| ---------------- | ----------------- | ------------------------------------ |
| 空间管理员       | `PROJECT_ADMIN`   | 不需要指定自定义组 ID                |
| 空间成员         | `PROJECT_MEMBER`  | 不需要指定自定义组 ID                |
| 指定自定义用户组 | `CUSTOMIZE`       | 传入目标组 ID，单次最多 50 个        |
| 全部自定义用户组 | `CUSTOMIZE`       | 留空，查询空间下所有自定义用户组成员 |

默认查询第一页，每页默认 50 条，最多 100 条。以 `data.pagination.has_more` 判断是否继续；返回的 `user_members` 仅包含用户成员，不返回部门成员。

<a id="注意事项"></a>

凭证获取方式见[获取用户访问凭证 user_access_token](../guides/获取访问凭证.md#3df3fccd)。

<a id="请求说明"></a>

## 请求说明

**请求方式**：`POST`

**请求地址**：`/open_api/:project_key/user_groups/members/page`

<a id="请求参数"></a>

## 请求参数

<a id="header"></a>

### 请求头

接口调用的 Header 配置详见[Header](../guides/OpenAPI概述.md#a8e43b86)。

<a id="Path"></a>

### 路径参数

| 参数          | 类型     | 是否必须 | 说明                                                                            |
| ------------- | -------- | -------- | ------------------------------------------------------------------------------- |
| `project_key` | `string` | 必须     | 空间 ID（project_key），或者空间域名（simple_name）。 [详细说明](#field-note-1) |

<a id="field-note-1"></a>

**project_key**

空间 ID（project_key），或者空间域名（simple_name）。

- 空间 ID（project_key），在飞书项目空间双击空间名称获取。
- 空间域名（simple_name），`simple_name` 一般在飞书项目空间 URL 中获取。例如空间 URL 为 “https://project.feishu.cn/doc/overview”，则 `simple_name`为 “doc”。

<a id="Body"></a>

### 请求体

| 参数              | 类型           | 是否必须 | 说明                                                  |
| ----------------- | -------------- | -------- | ----------------------------------------------------- |
| `user_group_type` | `string`       | 必须     | 用户组类型，枚举列表： [详细说明](#field-note-2)      |
| `user_group_ids`  | `list<string>` | 可选     | [详细说明](#field-note-3)                             |
| `page_num`        | `int64`        | 可选     | 页码，如果为空，默认查询第一页。                      |
| `page_size`       | `int64`        | 可选     | 页大小，默认查询50条数据，单页查询不能超过100条数据。 |

<a id="field-note-2"></a>

**user_group_type**

用户组类型，枚举列表：

- 空间管理员：PROJECT_ADMIN
- 空间成员：PROJECT_MEMBER
- 自定义用户组：CUSTOMIZE

<a id="field-note-3"></a>

**user_group_ids**

用户组 ID 列表，在该用户组页面 URL 中获取。例如该用户组 URL 为“https://project.feishu.cn/intxxxx/setting/userGroup/756472096042365xxxx”，则 `user_group_ids` 为“756472096042365xxxx”。

当 `user_group_type=CUSTOMIZE` 时，如果为空，则表示查询空间下所有的自定义用户组成员。单次查询不能超过50个用户组。

<a id="返回参数"></a>

## 返回参数

成功响应的业务对象位于 `data` 下，`err`、`err_msg`、`err_code` 位于响应顶层。

| 参数         | 类型           | 说明                                             |
| ------------ | -------------- | ------------------------------------------------ |
| `data.list`       | `list<object>` | 用户组列表。                                     |
| `data.pagination` | `object`       | 分页信息。                                       |
| `err`        | `object`       | 请求成功时返回空值，请求失败时返回实际错误信息。 |
| `err_msg`    | `string`       | 请求成功时返回空值，请求失败时返回实际错误信息。 |
| `err_code`   | `int32`        | 请求成功时0，请求失败返回实际错误码。            |

### `data.list`

| 参数           | 类型           | 说明                                                  |
| -------------- | -------------- | ----------------------------------------------------- |
| `id`           | `string`       | 用户组 ID。                                           |
| `name`         | `string`       | 用户组名称。                                          |
| `user_count`   | `int64`        | 用户组员工数量。                                      |
| `user_members` | `list<string>` | 用户组员工 user_key，只返回用户成员，不返回部门成员。 |

### `data.pagination`

| 参数        | 类型      | 说明           |
| ----------- | --------- | -------------- |
| `has_more`  | `boolean` | 是否还有数据。 |
| `page_num`  | `int64`   | 页码。         |
| `page_size` | `int64`   | 页大小。       |

### `err`

| 参数     | 类型     | 说明                                                                                 |
| -------- | -------- | ------------------------------------------------------------------------------------ |
| `code`   | `int32`  | 部分场景下，透出更详细错误对应的错误码。                                             |
| `msg`    | `string` | 部分场景下，透出更详细的错误描述。                                                   |
| `log_id` | `string` | 报错场景下的调用链标识符，用于追踪错误发生时的完整调用链路，便于日志记录和问题排查。 |
