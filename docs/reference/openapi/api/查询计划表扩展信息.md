# 查询计划表扩展信息

读取工作项使用的计划表模板、节点连接关系，以及按需开启的 WBS 链路信息。请求必须提供空间、工作项 ID 与工作项类型 key。

## 选择链路扩展

| 请求开关 | 返回对象 | 主要用途 |
| --- | --- | --- |
| `expand.need_wbs_relation_chain_path` | `relation_chain_path` | 链路层级、类型和模板或节点名称 |
| `expand.need_wbs_relation_chain_entity` | `relation_chain_entity` | 链路中的实际工作项、节点和子任务标识 |

两项扩展默认不查询，可分别或同时启用。层级从 `1` 开始；字段是否有意义取决于元素 `type`，不要要求每个元素都具有节点和子任务字段。

`connections` 在使用工作流模板时返回，目前只定义 `source_state_key` 和 `target_state_key`。模板版本对应当前工作流或状态流的版本。权限见[权限管理](../guides/权限管理.md)中的“工作项”。

<a id="请求说明"></a>

## 请求说明

**请求方式**：`POST`
**请求地址**：`/open_api/work_item/wbs_instance/expand/query`

<a id="请求参数"></a>

## 请求参数

<a id="a3c53a27"></a>

### 请求头

接口调用的 Header 配置详见[Header](../guides/OpenAPI概述.md#a8e43b86)

<a id="Body"></a>

### 请求体

| 参数 | 类型 | 是否必须 | 说明 |
| --- | --- | --- | --- |
| project_key | string | 必须 | 空间 ID（project_key）。<br>- 空间 ID（project_key），在飞书项目空间双击空间名称获取。 |
| work_item_id | int64 | 必须 | 工作项 id |
| work_item_type_key | string | 必须 | 工作项类型key |
| expand | object | 可选 | 扩展信息，不选择则默认不查询。 |
| expand.need_wbs_relation_chain_path | boolean | 可选 | 扩展查询, 是否需要wbs链路层级信息 |
| expand.need_wbs_relation_chain_entity | boolean | 可选 | 扩展查询, 是否需要wbs链路实例信息 |

<a id="返回参数"></a>

## 返回参数

### 按元素类型读取信息

| `type` | 含义 | 需要关注的实例字段 |
| --- | --- | --- |
| `rootWorkItem` | 根工作项 | 工作项 ID、名称、类型 |
| `subWorkItem` | 子流程工作项 | 工作项 ID、名称、类型 |
| `node` | 节点 | `state_key`、`node_name` |
| `subTask` | 子任务 | `sub_task_id`、`sub_task_name` |

外层 `relation_chain_path.work_item_id` 与 `relation_chain_entity.work_item_id` 是当前查询的工作项，数组中 `work_item_id` 是链路实体自身。成功样例将所有业务字段放在 `data` 下。

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `template_key` | string | 计划表模板 key |
| `template_version` | int64 | 计划表模板版本 |
| `template_name` | string | 计划表模板名称 |
| `connections` | `list<object>` | 节点间连接信息 |
| `relation_chain_path` | object | WBS 链路层级信息；仅请求 need_wbs_relation_chain_path 时返回 |
| `relation_chain_entity` | object | WBS 链路实例详情；仅请求 need_wbs_relation_chain_entity 时返回 |
| `err` | object | 对部分错误会在这里进行更详细的错误描述，可协助日志记录和问题反馈。 |
| `err_msg` | string | 错误信息。 |
| `err_code` | int32 | 错误码。 |

#### `connections`

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `source_state_key` | string | 原节点标识 |
| `target_state_key` | string | 目标节点标识 |

#### `relation_chain_path`

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `wbs_relation_chain_path` | `list<object>` | WBS链路层级数组，参见[WBSRelationChainPathItem](../formats/数据结构汇总.md#dc1d30cc)结构规范。 |
| `work_item_id` | int64 | 工作项 ID |

#### `relation_chain_path.wbs_relation_chain_path`

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `project_key` | string | 空间 key |
| `name` | string | 表示 WBS 链路层级中节点的模板名称，当节点类型为 `rootWorkItem`时会返回该字段。 |
| `level` | int32 | 节点所属层级，下标从1开始 |
| `node_name` | string | 节点名称，用于 `node` 类型；其他类型可能为空。 |
| `type` | string | 节点类型：rootWorkItem、subWorkItem、node、subTask |
| `work_item_type_key` | string | 工作项类型 |

#### `relation_chain_entity`

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `wbs_relation_chain_entity` | `list<object>` | WBS链路实例数组，参见[WBSRelationChainEntityItem](../formats/数据结构汇总.md#fd7d77ef)结构规范 |
| `work_item_id` | int64 | 表示 WBS 链路实例中关联的工作项 ID。 |

#### `relation_chain_entity.wbs_relation_chain_entity`

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `project_key` | string | 空间key |
| `type` | string | 表示 WBS 链路实例中节点的类型。支持的取值如下所示。<br>- `rootWorkItem`：根工作项；<br>- `subWorkItem`：子流程工作项；<br>- `node`：节点；<br>- `subTask`：子任务。 |
| `state_key` | string | 当节点类型为 `node`时返回该字段。 |
| `node_name` | string | 当节点类型为 `node`时返回该字段。 |
| `sub_task_name` | string | 当节点类型为 `subTask`时返回该字段。 |
| `sub_task_id` | int64 | 当节点类型为 `subTask`时返回该字段。 |
| `level` | int32 | 工作项所属层级 |
| `work_item_id` | int64 | 工作项id |
| `work_item_name` | string | 工作项名称 |
| `work_item_type_key` | string | 工作项类型 |

#### `err`

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `code` | int32 | 部分场景下，透出更详细错误对应的错误码。 |
| `msg` | string | 部分场景下，透出更详细的错误描述。 |
| `log_id` | string | 报错场景下的调用链标识符，用于追踪错误发生时的完整调用链路，便于日志记录和问题排查。 |
