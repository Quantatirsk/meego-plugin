## 文档约定

- 每篇先说明用途与限制，再按对象层级组织参数、场景示例和错误处理。
- 正文使用中文，参数、枚举和 ID 保持协议含义；代码块使用英文或等价 JSON Unicode 转义。
- 表格使用 GFM，不依赖网页合并单元格或交互展开。原章节锚点保留，维持跨篇引用。
- JSON 示例可解析；片段、占位符和 MQL 中需替换的固定值明确标注。语法有效不等于可直接用于真实租户。
- 原文错误不与正确写法并列作为规范。每篇语义页面的底部提供可复核的官方 URL。
