# 获取创建工作项元数据

<!-- capability-metadata:start -->
## 平台能力标记

<a id="capability-openapi.get.open-api-project-key-work-item-work-item-type-key-meta"></a>
- **获取创建工作项元数据** ｜ `openapi.get.open-api-project-key-work-item-work-item-type-key-meta` ｜ 频次：低 ｜ 状态：待运行时验证

<!-- capability-metadata:end -->

读取指定工作项类型的表单字段配置，用于准备[创建工作项](创建工作项.md)或[更新工作项](更新工作项.md)的字段值。只返回已在[页面布局](https://project.feishu.cn/1ykiuvvj/5z5dzo93)中配置的字段，返回顺序不代表表单展示顺序。接口权限位于[权限管理](../guides/权限管理.md)的“工作项实例”分类。

## 如何使用元数据

先通过 `field_key` 或 `field_alias` 确定字段，再依据 `field_type_key` 按[字段格式](../formats/字段与属性解析格式.md)构造值。选项字段使用 `options[].value` 作为实际写入值，`label` 仅供展示。

必填、可见、有效是三套独立状态，不能把这些整型枚举当成布尔值。条件必填、条件可见、条件有效的具体表达式需要到空间配置查看，本接口的枚举本身不能计算最终结果。

复合字段通过 `compound_fields` 递归描述子字段；级联字段还需读取 `sub_type_level_mode`，为 `SELECT_X_CLASS` 时配合 `sub_type_level_class` 决定至少选择到第几级。角色字段的 `role_assign` 与普通字段的 `default_value` 分开定义。

## 请求说明

**请求方式**：`GET`

**请求地址**：`/open_api/:project_key/work_item/:work_item_type_key/meta`

接口调用的 Header 配置详见 [Header](../guides/OpenAPI概述.md#a8e43b86)。

### 路径参数

| 参数                 | 类型     | 是否必须 | 说明                                                                            |
| -------------------- | -------- | -------- | ------------------------------------------------------------------------------- |
| `project_key`        | `string` | 必须     | 空间 ID（project_key），或者空间域名（simple_name）。 [详细说明](#field-note-1) |

<a id="field-note-1"></a>

**project_key**

空间 ID（project_key），或者空间域名（simple_name）。

- 空间 ID（project_key），在飞书项目空间双击空间名称获取。
- 空间域名（simple_name），`simple_name` 一般在飞书项目空间 URL 中获取。例如空间 URL 为 “https://project.feishu.cn/doc/overview”，则 `simple_name`为 “doc”。

<a id="field-note-2"></a>

**is_required**

标识表单项的必填状态，支持的取值如下所示。

- `1`：必填；
- `2`：非必填；
- `3`：条件必填（具体条件需在空间配置中查看）。

<a id="field-note-3"></a>

**is_visibility**

标识表单项的可见性状态。支持的取值如下所示。

- `1`：默认可见；
- `2`：条件可见（具体条件需在空间配置中查看）。

<a id="field-note-4"></a>

**is_validity**

标识表单项的有效性状态。支持的取值如下所示。

- `1`：有效；
- `2`：无效；
- `3`：条件有效（具体条件需在空间配置中查看）。

<a id="field-note-5"></a>

**free_add**

标识选项字段是否允许用户自行添加选项。支持的取值如下所示。

- `true`：允许用户添加选项；
- `false`：不允许用户添加选项。

<a id="field-note-6"></a>

**sub_type_level_mode**

仅当字段类型为级联单选、级联多选时存在该字段

该字段表示级联字段下的可选层级配置，为枚举值

- SELECT_LAST_CLASS ：表示级联选项必须选择到末级
- SELECT_X_CLASS：表示级联选项至少选择到X级，此处的X取 sub_type_level_class字段的值

<a id="field-note-7"></a>

**sub_type_level_class**

仅当sub_type_level_mode等于SELECT_X_CLASS时存在该字段

该字段表示级联字段下的选项至少选择到X级中的X

- sub_type_level_class是一个int类型的数字，例如：sub_type_level_class=1时表示级联字段下的选项至少选择到第一级
