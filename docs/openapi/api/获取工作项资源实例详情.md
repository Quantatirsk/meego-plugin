# 获取工作项资源实例详情

<!-- capability-metadata:start -->
## 平台能力标记

<a id="capability-openapi.post.open-api-work-item-resource-query"></a>
- **获取工作项资源实例详情** ｜ `openapi.post.open-api-work-item-resource-query` ｜ 频次：低 ｜ 状态：待运行时验证

<!-- capability-metadata:end -->

批量读取指定资源库实例的详细字段，最多 50 个 ID。工作项类型必须启用资源库，普通工作项实例不会作为资源实例返回；普通实例请使用[工作项详情](获取工作项详情.md)。授权位于[权限管理](../guides/权限管理.md)的“工作项实例”分类。

## 字段选择与扩展

请求体中的空间、工作项类型和 ID 列表均必填。`fields` 省略时默认返回全部；显式填写时限制返回的字段，示例展示仅选择 `role_owners`。

本接口的 `expand` 定义包含富文本、子任务父级、关联字段、Markdown 和节点子项关联开关，不含普通详情接口的 `need_workflow` 或 `need_user_detail`，不能直接复制普通详情的所有开关。

字段可能缺失，也可能显式返回 `null`；读取时同时处理这两种情况。

<a id="field-note-1"></a>

**update_mode**

字段的更新模式，用于控制字段值的更新方式。支持的取值如下所示。

- `0`：替换模式，提交的字段值将完全替换原有值；
- `1`：更新模式，仅更新提交的字段值，不影响其他字段。

默认值：`0`（替换模式）

## 请求示例

### 获取指定工作项资源实例

仅输入三个必填参数示例。

以下保留原文的脱敏或结构占位内容，仅作示意。

```text
{
    "project_key": "681c29c58d0d3cfe1498xxxx",
    "work_item_ids": [
        12897xxxx
    ],
    "work_item_type_key": "delixxxx"
}
```

### 获取指定工作项资源实例（带扩展参数）

设置全部必填参数和扩展参数。

以下保留原文的脱敏或结构占位内容，仅作示意。

```text
{
    "project_key": "681c29c58d0d3cfe1498xxxx",
    "work_item_ids": [
        12897xxxx
    ],
    "work_item_type_key": "delivery",
    "expand": {
        "need_multi_text": true,
        "relation_fields_detail": true
    }
}
```

### 指定 field 参数

限制返回参数的 Fields 结构中仅返回 `role_owners` 字段及相关信息。

以下保留原文的脱敏或结构占位内容，仅作示意。

```text
{
    "project_key": "681c29c58d0d3cfe1498xxxx",
    "work_item_ids": [
        12897xxxx
    ],
    "work_item_type_key": "delivery",
    "fields":["role_owners"]
}
```
