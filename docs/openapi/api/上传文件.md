上传一个小于 100M 的文件，取得 `file_token` 后再绑定到评论等业务。该接口一次只上传一个文件，采用 multipart 表单；超过 100M 时使用[分片初始化](分片初始化.md)开始分片上传。

原文只写“小于 100M”和“超过 100M”，未明确正好等于 100M 的边界，也未定义 M 的换算方式。本地保留该限制表述，不把它改写成精确字节数。

<a id="0dc80b71"></a>

## 上传后绑定与文件预览

通过本接口普通上传的文件，绑定到业务点位前不能下载，超过 **7 天**未绑定会自动删除；附件占用容量，删除后解除占用。分片上传使用[完成分片上传](完成分片上传.md)中的专属保留期和访问规则。

无法预览时，检查上传的 MIME 类型是否与内容匹配：JPEG 为 `image/jpeg`，MP4 音频为 `audio/mp4`，MP4 视频为 `video/mp4`。插件权限见[权限管理](../guides/权限管理.md)中的“工作项实例”。

## 请求定义

**请求方式**：`POST`
**请求地址**：`/open_api/:project_key/file/stream/resource/:resource_type/upload_form`

鉴权请求头见[OpenAPI 概述](../guides/OpenAPI概述.md#a8e43b86)。请求体为 multipart 表单，不能发送 JSON 文件名占位。

### 路径参数

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `project_key` | `string` | 是 | 空间 key |
| `resource_type` | `string` | 是 | 文件业务场景，见[业务点位](#43c5dcf9) |

### 表单字段

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `file` | 文件二进制 | 是 | 单个文件，不支持一次上传多个文件 |
| `field_map` | `map[string]string` | 按业务场景 | 文件属主信息，以 JSON 格式填写；原总表标为可选，同时说明部分业务必填 |

## 请求示例

原表单示例包含 `file` 文件流与上面的 `field_map`。以下按原字段组织成 curl，以 `example.pdf` 表示本地文件，空间、身份和工作项替换为实际值。

```bash
curl --request POST "https://project.feishu.cn/open_api/${PROJECT_KEY}/file/stream/resource/CommentAttachment/upload_form" \
  --header "X-Plugin-Token: ${PLUGIN_ACCESS_TOKEN}" \
  --header "X-User-Key: ${USER_KEY}" \
  --form 'file=@example.pdf;type=application/pdf' \
  --form 'field_map={"comment_biz_type":"WORKITEM","work_item_type_key":"story","work_item_id":"14580xxxx"}'
```

## 响应字段

文件服务使用 `code`、`message`、`data` 包裹响应，不能套用其他接口的 `err_code` 读取方式。

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `code` | `int` | `0` 表示成功，非零为实际错误码 |
| `message` | `string` | 响应信息；成功判定以 `code = 0` 为准，不依赖消息内容 |
| `data` | [UploadFileByFormV2Result](../formats/数据结构汇总.md#f1e33470) | 业务数据 |
| `data.file_token` | `string` | 上传后文件唯一标识 |

原参数表未把这些响应字段标为必填。成功后需继续在评论等业务接口中绑定文件。

### 成功示例

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "file_token": "ibZLIct7TjFr5hBaGIuxblv8Q1XEtqQ-xxxxxxkRKcy600orT6HYdocNjnRNZCZKSVBVKKVmc1Y4I58gEIZkxw0ymg8CIk8ZMqW7zIAVRB39X-Sq_j7o1HCTHJ-zHAFy0VKqRS3rlzW-_SxmoBoCBQ=="
  }
}
```

### 失败示例

```json
{
  "code": 1000051709,
  "message": "size limit exceeded",
  "data": null
}
```
