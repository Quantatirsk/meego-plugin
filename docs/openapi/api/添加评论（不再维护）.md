# 添加评论（不再维护）

<!-- capability-metadata:start -->
## 平台能力标记

<a id="capability-openapi.post.open-api-project-key-work-item-work-item-type-key-work-item-id-comment-create"></a>
- **添加评论（不再维护）** ｜ `openapi.post.open-api-project-key-work-item-work-item-type-key-work-item-id-comment-create` ｜ 频次：低 ｜ 状态：已废弃

<!-- capability-metadata:end -->

这是不再维护的工作项评论创建接口。保留原参数和示例供旧系统排查，新接入应使用[添加评论](添加评论.md)的 `POST /open_api/comment/create`。

## 使用前确认

旧接口从 URL 读取空间、工作项类型和实例 ID；Body 中的 `content` 与 `rich_text` 至少一项非空，同时有值时以 `rich_text` 为准，不能直接传 Markdown。

迁移到当前接口时，工作项定位改放 `object`，纯文本改为 `content.type=TEXT` 配合 `content.text`，富文本改放 `content.rich_text`。新接口的评论 ID 位于 `data.comment_id`，旧接口则直接返回数值 `data`。

该接口用于在指定工作项下添加一条评论，添加的评论内容会出现在工作项详情页的评论或备注页签中，并会显示该评论由插件添加。对应的权限申请在**权限管理-工作项实例** 分类下，相关功能介绍详见[权限管理](../guides/权限管理.md)。建议使用或更换为[添加评论](添加评论.md)接口。

<a id="请求说明"></a>

## 请求说明

- 请求方式：POST

- 请求地址：/open_api/:project_key/work_item/:work_item_type_key/:work_item_id/comment/create

<a id="请求参数"></a>

## 请求参数

<a id="header"></a>

### Header

接口调用的 Header 配置详见 [Header](../guides/OpenAPI概述.md#a8e43b86)。

<a id="Path"></a>

### Path

| 参数 | 类型 | 是否必须 | 说明 |
| --- | --- | --- | --- |
| `project_key` | string | 必须 | [说明](#parameter-note-1) |
| `work_item_type_key` | string | 必须 | 工作项类型，从[获取空间下工作项类型](获取空间下工作项类型.md)接口获取。 |
| `work_item_id` | string | 必须 | 工作项实例 ID，在工作项实例详情中，展开右上角 **··· \> ID**获取。 |

<a id="parameter-note-1"></a>

**project_key：说明**

空间 ID（project_key），或者空间域名（simple_name）。
- 空间 ID（project_key），在飞书项目空间双击空间名称获取。
- 空间域名（simple_name），`simple_name` 一般在飞书项目空间 URL 中获取。例如空间 URL 为 “https://project.feishu.cn/doc/overview”，则 `simple_name`为 “doc”。

<a id="Body"></a>

### Body

| 参数 | 类型 | 是否必须 | 说明 |
| --- | --- | --- | --- |
| `content` | string | 可选 | 评论内容，仅支持原生文本。<br>**注：content 参数与 rich_text 参数，可选择其中一个赋值，但不可全为空，都有值时 rich_text 优先。** |
| `rich_text` | `list<object>` | 可选 | [说明](#parameter-note-2) |

<a id="parameter-note-2"></a>

**rich_text：说明**

评论内容，支持富文本格式，可参考[富文本格式](../formats/字段与属性解析格式.md#110a33af)，目前不支持直接传递markdown格式来更新富文本字段。
**注：content 参数与 rich_text 参数，可选择其中一个赋值，但不可全为空，都有值时 rich_text 优先。**

<a id="返回参数"></a>

## 返回参数

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `data` | int64 | 新建的评论 ID。 |
| `err` | object | 请求成功时返回空值，请求失败时返回实际错误信息。 |
| `err_msg` | string | 请求成功时返回空值，请求失败时返回实际错误信息。 |
| `err_code` | int32 | 请求成功时0，请求失败返回实际错误码。 |

### `err` 的字段

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `code` | int32 | 部分场景下，透出更详细错误对应的错误码。 |
| `msg` | string | 部分场景下，透出更详细的错误描述。 |
| `log_id` | string | 报错场景下的调用链标识符，用于追踪错误发生时的完整调用链路，便于日志记录和问题排查。 |

<a id="请求示例"></a>

## 请求示例

### 新增纯文本评论

**请求路径：**`POST /open_api/680dc978eaf703f19c63/work_item/68c2d105010dd08c1cf/623714/comment/create`

```json
{
  "content": "\u6d4b\u8bd5\u8bc4\u8bba"
}
```

```json
{

    {
      "type": "paragraph",
      "content": [
        {
          "type": "text",
          "text": "\u6d4b\u8bd5\u8bc4\u8bba",
          "attrs": {
            "fontColor": "green",
            "fontSize": "h1"
          }
        }
      ]
    }
  ]
}
```
