# 查询评论

<!-- capability-metadata:start -->
## 平台能力标记

<a id="capability-openapi.post.open-api-comment-query"></a>
- **查询评论** ｜ `openapi.post.open-api-comment-query` ｜ 频次：低 ｜ 状态：待运行时验证

<!-- capability-metadata:end -->

按工作项、工作项字段或一级评论查询评论列表，支持方向选择和游标分页。响应同时包含正常、已更新和已删除等状态，客户端应依据 `status` 决定展示方式。

## 使用前确认

| `object.type` | 定位参数 |
| --- | --- |
| `WORKITEM` | `work_item_type_key`、`work_item_id` |
| `WORKITEMFIELD` | 上述两项，加 `field_key` |
| `CHILDCOMMENT` | `parent_id`，必须是相同实例的一级评论 ID |

每页最多 50 条；`direction` 为 `ASC` 或 `DESC`。首轮可省略 cursor，后续使用响应的 `data.next_cursor`，空游标表示结束。查询身份需具备工作项查看权限。需要富文本 Markdown 时设置 `need_rich_text_mark_down=true`。

该接口用于获取指定工作项下的所有评论信息，可按创建时间升序或降序分页返回，对应的权限申请在 权限管理-评论 分类下，相关功能介绍详见 [权限管理](../guides/权限管理.md)。

## 请求说明

- 请求方式：POST

- 请求地址：/open_api/comment/query

<a id="请求参数"></a>

## 请求参数

<a id="header"></a>

### Header

接口调用的 Header 配置详见 [Header](../guides/OpenAPI概述.md#a8e43b86)。

<a id="Body"></a>

### Body

| 参数 | 类型 | 是否必须 | 说明 |
| --- | --- | --- | --- |
| `object` | object | 必须 | 评论对象 |
| `project_key` | string | 必须 | 空间 ID（project_key），在飞书项目空间双击空间名称获取。 |
| `paginator` | object | 必须 | 分页参数 |
| `need_rich_text_mark_down` | boolean | 可选 | 是否需要返回富文本 Markdown 格式信息 |

#### `object` 的字段

| 参数 | 类型 | 是否必须 | 说明 |
| --- | --- | --- | --- |
| `type` | string | 必须 | [说明](#parameter-note-1) |
| `field_key` | string | 可选 | 字段 key，需要和工作项类型的中字段对齐 |
| `parent_id` | string | 可选 | 父评论 id ，可以通过[查询评论](查询评论.md)接口获取，也可以通过创建评论的返回值获取。<br>相同实例下的一级评论的 id。不可以使用二级评论 id |
| `work_item_id` | string | 可选 | 工作项实例 ID，在工作项实例详情中，展开右上角 **··· \> ID** 获取。 |
| `work_item_type_key` | string | 可选 | 工作项类型，从[获取空间下工作项类型](获取空间下工作项类型.md)接口获取。 |

<a id="parameter-note-1"></a>

**type：说明**

评论对象类型
- CHILDCOMMENT(子评论): 需要传参 parent_id
- WORKITEM(工作项): 需要传参 work_item_type_key+work_item_id
- WORKITEMFIELD(工作项字段): 需要传参 work_item_type_key+work_item_id+field_key

#### `paginator` 的字段

| 参数 | 类型 | 是否必须 | 说明 |
| --- | --- | --- | --- |
| `cursor` | string | 后续分页必填 | 分页游标，使用查询返回的 `data.next_cursor`，第一次查询不用传。 |
| `direction` | string | 必须 | 分页方向，ASC(升序) DESC(降序) |
| `page_size` | int32 | 必须 | 分页大小，单次最大 50 |
