# 获取工作项的工时登记记录列表

<!-- capability-metadata:start -->
## 平台能力标记

<a id="capability-openapi.post.open-api-work-item-man-hour-records"></a>
- **获取工作项的工时登记记录列表** ｜ `openapi.post.open-api-work-item-man-hour-records` ｜ 频次：低 ｜ 状态：待运行时验证

<!-- capability-metadata:end -->

分页查询一个工作项的工时登记记录，返回每日记录、登记归属人和关联节点或子任务。接口授权位于[权限管理](../guides/权限管理.md)的“工作项实例”分类。

## 分页与记录身份

页码从 `1` 开始，默认每页 `100` 条，最多 `1000` 条。记录的 `id` 用于后续[更新](更新工时登记记录.md)或[删除](删除工时登记记录.md)；`resource_id` 则是节点或子任务 ID，两者不能混用。

`work_date` 是精确到当天 `00:00:00` 的毫秒时间戳，`created_at` 和 `updated_at` 是记录创建/更新时间。`work_user_key` 表示工时归属人，不应简单等同于查询请求的调用用户。

<a id="注意事项"></a>

## 注意事项

1. 调用当前接口前，请先开启工时登记 API，有以下两种方式：
   - 通过[更新工作项基础信息配置](更新工作项基础信息配置.md)将 `actual_work_time_switch` 设置为 `true`。

   - 在飞书项目空间设置中安装[工时登记](https://project.feishu.cn/1ykiuvvj/3uh9k5d9)插件。

2. 以**工时登记**的方式使用”实际工时“后，对应节点或子任务上原有的历史”实际工时“会被清空。

<a id="请求说明"></a>

## 请求说明

**请求方式**：`POST`

**请求地址**：`/open_api/work_item/man_hour/records`

<a id="请求参数"></a>

## 请求参数

<a id="header"></a>

### 请求头

接口调用的 Header 配置详见 [Header](../guides/OpenAPI概述.md#a8e43b86)。

<a id="Body"></a>

### 请求体

| 参数                 | 类型     | 是否必须 | 说明                                                                                                  |
| -------------------- | -------- | -------- | ----------------------------------------------------------------------------------------------------- |
| `project_key`        | `string` | 必须     | 空间 ID（project_key），或者空间域名（simple_name）。 [详细说明](#field-note-1)                       |
| `work_item_type_key` | `string` | 必须     | 工作项类型，可以通过[获取空间下工作项类型](获取空间下工作项类型.md)接口获取，需要与 `work_item_id` 对应实例匹配。 |
| `work_item_id`       | `int64`  | 必须     | 工作项实例 ID，在工作项实例详情中，展开右上角 **··· \> ID** 获取。                                    |
| `page_num`           | `int64`  | 可选     | 分页页码（从1开始，默认为1）。                                                                        |
| `page_size`          | `int64`  | 可选     | 每页数据（默认100，最大1000）。                                                                       |

<a id="field-note-1"></a>

**project_key**

空间 ID（project_key），或者空间域名（simple_name）。

- 空间 ID（project_key），在飞书项目空间双击空间名称获取。
- 空间域名（simple_name），`simple_name` 一般在飞书项目空间 URL 中获取。例如空间 URL 为 “https://project.feishu.cn/doc/overview”，则 `simple_name`为 “doc”。

## 返回参数

| 参数         | 类型           | 说明                                             |

| 参数                         | 类型     | 说明                                                                       |
| ---------------------------- | -------- | -------------------------------------------------------------------------- |
| `id`                         | `int64`  | 工时登记记录 ID。                                                          |
| `work_date`                  | `int64`  | 工作日期（毫秒时间戳，精确到天，时间为00:00:00）。                         |
| `work_time`                  | `double` | 实际工时。                                                                 |
| `created_at`                 | `int64`  | 创建时间。                                                                 |
| `updated_at`                 | `int64`  | 更新时间。                                                                 |
| `resource_id`                | `string` | 关联对象 ID，对象类型为节点时返回节点 ID，类型为子任务时返回子任务 ID。    |
| `resource_name`              | `string` | 关联对象名。                                                               |
| `resource_type`              | `string` | 关联对象类型，对象类型为节点时返回 `node`，类型为子任务时返回 `sub_task`。 |
| `work_user_key`              | `string` | 该工时记录的归属人 userkey。                                               |
| `work_description`           | `string` | 工作描述。                                                                 |
| `related_work_item_id`       | `int64`  | 关联工作项 ID。                                                            |
| `related_work_item_name`     | `string` | 关联工作项名称。                                                           |
| `related_work_item_type_key` | `string` | 关联工作项类型。                                                           |

| `total`     | `int64` | 查询的数据总数。                    |
| `page_num`  | `int64` | 当前分页查询页数。                  |
| `page_size` | `int64` | 当前分页查询每页数据量，默认为100。 |

| 参数     | 类型     | 说明                                                                                 |

| `msg`    | `string` | 部分场景下，透出更详细的错误描述。                                                   |
| `log_id` | `string` | 报错场景下的调用链标识符，用于追踪错误发生时的完整调用链路，便于日志记录和问题排查。 |

<a id="请求示例"></a>

## 请求示例

请求和成功响应保留了原文的脱敏数值，例如 `12584****`、`18185xxxx`，属于结构示意；实际调用与解析前需替换为完整整数。原例 `work_time: 0.0435` 按原值保留，不四舍五入为节点排期接口的精度。

### 查询工时记录

```text
{
   "project_key":"66f11218c3b4a0b42334****",
   "work_item_type_key":"story",
   "work_item_id":12584****,
}
```

### 分页查询工时记录

```text
{
   "project_key":"66f11218c3b4a0b42334****",
   "work_item_type_key":"story",
   "work_item_id":12584****,
   "page_num": 1,
   "page_size": 10
}
```
