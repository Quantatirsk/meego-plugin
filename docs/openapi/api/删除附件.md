# 删除附件

<!-- capability-metadata:start -->
## 平台能力标记

<a id="capability-openapi.post.open-api-file-delete"></a>
- **删除附件** ｜ `openapi.post.open-api-file-delete` ｜ 频次：低 ｜ 状态：待运行时验证

<!-- capability-metadata:end -->

从指定工作项的一个附件字段中删除 `uuids` 指定的附件。接口使用 `POST /open_api/file/delete`，空间、工作项、目标字段与文件列表全部放在请求体中。

## 字段与文件如何对应

1. 通过[获取工作项详情](获取工作项详情.md)定位 `multi_file` 类型字段及其附件标识。
2. `field_key` 与 `field_alias` **必须且只能填写一个**，支持复合字段中的附件子字段。
3. 将要删除的附件标识放入 `uuids` 数组；目标字段与附件标识应来自同一个工作项的对应字段。

权限申请见[权限管理](../guides/权限管理.md)中的“工作项实例”。本篇未给出批量数量上限，不额外推定。

<a id="请求说明"></a>

## 请求说明

**请求方式**：`POST`
**请求地址**：`/open_api/file/delete`

<a id="请求参数"></a>

## 请求参数

<a id="header"></a>

### 请求头

接口调用的 Header 配置详见 [Header](../guides/OpenAPI概述.md#a8e43b86)。

<a id="Body"></a>

### 请求体

| 参数 | 类型 | 是否必须 | 说明 |
| --- | --- | --- | --- |
| work_item_id | int64 | 必须 | 工作项实例 ID，在工作项实例详情中，展开右上角 **··· \> ID** 获取。 |
| project_key | string | 必须 | [填写说明](#parameter-notes-1) |
| field_key | string | 可选 | 用于删除附件的附件字段 ID，支持复合字段的子字段，可通过[获取工作项详情](获取工作项详情.md)接口查询得到。<br>\*\*注意：\*\*与 `field_alias` 不能同时为空或同时填充。 |
| field_alias | string | 可选 | 用于删除附件的附件字段对接标识，支持复合字段的子字段，可通过[获取工作项详情](获取工作项详情.md)接口查询得到。<br>\*\*注意：\*\*与 `field_key`不能同时为空或同时填充。 |
| uuids | `list<string>` | 必须 | 需要删除的附件唯一标识列表，可通过[获取工作项详情](获取工作项详情.md)接口查询附件字段（multi_file 类型）获取。 |

<a id="parameter-notes-1"></a>

**project_key 的填写说明**

空间 ID（project_key），或者空间域名（simple_name）。

- 空间 ID（project_key），在飞书项目空间双击空间名称获取。

- 空间域名（simple_name），`simple_name` 一般在飞书项目空间 URL 中获取。例如空间 URL 为 “https://project.feishu.cn/doc/overview”，则 `simple_name`为 “doc”。
