# 获取子任务详情

<!-- capability-metadata:start -->
## 平台能力标记

<a id="capability-openapi.get.open-api-project-key-work-item-work-item-type-key-work-item-id-workflow-task"></a>
- **获取子任务详情** ｜ `openapi.get.open-api-project-key-work-item-work-item-type-key-work-item-id-workflow-task` ｜ 频次：低 ｜ 状态：待运行时验证

<!-- capability-metadata:end -->

读取一个工作项的子任务，按所属节点分组返回。省略 `node_id` 时返回所有节点，传入时只返回指定节点的任务；它不是按 `task_id` 获取单条记录的接口。

## 选择返回范围

| 查询条件 | 结果 |
| --- | --- |
| 不传 `node_id` | 工作项全部节点及各自的 `sub_tasks` |
| 传 `node_id` | 目标节点的子任务；该场景下节点 ID 与 `state_key` 等价 |
| `need_rich_text_mark_down = true` | 富文本字段附带 `field_value_markdown` 结构 |

负责人分为直接分配的 `assignee` 与角色联动的 `role_assignee`。不要将排期结构中的 `owners`、`actual_work_time` 当作子任务可写入能力：原文在这两个共享字段上明确标注“子任务不支持”。

权限位于“权限管理 → 工作项实例”，见[权限管理](../guides/权限管理.md)。产品操作见[任务管理](https://project.feishu.cn/1ykiuvvj/40gyakm8)、[完成任务](https://project.feishu.cn/1ykiuvvj/3bv61iew#%E5%AE%8C%E6%88%90%E4%BB%BB%E5%8A%A1)，常见问题见[子任务 FAQ](https://project.feishu.cn/b/helpcenter/1p8d7djs/f4ifnb0b)。

<a id="请求说明"></a>

## 请求说明

**请求方式**：`GET`
**请求地址**：`/open_api/:project_key/work_item/:work_item_type_key/:work_item_id/workflow/task`

<a id="请求参数"></a>

## 请求参数

<a id="header"></a>

### 请求头

接口调用的 Header 配置详见 [Header](../guides/OpenAPI概述.md#a8e43b86)。

<a id="Path"></a>

### 路径参数

| 参数 | 类型 | 是否必须 | 说明 |
| --- | --- | --- | --- |
| project_key | string | 必须 | [填写说明](#parameter-notes-1) |
| work_item_type_key | string | 必须 | 工作项类型，可以从[获取空间下工作项类型](获取空间下工作项类型.md)接口获取。 |
| work_item_id | string | 必须 | 工作项实例 ID，在工作项实例详情中，展开右上角 **··· \> ID** 获取。 |

<a id="parameter-notes-1"></a>

**project_key 的填写说明**

空间 ID（project_key），或者空间域名（simple_name）。

- 空间 ID（project_key），在飞书项目空间双击空间名称获取。

- 空间域名（simple_name），`simple_name` 一般在飞书项目空间 URL 中获取。例如空间 URL 为 “https://project.feishu.cn/doc/overview”，则 `simple_name`为 “doc”。

<a id="Query"></a>

### 查询参数

| 参数 | 类型 | 是否必须 | 说明 |
| --- | --- | --- | --- |
| node_id | string | 可选 | 目标节点的 `state_key`，用于指定查询特定节点的子任务，通过[获取指定的子任务列表（跨空间）](获取指定的子任务列表（跨空间）.md)接口获取。若不传递此参数，则查询所有节点的子任务。节点 ID 和节点  `state_key` 在此场景下等价。 |
| need_rich_text_mark_down | boolean | 可选 | 是否需要返回富文本 Markdown |

<a id="返回参数"></a>

## 返回参数

`data` 中每项是一个节点，`data[].sub_tasks` 才是子任务集合。排期时间为毫秒时间戳，实际开始和完成时间为 ISO 8601 字符串，不能统一按一种格式解析。

`data.state_key` 是节点状态标识；子任务是否完成由 `passed` 表示。

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `data` | `list<object>` | 包含节点及其子任务信息的数组，该返回结构遵循结构体[NodeTask](../formats/数据结构汇总.md#26ceb1ab)格式与规范，每个元素代表一个节点及其关联的子任务数据。 |
| `err` | object | 请求成功时返回空值，请求失败时返回实际错误信息。 |
| `err_code` | int32 | 请求成功时0，请求失败返回实际错误码。 |

<a id="请求示例"></a>

## 请求示例

示例中的数值型脱敏标识已用等长演示数字替代，调用时填写真实 ID；中文数据采用等义 Unicode 转义。

**获取所有节点子任务信息**

```text
GET /open_api/64f7f57d89aa3bb71bfdxxxx/work_item/story/node_1xxxx/workflow/task
```

**获取指定节点子任务信息**

获取 start 节点下的子任务信息。

```text
GET /open_api/64f7f57d89aa3bb71bfdxxxx/work_item/story/node_1xxxx/workflow/task?node_id=start
```

`owner_roles` 表示负责人范围或关联角色；当模式为 `1` 且范围为空时，原协议说明为自动添加、不限制范围。`role_assignee[].exist` 表示该角色在所属工作项实例上是否存在；`template_id`、`version` 分别是流程模板 ID 与版本，`node_name` 为节点名称。
