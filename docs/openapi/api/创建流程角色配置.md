# 创建流程角色配置

<!-- capability-metadata:start -->
## 平台能力标记

<a id="capability-openapi.post.open-api-project-key-flow-roles-work-item-type-key-create-role"></a>
- **创建流程角色配置** ｜ `openapi.post.open-api-project-key-flow-roles-work-item-type-key-create-role` ｜ 频次：低 ｜ 状态：待运行时验证

<!-- capability-metadata:end -->

为指定工作项类型创建流程角色，配置成员分配方式、是否允许多人、自动入群及插件锁定范围。创建成功后返回角色 ID；省略 `role.id` 时由平台生成。

## 使用前确认

- `member_assign_mode=1` 自行添加，`2` 默认指定人员，`3` 默认创建人。
- 仅模式 `2` 可且必须提交 `members`；其他模式提交该参数会被拦截。
- `is_member_multi=false` 表示限制为单人，默认 `true`。
- 设置 `lock_scope` 后，相应属性仅当前插件可修改，且管理员不能删除该角色；`all` 与其他值同时出现时按 `all` 处理。

接口用于**在指定工作项类型下添加一个角色**，对应的平台功能介绍详见[常见问题：角色管理](https://project.feishu.cn/1ykiuvvj/py7go937)。对应的权限申请在**权限管理-配置**分类下，相关功能介绍详见[权限管理](../guides/权限管理.md)。

<a id="parameter-note-1"></a>

**project_key：说明**

空间 ID（project_key），或者空间域名（simple_name）。
- 空间 ID（project_key），在飞书项目空间双击空间名称获取。
- 空间域名（simple_name），`simple_name` 一般在飞书项目空间 URL 中获取。例如空间 URL 为 “https://project.feishu.cn/doc/overview”，则 `simple_name`为 “doc”。

<a id="Body"></a>

### Body

| 参数 | 类型 | 是否必须 | 说明 |
| --- | --- | --- | --- |
| `role` | object | 必须 | 角色配置，参见[RoleConfCreate](../formats/数据结构汇总.md#27fc079c)数据结构规范。 |

#### `role` 的字段

| 参数 | 类型 | 是否必须 | 说明 |
| --- | --- | --- | --- |
| `id` | string | 可选 | 流程角色 ID，不传则随机生成 `role_[0-9a-z]{6}` 格式的  ID。 |
| `name` | string | 必须 | 流程角色名称。 |
| `role_alias` | string | 可选 | 角色对接标识 （默认值为空字符串）。 |
| `member_assign_mode` | int32 | 可选 | [说明](#parameter-note-2) |
| `members` | `list<string>` | 可选 | 指定分配成员的 `user_key` 列表，当成员分配方式为 `2`（默认分配为指定人员）时必传，其他分配方式传参将被拦截。 |
| `is_member_multi` | boolean | 可选 | 是否允许流程角色配置多人。`false` 限制为单人；默认值为 `true`。 |
| `is_owner` | boolean | 可选 | 该角色是否为需求负责人，默认值为 `false`。 |
| `auto_enter_group` | boolean | 可选 | 成员是否自动加入群组，默认值为 `false`。 |
| `lock_scope` | `list<string>` | 可选 | [说明](#parameter-note-3) |

<a id="parameter-note-2"></a>

**member_assign_mode：说明**

流程角色的成员分配方式。默认值为 `1`（自行添加）。支持的分配方式如下所示。
- `1`：自行添加；
- `2`：默认分配为指定人员；
- `3`：默认分配为创建人。

<a id="parameter-note-3"></a>

**lock_scope：说明**

锁定范围，用于控制哪些属性只能由**当前插件**修改。传值后，该角色不能被管理员删除，默认值为空。
取值范围：all / basic / role / member / auth（all 与其它取值互斥，若传递 all 和其他的，则按照 all 进行处理）
含义：
- all：整个角色配置全部锁定
- basic：锁定「基本信息」板块，包含「角色名称」、「角色 ID」、「对接标识」
- role：锁定「角色配置」板块，包含「角色出现方式」、「允许角色自定增删」、「需求负责人」
- member：锁定「成员配置」板块，包含「成员分配方式」、「限制为单人」、「成员自动入群」
- auth：锁定「权限配置」板块，包含「配置权限规则」、「编辑计划表」、「发布计划表」、「回滚作为节点负责人的节点」
