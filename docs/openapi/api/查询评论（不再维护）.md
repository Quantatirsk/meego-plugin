# 查询评论（不再维护）

<!-- capability-metadata:start -->
## 平台能力标记

<a id="capability-openapi.get.open-api-project-key-work-item-work-item-type-key-work-item-id-comments"></a>
- **查询评论（不再维护）** ｜ `openapi.get.open-api-project-key-work-item-work-item-type-key-work-item-id-comments` ｜ 频次：低 ｜ 状态：已废弃

<!-- capability-metadata:end -->

这是不再维护的旧评论查询接口，保留用于已有调用排查。新接入应使用[查询评论](查询评论.md)，其路径、分页方式和返回结构均不同。

## 使用前确认

| 项目 | 本篇旧接口 | 当前接口 |
| --- | --- | --- |
| 方法与路径 | `GET /open_api/:project_key/work_item/:work_item_type_key/:work_item_id/comments` | `POST /open_api/comment/query` |
| 定位 | URL 中的空间、类型、实例 ID | Body 中的 `project_key` 和 `object` |
| 分页 | `page_num` 从 1 开始，单页最多 200 | 游标分页，单页最多 50 |
| 数据位置 | `data[]` 与 `pagination` | `data.comments[]` 与 `data.next_cursor` |

旧接口按创建时间升序返回。迁移时需重新映射评论 ID、内容和分页字段，不能只替换 URL。

对应的权限申请在「权限管理 → 评论」分类下，详见[权限管理](../guides/权限管理.md)。

<a id="请求说明"></a>

## 请求说明

- 请求方式：GET

- 请求地址：/open_api/:project_key/work_item/:work_item_type_key/:work_item_id/comments

<a id="请求参数"></a>

## 请求参数

<a id="header"></a>

### Header

接口调用的 Header 配置详见 [Header](../guides/OpenAPI概述.md#a8e43b86)。

<a id="Path"></a>

### Path

| 参数 | 类型 | 是否必须 | 说明 |
| --- | --- | --- | --- |
| `project_key` | string | 必须 | [说明](#parameter-note-1) |
| `work_item_type_key` | string | 必须 | 工作项类型，从[获取空间下工作项类型](获取空间下工作项类型.md)接口获取。 |
| `work_item_id` | string | 必须 | 工作项实例 ID，在工作项实例详情中，展开右上角 **··· \> ID**获取。 |

<a id="parameter-note-1"></a>

**project_key：说明**

空间 ID（project_key），或者空间域名（simple_name）。
- 空间 ID（project_key），在飞书项目空间双击空间名称获取。
- 空间域名（simple_name），`simple_name` 一般在飞书项目空间 URL 中获取。例如空间 URL 为 “https://project.feishu.cn/doc/overview”，则 `simple_name`为 “doc”。

<a id="Query"></a>

### Query

| 参数 | 类型 | 是否必须 | 说明 |
| --- | --- | --- | --- |
| `page_size` | int32 | 可选 | 每页返回的数据条数，最大支持 `200`条。 |
| `page_num` | int32 | 可选 | 分页页码，从 `1` 开始计数，默认值为 `1`。 |

<a id="返回参数"></a>

## 返回参数

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `data` | `list<object>` | 返回的评论数据，该返回结构遵循结构体[Comment](../formats/数据结构汇总.md#006e1870)格式与规范。 |
| `pagination` | object | 分页信息，包含当前查询的数据总数、当前页数和每页数据量。 |
| `err` | object | 请求成功时返回空值，请求失败时返回实际错误信息。 |
| `err_msg` | string | 请求成功时返回空值，请求失败时返回实际错误信息。 |
| `err_code` | int32 | 请求成功时0，请求失败返回实际错误码。 |

### `data` 的字段

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `id` | int64 | 评论 ID |
| `work_item_id` | int64 | 评论所属工作项 ID |
| `work_item_type_key` | string | 评论所属工作项类型 |
| `created_at` | int64 | 评论创建时间，毫秒精度 |
| `operator` | string | 评论人 |
| `content` | string | 评论内容 |

### `pagination` 的字段

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `total` | int64 | 评论总数 |
| `page_num` | int64 | 分页计数 |
| `page_size` | int64 | 分页大小 |

### `err` 的字段

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `code` | int32 | 部分场景下，透出更详细错误对应的错误码。 |
| `msg` | string | 部分场景下，透出更详细的错误描述。 |
| `log_id` | string | 报错场景下的调用链标识符，用于追踪错误发生时的完整调用链路，便于日志记录和问题排查。 |
