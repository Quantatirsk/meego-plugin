# 获取租户信息

<!-- capability-metadata:start -->
## 平台能力标记

<a id="capability-openapi.get.open-api-commercial-tenant"></a>
- **获取租户信息** ｜ `openapi.get.open-api-commercial-tenant` ｜ 频次：低 ｜ 状态：待运行时验证

<!-- capability-metadata:end -->

ISV 认证租户使用买方 `tenant_key` 查询购买插件的租户资料，包括租户 F 码、名称及飞书集成所需的租户标识。该接口只用于 ISV 商业化场景。

## 使用前确认

这是按一个必填 `tenant_key` 查询的接口，不是无参数枚举租户列表。租户 key 可从插件安装（6001）、卸载（6002）或购买（6004）事件获取；插件还需在「权限管理 → 企业信息」添加并授权接口权限。

本接口仅在 ISV 场景使用。ISV 认证租户可以查询购买该插件的租户信息，目标租户由 `tenant_key` 指定。接口权限在飞书项目开放平台插件详情中**权限管理 \> 企业信息**下添加并授权。

<a id="请求说明"></a>

## 请求说明

- 请求方式：GET

- 请求地址：/open_api/commercial/tenant

<a id="请求参数"></a>

## 请求参数

<a id="header"></a>

### Header

接口调用的 Header 配置详见[Header](../guides/OpenAPI概述.md#a8e43b86)。

<a id="Query"></a>

### Query

| 参数 | 类型 | 是否必须 | 说明 |
| --- | --- | --- | --- |
| `tenant_key` | string | 必须 | 飞书项目租户 key，该参数在[插件安装（6001）](../events/插件装卸监听.md#79fb5e0a)、[插件卸载（6002）](../events/插件装卸监听.md#ae5f6449)、[插件购买（6004）](../events/插件装卸监听.md#686867c6)事件中返回。 |

<a id="返回参数"></a>

## 返回参数

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `tenant` | object | 租户信息，遵循[TenantInfo](../formats/数据结构汇总.md#9d3a8432)结构规范 |
| `err` | object | 请求成功时返回空值，请求失败时返回实际错误信息。 |
| `err_msg` | string | 请求成功时返回空值，请求失败时返回实际错误信息。 |
| `err_code` | int32 | 请求成功时0，请求失败返回实际错误码。 |

### `tenant` 的字段

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `display_id` | string | 租户 F 码 |
| `tenant_key` | string | 租户 key |
| `tenant_name` | string | 租户名称 |
| `tenant_key_lark` | string | 用于飞书集成场景，可通过此参数获取飞书开放平台的租户 Token，参见[飞书文档](https://open.larkoffice.com/document/server-docs/authentication-management/access-token/tenant_access_token)。 |

### `err` 的字段

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `code` | int32 | 部分场景下，透出更详细错误对应的错误码。 |
| `msg` | string | 部分场景下，透出更详细的错误描述。 |
| `log_id` | string | 报错场景下的调用链标识符，用于追踪错误发生时的完整调用链路，便于日志记录和问题排查。 |
