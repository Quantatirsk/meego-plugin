# 计划表草稿发布进度查询

<!-- capability-metadata:start -->
## 平台能力标记

<a id="capability-openapi.post.open-api-work-item-wbs-draft-publish-progress-query"></a>
- **计划表草稿发布进度查询** ｜ `openapi.post.open-api-work-item-wbs-draft-publish-progress-query` ｜ 频次：低 ｜ 状态：待运行时验证

<!-- capability-metadata:end -->

查询一次[发布计划表草稿](发布计划表草稿.md)操作是否完成。请求中的 `publish_order_id` 来自发布接口，同时传入该次发布的空间、工作项和草稿 ID。

## 发布状态

| `data.publish_status` | 含义 | 是否结束轮询 |
| --- | --- | --- |
| `0` | 发布中 | 否 |
| `1` | 发布成功 | 是 |
| `2` | 发布失败 | 是 |

这组数值取自官方响应示例注释，与创建草稿的 `draft_status` 数值含义不同。顶层 `err_code = 0` 表示查询成功，不能替代发布状态判断。

轮询间隔采用发布接口返回的 `recommend_interval_ms`，单位为毫秒。插件权限见[权限管理](../guides/权限管理.md)中的“工作项”。

## 请求说明

**请求方式**：`POST`
**请求地址**：`/open_api/work_item/wbs_draft_publish/progress/query`
