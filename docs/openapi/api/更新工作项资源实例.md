# 更新工作项资源实例

<!-- capability-metadata:start -->
## 平台能力标记

<a id="capability-openapi.post.open-api-work-item-resource-update"></a>
- **更新工作项资源实例** ｜ `openapi.post.open-api-work-item-resource-update` ｜ 频次：低 ｜ 状态：待运行时验证

<!-- capability-metadata:end -->

更新已启用资源库的工作项资源实例字段。空间、类型、资源实例 ID 和待更新字段都放在请求体中，接口权限位于[权限管理](../guides/权限管理.md)的“工作项实例”分类。

## 更新边界

仅资源字段和资源角色属于本接口的更新范围。提交非资源字段可能返回 `1000053593`，应按资源配置筛选待更新字段。

接口正文说明字段覆盖更新，尤其更新 `role_owners` 时需要携带仍需保留的其他角色及成员。共享参数表另列 `update_mode: 0/1`，但没有逐类型说明其适用范围，不能据此推断任意资源字段都支持增量追加。

字段值使用[字段格式](../formats/字段与属性解析格式.md)，普通富文本值与 Markdown 二选一；同一请求不可重复传入相同 `field_key`。

<a id="field-note-1"></a>

**update_fields**

目标更新的字段列表，遵循[FieldValuePair](../formats/数据结构汇总.md#10c42182)结构规范。

对指定的字段更新，更新后的值会覆盖之前的值，而非替换/追加（例如修改角色与成员类型，若需仅修改某角色的成员，依旧需将其他角色及成员传入）。

具体字段可以从[获取创建工作项元数据](获取创建工作项元数据.md)接口中获取。

#### `update_fields`

| 参数                   | 类型     | 是否必须 | 说明                                                                                                                             |
| ---------------------- | -------- | -------- | -------------------------------------------------------------------------------------------------------------------------------- |
| `field_key`            | `string` | 必须     | 待更新的字段 ID，需与 `field_alias`二选一填写，不能同时为空。                                                                    |
| `field_alias`          | `string` | 可选     | 待更新字段的别名                                                                                                                 |
| `field_value`          | `object` | 必须     | 字段值，可参考[字段与属性解析格式](../formats/字段与属性解析格式.md)                                                                       |
| `update_mode`          | `int32`  | 可选     | 字段的更新模式，用于控制字段值的更新方式。支持的取值如下所示。 [详细说明](#field-note-2)                                         |
| `field_type_key`       | `string` | 可选     | 字段类型                                                                                                                         |
| `field_name`           | `string` | 可选     | 字段名称                                                                                                                         |
| `field_value_markdown` | `object` | 可选     | 富文本内容 Markdown 格式，遵循 [Markdown 格式说明](../formats/Markdown%20格式说明.md)结构规范，和`field_value` 二选一，仅富文本格式字段生效 |

<a id="field-note-2"></a>

**update_mode**

字段的更新模式，用于控制字段值的更新方式。支持的取值如下所示。

- `0`：替换模式，提交的字段值将完全替换原有值；
- `1`：更新模式，仅更新提交的字段值，不影响其他字段。

默认值：`0`（替换模式）

#### `update_fields.field_value_markdown`

| 参数                | 类型           | 是否必须 | 说明                      |
| ------------------- | -------------- | -------- | ------------------------- |
| `markdown`          | `string`       | 可选     | 富文本内容 Markdown 格式  |
| `mention_user_keys` | `list<object>` | 可选     | 富文本中 @ 提到的人员信息 |

#### `update_fields.field_value_markdown.mention_user_keys`

| 参数       | 类型     | 是否必须 | 说明                  |
| ---------- | -------- | -------- | --------------------- |
| `id`       | `string` | 可选     | 富文本中对应的人员 id |
| `user_key` | `string` | 可选     | 对应的人员的 user_key |

## 返回参数

| 参数       | 类型     | 说明                                             |
