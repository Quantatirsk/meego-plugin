<a id="381ecf97"></a>

使用文件唯一标识 `file_token` 下载已经绑定到评论等业务的附件。先调用业务查询接口，例如[查询评论](查询评论.md)，取得文件标识，再调用本接口。

## 下载前的业务绑定

普通上传文件必须先绑定业务点位，未绑定不能下载，超过 **7 天**未绑定会自动删除。分片上传文件按[完成分片上传](完成分片上传.md)的专属规则处理：绑定前仅上传者可下载，未绑定保留期为 **14 天**。应按文件的上传机制判断访问与保留规则。

权限见[权限管理](../guides/权限管理.md)中的“工作项实例”。

## 请求定义

**请求方式**：`GET`
**请求地址**：`/open_api/:project_key/file/stream/download/:file_token`

鉴权请求头见[OpenAPI 概述](../guides/OpenAPI概述.md#a8e43b86)。只有路径参数，没有请求体。

| 路径参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `project_key` | `string` | 是 | 空间 key |
| `file_token` | `string` | 是 | 从业务查询接口读取的文件唯一标识 |

## 成功响应

响应体是文件二进制内容，不是 JSON。原文列出以下可选响应头：

| 响应头 | 类型 | 说明 |
| --- | --- | --- |
| `Content-Disposition` | `string` | 指示按附件下载，并给出文件名 |
| `Content-Range` | `string` | 分块或断点传输时，表示当前片段的字节区间与资源总大小 |
| `Content-Type` | `string` | 内容的 MIME 类型，用于决定如何解析数据；原例为 `text/html`、`application/json` |

原文未提供二进制成功体的示例，也未在请求参数表定义 Range 请求规则。此处保留响应头说明，不据此补造断点请求协议。

## 失败响应

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `code` | `int` | 请求成功为 `0`，失败为实际错误码 |
| `message` | `string` | 失败原因的具体描述 |
| `data` | `object` | 业务数据，失败样例为 `null` |

三个字段在原表均未标为必填。下载客户端应区分文件内容与 JSON 失败响应，避免把错误消息保存成目标附件。

```json
{
  "code": 1000051686,
  "message": "file internal error",
  "data": null
}
```

## 错误码

原文错误表使用其他 OpenAPI 的 `err_code` 等表头，但本接口失败示例使用 `code/message`。以下保留错误编号、名称和消息；更多说明见[Open API 错误码](../formats/Open%20API%20错误码.md)。

| 编号 | 原错误名称 | 消息 | 说明 |
