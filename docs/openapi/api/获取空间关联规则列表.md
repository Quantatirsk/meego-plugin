# 获取空间关联规则列表

<!-- capability-metadata:start -->
## 平台能力标记

<a id="capability-openapi.post.open-api-project-key-relation-rules"></a>
- **获取空间关联规则列表** ｜ `openapi.post.open-api-project-key-relation-rules` ｜ 频次：低 ｜ 状态：待运行时验证

<!-- capability-metadata:end -->

读取当前空间配置的跨空间关联规则，并按关联空间分组返回。`remote_projects` 可筛选关联空间，响应 `rules[].id` 可用于后续绑定、解绑或查询关联实例。

## 规则与实例的区别

本篇返回关联规则配置，包含双方工作项类型、启用状态与群聊合并设置；已经建立的实例关系请使用[获取空间关联下的关联工作项实例列表](获取空间关联下的关联工作项实例列表.md)。

| 规则字段 | 值的含义 |
| --- | --- |
| `disabled` | `1` 为启用，`2` 为禁用；不是布尔值 |
| `chat_group_merge` | `1` 为合并群聊，`2` 为不合并 |
| `id` | 空间关联规则 ID |
| `work_item_relation_id` | 工作项关联关系 ID，与规则 ID 是不同字段 |

配置方式见[跨空间联动规则配置](https://project.feishu.cn/1ykiuvvj/4g4laxgf)，申请权限见[权限管理](../guides/权限管理.md)中的“空间关联”。

<a id="请求说明"></a>

## 请求说明

**请求方式**：`POST`
**请求地址**：`/open_api/:project_key/relation/rules`

<a id="请求参数"></a>

## 请求参数

<a id="header"></a>

### 请求头

接口调用的 Header 配置详见 [Header](https://project.feishu.cn/b/helpcenter/developer/create-an-api-configuration#018a9fe7)。

<a id="Path"></a>

### 路径参数

| 参数 | 类型 | 是否必须 | 说明 |
| --- | --- | --- | --- |
| project_key | string | 必须 | [填写说明](#parameter-notes-1) |

<a id="parameter-notes-1"></a>

**project_key 的填写说明**

空间 ID（project_key），或者空间域名（simple_name）。

- 空间 ID（project_key），在飞书项目空间双击空间名称获取。

- 空间域名（simple_name），`simple_name` 一般在飞书项目空间 URL 中获取。例如空间 URL 为 “https://project.feishu.cn/doc/overview”，则 `simple_name`为 “doc”。

<a id="Body"></a>

### 请求体

| 参数 | 类型 | 是否必须 | 说明 |
| --- | --- | --- | --- |
| remote_projects | `list<string>` | 可选 | 关联空间的 `project_key`列表，用于指定需要关联的空间。 |

<a id="返回参数"></a>

## 返回参数

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `data` | `list<object>` | 遵循[ProjectRelationRule](../formats/数据结构汇总.md#db959e7d)结构规范 |
| `err` | object | 请求成功时返回空值，请求失败时返回实际错误信息。 |
| `err_code` | int32 | 请求成功时0，请求失败返回实际错误码。 |

### `data`

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `remote_project_key` | string | 关联空间 ID |
| `remote_project_name` | string | 关联空间名称 |
| `rules` | `list<object>` | 规则数组，遵循[RelationRule](../formats/数据结构汇总.md#7bf2a6bf)结构规范 |

### `data.rules`

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `id` | string | 空间关联规则 ID |
| `name` | string | 空间关联规则名称 |
| `disabled` | int64 | 表示规则是否被禁用。支持的取值如下所示。<br>- `1`：启用<br>- `2`：禁用 |
| `work_item_relation_id` | string | 工作项关联关系 ID |
| `work_item_relation_name` | string | 工作项关联关系名称 |
| `current_work_item_type_key` | string | 当前工作项类型 |
| `current_work_item_type_name` | string | 当前工作项类型名称 |
| `remote_work_item_type_key` | string | 关联工作项类型 |
| `remote_work_item_type_name` | string | 关联工作项类型名称 |
| `chat_group_merge` | int64 | 表示是否合并群聊。支持的取值如下所示。<br>- `1`：是<br>- `2`：否 |

### `err`

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `code` | int32 | 部分场景下，透出更详细错误对应的错误码。 |
| `msg` | string | 部分场景下，透出更详细的错误描述。 |
| `log_id` | string | 报错场景下的调用链标识符，用于追踪错误发生时的完整调用链路，便于日志记录和问题排查。 |

<a id="请求示例"></a>

## 请求示例

**请求路径：**`/open_api/``68382b399de4b0ec6c5xxxx``/relation/rules`

```json
{
  "remote_projects": [
    "62c79a4b33ca3fafc5fxxxxx"
  ]
}
```

<a id="返回示例"></a>

## 返回示例

### 空结果的解释

请求中的当前空间 `project_key` 不正确会报错；`remote_projects` 中的值不正确或未配置关联关系则可能成功但不返回 `data`。混合传入正确和错误的关联空间 key 时，只返回能匹配的结果。因此，空结果不等于所有输入标识都有效。

示例中工作项类型名称使用等义 Unicode 转义，字符串解码后的值保持不变。

### 请求成功示例

```json
{
  "data": [
    {
      "remote_project_key": "62c79a4b33ca3fafc5fxxxxx",
      "remote_project_name": "111",
      "rules": [
        {
          "id": "720286429011250xxxx",
          "name": "111",
          "disabled": 2,
          "work_item_relation_id": "63b3f8ee3a3c74bbbd88xxxx:work_item_relation:relation_167708676xxxx",
          "work_item_relation_name": "test",
          "current_work_item_type_key": "story",
          "current_work_item_type_name": "\u9700\u6c42",
          "remote_work_item_type_key": "story",
          "remote_work_item_type_name": "\u9700\u6c42",
          "chat_group_merge": 1
        }
      ]
    }
  ],
  "err": {},
  "err_code": 0,
  "err_msg": ""
}
```


### 错误返回示例

以下错误原因为 `project_key` 参数不正确。

```json
{
  "err_code": 1000052062,
  "err_msg": "Project Key Is Wrong",
  "err": {
    "code": 1000052062,
    "msg": "not found simple name: 68382b399de4b0ec6c5xxxx",
    "log_id": "2025102921002499843398F991EDCFxxxx"
  }
}
```

**空返回示例**

以下错误原因为传入的 `remote_projects` 不正确，或者查不到与 `remote_projects` 对应空间的关联关系。如果在 `remote_projects` 中同时传入正确和错误的 key，该接口不会报错，仅根据正确的 key 返回对应结果。

```json
{
  "err": {},
  "err_code": 0,
  "err_msg": ""
}
```
