# 完成分片上传

<!-- capability-metadata:end -->

<a id="9bc7b0f7"></a>

完成已经上传各分片的任务，取得文件唯一标识 `file_token`。使用与[分片初始化](分片初始化.md)相同的 `resource_id`；完成上传后还需要把文件绑定到评论等业务点位。

## 完成后的保留期与访问规则

经本分片流程完成上传的附件占用容量，绑定业务前**仅上传者可以下载**；超过 **14 天**未绑定会自动删除，并解除容量占用。

这组规则针对分片上传；普通上传的绑定规则见[上传文件](上传文件.md)。权限见[权限管理](../guides/权限管理.md)中的“工作项实例”。

<a id="e3e5a624"></a>

## 请求定义

**请求方式**：`POST`
**请求地址**：`/open_api/:project_key/file/upload/multipart/finish/:resource_id`

鉴权请求头见[OpenAPI 概述](../guides/OpenAPI概述.md#a8e43b86)。原文只定义路径参数，没有请求体字段。

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `project_key` | `string` | 是 | 空间 key |
| `resource_id` | `string` | 是 | 与初始化一致的上传资源 ID |

## 响应结构

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `code` | `int` | `0` 为成功，非零为实际错误码 |
| `message` | `string` | 响应信息，成功判定以 `code = 0` 为准 |
| `data` | [UploadPartFinishV2Result](../formats/数据结构汇总.md#21c5c827) | 完成上传结果 |
| `data.file_token` | `string` | 文件唯一标识，供后续业务绑定使用 |

原表未将顶层三个响应字段标为必填。`resource_id` 标识上传任务使用的资源，`file_token` 是完成后返回的文件标识，两者不能互换。

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "file_token": "xxxx"
  }
}
```

## 错误码

原文错误表使用 `err_code` 等表头，实际响应包裹层为 `code/message`。通用说明见[Open API 错误码](../formats/Open%20API%20错误码.md)。

| 编号 | 原错误名称 | 消息 | 说明 |
| --- | --- | --- | --- |
| `30016` | `ErrAPIProjectNotFound` | `Project Not Found` | `project_key` 不正确 |
| `1000051686` | `ErrFileInternal` | `file internal error` | 业务错误 |
