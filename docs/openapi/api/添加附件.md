# 添加附件

<!-- capability-metadata:start -->
## 平台能力标记

<a id="capability-openapi.post.open-api-project-key-work-item-work-item-type-key-work-item-id-file-upload"></a>
- **添加附件** ｜ `openapi.post.open-api-project-key-work-item-work-item-type-key-work-item-id-file-upload` ｜ 频次：低 ｜ 状态：待运行时验证

<!-- capability-metadata:end -->

把一个文件直接添加到指定工作项的附件字段。请求必须采用 `multipart/form-data` 上传文件二进制流，使用 `field_key` 或 `field_alias` 指定目标字段；复合字段还可传数组下标 `index`。

与[上传文件或富文本图片](上传文件或富文本图片.md)返回资源路径不同，本接口会写入工作项字段。产品效果见[上传附件](https://project.feishu.cn/1ykiuvvj/6boztqcg#%E4%B8%8A%E4%BC%A0%E9%99%84%E4%BB%B6)，申请权限见[权限管理](../guides/权限管理.md)中的“工作项实例”。

<a id="注意事项"></a>

## 注意事项

| 检查项 | 约束或排查方式 |
| --- | --- |
| 单次文件数 | 一次只能上传 1 个附件 |
| 单文件大小 | 最大 100M，沿用官方单位表述 |
| 单字段附件数 | 最多 50 个，超过后新增失败 |
| 成功但页面无文件 | 检查表单 `file` 是否确实包含文件内容；原文说明空文件当前不会被拦截 |
| 无法预览 | 设置与文件类型匹配的 MIME 类型，例如 JPEG 为 `image/jpeg`，MP4 音频为 `audio/mp4`，MP4 视频为 `video/mp4` |

<a id="请求说明"></a>

## 请求说明

**请求方式**：`POST`
**请求地址**：`/open_api/:project_key/work_item/:work_item_type_key/:work_item_id/file/upload`

<a id="请求参数"></a>

## 请求参数

<a id="header"></a>

### 请求头

接口调用的 Header 配置详见 [Header](../guides/OpenAPI概述.md#a8e43b86)。

<a id="Path"></a>

### 路径参数

| 参数 | 类型 | 是否必须 | 说明 |
| --- | --- | --- | --- |
| project_key | string | 必须 | [填写说明](#parameter-notes-1) |
| work_item_type_key | string | 必须 | 工作项类型，系统自动生成，可通过[获取空间下工作项类型](获取空间下工作项类型.md)接口获取 |
| work_item_id | string | 必须 | 工作项实例 ID，在工作项实例详情中，展开右上角 **··· \> ID**获取。 |

<a id="parameter-notes-1"></a>

**project_key 的填写说明**

空间 ID（project_key），或者空间域名（simple_name）。

- 空间 ID（project_key），在飞书项目空间双击空间名称获取。

- 空间域名（simple_name），`simple_name` 一般在飞书项目空间 URL 中获取。例如空间 URL 为 “https://project.feishu.cn/doc/overview”，则 `simple_name`为 “doc”。

<a id="Body"></a>

### 请求体

以下均为 multipart 表单字段。不要把文件名字符串作为 JSON 发给接口。

| 参数 | 类型 | 是否必须 | 说明 |
| --- | --- | --- | --- |
| file | file | 必须 | 附件，目前只支持同时传一个附件，最大支持100M |
| field_key | string | 可选 | 上传附件字段的唯一标识，用于指定附件上传的目标字段。与 `field_alias`参数二选一传入即可。 |
| field_alias | string | 可选 | 上传附件字段的对接标识，用于指定附件上传的目标字段。与 `field_key`参数二选一传入即可。 |
| index | string | 可选 | 复合字段适用，用于指定数组下标。 |

<a id="请求示例"></a>

## 请求示例

### multipart 调用写法

以下依据参数定义整理；curl 的 `--form` 会生成含 boundary 的 Content-Type，不要手工设置为 JSON。

```bash
curl --request POST "https://project.feishu.cn/open_api/${PROJECT_KEY}/work_item/${WORK_ITEM_TYPE_KEY}/${WORK_ITEM_ID}/file/upload" \
  --header "X-Plugin-Token: ${PLUGIN_ACCESS_TOKEN}" \
  --header "X-User-Key: ${USER_KEY}" \
  --form 'file=@example.pdf;type=application/pdf' \
  --form "field_key=${FIELD_KEY}"
```

### 在复合字段中上传

字段 ID 与别名二选一。下面使用别名 `custom_attachment_alias`，向复合字段索引 `0` 上传附件，文件仍以二进制 multipart 部分传递。

```bash
curl --request POST "https://project.feishu.cn/open_api/${PROJECT_KEY}/work_item/${WORK_ITEM_TYPE_KEY}/${WORK_ITEM_ID}/file/upload" \
  --header "X-Plugin-Token: ${PLUGIN_ACCESS_TOKEN}" \
  --header "X-User-Key: ${USER_KEY}" \
  --form 'file=@example.pdf;type=application/pdf' \
  --form 'field_alias=custom_attachment_alias' \
  --form 'index=0'
```
