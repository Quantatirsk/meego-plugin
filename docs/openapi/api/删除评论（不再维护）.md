# 删除评论（不再维护）

<!-- capability-metadata:start -->
## 平台能力标记

<a id="capability-openapi.delete.open-api-project-key-work-item-work-item-type-key-work-item-id-comment-comment-id"></a>
- **删除评论（不再维护）** ｜ `openapi.delete.open-api-project-key-work-item-work-item-type-key-work-item-id-comment-comment-id` ｜ 频次：低 ｜ 状态：已废弃

<!-- capability-metadata:end -->

这是不再维护的评论删除接口，旧调用通过 `DELETE` 路径参数定位评论。新接入应改用[删除评论](删除评论.md)的 `POST /open_api/comment/delete`。

## 使用前确认

迁移时将空间 ID 和评论 ID 放入请求体的 `project_key`、`comment_id`；新接口不再把工作项类型与实例 ID 放在删除路径中。两个版本都要求调用身份为评论创建人。

旧接口分别报告评论不存在（`1000050052`）、空间与工作项不匹配（`20014`）、Token 无效（`10211`）和无删除权限（`10001`）。

该接口用于删除工作项下一条指定的评论信息，对应的权限申请在**权限管理-评论**分类下，相关功能介绍详见[权限管理](../guides/权限管理.md)。建议使用或更换为[删除评论](删除评论.md)接口。

> **说明**：只有创建评论的人才能删除评论，且删除评论只能通过 API 操作。

<a id="请求说明"></a>

## 请求说明

- 请求方式：DELETE

- 请求地址：/open_api/:project_key/work_item/:work_item_type_key/:work_item_id/comment/:comment_id

<a id="请求参数"></a>

## 请求参数

<a id="header"></a>

### Header

接口调用的 Header 配置详见 [Header](../guides/OpenAPI概述.md#a8e43b86)。

<a id="Path"></a>

### Path

| 参数 | 类型 | 是否必须 | 说明 |
| --- | --- | --- | --- |
| `project_key` | string | 必须 | [说明](#parameter-note-1) |
| `work_item_type_key` | string | 必须 | 工作项类型 key，在[获取空间下工作项类型](获取空间下工作项类型.md)接口获取。 |
| `work_item_id` | string | 必须 | 工作项实例 ID，在工作项实例详情中，展开右上角 **··· \> ID** 获取。 |
| `comment_id` | string | 必须 | 评论 ID，可以通过[查询评论](查询评论（不再维护）.md)接口获取。 |

<a id="parameter-note-1"></a>

**project_key：说明**

空间 ID（project_key），或者空间域名（simple_name）。
- 空间 ID（project_key），在飞书项目空间双击空间名称获取。
- 空间域名（simple_name），`simple_name` 一般在飞书项目空间 URL 中获取。例如空间 URL 为 “https://project.feishu.cn/doc/overview”，则 `simple_name`为 “doc”。
