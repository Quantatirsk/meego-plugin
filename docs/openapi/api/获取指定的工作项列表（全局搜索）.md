# 获取指定的工作项列表（全局搜索）

<!-- capability-metadata:start -->
## 平台能力标记

<a id="capability-openapi.post.open-api-compositive-search"></a>
- **获取指定的工作项列表（全局搜索）** ｜ `openapi.post.open-api-compositive-search` ｜ 频次：低 ｜ 状态：待运行时验证

<!-- capability-metadata:end -->

按关键词跨空间搜索工作项或视图，匹配范围包括标题、描述和人员等。对应产品功能为[全局搜索](https://project.feishu.cn/1ykiuvvj/4uteveck)，接口权限位于[权限管理](../guides/权限管理.md)的“工作项实例”分类。

## 适用范围

本接口返回匹配度最高的前 200 条结果，适合交互式查找，不适合全量导出。需要遍历数据时，改用[全量搜索](获取指定的工作项列表（全量搜索）.md)等接口。

| 搜索目标 | `query_type` | 类型筛选                              |
| -------- | ------------ | ------------------------------------- |
| 工作项   | `workitem`   | `query_sub_type` 可指定多个工作项类型 |
| 视图     | `view`       | `query_sub_type` 不生效               |

`query` 必填，错误表约束为非空且不超过 200。分页默认每页 50 条、第一页；增加页数不会使可读取范围超过前 200 条。

响应保留接口原有大小写：`ID`、`ProjectKey`、`WorkItemTypeKey` 与小写 `name` 并存。`SearchHit` 表示命中的字段，例如 `created_by` 为创建人、`name` 为名称，不能把这些键统一改为小写。

## 请求说明

**请求方式**：`POST`

**请求地址**：`/open_api/compositive_search`

<a id="请求参数"></a>

## 请求参数

<a id="header"></a>

### 请求头

接口调用的 Header 配置详见 [Header](../guides/OpenAPI概述.md#a8e43b86)。

<a id="Body"></a>

### 请求体

| 参数             | 类型           | 是否必须 | 说明                                                                                                                                                                         |
| ---------------- | -------------- | -------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `project_keys`   | `list<string>` | 可选     | 指定搜索的空间范围，为空间 key 的列表                                                                                                                                        |
| `simple_names`   | `list<string>` | 可选     | 安装插件的飞书项目空间（simple_name）列表。`simple_name` 一般在飞书项目空间 URL 中获取。例如空间 URL 为 “https://project.feishu.cn/doc/overview”，则 `simple_name`为 “doc”。 |
| `query_type`     | `string`       | 必须     | 查询类型，可选值为工作项和视图： [详细说明](#field-note-1)                                                                                                                   |
| `query_sub_type` | `list<string>` | 可选     | 指定工作项类型列表，用于筛选查询结果。当 `query_type` 为 `workitem`时生效                                                                                                    |
| `query`          | `string`       | 必须     | 查询内容                                                                                                                                                                     |
| `page_size`      | `int64`        | 可选     | 分页大小 ，默认50                                                                                                                                                            |
| `page_num`       | `int64`        | 可选     | 页码，默认1                                                                                                                                                                  |

<a id="field-note-1"></a>

**query_type**

查询类型，可选值为工作项和视图：

- workitem：工作项
- view：视图

<a id="返回参数"></a>

## 返回参数

| 参数         | 类型           | 说明                                                                                           |
| ------------ | -------------- | ---------------------------------------------------------------------------------------------- |
| `data`       | `list<object>` | 最多只能查询到匹配度最高的前200条数据，遵循[CompInfo](../formats/数据结构汇总.md#43836e24)结构规范 |
| `pagination` | `object`       | 分页信息对象，包含分页查询结果的总记录数、当前页码和每页数据条目数量。                         |
| `err`        | `object`       | 请求成功时返回空值，请求失败时返回实际错误信息。                                               |
| `err_msg`    | `string`       | 请求成功时返回空值，请求失败时返回实际错误信息。                                               |
| `err_code`   | `int32`        | 成功为 `0`，失败返回错误码。 |

### `data`

| 参数              | 类型           | 说明                   |
| ----------------- | -------------- | ---------------------- |
| `ID`              | `string`       | 工作项/视图id          |
| `ViewScopeKey`    | `string`       | 视图类型               |
| `WorkItemTypeKey` | `string`       | 工作项类型             |
| `CreatedAt`       | `int64`        | 创建时间戳，毫秒精度   |
| `SearchHit`       | `list<string>` | 命中结果字段的 key     |
| `name`            | `string`       | 名称                   |
| `CreatedBy`       | `string`       | 创建人                 |
| `ProjectKey`      | `string`       | 所属空间               |
| `ProjectKeys`     | `list<string>` | 全景视图涉及的多数据源 |

### `pagination`

| 参数        | 类型    | 说明                                                         |
| ----------- | ------- | ------------------------------------------------------------ |
| `total`     | `int64` | 视图中工作项的总数。                                         |
| `page_num`  | `int64` | 当前页码，表示返回的数据属于分页结果的第几页。               |
| `page_size` | `int64` | 每页返回的数据条目数量，表示当前分页查询中每页包含的记录数。 |

### `err`

| 参数     | 类型     | 说明                                                                                 |
| -------- | -------- | ------------------------------------------------------------------------------------ |
| `code`   | `int32`  | 部分场景下，透出更详细错误对应的错误码。                                             |
| `msg`    | `string` | 部分场景下，透出更详细的错误描述。                                                   |
| `log_id` | `string` | 报错场景下的调用链标识符，用于追踪错误发生时的完整调用链路，便于日志记录和问题排查。 |
