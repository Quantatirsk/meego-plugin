# 按组更新复合字段值

<!-- capability-metadata:start -->
## 平台能力标记

<a id="capability-openapi.post.open-api-work-item-field-value-update-compound-field"></a>
- **按组更新复合字段值** ｜ `openapi.post.open-api-work-item-field-value-update-compound-field` ｜ 频次：低 ｜ 状态：待运行时验证

<!-- capability-metadata:end -->

对工作项的一个复合字段按组添加、更新或删除数据。适合只修改某一组或部分子字段，接口权限位于[权限管理](../guides/权限管理.md)的“工作项”分类。

## 操作与组标识

| `action` | `group_uuid`     | `fields`                                     |
| -------- | ---------------- | -------------------------------------------- |
| `add`    | 不可填写         | 二维数组，每个内层数组是一组，可一次增加多组 |
| `update` | 必填，指定已有组 | 二维数组中的一组，包含本次要修改的子字段     |
| `delete` | 必填，指定已有组 | 删除请求示例不填写                           |

先调用[获取工作项详情](获取工作项详情.md)，在 `expand` 中设置 `need_group_uuid_for_compound: true`，取得真实的组标识。`group_uuid` 不是数组下标；外层 `field_key` / `field_alias` 指向复合父字段，`fields` 内每项指向子字段。

<a id="请求说明"></a>

## 请求说明

**请求方式**：`POST`

**请求地址**：`/open_api/work_item/field_value/update_compound_field`

<a id="field-note-1"></a>

**project_key**

空间 ID（project_key），或者空间域名（simple_name）。

- 空间 ID（project_key），在飞书项目空间双击空间名称获取。
- 空间域名（simple_name），`simple_name` 一般在飞书项目空间 URL 中获取。例如空间 URL 为 “https://project.feishu.cn/doc/overview”，则 `simple_name`为 “doc”。

<a id="field-note-2"></a>

**group_uuid**

待处理的复合字段组标识，通过调用[获取工作项详情](获取工作项详情.md)接口传入

`need_group_uuid_for_compound` 获取。

- 执行 `update` 或 `delete` 操作时必填；
- 执行 `add`操作时不可填写。

<a id="field-note-3"></a>

**action**

指定对复合字段执行的操作类型。支持的取值如下所示。

- `delete`：删除指定的复合字段组；
- `update`：更新指定的复合字段组；
- `add`：添加新的复合字段组。

<a id="field-note-4"></a>

**fields**

参见[FieldValuePair](../formats/数据结构汇总.md#10c42182)，用于指定添加或更新的复合字段数据。

- 当 `action` 为 `add` 时，表示要添加的多组数据；
- 当 `action` 为 `update` 时，表示要更新的单组数据。

#### `fields`

| 参数                   | 类型     | 是否必须 | 说明                                                                                                                           |
| ---------------------- | -------- | -------- | ------------------------------------------------------------------------------------------------------------------------------ |
| `field_key`            | `string` | 必须     | 待更新的字段 ID，需与 `field_alias`二选一填写，不能同时为空。                                                                  |
| `field_alias`          | `string` | 可选     | 待更新字段的别名                                                                                                               |
| `field_value`          | `object` | 必须     | 字段值，可参考[字段与属性解析格式](../formats/字段与属性解析格式.md)                                                                     |
| `field_type_key`       | `string` | 可选     | 字段类型                                                                                                                       |
| `field_name`           | `string` | 可选     | 字段名称                                                                                                                       |
| `field_value_markdown` | `object` | 可选     | 富文本内容 Markdown 格式，遵循 [Markdown 格式说明](../formats/Markdown%20格式说明.md)结构规范，仅用于富文本写入，与 `field_value` 二选一 |

#### `fields.field_value_markdown`

| 参数                | 类型           | 是否必须 | 说明                      |
| ------------------- | -------------- | -------- | ------------------------- |
| `markdown`          | `string`       | 可选     | 富文本内容 Markdown 格式  |
| `mention_user_keys` | `list<object>` | 可选     | 富文本中 @ 提到的人员信息 |

#### `fields.field_value_markdown.mention_user_keys`

| 参数       | 类型     | 是否必须 | 说明                  |
| ---------- | -------- | -------- | --------------------- |
| `id`       | `string` | 可选     | 富文本中对应的人员 id |
| `user_key` | `string` | 可选     | 对应的人员的 user_key |

<a id="请求示例"></a>

## 请求示例

三组示例依次删除组、修改该组一个子字段、新增一组。`1181795xx` 是脱敏实例 ID，应替换为完整整数；中文示例值保留为等义 Unicode 转义，故以下为结构示意。

### 删除一组数据示例

```text

{
    "work_item_id": 1181795xx,
    "project_key": "xxxxxx",
    "field_key": "field_84bxx",
    "group_uuid": "InDBOBCF",
    "action": "delete"
}
```

### 更新一组数据示例

```text
{
    "work_item_id": 1181795xx,
    "project_key": "xxxxxx",
    "field_key": "field_84bxx",
    "group_uuid": "InDBOBCF",
    "action": "update",
    "fields": [

        [
            {
                "field_key": "field_f43fc4",
                "field_value": "haha\u6539"
            }
        ]
    ]
}
```

### 添加一组数据示例

```text
{
    "work_item_id": 1181795xx,
    "project_key": "xxxxxx",
    "field_key": "field_84bxx",
    "action": "add",
    "fields": [
        [
            {
                "field_key": "field_f43fc4",
                "field_value": "haha\u589e"
            }
        ]
    ]
}
```
