# 获取批量更新处理进度

<!-- capability-metadata:start -->
## 平台能力标记

<a id="capability-openapi.get.open-api-task-result"></a>
- **获取批量更新处理进度** ｜ `openapi.get.open-api-task-result` ｜ 频次：低 ｜ 状态：待运行时验证

<!-- capability-metadata:end -->

读取[批量更新工作项字段值](批量更新工作项字段值.md)提交的异步任务状态、成功实例和失败原因。使用提交接口返回的 `data.task_id` 查询；请求成功只说明拿到了任务结果，不代表批量更新全部成功。

## 判读任务状态

`IDLE` 表示等待，`RUNNING` 表示处理中；`SUCCESS`、`FAILED`、`CANCELED` 分别表示成功、失败、取消，`NOT_EXIST` 表示任务不存在。看到 `FAILED` 后还要读取成功/失败数量及列表，因为任务可能部分成功。

原文示例的 5 个实例中，3 个成功、2 个失败，顶层 `err_code` 仍为 `0`。`error_scenes` 给出失败场景，例如无编辑权限、工作项终止或关联关系循环，不能只检查 HTTP 状态或顶层返回码。

<a id="返回参数"></a>

## 返回参数

除 `err`、`err_code`、`err_msg` 外，任务业务字段均位于 `data` 对象内，下表按对象内相对路径阅读。

| 参数                    | 类型           | 说明                                                                                   |
| ----------------------- | -------------- | -------------------------------------------------------------------------------------- |
| `task_id`               | `string`       | 任务 ID。                                                                              |
| `task_status`           | `string`       | 任务的状态，用于标识当前任务的执行情况。支持的取值如下所示。 [详细说明](#field-note-1) |
| `total`                 | `int64`        | 任务更新的实例总数。                                                                   |
| `success_total`         | `int64`        | 更新成功的实例数量。按字段名与成功/失败示例校正原文笔误。                              |
| `error_total`           | `int64`        | 更新失败的实例数量。                                                                   |
| `success_sub_task_list` | `list<string>` | 成功实例列表                                                                           |
| `fail_sub_task_list`    | `list<string>` | 失败实例列表                                                                           |
| `error_scenes`          | `list<string>` | 任务执行过程中失败的场景类型列表，常见错误类型包括但不限于： [详细说明](#field-note-2) |
| `err`                   | `object`       | 请求成功时返回空值，请求失败时返回实际错误信息。                                       |
| `err_msg`               | `string`       | 请求成功时返回空值，请求失败时返回实际错误信息。                                       |
| `err_code`              | `int32`        | 请求成功时返回0，请求失败返回实际错误码。                                              |

<a id="field-note-1"></a>

**task_status**

任务的状态，用于标识当前任务的执行情况。支持的取值如下所示。

- `SUCCESS`：任务成功；
- `IDLE`：任务等待中；
- `RUNNING`：任务处理中；
- `FAILED`：任务失败；
- `CANCELED`：任务已取消；
- `NOT_EXIST`：任务不存在。

<a id="field-note-2"></a>

**error_scenes**

任务执行过程中失败的场景类型列表，常见错误类型包括但不限于：

- `RelationCaseLoops`：父子关系实例存在循环；
- `RelationCaseLevelExceeds`：父子关系实例层级超出限制；
- `DuplicationCheckEnabledForThisField`：字段已被占用；
- `NoPermissionToModify`：无编辑权限；
- `WorkItemTerminated`：工作项已终止。

### `err`

| 参数     | 类型     | 说明                                                                                 |
| -------- | -------- | ------------------------------------------------------------------------------------ |
| `code`   | `int32`  | 部分场景下，透出更详细错误对应的错误码。                                             |
| `msg`    | `string` | 部分场景下，透出更详细的错误描述。                                                   |
| `log_id` | `string` | 报错场景下的调用链标识符，用于追踪错误发生时的完整调用链路，便于日志记录和问题排查。 |
