# 终止/恢复工作项

<!-- capability-metadata:start -->
## 平台能力标记

<a id="capability-openapi.put.open-api-project-key-work-item-work-item-type-key-work-item-id-abort"></a>
- **终止/恢复工作项** ｜ `openapi.put.open-api-project-key-work-item-work-item-type-key-work-item-id-abort` ｜ 频次：低 ｜ 状态：待运行时验证

<!-- capability-metadata:end -->

切换指定工作项的终止状态，并记录终止或恢复原因。`is_aborted: true` 表示终止，`false` 表示恢复。接口权限位于[权限管理](../guides/权限管理.md)的“工作项实例”分类。

## 原因选项如何填写

终止原因来自空间中系统字段“终止原因”的配置，可通过[获取字段信息](获取字段信息.md)读取；原文列出的 `cancel`、`repeat`、`test`、`other` 是参考选项，不能代替当前空间配置。

恢复原因是固定选项：`restart` 表示工作项重启，`rollback` 表示误操作回退，`test` 表示测试，`other` 表示其他。选择 `other` 时，`reason` 必填。

重复终止返回 `20007`，重复恢复返回 `20008`。调用方应根据当前状态选择操作，不能把这些返回当作普通网络失败不断重试。

<a id="请求说明"></a>

## 请求说明

**请求方式**：`PUT`

**请求地址**：`/open_api/:project_key/work_item/:work_item_type_key/:work_item_id/abort`

<a id="请求参数"></a>

## 请求参数

<a id="header"></a>

### 请求头

接口调用的 Header 配置详见 [Header](../guides/OpenAPI概述.md#a8e43b86)。

<a id="Path"></a>

### 路径参数

| 参数                 | 类型     | 是否必须 | 说明                                                                            |
| -------------------- | -------- | -------- | ------------------------------------------------------------------------------- |
| `project_key`        | `string` | 必须     | 空间 ID（project_key），或者空间域名（simple_name）。 [详细说明](#field-note-1) |
| `work_item_type_key` | `string` | 必须     | 工作项类型，可以通过[获取空间下工作项类型](获取空间下工作项类型.md)接口获取。               |
| `work_item_id`       | `string` | 必须     | 工作项实例 ID，在工作项实例详情中，展开右上角 **··· \> ID** 获取。              |

<a id="field-note-1"></a>

**project_key**

空间 ID（project_key），或者空间域名（simple_name）。

- 空间 ID（project_key），在飞书项目空间双击空间名称获取。
- 空间域名（simple_name），`simple_name` 一般在飞书项目空间 URL 中获取。例如空间 URL 为 “https://project.feishu.cn/doc/overview”，则 `simple_name`为 “doc”。

<a id="Body"></a>

### 请求体

| 参数            | 类型      | 是否必须 | 说明                                                                  |
| --------------- | --------- | -------- | --------------------------------------------------------------------- |
| `is_aborted`    | `boolean` | 可选     | 标识是否终止或恢复需求。 [详细说明](#field-note-2)                    |
| `reason`        | `string`  | 可选     | 终止或恢复需求的原因，当 `reason_option` 为 `other`时，此字段为必填。 |
| `reason_option` | `string`  | 可选     | 终止/恢复原因选项 [详细说明](#field-note-3)                           |

<a id="field-note-2"></a>

**is_aborted**

标识是否终止或恢复需求。

- `true`：终止需求；
- `false`：恢复需求。

<a id="field-note-3"></a>

**reason_option**

终止/恢复原因选项

- 终止原因选项（对应用户配置的系统字段**终止原因**选项值，获取方式参考[获取字段信息](获取字段信息.md)，查看终止原因字段的选项）参考如下：
- cancel ： 取消，现在先不做了
- repeat ： 重复/合并，与其他在做的工作项一起推进
- test： 测试一下
- other：其他
- 恢复原因选项（固定选项，不可配置）：
- restart ： {name}重启 // name为工作项的名字
- rollback：误操作回退
- test ： 测试
- other： 其他

<a id="返回参数"></a>

## 返回参数

| 参数       | 类型     | 说明                                             |
| ---------- | -------- | ------------------------------------------------ |
| `err`      | `object` | 请求成功时返回空值，请求失败时返回实际错误信息。 |
| `err_msg`  | `string` | 请求成功时返回空值，请求失败时返回实际错误信息。 |
| `err_code` | `int32`  | 请求成功时返回0，请求失败返回实际错误码。        |

### `err`

| 参数     | 类型     | 说明                                                                                 |
| -------- | -------- | ------------------------------------------------------------------------------------ |
| `code`   | `int32`  | 部分场景下，透出更详细错误对应的错误码。                                             |
| `msg`    | `string` | 部分场景下，透出更详细的错误描述。                                                   |
| `log_id` | `string` | 报错场景下的调用链标识符，用于追踪错误发生时的完整调用链路，便于日志记录和问题排查。 |

<a id="请求示例"></a>

## 请求示例

### 终止工作项

```json
{
  "is_aborted": true,
  "reason": "\u6d4b\u8bd5",
  "reason_option": "test"
}
```

### 恢复工作项

```json
{
  "is_aborted": false,
  "reason": "\u6d4b\u8bd5",
  "reason_option": "test"
}
```
