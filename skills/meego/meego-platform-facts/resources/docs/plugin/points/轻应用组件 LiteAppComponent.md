# 轻应用组件 / LiteAppComponent

<!-- capability-metadata:start -->
## 平台能力标记

<a id="capability-plugin-point.lite-app-component"></a>
- **轻应用组件 / LiteAppComponent** ｜ `plugin-point.lite-app-component` ｜ 频次：中 ｜ 状态：待运行时验证

<!-- capability-metadata:end -->

轻应用组件通过插件为 [轻应用](https://project.feishu.cn/1ykiuvvj/us21tuni) 增加自定义组件，复用平台的属性配置和组件通信能力，与原生组件联动。一款插件最多添加 **20 个轻应用组件构成**，目前仅支持网页端。

管理员安装插件后，可在轻应用搭建器中选择该组件、拖入画布并在右侧配置属性。一个组件定义可以多次添加为独立实例，后台组件 ID 相同、实例 ID 不同。

![轻应用搭建器中使用插件组件](<../assets/9c7079694eabb3f798de0e64.png>)

运行时取值、监听、输出和数据源查询见 [LiteAppComponent API](<../jssdk/LiteAppComponent.md>)。本页聚焦后台配置和组件如何进入轻应用运行环境。

<a id="7da27ae1"></a>

## 开发流程

准备 Node.js 和开发者工具，创建插件、添加轻应用组件构成并初始化工程，完成组件实现和调试后发布，再由管理员安装使用。项目创建、编译与上传的通用步骤见 [开发并发布第一个插件](<../guides/开发并发布第一个插件.md>)。

开发时先确定输入、输出和布局约束，再实现组件。属性配置面板由平台生成，插件主要负责消费属性值、渲染业务内容并推送输出。

## 后台配置

| 配置项 | 用途 | 示例 |
| --- | --- | --- |
| 组件名称 | 显示在组件库 | 项目集评审 |
| 描述 | 组件列表悬停详情中的用途说明 | 根据视图中的评审信息汇总结果 |
| Key | 系统生成、不可修改的点位标识 | `lite_app_ire7pa` |
| 组件图标 | 显示在组件列表和配置页 | 按后台要求配置 |
| 适用端 | 当前仅网页端 | 网页端 |
| resourceId | 当前网页端代码资源的唯一标识 | `lite_app_resource_web` |
| 组件尺寸 | 栅格模式或固定值模式 | 见下节 |
| 组件属性 | 管理员可配置的输入，最多 20 项 | 视图、工作项类型、字段 |
| 输出属性 | 可供其他组件订阅的输出，最多 20 项 | 评审结论、数据集 |

输入和输出分别配置属性名称、类型及系统生成的不可修改属性 key。名称帮助管理员理解用途；运行时调用使用 key，例如 `nm8d_h`，不能用显示名称替代。原 resourceId 描述中关于移动端资源的通用措辞不适用于当前仅网页端的点位。

### 尺寸模式

| 模式 | 后台约束 | 运行时配置 |
| --- | --- | --- |
| 栅格 | 最小、最大宽高和默认尺寸 | `mode: 1`；宽高及上下限均为栅格数 |
| 固定值 / 定高 | 固定宽高 | `mode: 0`；`staticHeight` 为 px，`staticWidth` 为栅格数 |

栅格模式的默认尺寸不得超出上下限。例如宽度最小 3、最大 10，高度最小和最大均为 2，默认尺寸可设为宽 3、高 2。

固定模式的单位以 [getConfig 的字段表](<../jssdk/LiteAppComponent.md#8daf8bd0>) 为准，不能将宽高都按 px 解释。原点位页对默认尺寸与 API 预设单位说明不一致，固定模式的默认值换算仍需核实；本文不提供混合单位的预设示例。

## 输入属性

每个组件最多配置 **20 个输入属性**。搭建过程中**所有输入都选填**，既可以由管理员赋值，也可以订阅当前页面其他组件的输出。组件必须处理尚未配置和订阅值尚未到达的情况。

| 输入类型 | `propType` | 配置能力与限制 |
| --- | --- | --- |
| 文本 | `text` | 纯文本 |
| 数字 | `number` | 整数或小数，最多两位小数 |
| 开关 | `boolean` | 开或关 |
| 单选 | `select` | 开发者配置可选项，最多 2000 个 |
| 多选 | `multiSelect` | 开发者配置可选项，最多 2000 个 |
| 日期与时间 | `dateWithTime` | 精确到分钟 |
| 日期范围 | `dateRange` | 起止日期精确到天 |
| 视图 | `viewSelect` | 当前空间的视图 |
| 实例 | `workItemInstance` | 当前空间实例，可启用字段子属性 |
| 工作项类型 | `workItemTypeSelect` | 当前空间类型，可启用字段子属性 |
| 数据源 | `dataSource` | 当前空间的工作项实例列表配置，可启用字段子属性 |

启用字段子属性后，管理员可选择相关实例、类型或数据源的字段；实例字段选择还支持设置显隐。运行时分别使用 `workItemInstanceWithField`、`workItemTypeWithField`、`dataSourceWithField`，值中包含可选的 `fieldList`。

数据源配置能力在官方页面和查询方法中均有定义，但 SDK 2.1.8 的输入属性枚举缺少两个数据源成员，不能照抄不存在的枚举名称；详见 [类型清单与边界](<../jssdk/LiteAppComponent.md#c0e852a5>)。

例如“项目集评审”需要读取指定类型、字段和视图，可配置工作项类型并启用字段选择，再配置视图输入。当前视图值包含 `isMultiProject`，已经能区分普通视图和全景视图；另设工作项类型是为了明确业务数据范围，而非弥补视图类型无法区分的问题。

## 输出属性

每个组件最多配置 **20 个输出属性**，支持以下 8 种类型。插件通过 [notify()](<../jssdk/LiteAppComponent.md#ffd941f9>) 更新其值，由平台分发给订阅组件。

| 输出类型 | 传递的值 | 限制 |
| --- | --- | --- |
| 文本 | string | 纯文本 |
| 数字 | number | 最多两位小数 |
| 日期与时间 | number 时间戳 | 配置精度到分钟 |
| 日期范围 | 起止时间戳对象 | 配置精度到天 |
| 视图 | 视图 ID 对象 | 当前空间视图 |
| 实例 | 工作项类型与实例 ID 对象 | 当前空间实例 |
| 工作项类型 | 工作项类型 ID 对象 | 当前空间类型 |
| 数据集 | `{ moql: string }` | 查询当前空间实例 ID，必须以指定 SELECT 片段开头 |

数据集在业务上代表实例列表，传输的却是 MQL 查询描述，不是实例数组。查询必须以 `` SELECT `work_item_id` `` 开头，详见 [MQL 语法](https://project.feishu.cn/b/helpcenter/1p8d7djs/tsl2uj3i)。例如数据集组件输出当前空间的需求查询，评审组件订阅该输出后使用相应数据。

输入与输出结构并不对称：实例输入包含空间 ID，实例输出只包含工作项类型和实例 ID；视图输入包含 `isMultiProject`，输出只包含视图 ID。实现时按对应 API 的结构构造，不能直接把输入对象当输出契约。

## 属性分类与配置界面

| 分类 | 配置方式 | 常见用途 |
| --- | --- | --- |
| 基础属性 | 管理员输入字面值或选择选项 | 说明文本、季度目标、脱敏开关、等级、大区、截止日、周期 |
| 业务属性 | 平台封装当前空间的业务对象选择 | 重点项目视图、核心实例、预算字段、工作项类型、签约金额字段、数据源 |
| 系统属性 | 平台内置，无需声明且不可移除 | 标题、显示边框、背景色 |

![平台生成的组件属性配置面板](<../assets/bdcab436df115ea83f06c1ec.png>)

配置面板由平台根据后台属性声明生成，无需插件另写一套。系统属性的存在不等于已公布同名 JSSDK key；本页没有标题、边框、背景色的运行时 key 和值结构，不提供猜测的取值代码。

## 运行时数据与生命周期

| 数据 | API | 用途 |
| --- | --- | --- |
| 当前空间、轻应用、页面 | `getContext()` | 确定运行位置，不等同于工作项详情上下文 |
| 当前实例 ID、布局、输入值 | `getProps()` | 渲染当前实例 |
| 输入变化 | `watch()` | 响应配置调整或其他组件的输出变化 |
| 后台属性定义、布局约束 | `getConfig()` | 解释 key、类型和允许尺寸 |
| 单选、多选的完整选项 | `getPropFullConfig()` | 将选项 ID 对应到显示名称 |
| 默认尺寸 | `getPreset()` | 仅轻应用编辑态，当前只支持默认布局 |
| 数据源对应实例列表 | `getDataSourceResult()` | 使用必填分页参数查询 |
| 输出属性更新 | `notify()` | 推送给订阅组件 |

`getProps()` 得到当前实例值，`getConfig()` 得到开发者定义，`getPreset()` 得到编辑态默认值，三者不能互相替代。数据源 props 只是所属空间、类型、字段等配置定位信息，实际结果需查询，并按 `total`、`hasMore` 处理分页。

监听异步返回取消函数。组件卸载时释放订阅，避免重复挂载后累积回调；订阅 Promise 在卸载后才完成时，也应立即取消，见 [watch 示例](<../jssdk/LiteAppComponent.md#a16cc3c2>)。
