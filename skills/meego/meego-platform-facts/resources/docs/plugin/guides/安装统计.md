# 安装统计

插件发布后，开放平台自动统计该插件的安装信息。开发者可查看安装分布、空间使用版本和安装时间，辅助判断版本采用情况。

<a id="38ef067f"></a>

## 打开统计面板

在开发者后台打开目标插件详情，选择“管理 > 安装统计”。

## 版本筛选

默认展示**该插件所有版本**的安装情况。勾选“仅查看最新版本安装情况”，可以过滤到最新版本的安装信息。

这里查看的是空间使用的插件版本，不是 `lpm release` 输出的客户端产物编号；两者关系见[发布插件](<发布插件.md#b4debc3b>)。最新客户端产物上传后，仍需创建、发布插件版本并让空间更新，才会改变对应使用版本。

## 总览与明细

| 区域或字段 | 原文明确提供的信息 |
| --- | --- |
| 安装总览 | 插件安装空间总数，以及原文所称“插件安装路径”的数量 |
| 空间 ID | 安装插件的空间标识 |
| 使用版本 | 该空间使用的插件版本信息 |
| 安装时间 | 面板记录的安装时间 |
| 搜索 | 可按空间或租户 ID 查找目标安装信息 |

需要确认某个空间是否采用新版本时，先按空间或租户 ID 定位，再查看“使用版本”。发布时选择自动更新或管理员手动更新，会影响空间采用新版本的方式；发布成功本身不能证明所有空间已升级。

## 统计口径限制

- 原文未定义“安装路径数量”的分类和计数方式，不能将其直接解释为租户数、安装渠道数或累计安装次数。
- “安装空间总数”的去重方式、是否包含历史卸载、重复安装和重新安装未明确说明。
- 原文没有说明统计刷新延迟、时间范围，以及“安装时间”在升级或重新安装后是否变化。
- “最新版本”的发布状态判定、筛选对总览指标的具体影响也未定义。需要精确报表时，应先核对面板提示和目标版本范围。

因此，本页适合查看平台展示的安装明细；不能据此自行计算活跃用户、留存率或卸载率等未定义指标。
