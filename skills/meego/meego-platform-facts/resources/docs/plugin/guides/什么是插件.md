# 什么是插件

飞书项目插件是在飞书项目开放平台中扩展页面、交互、自动化和数据访问能力的交付单元。一个插件由开放平台中的功能构成、可选的客户端资源和可选的自有服务端共同组成；它不是某个行业系统或某个业务流程的模板。

## 插件的三个部分

| 部分 | 负责内容 | 关键文档 |
| --- | --- | --- |
| 平台配置 | 插件身份、功能构成、适用端、权限、发布范围和安装 | [创建插件](<创建插件.md>)、[添加插件功能](<添加插件功能.md>)、[发布插件](<发布插件.md>) |
| 客户端资源 | 在飞书项目网页或移动端点位中运行的界面，通过 `window.JSSDK` 获取宿主上下文和客户端能力 | [客户端开发概述](<../client/客户端开发概述.md>)、[客户端 API 概述](<../jssdk/客户端 API 概述.md>) |
| 自有服务端 | 保存敏感凭证，调用 OpenAPI，接收事件或为客户端提供业务接口 | [OpenAPI 文档库](<../../openapi/README.md>)、[获取访问凭证](<../../openapi/guides/获取访问凭证.md>) |

插件不一定同时包含三部分。只扩展页面交互时可以只有平台配置和客户端资源；只接收事件或调用 OpenAPI 时可以只有平台配置和服务端。涉及 `Plugin Secret`、插件访问凭证、用户访问凭证或刷新凭证时，必须由服务端持有，不能进入客户端代码、浏览器存储、日志或发布产物。

## 可扩展的能力

功能构成决定插件在平台中的入口和运行上下文。先选择构成，再阅读该构成的点位协议和端支持。

| 能力类别 | 可选构成 | 入口 |
| --- | --- | --- |
| 页面与展示 | 详情标签页、导航功能页、视图模式、轻应用组件 | [Tab](<../points/详情标签页 Tab.md>)、[Page](<../points/导航功能页 Page.md>)、[View](<../points/视图模式 View.md>)、[轻应用组件](<../points/轻应用组件 LiteAppComponent.md>) |
| 工作项交互 | 表格列、表单页控件、节点表单控件、各类按钮 | [Control](<../points/控件 Control.md>)、[Button](<../points/按钮 Button.md>) |
| 数据和配置 | 字段类型、节点排期、插件配置 | [字段类型](<../points/扩展字段-字段类型 CustomField.md>)、[节点排期](<../points/扩展字段-节点排期 Schedule.md>)、[Configuration](<../points/插件配置 Configuration.md>) |
| 服务端触发 | 监听事件、拦截事件、自动化触发器和操作 | [监听事件](<../../openapi/events/监听事件.md>)、[Intercept](<../points/拦截事件 Intercept.md>)、[Connector](<../points/自动化连接器 Connector.md>) |

后台构成中的 `ResourceId` 要与客户端工程 `plugin.config.json` 的 `resources[].id` 一一对应，`entry` 指向实际入口文件。构成 Key、ResourceId 和 Plugin ID 分别表示不同层次的标识，不能互换。

## 开发路径

从零开始时先阅读[快速开始](<快速开始.md>)，或按以下顺序进入相应细节：

1. 在开放平台创建插件，并在基本信息页取得 Plugin ID 和 Plugin Secret。
2. 在“插件功能”添加构成，记录生成的 ResourceId、适用端和工作项范围。
3. 使用平台生成的初始化命令创建工程，核对资源映射后开发并本地调试客户端。
4. 需要 OpenAPI、用户授权、事件回调或自有数据时，开发服务端并按接口申请权限。
5. 构建上传客户端产物，创建插件版本，发布后由空间管理员安装并在真实点位验证。

客户端产物上传、插件版本发布和自有服务端部署是三个独立动作。上传成功不表示插件版本已经发布；发布插件也不会部署自有服务端。
