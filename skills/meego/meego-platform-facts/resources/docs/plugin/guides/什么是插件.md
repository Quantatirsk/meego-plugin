# 什么是插件

<!-- capability-metadata:start -->
## 平台能力标记

> 调用频次：无直接调用频次。本页用于平台说明、格式、目录或支持信息。

插件是飞书项目开放平台承载扩展能力的方式。开发者可为组织定制界面、数据交互及自动化功能，也可安装插件市场中已有的集成，用于代码托管、文档管理、工时管理等业务场景。

本页是能力入口。具体点位、权限和端支持应继续查阅对应文档，不把能力概览当作某个点位的完整调用契约。

## 客户端与服务端交互

| 能力 | 运行方式与职责 | 阅读入口 |
| --- | --- | --- |
| 客户端 API | 通过 `window.JSSDK` 获取上下文、使用端能力和读取数据模型 | [客户端 API 概述](<../jssdk/客户端 API 概述.md>) |
| 客户端组件 | 宿主在运行时注入的基础组件和业务组件 | [客户端组件库接入](<../components/客户端组件库接入.md>) |
| 服务端 OpenAPI | 通过经过鉴权的接口获取或操作业务数据 | [OpenAPI 文档库](<../../openapi/README.md>) |

是否需要客户端或自建服务端，取决于插件实际功能。单纯的数据集成不必为了调用 OpenAPI 再增加 UI 构成；反之，前端组件接入也不代表已实现服务端的数据操作。

## MCP 服务

飞书项目的业务 MCP 服务基于插件体系，面向 AI Agent 提供操作能力，详见官方 [MCP Server 功能简介](https://project.feishu.cn/b/helpcenter/1p8d7djs/jdmql9oj)。它与开发时检索文档的 MCP 服务用途不同，不能混作同一个接口入口。

<a id="6cdcca32"></a>

## 快速入门

开发流程见[开发并发布第一个插件](<开发并发布第一个插件.md>)：

1. 在开放平台创建插件。
2. 按功能添加构成；仅做数据获取时可跳过 UI 构成。
3. 开发调试客户端；没有客户端功能时可跳过。
4. 开发涉及 OpenAPI 或其他服务端交互的后端；没有这类交互时可跳过。
5. 完成功能测试和相应代码部署，再发布插件版本，供有权限的空间管理员安装。

服务端部署与客户端产物上传分别处理。插件发布和可见范围规则见[发布插件](<发布插件.md>)，不能将“发布插件”当作代管后端服务的操作。

使用现有 MCP 服务时，官方另提供[在 AI 工具中使用 MCP Server](https://project.feishu.cn/b/helpcenter/1p8d7djs/73n2upf3)：先在开放平台开启服务，再在 AI 工具中配置，可用于按反馈创建工单、结合上下文驱动节点流转等场景。
