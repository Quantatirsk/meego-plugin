# 添加插件功能

<!-- capability-metadata:start -->
## 平台能力标记

> 调用频次：无直接调用频次。本页用于平台说明、格式、目录或支持信息。

<!-- capability-metadata:end -->

在已创建的插件中配置功能构成，决定页面入口、工作项范围、支持端，以及事件或自动化连接器的对接方式。客户端资源还需与工程入口关联，后台配置本身不包含实际前端实现。

<a id="b739a0ba"></a>

## 选择功能形态

### 页面、控件与字段

| 功能 | 使用场景与入口 | 支持端 |
| --- | --- | --- |
| [导航页](<../points/导航功能页 Page.md>) | 空间左侧一级导航中的自定义页面 | 网页、移动 |
| [视图](<../points/视图模式 View.md>) | 工作项视图右上角切换入口；可提供 feed 流、地图、日历等渲染方式 | 网页 |
| [详情标签页](<../points/详情标签页 Tab.md>) | 实例详情 Tab；例如进展、用例执行或需求合码记录 | 网页、移动 |
| [表格列控件](<../points/控件 Control.md#459e2395>) | 表格列中的评分、进度、地址、电话号码等展示 | 网页 |
| [表单页控件](<../points/控件 Control.md>) | 拖入工作项表单配置，提供评分、进度、地址等控件 | 网页、移动 |
| [节点表单控件](<../points/控件 Control.md>) | 拖入节点表单配置，提供自定义控件 | 网页、移动 |
| [组件](<../points/轻应用组件 LiteAppComponent.md>) | 拖入轻应用，与其他组件联动 | 网页 |
| [字段类型](<../points/扩展字段-字段类型 CustomField.md>) | 在可添加字段的位置使用自定义字段类型，支持视图筛选、度量与 API 读写 | 网页、移动 |
| [节点排期](<../points/扩展字段-节点排期 Schedule.md>) | 自定义排期面板、样式和范围，将符合规范的数据更新到实例 | 网页 |

节点排期仅用于**排期范围**，不适用于里程碑等其他日期选择器。原文列出的入口为视图页的需求节点与进行中节点排期、详情页的节点表单与节点子任务、WBS 实例计划表的计划表布局与节点子任务排期。

表格列展示使用预置布局与展示态数据接口，不在单元格内执行自定义脚本，见[表格列搭建工具](<../client/表格列搭建工具.md>)。控件展示不等同于扩展字段类型，字段筛选与 API 读写能力应按所选点位定义确认。

### 按钮

所有按钮的详细协议见[按钮 / Button](<../points/按钮 Button.md>)。

| 位置 | 使用场景与入口 | 支持端 |
| --- | --- | --- |
| 实例更多按钮 | 实例详情右上角更多菜单；发送邮件、上传 SVN、创建文档等操作 | 网页、移动 |
| 节点更多按钮 | 节点详情右上角更多菜单；针对当前节点执行操作 | 网页、移动 |
| 节点流转按钮 | 节点负责人右侧；自定义按钮行为和页面 | 网页、移动 |
| 新建按钮 | 新建按钮右侧下拉列表；Xmind、Jira 导入等替代表单录入方式 | 网页 |
| 计划表节点更多按钮 | WBS 计划表右侧更多菜单；修改节点属性等 | 网页 |
| 批量操作 | 视图批量操作，例如将选中工作项加入迭代 | 网页 |

批量操作仅支持表格、看板视图；不支持全景视图、资源库等跨工作项视图，也不支持子任务视图。

### 事件、配置与自动化

| 功能 | 使用方式 | 支持端 |
| --- | --- | --- |
| [监听事件](<../../openapi/events/监听事件.md>) | 在插件功能中配置订阅，发布新版并由用户安装；数据变化时平台发送事件请求 | 服务端事件，不按客户端端区分 |
| [拦截事件](<../points/拦截事件 Intercept.md>) | 操作前向开发者后端询问，在约定时间内返回是否干预；可用于字段修改审批等 | 网页、移动 |
| [插件配置](<../points/插件配置 Configuration.md>) | 空间管理员安装后，在插件列表点击“配置”打开自定义页面 | 网页 |
| [自动化连接器](<../points/自动化连接器 Connector.md>) | 在自动化中连接跨系统触发器、类型及规则表单 | 不按客户端端区分 |
| 自动化操作 | 自动化规则中的插件操作，例如跨系统数据同步 | 不按客户端端区分 |

## 添加客户端构成

1. 完成[创建插件](<创建插件.md>)，打开插件详情的“插件功能”。
2. 点击“添加构成”，选择所需形态并进入下一步。
3. 配置名称、工作项类型、适用端与 ResourceId，确认保存。

下面以详情标签页为例，字段并非所有点位通用。

| 字段 | 含义 |
| --- | --- |
| 名称 | 构成展示名称；详情页中为 Tab 标题 |
| 描述 | 构成实现的功能 |
| Key | 系统自动生成的构成唯一标识，不可修改 |
| 工作项类型 | 可选全部、需求、缺陷、版本、迭代及其他工作项，限定功能可见范围 |
| 适用端 | 网页、移动；详情页支持双端，工程分别维护两端代码 |
| ResourceId | 开发者定义的客户端资源标识，用于平台在对应端位置加载资源 |

![添加详情标签页构成](<../assets/b8cadf54a19605adf8916f71.gif>)

后台 ResourceId 对应工程的 `resources[].id`，同一插件中必须唯一；`entry` 指定其代码入口。构成 Key 与 ResourceId 不同，不能互换。初始化后新增构成，可在工程根目录通过 `lpm update` 同步，见[初始化插件工程](<../client/初始化插件工程.md#65644d0f>)。

## 添加自动化触发器或操作

同一插件可以有多个触发器和多个操作，各自配置独立生效。触发器与操作的配置以[连接器开发者流程](<../points/自动化连接器 Connector.md#dba501a4>)为准。

<a id="8000af4a"></a>

### 自动化触发器

在“插件功能”点击“添加触发器或操作”，选择“自动化触发器”并确认。例如，可配置“飞书消息连接器”，由收到群消息触发业务规则。

| 字段 | 含义 |
| --- | --- |
| 名称、描述 | 说明触发器功能和触发场景 |
| Key | 系统生成的唯一标识，不可修改 |
| Webhook 推送至 | 接收规则订阅事件的 HTTP/HTTPS 地址 |
| Token | 配置平台推送时携带的校验 Token |
| 触发器入参 | 供规则配置者填写的触发器节点表单 |
| 触发器出参 | 供后续条件、操作节点使用的字段定义 |

![添加自动化触发器](<../assets/39fd2e4978b96ff71a55786e.gif>)

<a id="a0035439"></a>

### 自动化操作

在相同入口选择“自动化操作”并确认。例如，可定义“创建飞书日程，并添加参与人”。

| 字段 | 含义 |
| --- | --- |
| 名称、描述 | 说明操作功能及具体行为 |
| Key | 系统生成的唯一标识，不可修改 |
| 适用的触发器类型 | 限定哪些触发器可调用操作，例如创建、完成、删除工作项；未选择时默认允许自动化内所有触发器 |
| Webhook 推送至 | 接收操作请求的 HTTP/HTTPS 地址 |
| Token | 配置平台推送时携带的校验 Token |
| 操作入参 | 供规则配置者指定或映射的操作节点表单 |

![添加自动化操作](<../assets/2094b017357e5c3068879758.gif>)

Webhook 地址和表单规则支持实时更新；**新增或删除功能点位仍需发布插件版本**。已安装空间使用更新后的自动化功能无需升级插件；若已配置的规则受变更影响，规则列表会提示重新配置。此热更新范围来自连接器专篇，不能推广到所有客户端构成、事件订阅或代码产物。

## 自动化表单字段结构

触发器入参、触发器出参和操作入参使用按字段 key 映射的定义对象。每个 key 由开发者指定且必须唯一；字段类型支持范围见[自动化出入参字段类型](<../points/自动化连接器 Connector.md#7b181259>)。

| 路径 | 含义 |
| --- | --- |
| `field_type` | 字段类型，如 `select` |
| `form_config.label.origin` | 表单展示名称 |
| `form_config.placeholder.origin` | 输入提示文案 |
| `form_config.validate.required.value` | 是否要求提供字段值，具体含义见下表 |
| `field_attr.option` | 选项定义，仅对 `select`、`radio`、`multi_select` 生效 |
| `field_attr.option.type` | `enum` 为静态枚举，`remote` 为接口获取 |
| `field_attr.option.enum` | 静态选项列表；每项含展示名称 `label.origin` 和选项 ID `value` |
| `field_attr.option.remote.url` | 开发者提供的公网可访问 POST 接口 |

| 使用位置 | `required.value: true` 的含义 |
| --- | --- |
| 触发器入参 | 配置触发器规则时必填 |
| 触发器出参 | 开发者调用触发器 API 时必须传值，缺失将被视为不满足触发条件 |
| 操作入参 | 规则配置者必须指定该字段的值 |

### 静态选项示例

本例定义必填单选字段 `field_xxx_1`。`Option`、`Choose an option`、`Option A` 分别代替原结构示意中的字段名称、提示文案和选项展示名称；`option_a` 是示例选项 ID。

```json
{
  "field_xxx_1": {
    "field_type": "select",
    "form_config": {
      "label": { "origin": "Option" },
      "placeholder": { "origin": "Choose an option" },
      "validate": {
        "required": { "value": true }
      }
    },
    "field_attr": {
      "option": {
        "type": "enum",
        "enum": [
          {
            "label": { "origin": "Option A" },
            "value": "option_a"
          }
        ]
      }
    }
  }
}
```

新增 `field_xxx_2` 等字段时，提供完整字段对象，不能提交原示意中的空对象。

### 动态选项示例

需要远程选项时，将上例的 `field_attr.option` 替换为下面对象。URL 是占位地址，需替换为自己的公网 POST 接口。

```json
{
  "type": "remote",
  "remote": {
    "url": "https://example.com/options"
  }
}
```

远程接口响应体是选项数组；此处 `label` 是字符串，与静态配置的 `label.origin` 不同。

```json
[
  {
    "label": "Option A",
    "value": "option_a"
  }
]
```
