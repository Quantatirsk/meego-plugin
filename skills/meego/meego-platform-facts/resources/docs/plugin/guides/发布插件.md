# 发布插件

<!-- capability-metadata:start -->
## 平台能力标记

> 调用频次：无直接调用频次。本页用于平台说明、格式、目录或支持信息。

<!-- capability-metadata:end -->

在开放平台创建插件版本，关联客户端产物并配置使用范围，然后按企业或市场插件流程提交发布。发布完成后，目标空间仍需安装或按所选策略更新版本。

| 插件类型 | 使用范围 |
| --- | --- |
| 官方插件 | 飞书项目官方开发维护的基础功能插件 |
| 企业插件 | 当前企业所在空间安装使用，具体可见范围由发布配置限定 |
| 市场插件 | 面向平台其他租户开放，由被授权的空间安装使用 |

本篇介绍企业和市场插件。共享到市场表示开放跨租户使用，不表示自动安装到所有空间。

<a id="b4debc3b"></a>

## 发布前提与版本关系

完成插件所需的客户端、服务端开发与联调。包含客户端构成时，应先[上传客户端产物](<../client/发布插件产物.md>)；自有服务端需已能提供对应服务。

| 阶段 | 结果 |
| --- | --- |
| 创建插件 | 后台初始状态为“待上线” |
| `lpm release` | 构建并上传客户端产物，输出产物版本编号 |
| 后台创建版本 | 填写插件版本号、描述，选择产物版本和发布配置 |
| 申请发布与审核 | 按对应发布流程处理，市场插件提交后可查询审核进度 |
| 空间安装或更新 | 目标空间采用已发布的版本 |

产物版本编号与插件版本号是不同标识。CLI 上传成功不代表平台审核通过，也不代表已安装空间已经更新。原文没有给出完整后台状态枚举，不能把此流程表当作状态机协议。

## 创建版本时的配置

| 字段 | 用途 |
| --- | --- |
| 版本号 | 本次插件发布的版本号 |
| 版本描述 | 本版功能项与更新日志 |
| 产物版本 | 已上传的客户端产物，选择与本次发布相符的版本 |
| 插件使用范围 | 企业内部使用，或共享到插件市场 |
| 插件商店可见范围 | 控制商店发现入口；企业范围的选项见下文 |
| 插件自动更新 | 已发布过版本后，配置已安装空间的升级方式 |

### 企业插件的商店可见范围

- 租户内所有空间的插件商店可见。
- 本企业指定空间的插件商店可见。
- 不可在插件商店查看；已发布插件的新版本选择此项后，插件从商店下线。

商店下线与删除插件是不同操作。本篇未说明下线是否影响已安装实例，不应将其解释为自动卸载。

### 已安装空间的更新策略

- 全量升级至当前版本：继续选择从哪个版本更新到最新版本。
- 由空间管理员手动更新版本。

自动化连接器已有表单及 Webhook 地址的热更新有单独规则，见[添加插件功能](<添加插件功能.md#e087a3cc>)；不能把该例外推广到客户端产物或新增、删除点位。

## 发布企业插件

1. 打开插件详情，在左侧选择“管理 > 插件发布”。
2. 在“版本管理和发布”点击“创建版本”。
3. 填写版本号和描述，选择产物版本；使用范围选择企业内部使用，设置可见范围及需要的更新策略，点击“确定”。
4. 点击“申请发布”，完成后台要求的发布操作。

![创建企业插件版本](<../assets/45bbda90afeea4a434898066.png>)

企业内部发布仍遵循所选企业范围，不因界面使用“插件市场”或“申请发布”字样而成为跨租户市场插件。

<a id="d0ba4375"></a>

## 发布市场插件

1. 在“管理 > 插件发布”创建版本，填写版本号、描述、产物版本，选择共享到插件市场。
2. 按后台页面完成“确认并上架”和“申请发布”流程。
3. 填写服务商信息，同意“飞书项目独立软件服务商协议，并在飞书项目插件市场上架我的插件”，进入下一步。
4. 完善封面图、插件说明文档、插件自检清单；可下载页面提供的模板。
5. 确认数据安全检查并提交，之后在发布历史查看审核进度。

![创建市场插件版本](<../assets/6ada389bb370c9c2ba1abf2d.png>)

ISV 插件需经过飞书项目企业管理员与平台管理员审批。提交进入审核流程，不能将“确认并上架”按钮名称理解为立即审核通过。封面和基础信息要求见[创建插件](<创建插件.md#1f36bc2a>)。

市场插件的具体商店可见范围待核实：本篇原始表格中的空间选项与其跨租户范围不一致，不能作为确定配置清单。以目标后台实际提供的选项及授权范围为准。

## 启用 MCP Server

飞书项目 MCP Server 提供创建、修改、查询工作项等工具，可结合 AI 创建工单、分析上下文并驱动节点流转。功能定义与接入规则见 [MCP Server 功能简介](https://project.feishu.cn/b/helpcenter/1p8d7djs/jdmql9oj)。

## 分享链接与安装加密

在“分享链接设置”配置是否允许通过链接安装，以及安装是否需要加密。启用安装加密后，系统自动生成用于安装插件的密钥，且不可更改。

![分享链接设置](<../assets/a942538204a7f8975a93c156.png>)

安装密钥用于分享链接安装，不是工程配置中的 Plugin Secret，也不是访问 token。

<a id="3099474b"></a>

## 插件装卸监听

在“插件装卸监听设置”中开启监听后，填写事件回调地址。系统自动生成回调 Token，用于该类事件监听；事件结构与处理要求见[插件装卸监听](<../../openapi/events/插件装卸监听.md>)。

![插件装卸监听设置](<../assets/2dbac3bda201d4af4cbc4dd4.png>)

## 发布后的安装与排查

发布完成后，目标空间按可见与使用范围从插件商店安装；开启分享链接时也可按链接流程安装。已有安装空间则按所选更新策略采用新版本。

![从插件商店安装](<../assets/1dc282cb37c283bfd928084f.png>)

安装分布见[安装统计](<安装统计.md>)，调用异常见[日志检索](<日志检索.md>)。
