来源链接：source_silent

本目录是飞书项目插件 2.0 的唯一客户端与工程资料树，覆盖插件点位、客户端 JSSDK、组件库、CLI、工程调试和发布。服务端接口与事件协议位于 [OpenAPI 文档](<../openapi/README.md>)。

每个可调用插件点位或 JSSDK 方法在页面顶部逐项标为高、中或低频。频次只用于本地查阅优先级；目录、工程说明和组件概览会标为无直接调用频次。

## 当前范围

| 目录 | 内容 |
| --- | --- |
| `points/` | 插件点位、资源绑定、运行时上下文和回调。 |
| `jssdk/` | 宿主客户端 API、支持范围和示例。 |
| `components/` | 轻应用组件与客户端组件库。 |
| `client/` | 客户端构成、登录态和运行时约束。 |
| `cli/` | `lpm` 工具、调试与发布。 |
| `guides/` | 创建、开发、调试和发布工作流。 |

本套资料按 `@lark-project/js-sdk` `2.1.8` 类型声明校订 JSSDK 类型与返回值；实际插件工程仍应以其安装版本和对应官方页面的支持范围为准。旧版插件 1.0 文档不在本库范围内。
