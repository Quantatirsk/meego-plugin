本目录是飞书项目服务端平台资料的唯一正文树。基于中文开发者手册 `2.0.0` 整理，收录 163 篇文档；有独立官方 URL 的页面按一个官方主题保留一份规范正文。

每个可调用接口、事件或 AI 能力都会在页面顶部标为高、中或低频。频次仅来自本地插件调用痕迹的静态推断；导读、格式、目录和支持页会明确标为无直接调用频次。

## 文档约定

- 每篇先说明用途与限制，再组织参数、场景示例和错误处理。
- 正文使用中文，参数、枚举和 ID 保持协议含义；代码块保持可解析的英文或 JSON。
- 已确认的错误只保留正确写法；无法确认的边界在对应页标为待验证或 `source_silent`。
- fixture 是本地脱敏示例，不是可直接发往真实租户的授权。

```sh
rg -n 'search_after|work_item_ids|x-auth-mode' docs/openapi --glob '*.md'
```
