## 超限表现与调用调整

超过限制可能收到业务错误码 `10429`。原文建议：

1. **错峰并增加调用间隔。** 减少高峰期和瞬间集中发出的请求。
2. **缓存低频变化的结果。** 降低对同一数据的重复查询。

这些建议用于降低调用频率，不改变每个接口自己的阈值。通用限流维度和其他特殊接口见[OpenAPI 概述：调用限流](../guides/OpenAPI概述.md#rate-limits)；错误码见[Open API 错误码](../formats/Open%20API%20错误码.md)。
