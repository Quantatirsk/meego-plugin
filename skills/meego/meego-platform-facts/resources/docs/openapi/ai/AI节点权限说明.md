# Open API 权限说明

<!-- capability-metadata:start -->
## 平台能力标记

<a id="capability-ai.node.permissions"></a>
- **AI 节点权限** ｜ `ai.node.permissions` ｜ 频次：低 ｜ 状态：待运行时验证

<!-- capability-metadata:end -->

创建 AI 节点后，平台默认开启获取节点实例信息、修改节点数据和完成节点等权限。实际可访问范围还取决于 AI 节点的配置方式、当前运行状态，以及是否通过 `X-AI-ENTITY-ID` 指定 AI 实体。

本篇仅描述 **AI 节点**。AI 操作应用有单独的[权限说明](AI操作权限说明.md)，两者的请求头条件不能混用。

<a id="9cffe454"></a>

## 配置方式决定鉴权身份

| AI 节点的来源 | 鉴权规则 |
| --- | --- |
| 管理员在工作流中配置 | 可通过 API 直接读取、修改该 AI 节点下的实例数据与信息 |
| 在工作项实例中将普通节点转为 AI 节点 | 按该 AI 节点操作人的 `user_key` 鉴权；操作其无权限的数据会失败 |

管理员配置的节点规则不能推导成任意实例、任意状态下均可读写。还需满足下面的范围与运行条件。

## 运行状态与 AI 实体请求头

原文规定，查询与写入动作仅能在 AI 节点运行时执行。操作其他实例的数据时，必须在请求头中增加 `X-AI-ENTITY-ID`，否则会报错；实体标识从[AI 节点事件](AI节点事件.md)获取。

`X-AI-ENTITY-ID` 是在[通用请求头](../guides/OpenAPI概述.md#authentication)之外增加的上下文，不能替代访问凭证。具体接口的状态前提仍需单独核对，例如[修改节点](修改AI节点数据.md)要求 `ai_status` 为 `running`，[完成节点](完成AI节点.md)要求 `ai_status` 为 `done`。

## 权限与接口的对应关系

### 获取节点信息

| 接口 | 请求头及访问范围 |
| --- | --- |
| [获取 AI 节点信息](获取AI节点信息.md) | 通用请求头即可；只能查询当前 AI 节点 |
| [获取子任务详情](../api/获取子任务详情.md) | 只操作当前 AI 节点的子任务时使用通用请求头；其他情况增加 `X-AI-ENTITY-ID` |
| [获取节点或状态流转必填信息](../api/获取指定节点与状态流转所需必填信息.md) | 只读取当前 AI 节点必填信息时使用通用请求头；其他情况增加 `X-AI-ENTITY-ID` |

### 获取工作项信息

以下接口读取当前 AI 节点所在实例时，只需通用请求头；读取其他实例时增加 `X-AI-ENTITY-ID`。

| 接口 |
| --- |
| [获取工作项详情](../api/获取工作项详情.md) |
| [获取工作项指定字段可选选项](../api/获取工作项指定字段可选选项.md) |
| [获取关联工作项列表](../api/获取指定的关联工作项列表（单空间）.md) |

### 修改节点相关数据

| 接口 | 请求头及访问范围 |
| --- | --- |
| [修改 AI 节点数据](修改AI节点数据.md) | 通用请求头即可；只能修改当前 AI 节点 |
| [创建子任务](../api/创建子任务.md) | 当前 AI 节点范围内只需通用请求头；其他情况增加 `X-AI-ENTITY-ID` |
| [更新子任务](../api/更新子任务.md) | 同上 |
| [子任务完成或回滚](../api/子任务完成与回滚.md) | 同上 |
| [删除子任务](../api/删除子任务.md) | 同上 |
| [更新节点或排期](../api/更新节点与排期.md) | 操作当前 AI 节点的值时只需通用请求头；其他情况增加 `X-AI-ENTITY-ID` |

### 工作项操作

| 接口 | 是否需要额外传 `X-AI-ENTITY-ID` |
| --- | --- |
| [创建工作项](../api/创建工作项.md) | 必须 |
| [获取创建工作项元数据](../api/获取创建工作项元数据.md) | 必须 |
| [更新工作项](../api/更新工作项.md) | 当前 AI 节点所在实例不需要；其他实例需要 |
| [按组更新复合字段值](../api/按组更新复合字段值.md) | 当前 AI 节点所在实例不需要；其他实例需要 |

### 附件与富文本图片

| 接口 | 是否需要额外传 `X-AI-ENTITY-ID` |
| --- | --- |
| [添加附件](../api/添加附件.md) | 当前 AI 节点所在实例不需要；其他实例需要 |
| [删除附件](../api/删除附件.md) | 当前 AI 节点所在实例不需要；其他实例需要 |
| [下载附件](../api/下载附件.md) | 当前 AI 节点所在实例不需要；其他实例需要 |
| [上传文件或富文本图片](../api/上传文件或富文本图片.md) | 必须 |

### 完成 AI 节点

[完成 AI 节点](完成AI节点.md)使用通用请求头，只能流转当前 AI 节点。节点必须满足完成接口规定的 `done` 状态前提。
