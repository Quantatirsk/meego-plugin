# 权限管理

插件能否访问空间数据，既取决于申请了哪些接口权限，也取决于当前处于开发调试还是正式安装阶段。开发时配置的“数据范围”只决定虚拟凭证能访问哪个空间，不等同于正式版本的空间授权。

**阅读导航**：[授权边界](#permission-boundaries) · [开发调试](#development) · [发布与安装](#release) · [权限选择](#select-permissions)

## 前提条件

已在飞书项目开放平台[创建插件](https://project.feishu.cn/b/helpcenter/1p8d7djs/49k1ojm9)，并能进入该插件的详情页。

## 三类授权边界

| 配置或操作 | 解决的问题 | 生效场景 |
| --- | --- | --- |
| 开发数据范围 | 虚拟凭证能访问哪个空间的数据 | 本地开发与联调 |
| 接口权限 | 插件被允许调用哪些 OpenAPI | 开发与正式使用均需申请 |
| 插件发布、安装及空间数据授权 | 目标空间是否授权使用对应版本及其能力 | 正式使用 |

接口权限按能力授权，并不一定与单个接口一一对应。选择权限前，应通过“查看 API”确认它覆盖的接口清单。

## 开发调试：配置一个可访问的空间

1. 登录飞书项目开放平台，进入插件详情页。
2. 在左侧菜单打开“权限管理”。
3. 在“数据范围”中选择调试空间。
4. 按后文步骤申请需要调用的接口权限，然后使用虚拟 Token 调用该空间的数据。

这一阶段**无需发布插件版本**，可以在本地环境联调真实空间数据，但有以下限制：

| 限制 | 具体规则 |
| --- | --- |
| 空间数量 | 只支持选择一个空间作为开发数据范围 |
| 可选空间 | 插件管理员具备管理权限的空间 |
| 切换权限 | 插件协作者不能切换数据范围中的空间 |

建议选择测试空间。虚拟凭证的调用仍会访问所选空间中的实际数据，不能把“本地调试”理解为平台自动提供了隔离数据。

虚拟凭证统一称为 `virtual_plugin_token`，获取方式见[获取访问凭证](获取访问凭证.md)。

<a id="release"></a>

## 正式使用：发布、安装并完成空间授权

开发完成后，需要经过以下步骤：

1. **发布插件。** 选择插件的可见空间范围，并完成上架。
2. **安装插件。** 由目标空间的空间管理员安装对应插件。
3. **授权空间数据。** 完成空间数据授权后，插件才能正式访问对应空间的数据。

因此，开发数据范围配置成功，不代表插件已获得其他空间的正式访问权限。调用方还应确认目标空间安装的是具有所需权限的插件版本；版本与用户权限的共同作用见[获取访问凭证：资源访问权限](获取访问凭证.md#c0d4c50f)。

<a id="select-permissions"></a>

## 选择接口权限

在插件详情页的“权限管理”页面中：

1. 按权限名称搜索，或根据用户、空间、工作项实例、配置、评论、视图与度量等分类查找。
2. 将鼠标移到目标权限右侧“操作”栏的“查看 API”，确认该权限覆盖需要调用的接口。
3. 勾选必要权限，单击“批量获取”。

企业管理员与飞书项目官方在上架审核时会检查权限申请是否合理。应只申请当前功能需要的权限；超出功能需要的权限可能导致审核不通过。

<a id="804fd1d2"></a>

## 验证顺序

将授权问题拆开排查，避免把某一层的成功当作全部权限已经就绪：

1. 开发调试时，确认虚拟插件凭证、开发数据范围和目标接口权限。
2. 正式调用前，确认已发布版本、空间安装、空间数据授权和调用用户自身权限。
3. 每个端点再按其文档确认身份请求头与 scope；数据范围或 token 可用不表示任意端点都可访问。

开发数据范围与正式空间授权是两套配置，前者不能替代后者。接口返回权限失败时，应保留平台 `log_id` 供排查，不记录 token、密钥或用户敏感数据。
