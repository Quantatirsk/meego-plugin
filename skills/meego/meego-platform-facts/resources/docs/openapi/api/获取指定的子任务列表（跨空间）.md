# 获取指定的子任务列表（跨空间）

<!-- capability-metadata:start -->
## 平台能力标记

<a id="capability-openapi.post.open-api-work-item-subtask-search"></a>
- **获取指定的子任务列表（跨空间）** ｜ `openapi.post.open-api-work-item-subtask-search` ｜ 频次：低 ｜ 状态：待运行时验证

<!-- capability-metadata:end -->

跨空间搜索满足名称、负责人、完成状态和创建时间条件的子任务。结果按工作项与节点定位子任务；读取单个工作项的完整节点任务结构时，使用[获取子任务详情](获取子任务详情.md)。

## 搜索范围与结果上限

- 只查询已安装插件的空间。`project_keys` 与 `simple_names` 均省略时，范围为请求头中 `user_key` 可访问且安装了插件的空间。
- 显式传入的两种空间标识取并集后不能超过 10 个。
- 匹配总数不能超过 5000；`page_size` 只控制每页大小，不能绕过总数限制。超过时应缩小时间、空间或负责人等筛选条件。
- 默认 `page_num = 1`、`page_size = 50`。`status = 0` 查询进行中任务，`status = 1` 查询已完成任务。

权限申请位于“权限管理 → 工作项”，见[权限管理](../guides/权限管理.md)。产品操作见[任务管理](https://project.feishu.cn/1ykiuvvj/40gyakm8)与节点配置中的[完成任务](https://project.feishu.cn/1ykiuvvj/3bv61iew#%E5%AE%8C%E6%88%90%E4%BB%BB%E5%8A%A1)。

## 请求说明

**请求方式**：`POST`
**请求地址**：`/open_api/work_item/subtask/search`

### 请求体

| 参数 | 类型 | 是否必须 | 说明 |
| --- | --- | --- | --- |
| `project_keys` | `list<string>` | 可选 | 需要查询的空间 ID，在飞书项目空间中双击空间名称获取，仅支持查询安装插件的空间下的子任务信息。<br>若 `project_keys` 和 `simple_names` 均不填则默认查询 header 中传入的 `user_key` 可访问且安装了插件的空间。 |
| `simple_names` | `list<string>` | 可选 | [填写说明](#parameter-notes-1) |
| `page_size` | int64 | 可选 | 分页大小，默认50。<br>分页设置不能控制总返回数量，查询结果超过 5000 会报错。 |
| `page_num` | int64 | 可选 | 页码，默认1。 |
| `name` | string | 可选 | 子任务名称，支持模糊匹配。 |
| `user_keys` | `list<string>` | 可选 | 子任务负责人的 user_key 的数组。<br>- 开发者自己的 user_key，在飞书项目空间左下角双击个人头像获取。<br>- 租户内其他成员的 user_key，请通过[搜索租户内的用户列表](搜索租户内的用户列表.md)接口获取。 |
| `status` | int32 | 可选 | 子任务的状态，支持的取值如下所示。<br>- `0`：进行中；<br>- `1`：已完成。 |
| `created_at` | object | 可选 | 子任务的创建时间区间，不传 `end`则默认为当前时间。 |

<a id="parameter-notes-1"></a>

**simple_names 的填写说明**

安装插件的飞书项目空间（simple_name）列表。`simple_name` 一般在飞书项目空间 URL 中获取。例如空间 URL 为 “https://project.feishu.cn/doc/overview”，则 `simple_name` 为 “doc”。

若 `project_keys` 和 `simple_names` 均不填则默认查询 header 中传入的 `user_key` 可访问且安装了插件的空间。

#### `created_at`

| 参数 | 类型 | 是否必须 | 说明 |
| --- | --- | --- | --- |
| `end` | int64 | 可选 | 结束时间，毫秒精度；省略时使用当前时间。 |
| `start` | int64 | 可选 | 开始时间，毫秒精度。 |
