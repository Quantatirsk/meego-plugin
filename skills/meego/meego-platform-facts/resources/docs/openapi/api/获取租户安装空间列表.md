# 获取租户安装空间列表

<!-- capability-metadata:start -->
## 平台能力标记

<a id="capability-openapi.post.open-api-tenant-projects-install-list"></a>
- **获取租户安装空间列表** ｜ `openapi.post.open-api-tenant-projects-install-list` ｜ 频次：低 ｜ 状态：待运行时验证

<!-- capability-metadata:end -->

按飞书项目租户 key 查询已安装插件的空间列表，返回 `data.project_key_list` 及所属租户 key。租户 key 可从插件安装、卸载或购买事件取得。

## 使用前确认

请求定义为 `POST /open_api/tenant/projects/install/list`，`tenant_key` 在本篇参数表中位于 Query。响应给出空间 ID 列表，本篇未定义分页参数。

<a id="请求说明"></a>

## 请求说明

- 请求方式：POST

- 请求地址：/open_api/tenant/projects/install/list

## 请求参数

### Header

### Query

| 参数 | 类型 | 是否必须 | 说明 |
