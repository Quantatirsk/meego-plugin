<a id="519b4348"></a>

终止一个分片上传任务。使用与[分片初始化](分片初始化.md)相同的 `resource_id`；需要完成并取得文件标识时，使用[完成分片上传](完成分片上传.md)。

原文没有定义终止后的分片保留方式、重复终止行为或已完成任务能否终止，本地不补造这些规则。权限见[权限管理](../guides/权限管理.md)中的“工作项实例”。

<a id="b4f2f0bb"></a>

## 请求定义

**请求方式**：`POST`
**请求地址**：`/open_api/:project_key/file/upload/multipart/abort/:resource_id`

鉴权请求头见[OpenAPI 概述](../guides/OpenAPI概述.md#a8e43b86)。原文只定义路径参数，没有请求体字段。

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `project_key` | `string` | 是 | 空间 key |
| `resource_id` | `string` | 是 | 与初始化一致的上传资源 ID |

## 响应结构

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `code` | `int` | `0` 为成功，非零为实际错误码 |
| `message` | `string` | 响应信息，成功判定以 `code = 0` 为准 |
| `data` | `object` | 无额外业务数据，示例为 `null` |

三个字段在原表均未标为必填。是否成功看 `code`，不能把 `data: null` 当作终止失败。

```json
{
  "code": 0,
  "message": "success",
  "data": null
}
```

<a id="4ae97c35"></a>

## 错误码

原文错误表沿用 `err_code` 等表头，实际响应使用 `code/message`。通用说明见[Open API 错误码](../formats/Open%20API%20错误码.md)。

| 编号 | 原错误名称 | 消息 | 说明 |
| --- | --- | --- | --- |
| `30016` | `ErrAPIProjectNotFound` | `Project Not Found` | `project_key` 不正确 |
| `1000051686` | `ErrFileInternal` | `file internal error` | 业务错误 |
