# 分片初始化

<a id="05e55c48"></a>

初始化一个分片上传任务，取得 `resource_id`、分片大小与待上传序号。适用于 **大于 5M** 的文件；小文件使用[上传文件](上传文件.md)。普通上传页要求超过 100M 使用分片，因此大于 5M 是本接口的适用下限，不等同于所有文件超过 5M 就必须分片。

## 分片上传流程

1. 初始化任务，保存返回的 `resource_id` 与 `multipart` 信息。
2. 按返回的 `need` 序号和 `part_size` 调用[上传分片](上传分片.md)，每片从 `0` 开始编号。
3. 上传完所有需要的分片后，调用[完成分片上传](完成分片上传.md)取得 `file_token`。
4. 不再继续的任务使用[终止分片上传](终止分片上传.md)。

插件权限见[权限管理](../guides/权限管理.md)中的“工作项实例”。

## 请求定义

**请求方式**：`POST`
**请求地址**：`/open_api/:project_key/file/resource/:resource_type/upload/preprocess`

鉴权请求头见[OpenAPI 概述](../guides/OpenAPI概述.md#a8e43b86)。本步骤提交文件元信息，不上传分片二进制。

### 路径参数

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `project_key` | `string` | 是 | 空间 key |
| `resource_type` | `string` | 是 | 文件业务场景，见[业务点位](#d695b5f5) |

### 请求体

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `size` | `int` | 是 | 文件大小，单位字节 |
| `file_name` | `string` | 是 | 带扩展名的展示文件名，例如 `test.jpg` |
| `field_map` | `map[string]string` | 按业务场景 | JSON 格式的文件属主信息；总表标为可选，并说明部分业务必填 |
| `mime_type` | `string` | 是 | 文件类型，原例 `image/jpg` |
| `resource_id` | `string` | 否 | 文件生成的唯一 ID，用于断点续传；省略时由服务端生成 |

### 自行生成资源 ID

原文要求保证唯一性、保持固定长度，建议 **32 个字符**，给出的计算示意为 `MD5(file_name + user_name + file_size + first_5M_bytes)`。这里是上传资源标识的计算建议，不是分片内容的 MD5 校验参数；上传每一片时还需要单独计算该片的 `md5`。

## 文件 OpenAPI 支持的点位

| `resource_type` | 业务场景 | 属主示例 |
| --- | --- | --- |
| `CommentAttachment` | 评论附件 | [附件属主](#table-content-1) |

## 响应结构

<a id="60bb5a03"></a>

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `code` | `int` | `0` 成功，非零为实际错误码 |
| `message` | `string` | 响应信息，成功判定以 `code = 0` 为准 |
| `data` | [UploadPreProcessV2Result](../formats/数据结构汇总.md#bded0d52) | 初始化结果 |
| `data.is_multipart` | `boolean` | 是否分片上传，示例为 `true` |
| `data.resource_id` | `string` | 上传资源 ID，供后续上传、完成和终止操作使用 |
| `data.multipart` | [Multipart](../formats/数据结构汇总.md#0c6f279e) | 分片信息 |

顶层三个字段在原表均未标为必填。下表按引用的 Multipart 结构补全分片字段说明：

| `multipart` 字段 | 类型 | 说明 |
| --- | --- | --- |
| `is_new` | `bool` | 是否新 session；结构汇总注释为“暂无用处” |
| `part_count` | `int` | 分片总数 |
| `part_size` | `int` | 分片大小；原示例为 `20971520` |
| `need` | `int[]` | 仍需上传的分片编号 |

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "is_multipart": true,
    "multipart": {
      "is_new": true,
      "part_count": 1,
      "part_size": 20971520,
      "need": [
        0
      ]
    },
    "resource_id": "12cb4e54-bf9f-4c31-8466-ed13xxxx947b"
  }
}
```

`part_size` 应读取实际响应，不能把此例的值固化为所有上传任务的分片大小。
