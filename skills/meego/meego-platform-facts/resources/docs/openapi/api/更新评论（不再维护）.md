# 更新评论（不再维护）

<!-- capability-metadata:start -->
## 平台能力标记

<a id="capability-openapi.put.open-api-project-key-work-item-work-item-type-key-work-item-id-comment-comment-id"></a>
- **更新评论（不再维护）** ｜ `openapi.put.open-api-project-key-work-item-work-item-type-key-work-item-id-comment-comment-id` ｜ 频次：低 ｜ 状态：已废弃

<!-- capability-metadata:end -->

这是不再维护的评论更新接口，使用 `PUT` 和路径中的评论 ID 修改内容。新接入应使用[更新评论](更新评论.md)的 `POST /open_api/comment/update`。

## 使用前确认

仅评论创建人可更新。旧 Body 的 `content` 与 `rich_text` 至少一项非空，两者都有值时富文本优先；旧接口不能直接传 Markdown。

迁移时，空间及评论 ID 从路径移入 Body，新内容放入带 `type` 的 `content` 对象。纯文本使用 `TEXT` 与 `text`，富文本使用 `RICHTEXT` 与 `rich_text` 或 `markdown`。

该接口用于对指定评论更新其内容，被更新的评论会显示该评论由插件添加。对应的权限申请在**权限管理-评论**分类下，相关功能介绍详见[权限管理](../guides/权限管理.md)。建议使用或更换为[更新评论](更新评论.md)接口。

> **说明**：仅评论创建人可以更新该评论。

<a id="请求说明"></a>

## 请求说明

- 请求方式：PUT

- 请求地址：/open_api/:project_key/work_item/:work_item_type_key/:work_item_id/comment/:comment_id

<a id="请求参数"></a>

## 请求参数

<a id="header"></a>

### Header

接口调用的 Header 配置详见 [Header](https://project.feishu.cn/b/helpcenter/developer/create-an-api-configuration#018a9fe7)。

<a id="Path"></a>

### Path

| 参数 | 类型 | 是否必须 | 说明 |
| --- | --- | --- | --- |
| `project_key` | string | 必须 | [说明](#parameter-note-1) |
| `work_item_type_key` | string | 必须 | 关联工作项类型，从[获取空间下工作项类型](获取空间下工作项类型.md)接口获取。 |
| `work_item_id` | string | 必须 | 工作项实例 ID，在工作项实例详情中，展开右上角 **··· \> ID**获取。 |
| `comment_id` | string | 必须 | 评论 ID，可以通过[查询评论](查询评论（不再维护）.md)接口获取。 |

<a id="parameter-note-1"></a>

**project_key：说明**

空间 ID（project_key），或者空间域名（simple_name）。
- 空间 ID（project_key），在飞书项目空间双击空间名称获取。
- 空间域名（simple_name），`simple_name` 一般在飞书项目空间 URL 中获取。例如空间 URL 为 “https://project.feishu.cn/doc/overview”，则 `simple_name`为 “doc”。

<a id="Body"></a>

### Body

| 参数 | 类型 | 是否必须 | 说明 |
| --- | --- | --- | --- |
| `content` | string | 可选 | 评论内容，仅支持原生文本。<br>**注意：**<br>**`content` 参数与 `rich_text` 参数不可同时为空，若都有值时 `rich_text` 优先。** |
| `rich_text` | `list<object>` | 可选 | [说明](#parameter-note-2) |

<a id="parameter-note-2"></a>

**rich_text：说明**

评论内容，支持富文本格式，参见[富文本格式](../formats/字段与属性解析格式.md#110a33af)。目前不支持直接传递 markdown 格式来更新富文本字段。
**注意：**
**`content` 参数与 `rich_text` 参数不可同时为空，若都有值时 `rich_text` 优先。**

<a id="返回参数"></a>

## 返回参数

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `err` | object | 请求成功时返回空值，请求失败时返回实际错误信息。 |
| `err_msg` | string | 请求成功时返回空值，请求失败时返回实际错误信息。 |
| `err_code` | int32 | 请求成功时0，请求失败返回实际错误码。 |

### `err` 的字段

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `code` | int32 | 部分场景下，透出更详细错误对应的错误码。 |
| `msg` | string | 部分场景下，透出更详细的错误描述。 |
| `log_id` | string | 报错场景下的调用链标识符，用于追踪错误发生时的完整调用链路，便于日志记录和问题排查。 |

<a id="请求示例"></a>

## 请求示例

### 更新为纯文本评论

**请求路径：**PUT /open_api/68382b399de4b0ec6c5axxxx/work_item/story/621541xxxx/comment/756542259956983xxxx

```json
{
  "content": "re-\u6d4b\u8bd5\u8bc4\u8bba"
}
```

### 更新为富文本评论

**请求路径：**PUT /open_api/68382b399de4b0ec6c5axxxx/work_item/story/621541xxxx/comment/756542259956983xxxx

```json
{
  "rich_text": [
    {
      "type": "paragraph",
      "content": [
        {
          "type": "text",
          "text": "re-\u6d4b\u8bd5\u8bc4\u8bba",
          "attrs": {
            "fontColor": "green",
            "fontSize": "h1"
          }
        }
      ]
    }
  ]
}
```
