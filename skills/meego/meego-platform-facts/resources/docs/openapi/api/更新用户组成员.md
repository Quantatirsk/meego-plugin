# 更新用户组成员

<!-- capability-metadata:start -->
## 平台能力标记

<a id="capability-openapi.patch.open-api-project-key-user-group-members"></a>
- **更新用户组成员** ｜ `openapi.patch.open-api-project-key-user-group-members` ｜ 频次：低 ｜ 状态：待运行时验证

<!-- capability-metadata:end -->

新增、删除或整体替换空间成员及自定义用户组成员。仅支持 `PROJECT_MEMBER` 和 `CUSTOMIZE`，不能使用本接口维护 `PROJECT_ADMIN`。接口权限位于[权限管理](../guides/权限管理.md)的“用户”分类。

## 先选择更新方式

| 方式     | 参数            | 生效规则                                                     |
| -------- | --------------- | ------------------------------------------------------------ |
| 增量添加 | `add_users`     | 单次最多 100 人，不能添加离职或不存在的用户                  |
| 增量删除 | `delete_users`  | 单次最多 100 人；与 `add_users` 重复的用户在本次更新中被忽略 |
| 全量替换 | `replace_users` | 非空时优先，只采用替换列表并忽略增删列表；单次最多 100 人    |

三个列表不能同时为空。超过 100 人的目标组不能用一次全量替换完成，可先设置首批成员，再用 `add_users` 继续添加。修改自定义组时必须提供单数参数 `user_group_id`。

<a id="注意事项"></a>

## 注意事项

- 该接口仅支持用户访问凭证（user_access_token）获取方式可参考[获取用户访问凭证 user_access_token](../guides/获取访问凭证.md#3df3fccd)。

- 从非空间成员添加用户时，会自动添加用户至空间成员。

- 从空间成员删除用户时，会自动从其他用户组删除用户。

<a id="请求说明"></a>

## 请求说明

**请求方式**：`PATCH`

**请求地址**：`/open_api/:project_key/user_group/members`

<a id="请求参数"></a>

## 请求参数

<a id="header"></a>

### 请求头

接口调用的 Header 配置详见 [Header](../guides/OpenAPI概述.md#a8e43b86)。

<a id="Path"></a>

### 路径参数

| 参数          | 类型     | 是否必须 | 说明                                                                            |
| ------------- | -------- | -------- | ------------------------------------------------------------------------------- |
| `project_key` | `string` | 必须     | 空间 ID（project_key），或者空间域名（simple_name）。 [详细说明](#field-note-1) |

<a id="field-note-1"></a>

**project_key**

空间 ID（project_key），或者空间域名（simple_name）。

- 空间 ID（project_key），在飞书项目空间双击空间名称获取。
- 空间域名（simple_name），`simple_name` 一般在飞书项目空间 URL 中获取。例如空间 URL 为 “https://project.feishu.cn/doc/overview”，则 `simple_name`为 “doc”。

<a id="Body"></a>

### 请求体

| 参数              | 类型           | 是否必须 | 说明                                                                                                                                                                                                                             |
| ----------------- | -------------- | -------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `user_group_type` | `string`       | 必须     | 用户组类型，枚举列表： [详细说明](#field-note-2)                                                                                                                                                                                 |
| `user_group_id`   | `string`       | 可选     | 用户组 ID，当 `user_group_type=CUSTOMIZE` 时，此字段必填。在该用户组页面 URL 中获取。例如该用户组 URL 为“https://project.feishu.cn/intxxxx/setting/userGroup/756472096042365xxxx”，则 `user_group_ids` 为“756472096042365xxxx”。 |
| `add_users`       | `list<string>` | 可选     | 待添加成员列表，成员标识为 user_key，不能添加已离职或不存在的员工，单次添加不能超过100个员工。 [详细说明](#field-note-3)                                                                                                         |
| `delete_users`    | `list<string>` | 可选     | 待删除成员列表，成员标识为 user_key，单次删除不能超过 100 个员工。 [详细说明](#field-note-4)                                                                                                                                     |
| `replace_users`   | `list<string>` | 可选     | [详细说明](#field-note-5)                                                                                                                                                                                                        |

<a id="field-note-2"></a>

**user_group_type**

用户组类型，枚举列表：

- 空间成员：PROJECT_MEMBER
- 自定义用户组：CUSTOMIZE

<a id="field-note-3"></a>

**add_users**

待添加成员列表，成员标识为 user_key，不能添加已离职或不存在的员工，单次添加不能超过100个员工。

**注意：**`add_users`、`delete_users`、`replace_users`三个字段不能同时为空。

<a id="field-note-4"></a>

**delete_users**

待删除成员列表，成员标识为 user_key，单次删除不能超过 100 个员工。

**注意：**

- `add_users`、`delete_users`、`replace_users`三个字段不能同时为空。
- `add_users`、`delete_users` 存在相同的 user_key 时，则忽略这个 user_key。

<a id="field-note-5"></a>

**replace_users**

全部覆盖已有用户组成员信息。员工标识为 user_key，单次设置不能超过 100 个员工。若需添加 100 个员工以上，请用 `add_users` 方式继续添加。

**注意：**

- `add_users`、`delete_users`、`replace_users`三个字段不能同时为空。
- 此字段不为空时，忽略 `add_users`、`delete_users` 参数。

## 请求示例

### 新增用户组成员

**请求路径：**`PATCH /open_api/68382b399de4b0ec6c5axxxx/user_group/members`

```json
{
  "user_group_type": "CUSTOMIZE",
  "user_group_id": "756472096042365xxxx",
  "add_users": ["749112601802809xxxx"]
}
```

### 删除用户组成员

**请求路径：**`PATCH /open_api/68382b399de4b0ec6c5axxxx/user_group/members`

```json
{
  "user_group_type": "CUSTOMIZE",
  "user_group_id": "756472096042365xxxx",
  "delete_users": ["749112601802809xxxx"]
}
```

**请求路径：**`PATCH /open_api/68382b399de4b0ec6c5axxxx/user_group/members`

```json
{
  "user_group_type": "CUSTOMIZE",
  "user_group_id": "7350184656806xxxxxx",
  "delete_users": ["7012514555133xxxx"],
  "add_users": ["8012514555133xxxx"],
  "replace_users": ["7012514555133xxxx", "8012514555133xxxx"]
}
```

### 同时新增、删除、覆盖

本示例中，同时传入了 `delete_users`、`add_users` 和 `replace_users` 参数，但仅 `replace_users `参数生效。
