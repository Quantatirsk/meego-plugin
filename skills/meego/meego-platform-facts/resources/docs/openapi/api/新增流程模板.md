# 新增流程模板

<!-- capability-metadata:start -->
## 平台能力标记

<a id="capability-openapi.post.open-api-template-v2-create-template"></a>
- **新增流程模板** ｜ `openapi.post.open-api-template-v2-create-template` ｜ 频次：低 ｜ 状态：待运行时验证

<!-- capability-metadata:end -->

在指定空间的工作项类型下新增流程模板。可仅填写模板名称创建新模板，也可通过 `copy_template_id` 复用已有模板；成功返回值 `data` 是新模板的数值 ID。

## 使用前确认

操作需要空间配置权限，权限不足返回 `10005`。模板名称不能重复，冲突返回 `50006`。复用时传入的是已有模板的数值 ID，可从模板列表获取。

对应的平台功能介绍详见[节点流程规则配置](https://project.feishu.cn/1ykiuvvj/3bv61iew)或[状态流程规则配置](https://project.feishu.cn/1ykiuvvj/2lgf2cd8)，对应的权限申请在**权限管理-配置**分类下，相关功能介绍详见 [权限管理](../guides/权限管理.md)。

<a id="请求说明"></a>

## 请求说明

- 请求方式：POST

- 请求地址：/open_api/template/v2/create_template

<a id="请求参数"></a>

## 请求参数

<a id="header"></a>

### Header

接口调用的 Header 配置详见 [Header](https://project.feishu.cn/b/helpcenter/developer/create-an-api-configuration#018a9fe7)。

<a id="Body"></a>

### Body

| 参数 | 类型 | 是否必须 | 说明 |
| --- | --- | --- | --- |
| `project_key` | string | 必须 | 空间 ID（project_key），在飞书项目空间双击空间名称获取。 |
| `work_item_type_key` | string | 必须 | 工作项类型，可以从[获取空间下工作项类型](获取空间下工作项类型.md)接口获取。 |
| `template_name` | string | 必须 | 流程模板名称。 |
| `copy_template_id` | int64 | 可选 | 复用的模板 ID，可通过[获取工作项下的流程模板列表](获取工作项下的流程模板列表.md)接口获取。 |

<a id="返回参数"></a>

## 返回参数

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `data` | int64 | 新建流程模板的模板 ID。 |
| `err` | object | 请求成功时返回空值，请求失败时返回实际错误信息。 |
| `err_msg` | string | 请求成功时返回空值，请求失败时返回实际错误信息。 |
| `err_code` | int32 | 请求成功时返回0，请求失败返回实际错误码。 |

### `err` 的字段

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `code` | int32 | 部分场景下，透出更详细错误对应的错误码。 |
| `msg` | string | 部分场景下，透出更详细的错误描述。 |
| `log_id` | string | 报错场景下的调用链标识符，用于追踪错误发生时的完整调用链路，便于日志记录和问题排查。 |

<a id="请求示例"></a>

## 请求示例

### 新建模板

```json
{
  "project_key": "68ad83ea452263aabdcf****",
  "work_item_type_key": "story",
  "template_name": "\u6280\u672f\u9700\u6c42"
}
```

### 复用已有模板

```json
{
  "project_key": "68ad83ea452263aabdcf****",
  "work_item_type_key": "story",
  "template_name": "\u9700\u6c42\u6a21\u677f",
  "copy_template_id": 445
}
```

<a id="返回示例"></a>

## 返回示例

### 请求成功示例

```text
{
    "data": 12***,
    "err": {},
    "err_msg": "",
    "err_code": 0

```

### 错误返回示例

以下错误原因为模板名字已存在，请更换名字。

```json
{
  "err_code": 50006,
  "err_msg": "template name duplicate",
  "err": {
    "code": 50006,
    "msg": "Workflow name duplicated.",
    "log_id": "20251030172410A474F2A664F13056xxxx"
  }
}
```
