# 客户端运行时

在 React/TypeScript/JSSDK 资源入口、字段读写或客户端异步流程发生改动时读取。本页是工程实现约束，不替代点位、JSSDK 或 OpenAPI 的事实资料。

## 资源入口

`plugin.config.json` 的 `resources[].id -> entry` 决定宿主如何加载代码。先确认正在修改的入口、其点位类型和目标端；不要仅因两个点位功能相近就假设它们共享上下文或支持范围。

当当前工程使用 React 和共享模块时，入口保持薄：等待共享模块准备完成，再延迟加载依赖注入资源的应用模块，最后挂载。共享模块的具体顺序和可用端以 `meego-platform-facts` 中 `shared` 的资料为准。

在入口边界读取与点位匹配的 JSSDK context，校验调用真正需要的 key，再把已验证的局部类型传给业务组件。不要把 `control`、`button`、`configuration`、`tab`、`page` 等 namespace 当作可互换接口；也不要假定创建态一定有持久化的工作项 ID。

创建态和详情态应显式分支：只有在资料和当前 context 确认存在时，才使用持久化工作项 ID 或创建实例的稳定标识。不要用空字符串、展示名称或猜测的字段代替缺失标识。

## 前端状态与请求边界

- 组件内部的短生命周期状态留在组件；跨组件的表单或配置状态使用 Context/reducer；只有多视图、长期共享的状态才引入现有工程已采用的 store。状态库不是平台前置条件。
- 为平台调用和自建后端分别保留窄且强类型的 adapter。adapter 负责序列化、错误映射和上下文注入；UI 不应拼接平台请求体或依赖项目私有的响应码约定。
- 多资源复用 UI 时，由资源入口注入已验证的 context 和少量差异配置；共享组件只依赖窄 adapter，不直接绑定某个资源或后端实现。
- 客户端只能持有自己的短期会话标识。所有平台 token、refresh token 和插件密钥都由服务端管理；具体授权链路必须回到 `meego-platform-facts` 的凭证资料确认。
- 对加载、空结果、权限不足、重复提交和失败建立可见状态。按钮或 modal 只有在成功结果已确认后才能关闭宿主界面。

## 数据写回

读取工作项或字段元数据后，按返回的 field key、field type 和选项 value 生成写入结构。label 只用于展示；不能把当前空间的字段别名、选项、工作项类型或请求示例写成通用常量。

对文件、批量提交和导入可在客户端做格式、数量和内容预检，但服务端必须再次校验。客户端校验不是授权或数据完整性的安全边界。

## 异步与本地存储

- 可取消的加载使用取消信号或请求代次，组件卸载或条件切换后不得落入旧结果。
- 轮询和流式连接必须定义间隔、超时、失败、重试预算和清理路径。长任务应显示可恢复的状态，而不是无限重连。
- 只把可丢失的 UI 偏好放入宿主 storage，并处理解析失败、去重和容量上限。不得存放平台凭证、敏感业务数据或服务端状态副本。

## 不从样例继承

不要把目标工程的领域字段、外部系统集成、私有域名、随机资源 ID、特定 UI 文案或项目私有响应 envelope 带入插件通用实现。它们只能说明边界应该存在，不能说明边界里面应该是什么。
