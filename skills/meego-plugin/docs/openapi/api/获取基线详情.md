# 获取基线详情

用[基线列表](获取计划表基线列表.md)返回的 ID 查询该工作项的历史快照。指定 `uuids` 时按请求顺序返回，未命中行仍返回只有 `uuid` 的占位对象。未指定 UUID 时从第 1 页开始分页。默认每页 100，实际限制以平台配置为准。`fields` 支持 `estimate_start_date`、`estimate_end_date`、`points`、`estimate_duration`，空列表返回全部合法排期字段。官方页顶部关于用户详情及权限分类的描述与接口内容冲突，具体 scope 以控制台为准。

## 请求

`POST /open_api/:project_key/work_item_baseline/:work_item_id/query`

请求头按 [Open API 概述](../guides/OpenAPI概述.md) 和 [权限管理](../guides/权限管理.md) 选择调用身份。

## 路径参数

| 字段 | 类型 | 必须 | 说明 |
| --- | --- | --- | --- |
| `project_key` | `string` | 必须 | 空间 ID（project_key），或者空间域名（simple_name）。 空间 ID（project_key），在飞书项目空间双击空间名称获取。 空间域名（simple_name）， simple_name 一般在飞书项目空间 URL 中获取。例如空间 URL 为 “https://project.feishu.cn/doc/overview”，则 simple_name 为 “doc”。 |
| `work_item_id` | `string` | 必须 | 工作项实例 ID，在工作项实例详情右上角展开 ··· ，单击 ID 信息即可获取。 |

## 请求体

| 字段 | 类型 | 必须 | 说明 |
| --- | --- | --- | --- |
| `baseline_id` | `string` | 必须 | 待查询的基线 ID，来自 获取计划表基线列表 |
| `uuids` | `list<string>` | 可选 | 只查询指定 WBS 行。不传或传空数组时查询全部行并使用分页；最多 100 个，实际上限由配置控制。传入后结果按请求顺序返回，未命中的 UUID 也会返回一条只包含 UUID 的占位记录。 |
| `fields` | `list<string>` | 可选 | 需要返回的排期字段；为空时返回全部合法字段。 参考： fields 支持的字段列表 |
| `page_num` | `int64` | 可选 | 页码，从 1 开始；仅 UUIDs 为空时生效。默认 1，小于等于 0 时按 1 处理。 |
| `page_size` | `int64` | 可选 | 每页行数；仅 UUIDs 为空时生效。默认 100、最大 100，实际值由配置控制；超过上限返回参数错误，不自动截断。 |

## 返回数据与错误信封

| 字段 | 类型 | 必须 | 说明 |
| --- | --- | --- | --- |
| `baseline` | `object` | — | 本次查询对应的基线基本信息。基线不存在、不属于目标工作项或未创建完成时，接口返回错误，不返回该对象。 |
| `baseline.name` | `string` | — | 基线名称 |
| `baseline.created_at` | `int64` | — | 基线创建时间，毫秒级 Unix 时间戳。列表按该字段倒序排列；时间相同时按 baseline_id 倒序排列。 |
| `baseline.created_by` | `string` | — | 基线创建人的用户标识 |
| `baseline.baseline_id` | `string` | — | 基线 ID |
| `baseline.description` | `string` | — | 基线描述。创建时未填写描述时返回空字符串。 |
| `rows` | `list<object>` | — | 当前页或指定 UUID 的基线行数据。没有数据时返回空数组，不返回 null。 |
| `rows.name` | `string` | — | 创建基线时保存的行名称。未命中 UUID 的占位行不返回。 |
| `rows.type` | `string` | — | 行类型。 node 表示节点， sub_instance 表示子工作项， sub_task 表示子任务。 |
| `rows.uuid` | `string` | — | WBS 行唯一标识。如果请求的 UUID 未命中，该行只返回 uuid，其余字段不返回。 |
| `rows.owners` | `list<string>` | — | 创建基线时保存的负责人列表。元素为 UserKey；没有负责人时返回空数组。 |
| `rows.points` | `double` | — | 创建基线时的估分。fields 未选择或快照无值时不返回。 |
| `rows.work_item_id` | `int64` | — | 该行实际所属的工作项 ID。子工作项、子任务返回自己的归属工作项。 |
| `rows.estimate_duration` | `double` | — | 创建基线时的计划工期，统一按天返回，允许小数。fields 未选择或快照无值时不返回。 |
| `rows.estimate_end_date` | `int64` | — | 创建基线时的计划完成时间，毫秒级 Unix 时间戳。fields 未选择或快照无值时不返回。 |
| `rows.estimate_start_date` | `int64` | — | 创建基线时的计划开始时间，毫秒级 Unix 时间戳。fields 未选择或快照无值时不返回。 |
| `pagination` | `object` | — | 分页信息。传入 uuids 时固定返回一页，page_num 为 1，page_size 和 total 为请求 UUID 数量。 |
| `pagination.total` | `int64` | — | 符合查询条件的行总数。传 uuids 时等于 uuids 数量，未命中的占位行也计入。 |
| `pagination.page_num` | `int64` | — | 当前页码。未传 uuids 时从 1 开始；传入 uuids 时固定返回 1。 |
| `pagination.page_size` | `int64` | — | 本次请求使用的每页行数。未传 uuids 时返回实际页大小且不超过配置上限；传入 uuids 时等于本次 UUID 数量。 |
| `err` | `object` | — | 对部分错误会在这里进行更详细的错误描述，可协助日志记录和问题反馈。 |
| `err.code` | `int32` | — | 部分场景下，透出更详细错误对应的错误码。 |
| `err.msg` | `string` | — | 部分场景下，透出更详细的错误描述。 |
| `err.log_id` | `string` | — | 报错场景下的调用链标识符，用于追踪错误发生时的完整调用链路，便于日志记录和问题排查。 |
| `err_msg` | `string` | — | 错误信息。 |
| `err_code` | `int32` | — | 错误码。 |

## 错误处理

- `20005` 必填参数缺失，例如 project_key 为空、work_item_id 未传、baseline_id 为空。请检查路径参数和请求体是否完整。
- `20006` 请求参数不合法，例如 work_item_id 小于等于 0、page_num/page_size 非法、uuids 数量超过上限、baseline_id 非法或与 work_item_id 不匹配。请按接口参数说明修正后重试。
- `10001` 当前调用人没有目标工作项读取权限。请确认用户能在页面上访问该工作项，且插件使用的是正确的用户访问凭证。
- `10002` 目标工作项类型未开启基线能力。请在空间配置中确认该工作项类型是否支持并已启用基线。
- `30005` 工作项未找到。可能是工作项已删除、work_item_id 不正确，或工作项不属于当前 project_key。
- `50006` 服务端或下游依赖异常，例如查询基线元信息、基线行总数、分页数据或快照模型转换失败。请稍后重试；持续失败时联系技术支持并提供 request_id。

按接口响应检查 `err_code`，排障时保留 `err.log_id` 或 `request_id`。示例用于本地结构校验，租户权限与运行时行为待验证。
