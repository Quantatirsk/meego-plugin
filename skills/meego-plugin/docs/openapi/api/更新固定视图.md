# 更新固定视图

<!-- capability-metadata:start -->
## 平台能力标记

<a id="capability-openapi.post.open-api-project-key-work-item-type-key-fix-view-view-id"></a>
- **更新固定视图** ｜ `openapi.post.open-api-project-key-work-item-type-key-fix-view-view-id` ｜ 频次：低 ｜ 状态：待运行时验证

<!-- capability-metadata:end -->

向固定视图添加工作项，或从中移除工作项。每次请求只能选择一种操作，单次最多处理 200 个 ID；操作只改变视图成员列表。

## 使用前确认

`add_work_item_ids` 与 `remove_work_item_ids` 必须二选一且非空，不能同一次同时增删。调用身份需要视图操作权限。对相同工作项重复添加或移除，原文明确返回成功；这条规则不适用于无效的工作项 ID 或不存在的视图。

对应的平台功能介绍详见[固定视图](https://project.feishu.cn/1ykiuvvj/4w2iz8d8#%E5%9B%BA%E5%AE%9A%E8%A7%86%E5%9B%BE)。对应的权限申请在**权限管理-视图&度量**分类下，相关功能介绍详见[权限管理](../guides/权限管理.md)。

<a id="请求说明"></a>

## 请求说明

- 请求方式：POST

- 请求地址：/open_api/:project_key/:work_item_type_key/fix_view/:view_id

<a id="请求参数"></a>

## 请求参数

<a id="header"></a>

### Header

接口调用的 Header 配置详见 [Header](../guides/OpenAPI概述.md#a8e43b86)。

<a id="Path"></a>

### Path

| 参数 | 类型 | 是否必须 | 说明 |
| --- | --- | --- | --- |
| `project_key` | string | 必须 | [说明](#parameter-note-1) |
| `work_item_type_key` | string | 必须 | 工作项类型，通过[获取空间下工作项类型](获取空间下工作项类型.md)接口获取。 |
| `view_id` | string | 必须 | 视图 ID。可以通过接口[获取某工作项的视图列表及配置信息](获取视图列表及配置信息.md)接口获取视图 ID。 |

<a id="parameter-note-1"></a>

**project_key：说明**

空间 ID（project_key），或者空间域名（simple_name）。
- 空间 ID（project_key），在飞书项目空间双击空间名称获取。
- 空间域名（simple_name），`simple_name` 一般在飞书项目空间 URL 中获取。例如空间 URL 为 “https://project.feishu.cn/doc/overview”，则 `simple_name`为 “doc”。

<a id="Body"></a>

### Body

| 参数 | 类型 | 是否必须 | 说明 |
| --- | --- | --- | --- |
| `add_work_item_ids` | `list<int64>` | 可选 | [说明](#parameter-note-2) |
| `remove_work_item_ids` | `list<int64>` | 可选 | [说明](#parameter-note-3) |

<a id="parameter-note-2"></a>

**add_work_item_ids：说明**

待添加的工作项 ID 列表（操作数据上限200个）。
注意：`add_work_item_ids` 与 `remove_work_item_ids`不能同时为空，且不能同时传入。

<a id="parameter-note-3"></a>

**remove_work_item_ids：说明**

待移除的工作项 ID 列表（操作数据上限200个）。
注意：`add_work_item_ids` 与 `remove_work_item_ids`不能同时为空，且不能同时传入。

<a id="返回参数"></a>

## 返回参数

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `data` | object | 更新成功返回空值，请求失败不返回。 |
| `err` | object | 请求成功时返回空值，请求失败时返回实际错误信息。 |
| `err_msg` | string | 请求成功时返回空值，请求失败时返回实际错误信息。 |
| `err_code` | int32 | 请求成功时0，请求失败返回实际错误码。 |

### `err` 的字段

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `code` | int32 | 部分场景下，透出更详细错误对应的错误码。 |
| `msg` | string | 部分场景下，透出更详细的错误描述。 |
| `log_id` | string | 报错场景下的调用链标识符，用于追踪错误发生时的完整调用链路，便于日志记录和问题排查。 |

<a id="请求示例"></a>

## 请求示例

### 在固定视图中增加工作项

**请求路径：**`POST /open_api/68382b399de4b0ec6c5xxxx/story/fix_view/z9matxxxx`

```text
{
    "add_work_item_ids": [612542xxxx]
}
```

### 在固定视图中删除工作项

**请求路径：**`POST /open_api/68382b399de4b0ec6c5xxxx/story/fix_view/z9matxxxx`

```text
{
    "remove_work_item_ids": [61254xxxx]
}
```

<a id="返回示例"></a>

## 返回示例

### 正确返回示例

```json
{
  "err": {},
  "err_code": 0,
  "err_msg": "",
  "data": {}
}
```

### 错误返回示例

以下错误原因为传入的 `remove_work_item_ids` 或 `add_work_item_ids` 错误，需要更正后重试。

```json
{
  "err_code": 30005,
  "err_msg": "WorkItem Not Found",
  "err": {
    "code": 30005,
    "msg": "WorkItem Not Found, please refer to https://project.feishu.cn/b/helpcenter/1p8d7djs/5aueo3jr",
    "log_id": "2025102614191686528B0A6C3A45CFxxxx"
  }
}
```

### 重复添加、删除工作项

在固定视图中重复添加或者删除工作项，不会报错，会返回以下信息。

```json
{
  "err": {},
  "err_code": 0,
  "err_msg": "",
  "data": {}
}
```
