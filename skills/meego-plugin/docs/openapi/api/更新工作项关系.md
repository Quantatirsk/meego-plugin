# 更新工作项关系

<!-- capability-metadata:start -->
## 平台能力标记

<a id="capability-openapi.post.open-api-work-item-relation-update"></a>
- **更新工作项关系** ｜ `openapi.post.open-api-work-item-relation-update` ｜ 频次：低 ｜ 状态：待运行时验证

<!-- capability-metadata:end -->

按 `relation_id` 覆盖更新工作项关系配置，包括关系名称、来源工作项类型和完整的目标关系列表。调用前应读取现有配置，再组成希望保留的最终内容。

## 使用前确认

**这是覆盖更新接口。** `relation_details` 应包含更新后完整的目标列表；仅发送新增目标不能当作追加操作。

调用身份需要管理员权限；同空间目标仍必须填写 `project_key`。关系名称不可用或重复时返回 `50006`。

对应的平台功能介绍详见[关系管理](https://project.feishu.cn/1ykiuvvj/se3xal6e)。对应的权限申请在**权限管理-工作项实例**分类下，相关功能介绍详见[权限管理](../guides/权限管理.md)。

<a id="注意事项"></a>

## 注意事项

先通过[获取工作项关系列表](获取工作项关系列表.md)取得关系 ID 和当前配置。保留需要继续使用的关系明细，再提交完整请求。

<a id="请求说明"></a>

## 请求说明

- 请求方式：POST

- 请求地址：/open_api/work_item/relation/update

<a id="请求参数"></a>

## 请求参数

<a id="header"></a>

### Header

接口调用的 Header 配置详见 [Header](../guides/OpenAPI概述.md#a8e43b86)。

<a id="Body"></a>

### Body

| 参数 | 类型 | 是否必须 | 说明 |
| --- | --- | --- | --- |
| `project_key` | string | 必须 | [说明](#parameter-note-1) |
| `work_item_type_key` | string | 必须 | 工作项类型，可以从[获取空间下工作项类型](获取空间下工作项类型.md)接口获取。 |
| `name` | string | 必须 | 关系名称。 |
| `relation_id` | string | 必须 | 工作项关系 ID，可通过[获取工作项关系列表](获取工作项关系列表.md)获得。 |
| `relation_details` | `list<object>` | 必须 | 工作项关系详情列表，`project_key` 和 `work_item_type_key` 必填。 |

<a id="parameter-note-1"></a>

**project_key：说明**

空间 ID（project_key），或者空间域名（simple_name）。
- 空间 ID（project_key），在飞书项目空间双击空间名称获取。
- 空间域名（simple_name），飞书项目空间 URL 中的空间标识，一般在在创建空间时自定义。例如 URL 为`https://project.feishu.cn/simple_name` ，则 simple_name 为 `simple_name`。

#### `relation_details` 的字段

| 参数 | 类型 | 是否必须 | 说明 |
| --- | --- | --- | --- |
| `project_key` | string | 必须 | 关联空间的空间 ID。如果是同空间关联，仍需要填写该空间的 `project_key`。 |
| `project_name` | string | 可选 | 关联空间名称。 |
| `work_item_type_key` | string | 必须 | 关联工作项类型 key。 |
| `work_item_type_name` | string | 可选 | 关联工作项类型名称。 |

<a id="返回参数"></a>

## 返回参数

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `err` | object | 请求成功时返回空值，请求失败时返回实际错误信息。 |
| `err_msg` | string | 请求成功时返回空值，请求失败时返回实际错误信息。 |
| `err_code` | int32 | 请求成功时0，请求失败返回实际错误码。 |

### `err` 的字段

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `code` | int32 | 部分场景下，透出更详细错误对应的错误码。 |
| `msg` | string | 部分场景下，透出更详细的错误描述。 |
| `log_id` | string | 报错场景下的调用链标识符，用于追踪错误发生时的完整调用链路，便于日志记录和问题排查。 |
