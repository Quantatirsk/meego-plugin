# 创建计划表草稿

<!-- capability-metadata:start -->
## 平台能力标记

<a id="capability-openapi.post.open-api-work-item-wbs-draft-create"></a>
- **创建计划表草稿** ｜ `openapi.post.open-api-work-item-wbs-draft-create` ｜ 频次：低 ｜ 状态：待运行时验证

<!-- capability-metadata:end -->

为一个工作项创建计划表草稿。创建是异步操作：先取得草稿 ID，再确认草稿已就绪，之后才能修改草稿内容。插件权限位于“权限管理 → 工作项”，见[权限管理](../guides/权限管理.md)。

## 创建后的处理顺序

1. 提交空间 ID、工作项类型 key 和工作项 ID。
2. 从成功响应的 `data.draft_meta.draft_id` 保存草稿 ID。
3. 使用[创建计划表草稿进度查询](创建计划表草稿进度查询.md)查询同一草稿，直到 `draft_status = 2`。
4. 草稿可用后，读取[草稿骨架](查询全量计划表草稿骨架.md)或[更新计划表草稿](更新计划表草稿.md)。

| `draft_status` | 含义 | 是否可以使用草稿 |
| --- | --- | --- |
| `0` | 未知状态 | 不能据此判定可用 |
| `1` | 创建中 | 否 |
| `2` | 创建完成 | 是 |

<a id="请求说明"></a>

## 请求说明

**请求方式**：`POST`
**请求地址**：`/open_api/work_item/wbs_draft/create`

<a id="请求参数"></a>

## 请求参数

<a id="a3c53a27"></a>

### 请求头

接口调用的 Header 配置详见[Header](../guides/OpenAPI概述.md#a8e43b86)

<a id="Body"></a>

### 请求体

| 参数 | 类型 | 是否必须 | 说明 |
| --- | --- | --- | --- |
| project_key | string | 必须 | 空间 ID（project_key）。<br>- 空间 ID（project_key），在飞书项目空间双击空间名称获取。 |
| work_item_type_key | string | 必须 | 工作项类型列表，可通过[获取空间下工作项类型](获取空间下工作项类型.md)获取。 |
| work_item_id | int64 | 必须 | 工作项实例ID |

<a id="返回参数"></a>

## 返回参数

业务响应位于 `data.draft_meta`，创建完成条件为 `draft_status = 2`。

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| data.draft_meta | object | 草稿元信息 |
| data.draft_meta.draft_id | string | 草稿 ID |
| data.draft_meta.draft_status | int32 | 创建进度：`0` 未知；`1` 创建中、不可用；`2` 创建完成、可用 |
| err | object | 对部分错误会在这里进行更详细的错误描述，可协助日志记录和问题反馈。 |
| err.code | int32 | 部分场景下，透出更详细错误对应的错误码。 |
| err.msg | string | 部分场景下，透出更详细的错误描述。 |
| err.log_id | string | 报错场景下的调用链标识符，用于追踪错误发生时的完整调用链路，便于日志记录和问题排查。 |
| err_msg | string | 错误信息。 |
| err_code | int32 | 错误码。 |
