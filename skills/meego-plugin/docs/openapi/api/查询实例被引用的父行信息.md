# 查询实例被引用的父行信息

<!-- capability-metadata:start -->
## 平台能力标记

- **查询实例被引用的父行信息** ｜ `openapi.post.open-api-work-item-wbs-ref-source-list` ｜ 频次：低 ｜ 状态：待运行时验证 ｜ 示例：[`openapi.post.open-api-work-item-wbs-ref-source-list.fixture`](<../../../fixtures/openapi/list-bd8ibynh.json>)

<!-- capability-metadata:end -->

从源工作项反查引用它的计划表，支持跨空间。用 `ref_project_key` 和 `ref_root_work_item_id` 定位引用方计划表，用 `parent_uuid` 和 `parent_work_item_id` 定位挂载位置。`reference_head_uuid` 标识片段首行，`is_reference_head` 指示当前源实例是否处于首行。

## 请求

`POST /open_api/work_item/wbs_ref/source/list`

请求头按 [Open API 概述](../guides/OpenAPI概述.md) 和 [权限管理](../guides/权限管理.md) 选择调用身份。

## 请求体

| 字段 | 类型 | 必须 | 说明 |
| --- | --- | --- | --- |
| `project_key` | `string` | 必须 | 空间 ID（project_key）。 空间 ID（project_key），在飞书项目空间双击空间名称获取。 |
| `work_item_id` | `int64` | 必须 | 工作项实例ID |
