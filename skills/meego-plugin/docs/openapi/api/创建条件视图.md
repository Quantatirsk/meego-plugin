# 创建条件视图

<!-- capability-metadata:start -->
## 平台能力标记

<a id="capability-openapi.post.open-api-view-v1-create-condition-view"></a>
- **创建条件视图** ｜ `openapi.post.open-api-view-v1-create-condition-view` ｜ 频次：低 ｜ 状态：待运行时验证

<!-- capability-metadata:end -->

创建由筛选表达式决定成员的条件视图。请求提交空间 ID、工作项类型、视图名称和 `search_group`，可额外指定协作人员或团队；成功返回 `data.view_id`。

## 使用前确认

- `project_key` 只接受空间 ID，不支持空间域名。
- 条件组通过 `AND`、`OR` 组合，具体字段值和操作符需要匹配字段类型。
- 日期和日期时间使用带时区的标准时间表达式，例如 `2024-09-01T00:00:00+07:00`；平台按天处理，不支持时分秒级筛选。
- 复合父字段使用 `MEET` 或 `NOT MEET` 时，子字段条件放入 `value_search_groups`；内部不支持再设置 `pre_operator`。
- 省略协作模式时默认 `1`，即指定人员或团队。

对应的平台功能介绍详见[条件视图](https://project.feishu.cn/1ykiuvvj/4w2iz8d8#%E6%9D%A1%E4%BB%B6%E8%A7%86%E5%9B%BE)。对应的权限申请在 权限管理-视图 分类下，相关功能介绍详见 [权限管理](../guides/权限管理.md)。

## 请求参数

<a id="header"></a>

### Header

接口调用的 Header 配置详见 [Header](../guides/OpenAPI概述.md#a8e43b86)。

<a id="Body"></a>

### Body

| 参数 | 类型 | 是否必须 | 说明 |
| --- | --- | --- | --- |
| `project_key` | string | 必须 | 空间 ID（project_key），在飞书项目空间双击空间名称获取。<br>注意：不支持空间域名 |
| `work_item_type_key` | string | 必须 | 工作项类型，系统自动生成，可通过[获取空间下工作项类型](获取空间下工作项类型.md)接口获取 |
| `name` | string | 必须 | 视图名称 |
| `search_group` | object | 必须 | [说明](#parameter-note-1) |
| `cooperation_mode` | int64 | 可选 | [说明](#parameter-note-2) |
| `cooperation_user_keys` | `list<string>` | 可选 | 指定人员 user_key，cooperation_mode 为1时适用 |
| `cooperation_team_ids` | `list<int64>` | 可选 | 指定团队 team_id，cooperation_mode为 1 时适用 |

<a id="parameter-note-1"></a>

**search_group：说明**

筛选条件，用于组合条件搜索时使用。遵循[SearchGroup](../formats/数据结构汇总.md#a889b622)结构规范，可参考[条件视图格式及常用示例](条件视图格式及常用示例.md)。
特殊说明：
`日期`、`日期+时间`类型的字段进行筛选时，时间表达需为包含时区偏移的标准格式（2024-09-01T00:00:00+07:00）。
这类字段通过 OpenAPI 处理，暂不支持时分秒级筛选，所填参数会统一处理为天级计算。

<a id="parameter-note-2"></a>

**cooperation_mode：说明**

协作模式，用于指定视图的协作范围。支持的取值如下所示。
- `1`：指定人员或团队；
- `2`：全部空间管理员；
- `3`：全部空间成员。
默认值为 `1`（指定人员或团队）。

#### `search_group` 的字段

| 参数 | 类型 | 是否必须 | 说明 |
| --- | --- | --- | --- |
| `conjunction` | string | 必须 | 用于指定筛选条件之间的逻辑关系。支持的取值如下所示。<br>- `AND`：所有条件必须同时满足；<br>- `OR`：任一条件满足即可。 |
| `search_groups` | `list<object>` | 可选 | 筛选组，遵循[SearchGroup](../formats/数据结构汇总.md#a889b622)结构规范 |
| `search_params` | `list<object>` | 必须 | 固定参数，遵循[SearchParam](../formats/数据结构汇总.md#e2caf2db)结构规范 |

#### `search_group.search_params` 的字段

| 参数 | 类型 | 是否必须 | 说明 |
| --- | --- | --- | --- |
| `value` | file | 必须 | [说明](#parameter-note-3) |
| `operator` | string | 必须 | [说明](#parameter-note-4) |
| `param_key` | string | 必须 | 字段 key，可通过[获取字段信息](获取字段信息.md)接口查询。 |
| `pre_operator` | string | 可选 | 前置操作符，用于指定复合字段搜索时的逻辑关系。支持的取值如下所示。<br>- `ANY`：存在一组满足条件即可；<br>- `EVERY`：每一组都必须满足条件。 |
| `value_search_groups` | object | 可选 | [说明](#parameter-note-5) |

<a id="parameter-note-3"></a>

**value：说明**

搜索字段值结构
- 搜索可参考[搜索参数格式及常用示例](../formats/搜索参数格式及常用示例.md)
- 条件视图可参考[条件视图格式及常用示例](条件视图格式及常用示例.md)。

<a id="parameter-note-4"></a>

**operator：说明**

用于指定搜索条件的操作符类型，支持的取值如下所示。
- `Reg = "~" //匹配`
- `NReg = "!~" //不匹配`
- `Eq = "=" //等于`
- `Ne = "!=" //不等于`
- `Lt = "<" //小于`
- `Gt = ">" //大于`
- `Lte = "<=" //小于等于`
- `Gte = ">=" //大于等于`
- `HasAnyOf = "HAS ANY OF" //存在选项属于`
- `HasNoneOf = "HAS NONE OF" //全部选项均不属于`
- `IsNull = "IS NULL" //为空`
- `NotNull = "IS NOT NULL" //不为空`
- `Contains = "CONTAINS" //包含`
- `NotContains = "NOT CONTAINS" //不包含`
- `Meet = "MEET" //满足`
- `NotMeet = "NOT MEET" //不满足`

<a id="parameter-note-5"></a>

**value_search_groups：说明**

参见[SearchGroup](../formats/数据结构汇总.md#a889b622)结构规范。
**出现条件**：`param_key` 为复合字段的「父字段」且 operator 为「满足/不满足」。
**内容**：`value_search_groups` 中包含「复合字段子字段」的 `param_key`、`value`、`operator`；其中 `value`、`operator` 跟随「复合字段子字段」`param_key`。
**注意**：`value_search_groups` 内部目前不支持 `pre_operator`。

## 请求示例

### 创建指定条件视图

```json
{
  "project_key": "68d2526a6705dxxxxxxxxxx",
  "work_item_type_key": "story",
  "search_group": {
    "conjunction": "AND",
    "search_params": [
      {
        "param_key": "work_item_status",
        "value": [
          "start"
        ],
        "operator": "="
      }
    ]
  },
  "cooperation_mode": 1,
  "cooperation_user_keys": [
    "123352"
  ],
  "cooperation_team_ids": [
    123
  ],
  "name": "test"
}
```
