# 获取空间下工作项类型

<!-- capability-metadata:start -->
## 平台能力标记

<a id="capability-openapi.get.open-api-project-key-work-item-all-types"></a>
- **获取空间下工作项类型** ｜ `openapi.get.open-api-project-key-work-item-all-types` ｜ 频次：低 ｜ 状态：待运行时验证

<!-- capability-metadata:end -->

读取空间中的工作项类型，取得名称、类型 key、对接标识及启用状态，供后续接口选择 `work_item_type_key` 使用。

## 类型标识与可用状态

| 字段 | 含义 | 使用时的区别 |
| --- | --- | --- |
| `name` | 显示名称 | 用于展示，不当作接口类型 key |
| `type_key` | 工作项类型唯一 key | 标识工作项类型 |
| `api_name` | 类型对接标识 | 与 `type_key` 分开保存，不能由样例同值推定永远相等 |
| `is_disable` | `1` 已禁用，`2` 未禁用 | 数值枚举，不是布尔值 |
| `enable_model_resource_lib` | 资源库是否开启并可用 | 与类型禁用状态是不同能力维度 |

原简介称该接口用于获取后续接口参数，但未逐项说明所有接口对 `api_name` 与 `type_key` 的接受范围；调用具体接口时仍应以该接口参数定义为准。申请权限见[权限管理](../guides/权限管理.md)中的“配置”。

<a id="请求说明"></a>

## 请求说明

**请求方式**：`GET`
**请求地址**：`/open_api/:project_key/work_item/all-types`

<a id="请求参数"></a>

## 请求参数

<a id="header"></a>

### 请求头

接口调用的请求头见[OpenAPI 概述](../guides/OpenAPI概述.md#a8e43b86)。当前调用用户不存在时会返回 `10023`，需检查用户身份请求头。

<a id="Path"></a>

### 路径参数

| 参数 | 类型 | 是否必须 | 说明 |
| --- | --- | --- | --- |
| project_key | string | 必须 | [填写说明](#parameter-notes-1) |

<a id="parameter-notes-1"></a>

**project_key 的填写说明**

空间 ID（project_key），或者空间域名（simple_name）。

- 空间 ID（project_key），在飞书项目空间双击空间名称获取。

- 空间域名（simple_name），`simple_name` 一般在飞书项目空间 URL 中获取。例如空间 URL 为 “https://project.feishu.cn/doc/overview”，则 `simple_name`为 “doc”。

<a id="返回参数"></a>

## 返回参数

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `data` | `list<object>` | 返回结果，遵循[WorkItemKeyType](../formats/数据结构汇总.md#c1f7a1d1)结构规范 |
| `err` | object | 请求成功时返回空值，请求失败时返回实际错误信息。 |
| `err_msg` | string | 请求成功时返回空值，请求失败时返回实际错误信息。 |
| `err_code` | int32 | 请求成功时0，请求失败返回实际错误码。 |

### `data`

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `name` | string | 工作项类型名称 |
| `api_name` | string | 工作项类型对接标识 |
| `type_key` | string | 工作项类型唯一key |
| `is_disable` | int32 | 标识工作项类型是否被禁用。支持的取值如下所示。<br>- `1`：已禁用；<br>- `2`：未禁用。 |
| `enable_model_resource_lib` | boolean | 资源库是否开启并可用 |

### `err`

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `code` | int32 | 部分场景下，透出更详细错误对应的错误码。 |
| `msg` | string | 部分场景下，透出更详细的错误描述。 |
| `log_id` | string | 报错场景下的调用链标识符，用于追踪错误发生时的完整调用链路，便于日志记录和问题排查。 |
