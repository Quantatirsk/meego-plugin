# 删除流程模板

<!-- capability-metadata:start -->
## 平台能力标记

<a id="capability-openapi.delete.open-api-template-v2-delete-template-project-key-template-id"></a>
- **删除流程模板** ｜ `openapi.delete.open-api-template-v2-delete-template-project-key-template-id` ｜ 频次：低 ｜ 状态：待运行时验证

<!-- capability-metadata:end -->

删除由路径中的空间 ID 和模板 ID 指定的流程模板。模板 ID 可先从工作项类型的流程模板列表取得；返回 `err_code=0` 表示操作成功。

## 使用前确认

请求定义只列出 Path 参数，两个 ID 应放入 URL。模板 ID 格式不正确时，原示例返回 `9999` 和 `key template_id value invalid`。

对应的平台功能介绍详见[节点流程规则配置](https://project.feishu.cn/1ykiuvvj/3bv61iew)或[状态流程配置](https://project.feishu.cn/1ykiuvvj/2lgf2cd8)，对应的权限申请在**权限管理-配置**分类下，相关功能介绍详见 [权限管理](../guides/权限管理.md)。

<a id="请求说明"></a>

## 请求说明

- 请求方式：DELETE

- 请求地址：/open_api/template/v2/delete_template/:project_key/:template_id

<a id="请求参数"></a>

## 请求参数

<a id="header"></a>

### Header

接口调用的 Header 配置详见 [Header](../guides/OpenAPI概述.md#a8e43b86)。

<a id="Path"></a>

### Path

| 参数 | 类型 | 是否必须 | 说明 |
| --- | --- | --- | --- |
| `project_key` | string | 必须 | 空间 ID（project_key），在飞书项目空间双击空间名称获取。 |
| `template_id` | string | 必须 | 模板 ID，可通过[获取工作项下的流程模板列表](获取工作项下的流程模板列表.md)接口获取。 |

<a id="返回参数"></a>

## 返回参数

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `err` | object | 请求成功时返回空值，请求失败时返回实际错误信息。 |
| `err_msg` | string | 请求成功时返回空值，请求失败时返回实际错误信息。 |
| `err_code` | int32 | 请求成功时返回0，请求失败返回实际错误码。 |

### `err` 的字段

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `code` | int32 | 部分场景下，透出更详细错误对应的错误码。 |
| `msg` | string | 部分场景下，透出更详细的错误描述。 |
| `log_id` | string | 报错场景下的调用链标识符，用于追踪错误发生时的完整调用链路，便于日志记录和问题排查。 |
