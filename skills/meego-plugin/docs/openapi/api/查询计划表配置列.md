# 查询计划表配置列

<!-- capability-metadata:start -->
## 平台能力标记

- **查询计划表配置列** ｜ `openapi.post.open-api-work-item-wbs-view-column-config-query` ｜ 频次：低 ｜ 状态：待运行时验证 ｜ 示例：[`openapi.post.open-api-work-item-wbs-view-column-config-query.fixture`](<../../../fixtures/openapi/query-0tfjtyns.json>)

<!-- capability-metadata:end -->

读取计划表控件配置的预置列和自定义聚合列。`column_type` 缺省时返回全部。自定义列的 `columns[].key` 是聚合字段 key，构造行详情掩码时使用这个 key。

## 请求

`POST /open_api/work_item/wbs_view/column_config/query`

请求头按 [Open API 概述](../guides/OpenAPI概述.md) 和 [权限管理](../guides/权限管理.md) 选择调用身份。

## 请求体

| 字段 | 类型 | 必须 | 说明 |
| --- | --- | --- | --- |
| `project_key` | `string` | 必须 | 空间 ID（project_key）。 空间 ID（project_key），在飞书项目空间双击空间名称获取。 |
| `work_item_type_key` | `string` | 必须 | 工作项类型key |
| `work_item_id` | `int64` | 可选 | 工作项实例id |
| `column_type` | `string` | 可选 | 要查询的列类型 preset ：只返回预置列； custom ：只返回自定义列； 不传返回全部列 |

## 返回数据与错误信封

## 错误处理

- `20006` 参数错误
- `20005` 缺少用户标识 user_key

按接口响应检查 `err_code`，排障时保留 `err.log_id` 或 `request_id`。示例用于本地结构校验，租户权限与运行时行为待验证。
