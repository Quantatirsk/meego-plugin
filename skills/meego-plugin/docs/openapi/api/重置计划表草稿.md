# 重置计划表草稿

<!-- capability-metadata:start -->
## 平台能力标记

<a id="capability-openapi.post.open-api-work-item-wbs-draft-reset"></a>
- **重置计划表草稿** ｜ `openapi.post.open-api-work-item-wbs-draft-reset` ｜ 频次：低 ｜ 状态：待运行时验证

<!-- capability-metadata:end -->

对已有计划表草稿执行全量或部分重置。响应返回新的草稿 ID 与实际重置范围；应配合[重置计划表草稿进度查询](重置计划表草稿进度查询.md)确认任务状态。

## 选择重置范围

| `uuids` | 重置方式 |
| --- | --- |
| 省略或空数组 | 全量重置 |
| 非空数组 | 按选中的子树部分重置 |

部分重置以子树为单位，不应只把请求中的 UUID 当成最终影响范围。响应 `reset_uuids` 是实际触发重置的行，`uuids_not_reset` 是指定但未进入范围的行。

保存 `data.new_draft_id` 作为重置后草稿标识；推荐查询间隔由 `recommend_interval_ms` 给出，单位毫秒。进度接口的参数名仍是 `draft_id`，原文没有明确说明重置过程中旧 ID 与新 ID 的适用阶段，不能据此推定旧 ID 始终有效。

申请权限见[权限管理](../guides/权限管理.md)中的“工作项”。

## 请求说明

**请求方式**：`POST`
**请求地址**：`/open_api/work_item/wbs_draft/reset`

<a id="请求参数"></a>

## 请求参数

<a id="a3c53a27"></a>

### 请求头

接口调用的 Header 配置详见[Header](../guides/OpenAPI概述.md#a8e43b86)

<a id="Body"></a>

### 请求体

| 参数 | 类型 | 是否必须 | 说明 |
| --- | --- | --- | --- |
| project_key | string | 必须 | 空间 ID（project_key）。<br>- 空间 ID（project_key），在飞书项目空间双击空间名称获取。 |
| work_item_id | int64 | 必须 | 工作项id |
| draft_id | string | 必须 | 草稿id |
| uuids | `list<string>` | 可选 | 部分重置行uuid列表：不传或空数组表示全量重置；非空表示按选中子树部分重置 |

<a id="返回参数"></a>

## 返回参数

下列业务字段在成功示例中位于 `data` 下。请求成功并不代表异步重置已经完成。

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `new_draft_id` | string | 重置后的新草稿id |
| `recommend_interval_ms` | int64 | 推荐的轮询间隔，单位毫秒 |
| `reset_uuids` | `list<string>` | 本次实际触发重置的行uuid列表 |
| `uuids_not_reset` | `list<string>` | 指定但未进入重置范围的行uuid列表 |
| `err` | object | 对部分错误会在这里进行更详细的错误描述，可协助日志记录和问题反馈。 |
| `err_msg` | string | 错误信息。 |
| `err_code` | int32 | 错误码。 |

### `err`

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `code` | int32 | 部分场景下，透出更详细错误对应的错误码。 |
| `msg` | string | 部分场景下，透出更详细的错误描述。 |
| `log_id` | string | 报错场景下的调用链标识符，用于追踪错误发生时的完整调用链路，便于日志记录和问题排查。 |
