# 获取工作项详情

<!-- capability-metadata:start -->
## 平台能力标记

<a id="capability-openapi.work-item.get"></a>
- **获取工作项详情** ｜ `openapi.work-item.get` ｜ 频次：高 ｜ 状态：已验证 ｜ 示例：[`openapi.work-item.get.fixture`](<../../../fixtures/openapi/work-item-get.json>)

<!-- capability-metadata:end -->

批量读取同一空间、同一工作项类型下的实例详情，一次最多 50 个 ID。适合已知实例 ID 后加载字段、富文本、工作流和关联数据；按条件查找 ID 时，先使用[工作项查询接口](获取指定的工作项列表（单空间）.md)。接口权限位于[权限管理](../guides/权限管理.md)的“工作项”分类，术语见[官方名词解释](https://project.feishu.cn/b/helpcenter/1p8d7djs/4bsmoql6#92679309)，常见问题见[工作项实例 FAQ](../support/OpenAPI调用咨询.md#3fc52507)。

## 控制返回内容

`fields` 省略时默认返回全部可返回字段；显式字段名为包含模式，`-` 前缀为排除模式，两种模式不能混用。字段未配置到新建页、也从未更改时，可能完全不出现在 `fields` 数组中，业务判空应覆盖字段缺失的情况。

## 鉴权与读取边界

本端点在已发布的 `x-auth-mode` 支持范围内。使用 `plugin_access_token` 或 `virtual_plugin_token` 并需要严格按用户可见性读取时，传入对应用户标识与 `x-auth-mode: 1`；`0` 或省略是兼容读取模式。`user_access_token` 始终按其绑定用户鉴权，添加该请求头不会改变这一行为。

`x-auth-mode` 是本端点的特例，不能复制到字段、配置、下载或写入接口。`X-User-Key` 也应按当前凭证类型和端点定义提供，不能因为示例中出现就视为所有 OpenAPI 的固定 Header。

| 需求              | `expand` 开关                                    | 说明                                    |
| ----------------- | ------------------------------------------------ | --------------------------------------- |
| 用户详情          | `need_user_detail`                               | 默认 `false`，原文限定状态流不返回      |
| 工作流            | `need_workflow`                                  | 请求定义仅支持节点流，状态流返回空结构  |
| 富文本与 Markdown | `need_multi_text`、`need_rich_text_mark_down`    | 分别控制富文本详情与 Markdown 表达      |
| 父级与关联信息    | `need_sub_task_parent`、`relation_fields_detail` | 分别返回子任务父级和工作项关联详情      |
| 节点子项关联      | `need_sub_workitem_detail`                       | 未传或 `false` 不返回                   |
| 复合字段组标识    | `need_group_uuid_for_compound`                   | 补充每组的 `group_uuid`，供按组更新使用 |

### 读取时注意的差异

节点完成表单不返回投票类字段。节点 `status` 的 `1`、`2`、`3` 分别表示未开始、进行中、已完成；`owner_usage_mode` 的 `1`、`2` 分别表示手动指定、与角色联动。

群组字段优先读取 `chat_group`。原文说明旧 `group_id` 历史上可能为数字字符串；`template_type` 和早期实例的 `sub_stage` 已弃用。下面按父对象拆表，保留所有对象、枚举及字段说明。

**project_key**

空间 ID（project_key），或者空间域名（simple_name）。

- 空间 ID（project_key），在飞书项目空间双击空间名称获取。
- 空间域名（simple_name），`simple_name` 一般在飞书项目空间 URL 中获取。例如空间 URL 为 “https://project.feishu.cn/doc/overview”，则 `simple_name`为 “doc”。

<a id="field-note-2"></a>

**fields**

工作项中的字段标识，非必填，默认返回全部。字段格式可查看[字段与属性解析格式](../formats/字段与属性解析格式.md)。支持两种模式，两种模式不可混用。

- 指定字段：仅返回`fields` 中列出的字段。例如 \["aborted","role_owners"\] 表示只返回 `aborted` 和 `role_owners` 字段。
- 排除字段：以 `-` 开头表示排除该字段。例如 \["-aborted","-role_owners"\] 表示返回除`aborted`和 `role_owners` 外的所有字段。

## 实现边界

一次请求最多传入 50 个同类型工作项 ID。显式 `fields` 使用包含模式，`-` 前缀使用排除模式，二者不能混用；富文本、工作流、关联信息等扩展数据必须显式开启相应 `expand` 项。失败时保留 `err.log_id` 用于平台排障，不能自行拼造平台错误对象或假设某个 HTTP 成功状态码。

完整的占位请求、严格读取样例及成功、失败结果见本地 fixture：[获取工作项详情](../../../fixtures/openapi/work-item-get.json)。

## 产品关系与补充字段

产品关系能力可用时，响应可包含 `parent_product`（所属产品）及 `contained_work_items`（该产品包含的工作项）。流程详情下 `workflow_infos.workflow_nodes[].checkers` 表示节点完成情况，状态流工作项可返回 `workflow_infos.state_flow_nodes`。
