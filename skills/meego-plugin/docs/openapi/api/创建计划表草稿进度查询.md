<a id="使用说明"></a>

## 使用说明

查询[创建计划表草稿](创建计划表草稿.md)发起的异步创建是否完成。请求携带创建时的空间、工作项与返回的 `draft_id`，本接口不使用更新事务 ID 或发布单 ID。

| `data.draft_status` | 创建状态 | 下一步 |
| --- | --- | --- |
| `0` | 未知 | 不能判为创建成功 |
| `1` | 创建中，草稿不可用 | 等待后继续查询 |
| `2` | 创建完成，草稿可用 | 可读取或更新草稿 |

`err_code = 0` 只表示本次查询成功，最终是否可用仍取决于 `draft_status`。原文没有给出本接口的推荐轮询间隔，不套用发布或重置接口的默认值。权限见[权限管理](../guides/权限管理.md)中的“工作项”。

## 请求说明

**请求方式**：`POST`
**请求地址**：`/open_api/work_item/wbs_draft_create/progress/query`

### 请求体

| 参数 | 类型 | 是否必须 | 说明 |

## 返回参数

创建状态位于 `data.draft_status`，与创建草稿响应使用相同的状态枚举。

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| data.draft_status | int32 | 创建进度：`0` 未知；`1` 创建中、不可用；`2` 创建完成、可用 |
| err | object | 对部分错误会在这里进行更详细的错误描述，可协助日志记录和问题反馈。 |
| err.code | int32 | 部分场景下，透出更详细错误对应的错误码。 |
| err.msg | string | 部分场景下，透出更详细的错误描述。 |
| err.log_id | string | 报错场景下的调用链标识符，用于追踪错误发生时的完整调用链路，便于日志记录和问题排查。 |
| err_msg | string | 错误信息。 |
| err_code | int32 | 错误码。 |
