# 获取视图下工作项列表（全景视图）

<!-- capability-metadata:start -->
## 平台能力标记

<a id="capability-openapi.post.open-api-project-key-view-view-id"></a>
- **获取视图下工作项列表（全景视图）** ｜ `openapi.post.open-api-project-key-view-view-id` ｜ 频次：低 ｜ 状态：待运行时验证

<!-- capability-metadata:end -->

分页获取全景视图中的工作项详情，可携带快捷筛选 ID。结果包含每条工作项的所属空间、类型、当前节点、状态和有值字段，适合跨空间视图读取。

## 使用前确认

单页最多 50 条，分页参数放在 POST 请求体，页码从 1 开始。`pattern=Node` 为节点模式，`State` 为状态模式；状态模式的 `current_nodes` 为空。`fields` 只返回有值字段，不能将字段缺席直接解释为字段配置不存在。

普通视图读取使用[非全景接口](获取视图下工作项列表（非全景视图）.md)，其单页上限和返回结构不同。

对应的平台功能介绍详见[全景视图](https://project.feishu.cn/1ykiuvvj/2itxzzn2)。对应的权限申请在 权限管理-视图 分类下，相关功能介绍详见 [权限管理](../guides/权限管理.md)。

<a id="请求说明"></a>

## 请求说明

- 请求方式：POST

- 请求地址：/open_api/:project_key/view/:view_id

<a id="请求参数"></a>

## 请求参数

<a id="header"></a>

### Header

接口调用的 Header 配置详见 [Header](../guides/OpenAPI概述.md#a8e43b86)。

<a id="Path"></a>

### Path

| 参数 | 类型 | 是否必须 | 说明 |
| --- | --- | --- | --- |
| `project_key` | string | 必须 | [说明](#parameter-note-1) |
| `view_id` | string | 必须 | 全景视图 ID，当前只支持通过浏览器 url 后缀获取。例如当前视图 URL 为 `https://project.feishu.cn/doc/multiProjectView/view_text`，则 `view_id` 为 “view_text”。 |

<a id="parameter-note-1"></a>

**project_key：说明**

空间 ID（project_key），或者空间域名（simple_name）。
- 空间 ID（project_key），在飞书项目空间双击空间名称获取。
- 空间域名（simple_name），`simple_name` 一般在飞书项目空间 URL 中获取。例如空间 URL 为 “https://project.feishu.cn/doc/overview”，则 `simple_name`为 “doc”。

<a id="Body"></a>

### Body

| 参数 | 类型 | 是否必须 | 说明 |
| --- | --- | --- | --- |
| `page_size` | int64 | 可选 | 每页数据，最大50 |
| `page_num` | int64 | 可选 | 分页页码，从1开始，默认为1 |
| `quick_filter_id` | string | 可选 | 快捷筛选的标识 ID，用于快速筛选视图列表中的数据。可通过[获取某工作项的视图列表及配置信息](获取视图列表及配置信息.md)接口获取。 |
