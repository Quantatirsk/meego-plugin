# 获取计划表基线列表

<!-- capability-metadata:start -->

- **获取计划表基线列表** ｜ `openapi.get.open-api-project-key-work-item-baseline-work-item-id-list` ｜ 频次：低 ｜ 状态：待运行时验证 ｜ 示例：[`openapi.get.open-api-project-key-work-item-baseline-work-item-id-list.fixture`](<../../../fixtures/openapi/list-w7ozv537.json>)

<!-- capability-metadata:end -->

读取指定工作项已创建完成的历史基线。结果按 `created_at` 倒序，同一时间按 `baseline_id` 倒序。无基线时返回空数组。使用返回的 `baseline_id` 查询[基线详情](获取基线详情.md)。

## 请求

`GET /open_api/:project_key/work_item_baseline/:work_item_id/list`

请求头按 [Open API 概述](../guides/OpenAPI概述.md) 和 [权限管理](../guides/权限管理.md) 选择调用身份。

## 路径参数

| 字段 | 类型 | 必须 | 说明 |
| --- | --- | --- | --- |
| `project_key` | `string` | 必须 | 空间 ID（project_key），或者空间域名（simple_name）。 空间 ID（project_key），在飞书项目空间双击空间名称获取。 空间域名（simple_name）， simple_name 一般在飞书项目空间 URL 中获取。例如空间 URL 为 “https://project.feishu.cn/doc/overview”，则 simple_name 为 “doc”。 |
| `work_item_id` | `string` | 必须 | 工作项实例 ID，在工作项实例详情右上角展开 ··· ，单击 ID 信息即可获取。 |

## 返回数据与错误信封

| 字段 | 类型 | 必须 | 说明 |
| --- | --- | --- | --- |
| `baselines` | `list<object>` | — | 基线数组。没有基线时返回空数组。 |
| `baselines.name` | `string` | — | 基线名称 |
| `baselines.created_at` | `int64` | — | 基线创建时间，毫秒级 Unix 时间戳。列表按该字段倒序排列；时间相同时按 baseline_id 倒序排列。 |
| `baselines.created_by` | `string` | — | 基线创建人的用户标识 |
| `baselines.baseline_id` | `string` | — | 基线 ID |
| `baselines.description` | `string` | — | 基线描述。创建时未填写描述时返回空字符串。 |
| `err` | `object` | — | 对部分错误会在这里进行更详细的错误描述，可协助日志记录和问题反馈。 |
| `err.code` | `int32` | — | 部分场景下，透出更详细错误对应的错误码。 |
| `err.msg` | `string` | — | 部分场景下，透出更详细的错误描述。 |
| `err.log_id` | `string` | — | 报错场景下的调用链标识符，用于追踪错误发生时的完整调用链路，便于日志记录和问题排查。 |
| `err_msg` | `string` | — | 错误信息。 |
| `err_code` | `int32` | — | 错误码。 |

## 错误处理

- `20005` 必填参数缺失，例如 project_key 为空、work_item_id 未传。请检查路径参数是否完整。
- `20006` 请求参数不合法，例如 work_item_id 小于等于 0。请确认工作项 ID 为有效数字。
- `10001` 当前调用人没有目标工作项读取权限。请确认用户能在页面上访问该工作项，且插件使用的是正确的用户访问凭证。
- `10002` 目标工作项类型未开启基线能力。请在空间配置中确认该工作项类型是否支持并已启用基线。
- `30005` 工作项未找到。可能是工作项已删除、work_item_id 不正确，或工作项不属于当前 project_key。
- `50006` 服务端或下游依赖异常，例如查询基线列表时数据库或 RPC 调用失败。请稍后重试；持续失败时联系技术支持并提供 request_id。

按接口响应检查 `err_code`，排障时保留 `err.log_id` 或 `request_id`。示例用于本地结构校验，租户权限与运行时行为待验证。
