# 获取指定的工作项列表（全量搜索）

<!-- capability-metadata:start -->
## 平台能力标记

<a id="capability-openapi.post.open-api-view-search-universal-search"></a>
- **获取指定的工作项列表（全量搜索）** ｜ `openapi.post.open-api-view-search-universal-search` ｜ 频次：低 ｜ 状态：待运行时验证

<!-- capability-metadata:end -->

在指定空间、指定工作项类型下按筛选条件连续查询数据，使用 `search_after` 游标分页，并按需选择返回字段。接口权限位于[权限管理](../guides/权限管理.md)的“工作项”分类。

## 连续读取流程

1. 提供 `project_key`、`work_item_type_key` 和 `search_group`，首次请求可省略 `pagination.search_after`。
2. 每次从响应读取 `pagination.search_after`，原样传给下一次请求；保持筛选条件一致，不用 `page_num` 替代游标。
3. 数据按工作项 ID 排序，`page_size` 默认和最大值均为 `200`。本篇未定义明确的结束标识，接入时需根据实际响应确认结束条件，不能假定存在 `has_more`。

`field_selected` 省略时仅返回工作项 ID，单次最多选择 20 个字段；要读取名称、创建时间等内容必须显式选择。筛选条件最多 50 个。

### 响应命名差异

本接口结果数组叫 `datas`，不是其他查询接口常见的 `data`。Markdown 开关 `need_rich_text_mark_down` 位于请求体顶层，不放进 `expand`。下方对象表标题保留完整父路径，表格列出直接子字段。

**field_selected**

**field_selected查询参数说明**

- **字段选择机制**：支持按需查询，用户可自定义指定需返回的字段集合，该参数为非必选项。如未指定，系统默认仅返回工作项ID。
- **字段数量限制**：当前系统设定单次查询最多可返回20个字段。
- **字段格式规范**：具体字段格式定义及属性解析规则，请参阅[字段与属性解析格式](../formats/字段与属性解析格式.md)说明文档。

**search_after**

**search_after** 分页参数说明

该参数用于实现分页查询功能，具体逻辑如下：

- 指定初始查询起始值
- 每次执行查询后，系统将返回当前页的末位标识值
- 该末位标识值将作为后续查询的新起始值
- 通过循环上述过程实现连续分页操作

```json

  "project_key": "66542b5xxxxxxxxxxxxf15449",
  "work_item_type_key": "story",
  "search_group": {
    "conjunction": "AND",
    "search_params": [
      {
        "param_key": "created_at",

}
```
