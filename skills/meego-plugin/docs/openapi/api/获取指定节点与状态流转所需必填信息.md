# 获取指定节点/状态流转所需必填信息

<!-- capability-metadata:start -->
## 平台能力标记

<a id="capability-openapi.post.open-api-work-item-transition-required-info-get"></a>
- **获取指定节点/状态流转所需必填信息** ｜ `openapi.post.open-api-work-item-transition-required-info-get` ｜ 频次：低 ｜ 状态：待运行时验证

<!-- capability-metadata:end -->

查询一个工作项在指定节点或目标状态流转前必须完成的内容，包括表单项、节点字段、子任务和交付物。每次只能查询一个工作项的一个目标节点或状态。

## 如何指定查询目标

| 工作流类型 | `state_key` 应传入的值 | 查询用途 |
| --- | --- | --- |
| 节点流 | 节点 ID，也称 `node_key` 或 `state_key` | 检查该节点流转前的必填项 |
| 状态流 | 目标状态的 key | 检查进入该目标状态前的必填项 |

目标值从[获取工作流详情](获取工作流详情.md)读取。这里使用 `state_key`，而[状态流转](状态流转.md)实际执行接口使用 `transition_id`，两者不要混用。

默认返回全部必填项；传 `mode: "unfinished"` 时，只保留尚未完成的必填信息。插件需申请“权限管理 → 工作项实例”中的对应权限，见[权限管理](../guides/权限管理.md)。

<a id="请求说明"></a>

## 请求说明

**请求方式**：`POST`
**请求地址**：`/open_api/work_item/transition_required_info/get`

<a id="请求参数"></a>

## 请求参数

<a id="header"></a>

### 请求头

接口调用的 Header 配置详见 [Header](../guides/OpenAPI概述.md#a8e43b86)。

<a id="Body"></a>

### 请求体

| 参数 | 类型 | 是否必须 | 说明 |
| --- | --- | --- | --- |
| project_key | string | 必须 | 空间 ID（project_key），在飞书项目空间双击空间名称获取。 |
| work_item_type_key | string | 可选 | 工作项类型，可以通过[获取空间下工作项类型](获取空间下工作项类型.md)接口获取。 |
| work_item_id | int64 | 必须 | 工作项实例 ID，在工作项实例详情中，展开右上角 **··· \> ID** 获取。 |
| state_key | string | 必须 | 流转时的节点标识，其含义根据工作流类型不同而有所区别：<br>- 节点流：表示节点 ID（或称 `node_key`、`state_key`）；<br>- 状态流：表示状态流流转的目标状态 key；<br>可通过[获取工作流详情](获取工作流详情.md)查询具体值。 |
| mode | string | 可选 | 查询模式，默认查询所有必填项。支持的取值如下所示。<br>- `unfinished`：仅查询**必填项**中未完成的信息。 |

<a id="返回参数"></a>

## 返回参数

先检查顶层 `err_code`，再处理 `data` 内四类结果。`finished` 表示对应项是否完成；多人复合字段还会返回 `not_finished_owner`，用于识别仍需填写的人员。复合字段的 `sub_field` 可以继续嵌套。

| 结果集合 | 需要补全的对象 |
| --- | --- |
| `data.tasks` | 流转前必须完成的子任务 |
| `data.form_items` | 字段、角色或控件表单项 |
| `data.node_fields` | 节点字段及复合子字段 |
| `data.deliverables` | 必填交付物 |

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `data` | object | 返回结果，遵循[TransRequiredInfo](../formats/数据结构汇总.md#a13386bd)结构规范 |
| `err` | object | 部分错误透出更详细的错误描述，可协助日志记录和问题反馈 |
| `err_msg` | string | 错误信息 |
| `err_code` | int32 | 错误码 |

### `data`

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `tasks` | `list<object>` | 必填子任务，遵循[RequiredTask](../formats/数据结构汇总.md#7bd91a34)结构规范 |
| `form_items` | `list<object>` | 必填表单项，遵循[RequiredFormItem](../formats/数据结构汇总.md#f4011933)结构规范 |
| `node_fields` | `list<object>` | 必填节点字段，遵循[RequiredField](../formats/数据结构汇总.md#27ebd3bd)结构规范 |
| `deliverables` | `list<object>` | 必填交付物，遵循[RequiredDeliverable](../formats/数据结构汇总.md#12e714a5)结构规范 |

### `data.tasks`

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `task_id` | int64 | 子任务 ID |
| `finished` | boolean | 子任务是否已经完成 |

### `data.form_items`

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `class` | string | 表单项类型<br>- 字段 field<br>- 角色 role<br>- 控件 control |
| `key` | string | 表单项 key：字段使用 `field_key`，角色使用 `role_key`，控件使用控件 ID；节点信息控件为 `workflow_state_info`。 |
| `field_type_key` | string | 字段类型表单项的字段类型 |
| `finished` | boolean | 该节点表单项是否已填写 |
| `not_finished_owner` | `list<string>` | 未完成人员 key |
| `sub_field` | `list<object>` | 复合字段类型表单项的必填子字段，遵循[RequiredField](../formats/数据结构汇总.md#27ebd3bd)结构规范 |
| `state_info` | object | 节点信息控件表单项的节点信息，遵循[RequiredDeliverable](../formats/数据结构汇总.md#12e714a5)结构规范 |

### `data.form_items.sub_field`

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `field_key` | string | 节点字段 key |
| `field_type_key` | string | 节点字段类型 |
| `finished` | boolean | 节点信息控件的必填节点字段是否完成 |
| `not_finished_owner` | `list<string>` | 未完成人员 |
| `sub_field` | `list<object>` | 复合字段类型的必填子字段，遵循[RequiredField](../formats/数据结构汇总.md#27ebd3bd)结构规范 |

### `data.form_items.state_info`

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `state_key` | string | 节点 node_id |
| `node_fields` | `list<object>` | 节点信息控件的必填节点字段，遵循[RequiredField](../formats/数据结构汇总.md#27ebd3bd)结构规范 |

### `data.form_items.state_info.node_fields`

节点信息控件的 `field_key: "owner"` 表示负责人必填，`field_key: "schedule"` 表示排期必填；`finished` 表示该要求是否已满足。

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `field_key` | string | 节点字段 key |
| `field_type_key` | string | 节点字段类型 |
| `finished` | boolean | 节点信息控件的必填节点字段是否完成 |
| `sub_field` | `list<object>` | 节点信息控件的必填复合节点字段类型的必填子字段，遵循[RequiredField](../formats/数据结构汇总.md#27ebd3bd)结构规范 |

### `data.node_fields`

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `field_key` | string | 节点字段 key |
| `field_type_key` | string | 节点字段类型 |
| `finished` | boolean | 节点信息控件的必填节点字段是否完成 |
| `not_finished_owner` | `list<string>` | 未完成人员 |
| `sub_field` | `list<object>` | 节点多人复合字段类型的必填子字段，遵循[RequiredField](../formats/数据结构汇总.md#27ebd3bd)结构规范 |

### `data.deliverables`

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `finished` | boolean | 是否完成 |
| `deliverable_id` | int64 | 交付物 ID |

### `err`

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `code` | int32 | 部分场景下，透出更详细错误对应的错误码。 |
| `msg` | string | 部分场景下，透出更详细的错误描述。 |
| `log_id` | string | 报错场景下的调用链标识符，用于追踪错误发生时的完整调用链路，便于日志记录和问题排查。 |
