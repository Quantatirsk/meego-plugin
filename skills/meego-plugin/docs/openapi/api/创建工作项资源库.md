# 创建工作项资源库

<!-- capability-metadata:start -->
## 平台能力标记

<a id="capability-openapi.post.open-api-work-item-resource-create-work-item"></a>
- **创建工作项资源库** ｜ `openapi.post.open-api-work-item-resource-create-work-item` ｜ 频次：低 ｜ 状态：待运行时验证

<!-- capability-metadata:end -->

在指定空间和工作项类型下创建一个资源库实例。此接口创建的是库中的资源实例，不是启用资源库功能；工作项类型须事先在“高级信息配置”中开启资源库。授权说明参见[权限管理](../guides/权限管理.md)。

## 创建资源实例

最小请求包含 `project_key` 与 `work_item_type_key`。可选的 `template_id` 省略时使用该类型的第一个流程模板，字段值按[创建元数据](获取创建工作项元数据.md)和[字段格式](../formats/字段与属性解析格式.md)填写。

普通字段和 Markdown 富文本值二选一；单选字段的 `field_value.value` 使用选项 ID，不能传显示名称。成功响应从 `data.work_item_id` 取得资源实例 ID，后续可用于[通过资源创建实例](通过资源创建实例.md)。

## 请求说明

**请求方式**：`POST`

## 请求参数

<a id="header"></a>

### 请求头

接口调用的 Header 配置详见 [Header](../guides/OpenAPI概述.md#a8e43b86)。

<a id="Body"></a>

### 请求体

| 参数                 | 类型           | 是否必须 | 说明                                                                                                                                         |
| -------------------- | -------------- | -------- | -------------------------------------------------------------------------------------------------------------------------------------------- |
| `project_key`        | `string`       | 必须     | 飞书项目空间的唯一标识，在飞书项目空间双击空间名称即可获取。                                                                                 |
| `work_item_type_key` | `string`       | 必须     | 工作项类型，系统自动生成，可以从[获取空间下工作项类型](获取空间下工作项类型.md)接口获取。                                                                |
| `template_id`        | `int64`        | 可选     | 模板 ID，未传值时，会选取该工作项类型的第一个流程模版 [详细说明](#field-note-1)                                                              |
| `field_value_pairs`  | `list<object>` | 可选     | 遵循[FieldValuePair](../formats/数据结构汇总.md#10c42182)结构规范，创建工作项的具体字段可以从获取[获取创建工作项元数据](获取创建工作项元数据.md)接口中获取。 |

<a id="field-note-1"></a>

**template_id**

模板 ID，未传值时，会选取该工作项类型的第一个流程模版

可以从以下途径获取:

- [获取创建工作项元数据](获取创建工作项元数据.md)接口中的 `template` 字段的 `options` 中获取，选择对应的 `value`。
- [获取工作项下的流程模板列表](获取工作项下的流程模板列表.md)接口的 `template_id`。
- [获取字段信息](获取字段信息.md)接口中的 `template` 字段的 `options` 中获取，选择对应的 `value`。

#### `field_value_pairs`

| 参数                   | 类型     | 是否必须 | 说明                                                                                                                             |
| ---------------------- | -------- | -------- | -------------------------------------------------------------------------------------------------------------------------------- |
| `field_key`            | `string` | 必须     | 待更新的字段 ID，需与 `field_alias`二选一填写，不能同时为空。                                                                    |
| `field_alias`          | `string` | 可选     | 待更新字段的别名                                                                                                                 |
| `field_value`          | `object` | 必须     | 字段值，可参考[字段与属性解析格式](../formats/字段与属性解析格式.md)                                                                       |
| `update_mode`          | `int32`  | 可选     | 字段的更新模式，用于控制字段值的更新方式。支持的取值如下所示。 [详细说明](#field-note-2)                                         |
| `field_type_key`       | `string` | 可选     | 字段类型                                                                                                                         |
| `field_name`           | `string` | 可选     | 字段名称                                                                                                                         |
| `field_value_markdown` | `object` | 可选     | 富文本内容 Markdown 格式，遵循 [Markdown 格式说明](../formats/Markdown%20格式说明.md)结构规范，和`field_value` 二选一，仅富文本格式字段生效 |

<a id="field-note-2"></a>

**update_mode**

字段的更新模式，用于控制字段值的更新方式。支持的取值如下所示。

- `0`：替换模式，提交的字段值将完全替换原有值；
- `1`：更新模式，仅更新提交的字段值，不影响其他字段。

默认值：`0`（替换模式）

#### `field_value_pairs.field_value_markdown`

| 参数                | 类型           | 是否必须 | 说明                      |
| ------------------- | -------------- | -------- | ------------------------- |
| `markdown`          | `string`       | 可选     | 富文本内容 Markdown 格式  |
| `mention_user_keys` | `list<object>` | 可选     | 富文本中 @ 提到的人员信息 |

#### `field_value_pairs.field_value_markdown.mention_user_keys`

| 参数       | 类型     | 是否必须 | 说明                  |
| ---------- | -------- | -------- | --------------------- |
| `id`       | `string` | 可选     | 富文本中对应的人员 id |
| `user_key` | `string` | 可选     | 对应的人员的 user_key |

<a id="请求示例"></a>

## 请求示例

### 仅提供必填参数创建资源实例

仅传入两个必填参数示例。

```json
{
  "project_key": "681c29c58d0d3cfe1498xxxx",
  "work_item_type_key": "delivery"
}
```

### 指定模板和字段创建资源实例

传入所有参数示例。

```text
{
    "project_key": "673b40feb319263a44a6xxxx",
    "work_item_type_key": "delivery",
    "template_id": 8976234xxxx,
    "field_value_pairs": [
        {
            "field_key": "description",
            "field_value": "2333"
        },
        {
            "field_key":"priority",
            "field_value":{
                "value":"xxxxxx"
            }
        },
        {
            "field_key": "role_owners",
            "field_value":[
                {
                   "role":"rd",
                   "owners":["testuser"]
                }
            ]
        }
    ]
}
```

<a id="返回示例"></a>

## 返回示例

原文带 `xxxx` 或 `****` 的数字为脱敏占位符，完整字段请求及成功返回按结构示意阅读；实际类型保持 `int64`。

### 请求成功示例

以下保留原文的脱敏或结构占位内容，仅作示意。

```text
{
    "data": {
        "work_item_id": 87236****
    },
    "err": {},
    "err_msg": "",
    "err_code": 0
}
```

### 请求失败示例

以下错误原因为传入的字段 `priority` 是一个单选类型字段，但是传入的 `field_value_pairs` 结构不符合单选字段规范，字段规范参考[字段与属性解析格式](../formats/字段与属性解析格式.md)。

```json
{
  "err_code": 20006,
  "err_msg": "Invalid Param",
  "err": {
    "code": 20006,
    "msg": "field [priority] is illegal",
    "log_id": "202510302030302420D7314CAF22B1xxxx"
  }
}
```
