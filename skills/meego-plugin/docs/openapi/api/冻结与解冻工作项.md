# 冻结/解冻工作项

<!-- capability-metadata:start -->
## 平台能力标记

<a id="capability-openapi.put.open-api-work-item-freeze"></a>
- **冻结/解冻工作项** ｜ `openapi.put.open-api-work-item-freeze` ｜ 频次：低 ｜ 状态：待运行时验证

<!-- capability-metadata:end -->

冻结或解冻指定空间的一个工作项。请求体必须同时提供空间 ID、工作项 ID 和目标冻结状态，接口权限位于[权限管理](../guides/权限管理.md)的“工作项实例”分类。

## 冻结和解冻

两个方向使用同一个 `PUT /open_api/work_item/freeze`，仅改变 `is_frozen`：`true` 冻结，`false` 解冻。空间和实例标识位于请求体，本接口不要求另传工作项类型。

冻结与[终止/恢复](终止与恢复工作项.md)是不同操作。本篇没有说明冻结对各项编辑权限的完整影响，也没有定义重复冻结的返回规则，不能仅凭名称推导这些行为。

<a id="请求说明"></a>

## 请求说明

**请求方式**：`PUT`

**请求地址**：`/open_api/work_item/freeze`

<a id="请求参数"></a>

## 请求参数

<a id="header"></a>

### 请求头

接口调用的 Header 配置详见 [Header](../guides/OpenAPI概述.md#a8e43b86)。

<a id="Body"></a>

### 请求体

| 参数           | 类型      | 是否必须 | 说明                                                              |
| -------------- | --------- | -------- | ----------------------------------------------------------------- |
| `project_key`  | `string`  | 必须     | 空间 ID（project_key），在飞书项目空间双击空间名称获取。          |
| `work_item_id` | `int64`   | 必须     | 工作项实例 ID，在工作项实例详情中，展开右上角 **··· \> ID**获取。 |
| `is_frozen`    | `boolean` | 必须     | 选择执行冻结操作还是解冻操作： [详细说明](#field-note-1)          |

<a id="field-note-1"></a>

**is_frozen**

选择执行冻结操作还是解冻操作：

- `true`：冻结
- `false`：解冻

<a id="返回参数"></a>

## 返回参数

| 参数       | 类型     | 说明                                             |
| ---------- | -------- | ------------------------------------------------ |
| `err`      | `object` | 请求成功时返回空值，请求失败时返回实际错误信息。 |
| `err_msg`  | `string` | 请求成功时返回空值，请求失败时返回实际错误信息。 |
| `err_code` | `int32`  | 请求成功时0，请求失败返回实际错误码。            |

### `err`

| 参数     | 类型     | 说明                                                                                 |
| -------- | -------- | ------------------------------------------------------------------------------------ |
| `code`   | `int32`  | 部分场景下，透出更详细错误对应的错误码。                                             |
| `msg`    | `string` | 部分场景下，透出更详细的错误描述。                                                   |
| `log_id` | `string` | 报错场景下的调用链标识符，用于追踪错误发生时的完整调用链路，便于日志记录和问题排查。 |

