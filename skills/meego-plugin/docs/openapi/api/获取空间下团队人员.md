# 获取空间下团队人员

<!-- capability-metadata:start -->
## 平台能力标记

<a id="capability-openapi.get.open-api-project-key-teams-all"></a>
- **获取空间下团队人员** ｜ `openapi.get.open-api-project-key-teams-all` ｜ 频次：低 ｜ 状态：待运行时验证

<!-- capability-metadata:end -->

查询指定空间可见的团队及其人员、管理员列表。团队必须同时满足“允许在指定空间被搜索”和“可见空间包含本次请求空间”两项配置。团队配置参见[团队管理](https://project.feishu.cn/1ykiuvvj/3f1mczht2)，接口授权位于[权限管理](../guides/权限管理.md)的“用户”分类。

## 分页与人员字段

`offset` 在本接口中定义为从 `0` 开始的页码，不应套用数据库偏移量的含义。`limit` 最大为 `300`；省略分页参数只返回前 300 个团队，继续查询时检查 `has_more`。

`user_keys` 表示团队人员列表，`administrators` 表示管理员列表，`members` 表示成员列表。三者均返回用户标识，不包含用户详情；需要名称和头像时再调用[获取用户详情](获取用户详情.md)。

## 请求说明

**请求方式**：`GET`

**请求地址**：`/open_api/:project_key/teams/all`

<a id="请求参数"></a>

## 请求参数

<a id="header"></a>

### 请求头

接口调用的 Header 配置详见 [Header](../guides/OpenAPI概述.md#a8e43b86)。

<a id="Path"></a>

### 路径参数

| 参数          | 类型     | 是否必须 | 说明                                                                            |
| ------------- | -------- | -------- | ------------------------------------------------------------------------------- |
| `project_key` | `string` | 必须     | 空间 ID（project_key），或者空间域名（simple_name）。 [详细说明](#field-note-1) |

<a id="field-note-1"></a>

**project_key**

空间 ID（project_key），或者空间域名（simple_name）。

- 空间 ID（project_key），在飞书项目空间双击空间名称获取。
- 空间域名（simple_name），`simple_name` 一般在飞书项目空间 URL 中获取。例如空间 URL 为 “https://project.feishu.cn/doc/overview”，则 `simple_name` 为 “doc”。

<a id="Query"></a>

### 查询参数

| 参数     | 类型    | 是否必须 | 说明                                            |
| -------- | ------- | -------- | ----------------------------------------------- |
| `offset` | `int64` | 可选     | 页码 0-n                                        |
| `limit`  | `int64` | 可选     | 每页数量 max 300，不填写默认只拉取前 300 个团队 |

<a id="返回参数"></a>

## 返回参数

| 参数       | 类型           | 说明                                             |
| ---------- | -------------- | ------------------------------------------------ |
| `has_more` | `boolean`      | 是否还有团队                                     |
| `data`     | `list<object>` | 团队信息列表信息，                               |
| `err`      | `object`       | 请求成功时返回空值，请求失败时返回实际错误信息。 |
| `err_msg`  | `string`       | 请求成功时返回空值，请求失败时返回实际错误信息。 |
| `err_code` | `int32`        | 请求成功时返回0，请求失败返回实际错误码。        |

### `data`

| 参数             | 类型           | 说明                 |
| ---------------- | -------------- | -------------------- |
| `team_id`        | `int64`        | 团队 ID。            |
| `team_name`      | `string`       | 团队名称。           |
| `user_keys`      | `list<string>` | 团队下的人员列表。   |
| `administrators` | `list<string>` | 团队下的管理员列表。 |
| `members`        | `list<string>` | 团队成员             |

### `err`

| 参数     | 类型     | 说明                                                                                 |
| -------- | -------- | ------------------------------------------------------------------------------------ |
| `code`   | `int32`  | 部分场景下，透出更详细错误对应的错误码。                                             |
| `msg`    | `string` | 部分场景下，透出更详细的错误描述。                                                   |
| `log_id` | `string` | 报错场景下的调用链标识符，用于追踪错误发生时的完整调用链路，便于日志记录和问题排查。 |
