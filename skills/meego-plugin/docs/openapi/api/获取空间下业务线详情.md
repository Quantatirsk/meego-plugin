# 获取空间下业务线详情

<!-- capability-metadata:start -->
## 平台能力标记

<a id="capability-openapi.get.open-api-project-key-business-all"></a>
- **获取空间下业务线详情** ｜ `openapi.get.open-api-project-key-business-all` ｜ 频次：低 ｜ 状态：待运行时验证

<!-- capability-metadata:end -->

查询指定空间的业务线树及角色、关注者和管理员配置。返回对象包含业务线本身的属性和子业务线；列表为空时，表示该空间没有业务线信息。

## 使用前确认

`project_key` 可使用空间 ID 或空间域名；空间标识错误与业务线列表为空是两种不同结果。

对应的平台功能可参考[业务线配置](https://project.feishu.cn/1ykiuvvj/6ckdyisc)。对应的权限申请在**权限管理-配置**分类下，相关功能介绍详见 [权限管理](../guides/权限管理.md)。

<a id="请求说明"></a>

## 请求说明

- 请求方式：GET

- 请求地址：/open_api/:project_key/business/all

<a id="请求参数"></a>

## 请求参数

<a id="header"></a>

### Header

接口调用的 Header 配置详见 [Header](../guides/OpenAPI概述.md#a8e43b86)。

<a id="Path"></a>

### Path

| 参数 | 类型 | 是否必须 | 说明 |
| --- | --- | --- | --- |
| `project_key` | string | 必须 | [说明](#parameter-note-1) |

<a id="parameter-note-1"></a>

**project_key：说明**

空间 ID（project_key），或者空间域名（simple_name）。
- 空间 ID（project_key），在飞书项目空间双击空间名称获取。
- 空间域名（simple_name），`simple_name` 一般在飞书项目空间 URL 中获取。例如空间 URL 为 “https://project.feishu.cn/doc/overview”，则 `simple_name`为 “doc”。

<a id="返回参数"></a>

## 返回参数

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `data` | `list<object>` | 遵循[Business](../formats/数据结构汇总.md#6a7f1b55)结构规范。 |
| `err` | object | 请求成功时返回空值，请求失败时返回实际错误信息。 |
| `err_msg` | string | 请求成功时返回空值，请求失败时返回实际错误信息。 |
| `err_code` | int32 | 请求成功时0，请求失败返回实际错误码。 |

### `data` 的字段

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `id` | string | 业务线 ID |
| `name` | string | 业务线名称 |
| `order` | double | 顺序 |
| `labels` | `list<string>` | 业务线标签数组 |
| `parent` | string | 父级业务线 |
| `project` | string | 所属空间 |
| `children` | `list<object>` | 子业务线 |
| `disabled` | boolean | 标识业务线是否被禁用 |
| `level_id` | int64 | 业务线的层级 ID，最顶层为 `1`，子节点的层级 ID 等于父节点的层级 ID + `1`。 |
| `watchers` | `list<string>` | 默认的关注者数组 |
| `role_owners` | 待核实 | 业务线角色信息；原表与示例的容器类型不一致，确认实际响应前不据此实现反序列化。角色成员属性见下表。 |
| `super_masters` | `list<string>` | 业务线超级管理员 |

### `data.role_owners` 的字段

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `name` | string | 名称，作为请求参数非必填。 |
| `role` | string | 角色 ID |
| `owners` | `list<string>` | 负责人 user_key 数组 |

### `err` 的字段

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `code` | int32 | 部分场景下，透出更详细错误对应的错误码。 |
| `msg` | string | 部分场景下，透出更详细的错误描述。 |
| `log_id` | string | 报错场景下的调用链标识符，用于追踪错误发生时的完整调用链路，便于日志记录和问题排查。 |
