# 删除视图

<!-- capability-metadata:start -->
## 平台能力标记

<a id="capability-openapi.delete.open-api-project-key-fix-view-view-id"></a>
- **删除视图** ｜ `openapi.delete.open-api-project-key-fix-view-view-id` ｜ 频次：低 ｜ 状态：待运行时验证

<!-- capability-metadata:end -->

删除指定空间中的一个视图，支持固定视图、条件视图和全景视图。虽然路径包含 `fix_view`，本接口的删除范围并不限于固定视图。

## 使用前确认

空间与视图 ID 均放在 DELETE 路径中。可先查询视图列表确认目标 ID；`30004` 表示目标不存在。本篇没有请求体参数，也没有把重复删除定义为成功。

对应的平台功能介绍详见[删除视图](https://project.feishu.cn/1ykiuvvj/4w2iz8d8#%E5%88%A0%E9%99%A4%E8%A7%86%E5%9B%BE)。对应的权限申请在**权限管理-视图&度量**分类下，相关功能介绍详见 [权限管理](../guides/权限管理.md)。

<a id="请求说明"></a>

## 请求说明

- 请求方式：DELETE

- 请求地址：/open_api/:project_key/fix_view/:view_id

<a id="请求参数"></a>

## 请求参数

<a id="header"></a>

### Header

接口调用的 Header 配置详见[Header](../guides/OpenAPI概述.md#a8e43b86)。

<a id="Path"></a>

### Path

| 参数 | 类型 | 是否必须 | 说明 |
| --- | --- | --- | --- |
| `project_key` | string | 必须 | [说明](#parameter-note-1) |
| `view_id` | string | 必须 | 视图 ID，支持固定、条件以及全景视图。可以通过接口[获取某工作项的视图列表及配置信息](获取视图列表及配置信息.md)接口获取视图 ID。 |

<a id="parameter-note-1"></a>

**project_key：说明**

空间 ID（project_key），或者空间域名（simple_name）。
- 空间 ID（project_key），在飞书项目空间双击空间名称获取。
- 空间域名（simple_name），飞书项目空间 URL 中的空间标识，一般在创建空间时自定义。例如 URL 为`https://project.feishu.cn/simple_name` ，则 simple_name 为 `simple_name`。

## 返回参数
