# 查询计划表草稿行配置信息

<!-- capability-metadata:start -->
## 平台能力标记

<a id="capability-openapi.post.open-api-work-item-wbs-draft-task-conf-query"></a>
- **查询计划表草稿行配置信息** ｜ `openapi.post.open-api-work-item-wbs-draft-task-conf-query` ｜ 频次：低 ｜ 状态：待运行时验证

<!-- capability-metadata:end -->

读取指定草稿行允许拆解创建的子工作项类型。它返回创建配置，不返回已有子项实例，也不直接创建子工作项。

## 使用查询结果

从[查询全量计划表草稿骨架](查询全量计划表草稿骨架.md)取得 `uuid`，连同工作项和 `draft_id` 调用本接口。响应 `data.sub_work_instance_create_info.work_item_type_infos` 给出可创建类型的名称与 `work_item_type_key`，可用于[更新计划表草稿](更新计划表草稿.md)的 `AddSubInstanceRows` 操作。

原文将 `project_key` 描述为关联空间 ID，即使同空间关联也必须填写，以下保留此要求。权限见[权限管理](../guides/权限管理.md)中的“工作项”。

<a id="请求说明"></a>

## 请求说明

**请求方式**：`POST`
**请求地址**：`/open_api/work_item/wbs_draft/task_conf/query`

<a id="请求参数"></a>

## 请求参数

<a id="a3c53a27"></a>

### 请求头

接口调用的 Header 配置详见[Header](../guides/OpenAPI概述.md#a8e43b86)

<a id="Body"></a>

### 请求体

| 参数 | 类型 | 是否必须 | 说明 |
| --- | --- | --- | --- |
| project_key | string | 必须 | 关联空间的空间 ID。如果是同空间关联，仍需要填写该空间的 `project_key`。 |
| work_item_id | int64 | 必须 | 工作项Id |
| draft_id | string | 必须 | 草稿id |
| uuid | string | 必须 | 行uuid |

<a id="返回参数"></a>

## 返回参数

`work_item_type_infos` 是允许创建的类型列表，不能把每项理解为已经存在的工作项。示例中 `delivery` 是类型 key，“交付物”是显示名称。

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `sub_work_instance_create_info` | object | 当前行可拆解子工作项创建配置 |
| `err` | object | 对部分错误会在这里进行更详细的错误描述，可协助日志记录和问题反馈。 |
| `err_msg` | string | 错误信息。 |
| `err_code` | int32 | 错误码。 |

### `sub_work_instance_create_info`

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `work_item_type_infos` | `list<object>` | 可创建的子工作项类型列表 |

### `sub_work_instance_create_info.work_item_type_infos`

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `name` | string | 子工作项类型名称 |
| `work_item_type_key` | string | 子工作项类型 key |

### `err`

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `code` | int32 | 部分场景下，透出更详细错误对应的错误码。 |
| `msg` | string | 部分场景下，透出更详细的错误描述。 |
| `log_id` | string | 报错场景下的调用链标识符，用于追踪错误发生时的完整调用链路，便于日志记录和问题排查。 |
