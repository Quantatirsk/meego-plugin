# 更新工时登记记录

<!-- capability-metadata:start -->
## 平台能力标记

<a id="capability-openapi.put.open-api-project-key-work-item-work-item-type-key-work-item-id-work-hour-record"></a>
- **更新工时登记记录** ｜ `openapi.put.open-api-project-key-work-item-work-item-type-key-work-item-id-work-hour-record` ｜ 频次：低 ｜ 状态：待运行时验证

<!-- capability-metadata:end -->

更新指定工作项下已有工时记录的工时或工作描述。先通过[工时登记记录列表](获取工作项的工时登记记录列表.md)读取记录 ID，再提交 `working_hour_records`；接口授权位于[权限管理](../guides/权限管理.md)的“工作项实例”分类。

## 识别更新对象

路径标识工作项，列表中每项的 `id` 标识工时记录。`work_time` 和 `work_description` 可选，但 `id` 必填；本接口没有定义改工作日期或改关联节点的参数。

填写 `work_time` 时必须为正数，按请求参数和 `UpdateWorkingHourRecord` 定义使用数值字符串；非正数返回 `50006`。

<a id="注意事项"></a>

## 注意事项

1. 调用当前接口前，请先开启工时登记 API，有以下两种方式：
   - 通过[更新工作项基础信息配置](更新工作项基础信息配置.md)将 `actual_work_time_switch` 设置为 `true`。

   - 在飞书项目空间设置中安装[工时登记](https://project.feishu.cn/1ykiuvvj/3uh9k5d9)插件。

2. 以**工时登记**的方式使用”实际工时“后，对应节点或子任务上原有的历史”实际工时“会被清空。

<a id="请求说明"></a>

## 请求说明

**请求方式**：`PUT`

**请求地址**：`/open_api/:project_key/work_item/:work_item_type_key/:work_item_id/work_hour_record`

<a id="请求参数"></a>

## 请求参数

<a id="header"></a>

### 请求头

接口调用的 Header 配置详见 [Header](../guides/OpenAPI概述.md#a8e43b86)。

<a id="Path"></a>

### 路径参数

| 参数                 | 类型     | 是否必须 | 说明                                                                                                 |
| -------------------- | -------- | -------- | ---------------------------------------------------------------------------------------------------- |
| `project_key`        | `string` | 必须     | 空间 ID（project_key），在飞书项目空间双击空间名称获取。需要与 `work_item_id`对应实例匹配。          |
| `work_item_type_key` | `string` | 必须     | 工作项类型，可以通过[获取空间下工作项类型](获取空间下工作项类型.md)接口获取，需要与 `work_item_id`对应实例匹配。 |
| `work_item_id`       | `string` | 必须     | 工作项实例 ID，在工作项实例详情中，展开右上角 **··· \> ID** 获取。                                   |

<a id="Body"></a>

### 请求体

| 参数                   | 类型           | 是否必须 | 说明                                                                                                   |
| ---------------------- | -------------- | -------- | ------------------------------------------------------------------------------------------------------ |
| `working_hour_records` | `list<object>` | 必须     | 待更新的工时登记记录信息列表，遵循[UpdateWorkingHourRecord](../formats/数据结构汇总.md#c95befa8)结构规范。 |

#### `working_hour_records`

| 参数               | 类型     | 是否必须 | 说明                                                                       |
| ------------------ | -------- | -------- | -------------------------------------------------------------------------- |
| `id`               | `int64`  | 必须     | 工时登记记录 ID，通过[获取工作项的工时登记记录列表](获取工作项的工时登记记录列表.md)接口获取。 |
| `work_time`        | `string` | 可选     | 更新后的实际工时。                                                         |
| `work_description` | `string` | 可选     | 更新后的工作描述。                                                         |

| `log_id` | `string` | 报错场景下的调用链标识符，用于追踪错误发生时的完整调用链路，便于日志记录和问题排查。 |
