# 绑定空间关联的关联工作项实例

<!-- capability-metadata:start -->
## 平台能力标记

<a id="capability-openapi.post.open-api-project-key-relation-work-item-type-key-work-item-id-batch-bind"></a>
- **绑定空间关联的关联工作项实例** ｜ `openapi.post.open-api-project-key-relation-work-item-type-key-work-item-id-batch-bind` ｜ 频次：低 ｜ 状态：待运行时验证

<!-- capability-metadata:end -->

按照空间关联规则，把路径指定的当前工作项与 `instances` 中的工作项建立关联。请求允许为各个目标实例指定是否合并群聊。

## 准备绑定信息

1. 从[获取空间关联规则列表](获取空间关联规则列表.md)读取规则 ID，并核对规则适用的两端工作项类型。
2. 路径填写当前工作项；`instances[].work_item_id` 填写要关联的另一端工作项。
3. `chat_group_merge = 1` 表示合并群聊，`2` 表示不合并。原文未说明省略值时的默认行为。

重复绑定会返回 `1000051617`，不要把重复绑定失败当成创建新关联成功。产品操作见[跨空间关联控件配置](https://project.feishu.cn/1ykiuvvj/4g4laxgf#16c87d68)，权限见[权限管理](../guides/权限管理.md)中的“工作项实例”。

<a id="请求说明"></a>

## 请求说明

**请求方式**：`POST`
**请求地址**：`/open_api/:project_key/relation/:work_item_type_key/:work_item_id/batch_bind`

<a id="请求参数"></a>

## 请求参数

<a id="header"></a>

### 请求头

接口调用的 Header 配置详见 [Header](../guides/OpenAPI概述.md#a8e43b86)。

<a id="Path"></a>

### 路径参数

| 参数 | 类型 | 是否必须 | 说明 |
| --- | --- | --- | --- |
| project_key | string | 必须 | [填写说明](#parameter-notes-1) |
| work_item_type_key | string | 必须 | 工作项类型，系统自动生成，可通过[获取空间下工作项类型](获取空间下工作项类型.md)接口获取。 |
| work_item_id | string | 必须 | 工作项实例 ID，在工作项实例详情中，展开右上角 **··· \> ID**获取。 |

<a id="parameter-notes-1"></a>

**project_key 的填写说明**

空间 ID（project_key），或者空间域名（simple_name）。

- 空间 ID（project_key），在飞书项目空间双击空间名称获取。

- 空间域名（simple_name），`simple_name` 一般在飞书项目空间 URL 中获取。例如空间 URL 为 “https://project.feishu.cn/doc/overview”，则 `simple_name`为 “doc”。

<a id="Body"></a>

### 请求体

参数表将这些字段标为可选，但没有定义空请求行为或批量上限。实际绑定时应明确提供关联规则和目标实例；空请求是否有效待核实。

| 参数 | 类型 | 是否必须 | 说明 |
| --- | --- | --- | --- |
| relation_rule_id | string | 可选 | 空间关联关系规则 ID，用于标识特定的空间关联规则。可通过调用[获取空间关联规则列表](获取空间关联规则列表.md)接口获取该 ID。 |
| instances | `list<object>` | 可选 | 绑定工作项实例列表，遵循[RelationInstance](https://project.feishu.cn/b/helpcenter/1p8d7djs/1x1d372l#2eb833f0)结构规范。 |
| instances.work_item_id | int64 | 可选 | 关联工作项 ID。 |
| instances.chat_group_merge | int64 | 可选 | 是否合并群聊，支持的取值如下所示。<br>- `1`：合并群聊；<br>- `2`：不合并群聊。 |

<a id="请求示例"></a>

## 请求示例

示例中的数值型脱敏标识已用等长演示数字替代，调用时填写真实 ID；中文数据采用等义 Unicode 转义。

两个示例表达同类绑定结构，关联工作项 ID 均按 int64 数值填写。

**绑定关联关系**

**请求路径**：`POST /open_api/64f7f57d89aa3bb71bfdxxxx/relation/story/12584xxxx/batch_bind`

```json
{
  "relation_rule_id": "720286429011250xxxxx",
  "instances": [
    {
      "work_item_id": 3012280000,
      "chat_group_merge": 1
    }
  ]
}
```

**绑定关联规则及关联关系**

**请求路径**：`POST /open_api/64f7f57d89aa3bb71bfdxxxx/relation/story/12584xxxx/batch_bind`

```json
{
  "relation_rule_id": "rule_123456xxxx",
  "instances": [
    {
      "work_item_id": 3012280000,
      "chat_group_merge": 1
    }
  ]
}
```
