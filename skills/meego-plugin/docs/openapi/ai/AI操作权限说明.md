# AI 操作 Open API 权限说明

<!-- capability-metadata:start -->
## 平台能力标记

<a id="capability-ai.operation.permissions"></a>
- **AI 操作权限** ｜ `ai.operation.permissions` ｜ 频次：低 ｜ 状态：待运行时验证

<!-- capability-metadata:end -->

创建 AI 操作应用后，平台默认开启更新 AI 实体状态及部分业务接口权限。调用这些接口时，需要根据目标资源与当前 AI 操作的关系，判断是否额外传入 `X-AI-ENTITY-ID`。

本篇说明 **AI 操作应用** 的权限。AI 节点的规则不同，参见[AI 节点权限说明](AI节点权限说明.md)。

<a id="a04f3ec4"></a>

## 更新 AI 操作状态

| 接口 | 请求头要求 | 可执行操作 |
| --- | --- | --- |
| [更新 AI 操作的运行状态](更新AI操作运行状态.md) | 填写[通用请求头](../guides/OpenAPI概述.md#authentication) | 只能更新 AI 操作状态 |

具体可写状态及请求参数见接口文档。不要把这个权限理解为对所有业务数据的通用写权限。

下列四个接口只读取当前 AI 操作所在实例的信息时，使用通用请求头即可；读取其他实例时，必须增加 `X-AI-ENTITY-ID`。

| 接口 |
| --- |
| [获取工作项详情](../api/获取工作项详情.md) |
| [获取节点或状态流转所需必填信息](../api/获取指定节点与状态流转所需必填信息.md) |

| [获取创建工作项元数据](../api/获取创建工作项元数据.md) |

### 下载附件的额外要求

[下载附件](../api/下载附件.md)必须额外传入 `X-AI-ENTITY-ID`。原文没有为“当前 AI 操作所在实例”给出省略该请求头的例外。

## 修改实例数据

### 按目标实例决定是否传 AI 实体标识

下列接口只变更当前 AI 操作所在实例的数据时，使用通用请求头即可；其他情况增加 `X-AI-ENTITY-ID`。

| 接口 |
| --- |
| [更新工作项](../api/更新工作项.md) |
| [删除附件](../api/删除附件.md) |
| [上传文件或富文本图片](../api/上传文件或富文本图片.md) |

[创建工作项](../api/创建工作项.md)的 AI 实体 Header 适用条件待核实，接入前需确认，不提供省略该 Header 的请求示例。

### 拉机器人入群的额外要求

[拉机器人入群](../api/拉机器人入群.md)必须额外传入 `X-AI-ENTITY-ID`，不能套用上一组接口的条件省略规则。

## 与 AI 节点权限的差异

两份文档对同名业务接口可能规定不同的请求头条件。例如：

| 接口 | AI 操作 | AI 节点 |
| --- | --- | --- |
| 获取创建工作项元数据 | 原文按当前实例或其他实例区分 | 必须增加 `X-AI-ENTITY-ID` |
| 下载附件 | 必须增加 `X-AI-ENTITY-ID` | 原文按当前实例或其他实例区分 |
| 上传文件或富文本图片 | 原文按当前实例或其他实例区分 | 必须增加 `X-AI-ENTITY-ID` |

上表来自两份官方权限文档的对照，接入时先确定应用类型，避免直接复制另一类 AI 应用的请求头。
