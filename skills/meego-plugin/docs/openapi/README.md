# 飞书项目 OpenAPI 文档

自建服务端调用飞书项目接口时，先确定目标接口与调用身份，再按该页面的完整请求、响应和错误处理实现。平台 token、用户 token 和 refresh token 都不能下发到浏览器。

## 优先入口

| 需求 | 入口 |
| --- | --- |
| 获取插件或用户访问凭证 | [获取访问凭证](guides/获取访问凭证.md) |
| 配置开发数据范围、权限、正式安装与空间授权 | [权限管理](guides/权限管理.md) |
| 理解通用 Header、鉴权模式、限流和错误处理 | [Open API 概述](guides/OpenAPI概述.md) |
| 快速定位精确 HTTP 方法与路径 | [HTTP 接口速查](ENDPOINTS.md) |
| 按资源领域浏览全部接口 | [完整文档目录](INDEX.md) |
| 事件验签、拦截和监听 | [事件与回调](events/) |

## 范围

| 目录 | 内容 |
| --- | --- |
| `guides/` | 概述、权限、凭证、鉴权模式、SDK 和 Postman。 |
| `formats/` | 数据结构、字段格式、Markdown、搜索参数、MQL 和错误码。 |
| `api/` | 用户、空间、工作项、计划表、文件、配置、评论、视图、度量和租户接口。 |
| `events/` | 拦截、监听、精细化配置、插件装卸和验签。 |
| `ai/` | AI 节点、AI 字段、AI 操作的接口、权限、事件和动态选项。 |
| `support/` | 限流公告、凭证 FAQ、调用 FAQ 和错误排查。 |

每篇接口页按一个平台主题整理，保留用途、限制、参数、完整请求与响应示例、错误处理和关联接口。不要把某个接口的 Header、字段 key 或响应包装套到其他接口。
