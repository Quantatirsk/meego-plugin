# 创建插件

在飞书项目开放平台创建插件后，先完善基本信息、配置协作人，再[添加插件功能](<添加插件功能.md>)。新建插件初始状态为**待上线**；创建成功不代表已经发布或安装到空间。

<a id="0e3b3561"></a>

## 创建入口

1. 访问飞书项目开放平台，在“我的插件”区域点击“添加插件”。
2. 在对话框中填写名称、选择图标，点击“确定”。
3. 回到“我的插件”查看新插件及其“待上线”状态。

<a id="2b5544b4"></a>

## 基本信息页面

| 区域 | 用途 |
| --- | --- |
| 插件凭证 | 查看 Plugin ID 和 Plugin Secret，供工程初始化与开发使用 |
| 基本信息 | 配置语言、图标、名称、描述、详情、封面等信息 |
| 协作人 | 添加开发协作者、转交负责人或移除协作者 |
| 删除插件 | 仅插件负责人可操作 |

Plugin ID 是插件标识，Plugin Secret 是插件密钥；二者不同于调用 OpenAPI 时获取的 `plugin_access_token` 或 `user_access_token`。凭证交换规则见[获取访问凭证](<../../openapi/guides/获取访问凭证.md>)。原文要求不要泄露插件凭据。

<a id="1f36bc2a"></a>

## 完善展示信息

| 字段 | 要求与用途 |
| --- | --- |
| 国际化配置 | 可多选中文、英文、日文；启用其他语言后需补齐对应语言的基本信息 |
| 插件图标 | SVG、PNG、JPEG；大小不超过 2 MB，清晰度不低于 240 × 240 px |
| 插件名称 | 描述插件名称 |
| 插件短描述 | 描述功能与使用场景，不超过 100 字 |
| 插件分类 | 最多 3 个；现有分类不合适时可点击“申请分类” |
| 插件详情 | 展开说明功能、使用场景和使用指导，超过 50 字 |
| 封面图 | 企业插件可选，市场插件必填；上传 1–5 张，比例 2:1，至少 1600 × 800 px，大小不超过 10 MB |
| 帮助文档 | 填写指导用户使用插件的文档链接 |

封面图展示在插件详情卡片中。国际化配置与企业/市场发布范围是不同配置，发布条件见[发布插件](<发布插件.md>)。

<a id="f6699af3"></a>

## 管理协作人

在“协作人”区域按姓名或邮箱搜索并添加企业成员。已添加成员可执行以下操作：

| 操作 | 结果 |
| --- | --- |
| 升级负责人 | 该协作人成为插件负责人，原负责人降为协作人 |
| 移除协作人 | 该成员不再参与当前插件的协作开发 |

原文未给出负责人和协作人的完整操作权限矩阵；本篇仅确认删除插件限负责人，以及上述转交结果。

<a id="beb918f3"></a>

## 删除插件

如果插件仍被空间安装使用，先联系对应空间管理员，在各自空间删除该插件。安装分布可结合[安装统计](<安装统计.md>)查看。

完成空间侧处理后，插件负责人在“基本信息”页面底部点击“删除插件”，在确认框中确认。

原文没有说明删除后的恢复能力或关联数据保留期限，不能把删除视为临时下线或可随时恢复的操作。
