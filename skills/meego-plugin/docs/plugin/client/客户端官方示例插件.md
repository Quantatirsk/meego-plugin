# 客户端官方示例插件

官方示例插件用于在真实飞书项目点位中体验客户端 API 与组件，查看示例代码、运行日志和文档。不同点位提供的上下文和能力不同，应在目标点位中验证，不能将 Page 中的结果直接视为所有点位的行为。

<a id="d36958d4"></a>

## 安装与进入

访问[客户端官方示例插件安装页](https://project.feishu.cn/openapp/plugin_share?appKey=MII_67FE4C1D95C54004)，点击“安装插件”，按页面提示完成安装。

安装后，从目标空间的对应点位进入。表单控件、节点表单控件和节点流转按钮需要额外配置，见下方[点位入口](#5e5f5761)。本文整理不执行安装或修改空间配置。

<a id="1104cc15"></a>

## 两种体验模式

| 模式 | 用途 | 可查看内容 |
| --- | --- | --- |
| 客户端 API | 在当前点位触发某个 API 并观察结果 | 示例代码、运行日志、API 文档 |
| 客户端组件 | 体验组件交互及展示效果 | 组件示例代码、组件文档 |

官方定义见[客户端 API 简介](<../jssdk/客户端 API 概述.md>)与[客户端组件库接入](<../components/客户端组件库接入.md>)。下面的界面说明以内嵌页面 Page 为例。

<a id="95899c2c"></a>

### API 调试界面

| 功能 | 操作 |
| --- | --- |
| 模式切换 | 切换“客户端 API”与“客户端组件”模式 |
| API 搜索 | 搜索 API 名称 |
| API 调用 | 触发目标 API，观察它在当前 Page 点位的运行结果 |
| 示例代码 | 查看示例代码，点击右上角复制按钮获取代码 |
| 运行日志 | 查看本次调试的日志 |
| API 文档 | 查看目标 API 文档 |

<a id="1c44853b"></a>

### 组件调试界面

| 功能 | 操作 |
| --- | --- |
| 模式切换 | 切换“客户端 API”与“客户端组件”模式 |
| 组件搜索 | 搜索组件名称 |
| 交互与代码 | 体验组件交互、查看代码；展开或收起代码区域，或复制代码 |
| 组件文档 | 查看组件文档 |

将组件示例接入自己的工程时，还需遵循[共享模块初始化顺序](<../jssdk/shared.md>)。示例插件已经提供的运行环境，不会随复制单段组件代码自动带入自己的插件。

## 点位入口

| 点位 | 安装后的入口或额外配置 |
| --- | --- |
| 内嵌页面 / Page | 从内嵌页面体验入口进入 |
| 详情页 / Tab | 从实例详情页的插件页签进入 |
| 视图页 / View | 从视图页的插件入口进入 |
| 表单页 / Control | 先在工作项页面布局中添加插件 |
| 节点表单页 / Control | 先在流程管理的节点表单中添加插件，保存并发布 |
| 新建 / Button | 从新建按钮区域的体验入口进入 |
| 实例更多按钮 / Button | 从实例更多操作进入 |
| 节点更多按钮 / Button | 从节点更多操作进入 |
| 节点流转按钮 / Button | 先在流程管理的节点流转页签中新增插件按钮并保存 |
| 插件配置 | 从插件配置入口进入 |

### 表单页 / Control

1. 在工作项“页面布局”中加入示例插件。
2. 打开工作项实例详情页，体验对应控件。

### 节点表单页 / Control

1. 在工作项“流程管理”中，为目标节点表单添加示例插件。
2. 保存并发布流程配置。
3. 到工作项对应的节点表单中体验控件。

### 节点流转按钮 / Button

1. 在工作项“流程管理”的“节点流转”页签新增插件按钮并保存。
2. 在节点流转的更多操作中找到对应入口。

## 接入自己的插件

体验目标能力后，回到对应 API 或组件文档核对参数、当前端版本和点位限制，再按[开发调试客户端](<开发调试客户端.md>)接入自己的工程。官方示例插件是运行效果参考，不能替代自己插件的资源配置、权限和上下文验证。

原文未给出本示例插件逐点位的网页/移动端支持矩阵，也未标注示例代码的版本与 SDK 版本对应关系。应结合当前安装版本和所用能力文档确认，不能仅凭示例插件推导移动端兼容性。
