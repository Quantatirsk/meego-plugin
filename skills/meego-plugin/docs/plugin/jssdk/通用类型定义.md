# 通用类型定义

本页整理客户端 JSSDK 共用的枚举、对象及新建表单预设结构。字段名和枚举值保留协议大小写；调用入口见[客户端 API 简介](<客户端 API 概述.md>)，平台上下文见 [Context](<Context.md>)。

**阅读导航**：[属性与流程](#eda57c9d) · [字段类型](#597e7001) · [字段值](#ebc3167f) · [节点状态](#119659f4) · [拦截事件](#8717ee48) · [对象类型](#2a3fce2e) · [新建表单预设](#afc5bc76)

这里的客户端字段值不能直接当作服务端 OpenAPI 的请求体。例如客户端单选值为字符串，而服务端字段值有自己的对象结构。两套接口的字段格式应分别查阅；服务端定义见[字段与属性解析格式](<../../openapi/formats/字段与属性解析格式.md>)。

## 枚举

| 成员 | 值 | 含义 |

### FieldType：字段类型

左列是枚举成员，例如 `FieldType.text`；中列是对应协议字符串，例如 `"text"`。不要将成员名改成未经定义的全大写形式。

| 成员 | 值 | 字段 |
| --- | --- | --- |
| `attachment` | `"multi_file"` | 附件 |
| `bool` | `"bool"` | 开关 |
| `compoundField` | `"compound_field"` | 复合字段 |
| `date` | `"date"` | 日期、日期与时间 |
| `dateRange` | `"schedule"` | 日期区间 |
| `link` | `"link"` | 超链接 |
| `select` | `"select"` | 单项选择 |
| `multiSelect` | `"multi_select"` | 多项选择 |
| `multiUser` | `"multi_user"` | 多选人员 |
| `multiVoting` | `"vote_option_multi"` | 多选投票 |
| `number` | `"number"` | 数字 |
| `radio` | `"radio"` | 单选按钮 |
| `richText` | `"multi_text"` | 富文本 |
| `simpleVoting` | `"vote_boolean"` | 表态投票 |
| `singleVoting` | `"vote_option"` | 单选投票 |
| `singleSignal` | `"signal"` | 系统外信号 |
| `multiSignal` | `"multi_signal"` | 多值系统外信号 |
| `text` | `"text"` | 文本 |
| `treeMultiSelect` | `"tree_multi_select"` | 级联多选 |
| `treeSelect` | `"tree_select"` | 级联单选 |
| `user` | `"user"` | 单选人员 |
| `workItemRelatedMultiSelect` | `"work_item_related_multi_select"` | 多选关联工作项 |
| `workItemRelatedSelect` | `"work_item_related_select"` | 单选关联工作项 |
| `unknown` | `"unknown"` | 未知字段类型 |

本表保留官方页面列出的全部成员。本套资料采用的官方 SDK `2.1.8` 还声明 `FieldType.control = "control"`，用于角色与人员等平台控件；该成员也出现在官方 [Control API](<Control.md>) 的表单监听参数中。具体方法能接受哪些类型，仍以该方法的限制为准。

| `multi_user` | 多选人员 | `string[]` |
| `link` | 超链接 | `string` |

## WorkItemCreateFormPreset：新建表单预设

用于客户端打开新建工作项表单时预填值，例如 [navigation.openWorkItemCreatePage](<navigation.md>)。预设表单值不等于直接调用服务端接口创建实例。

| 属性 | 必填性 | 结构 |
| --- | --- | --- |
| `attribute` | 可选 | [属性预设](#table-content-1)，当前仅支持名称 |
| `field` | 可选 | [字段预设](#table-content-2)，仅支持规定的字段类型 |

<a id="table-content-1"></a>

### attribute：属性预设

以 `AttributeType.name`（协议值 `name`）为键，对应对象包含字符串 `attributeValue`。官方 SDK 的类型声明允许更宽的属性索引，但其注释及本页参数定义都限定当前仅支持名称，因此不提供模板属性预填示例。

| 路径 | 类型 | 含义 |
| --- | --- | --- |
| `attribute.name.attributeValue` | `string` | 预填的工作项名称 |

<a id="table-content-2"></a>

### field：字段预设

以实际字段 ID 为键，每项包含以下两个属性。

| 属性 | 类型 | 含义 |
| --- | --- | --- |
| `fieldType` | `FieldType` 的受限子集 | 必须与目标字段类型一致，排除项见下表 |
| `fieldValue` | 随字段类型确定 | 按本页 [FieldValue](#ebc3167f) 及目标字段定义填写；原参数不限定统一的具体值类型 |

`fieldType` 排除以下全部成员：

| 排除成员 | 不支持预设的字段 |
| --- | --- |
| `FieldType.simpleVoting` | 表态投票 |
| `FieldType.singleVoting` | 单选投票 |
| `FieldType.multiVoting` | 多选投票 |
| `FieldType.attachment` | 附件 |
| `FieldType.singleSignal` | 系统外信号 |
| `FieldType.multiSignal` | 多值系统外信号 |
| `FieldType.compoundField` | 复合字段 |
| `FieldType.unknown` | 未知字段类型 |

### 名称与数字字段示例

以下是本地补充的类型化预设对象。`field_example_number` 需替换为真实数字字段 ID；实际使用时将该对象传给导航接口的 `formPreset`。

```typescript
import { AttributeType, FieldType } from '@lark-project/js-sdk';
import type { WorkItemCreateFormPreset } from '@lark-project/js-sdk';

const formPreset: WorkItemCreateFormPreset = {
  attribute: {
    [AttributeType.name]: { attributeValue: 'Example work item' },
  },
  field: {
    field_example_number: {
      fieldType: FieldType.number,
      fieldValue: 1,
    },
  },
};
```
