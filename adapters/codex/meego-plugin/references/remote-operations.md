# 远端操作

在执行任何会访问或变更插件平台的命令前，立即使用本参考。

## 命令边界

`meego` 解析本地知识，不操作远端平台。插件生命周期和平台托管配置操作均使用 `lpm --cwd <plugin-root> ...`，包括检查、创建项目、配置、权限管理、上传产物和发布。

不得用直接 HTTP 请求、SDK 调用、浏览器自动化或手动写入 CLI 托管的平台配置替代 `lpm`。使用 `lpm --help` 获取已安装命令的准确语法，不要假定旧工具的 flag 仍然可用。

插件自身服务端按已解析的 OpenAPI 契约调用业务接口，属于运行时代码，不是生命周期或托管配置操作。agent 不得为验证文档示例自行执行真实请求；只有用户明确要求的远端操作才能使用实际凭证执行。

## 先读取，再写入

变更任何配置时：

1. 确定插件根目录，并用 `lpm` 获取完整远端基线；
2. 基于该基线构建完整草案，而不是局部 patch；
3. 检查 CLI diff，识别新增、修改和删除；
4. 展示具体变更并等待所需确认；
5. 执行获批的 `lpm` 操作并报告结果。

若 CLI 阻止删除或要求仅限用户的授权步骤，停止操作并展示 CLI 输出。不得绕过保护、创建长期授权，或运行保留给用户的命令。

## 确认边界

以下操作执行前必须立即获得明确确认：

| 操作 | 先展示的内容 |
| --- | --- |
| 创建插件 | 目标站点、插件类型和产生的远端记录 |
| 推送配置 | 完整 diff，包括每个删除项 |
| 应用权限 | 准确 scope 列表及每项 scope 所需的能力 |
| 更新元数据 | 字段和新值 |
| 发布 | 版本或发布目标、可见性和受影响受众 |

上传产物与发布是不同操作。它可以为发布做准备，但不得被解释为获准发布。

## 证据与秘密信息

只请求已解析资料和用户批准的实现所支持的权限、配置值或服务端行为。绝不打印、持久化或复制 access token、secret 或含凭据的命令输出。若远端操作需要用户尚未提供的业务值，停止并索取该值，不得自行选择。
